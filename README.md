# AI 日报

每天自动生成、自动发布的 AI 领域日报,收录搜索/推荐/广告方向论文与 AI 产业动态。

## 内容

### 搜广推论文报告

搜索、推荐、广告方向论文的每日筛选与精读,覆盖召回、粗排、精排、生成式召回、跨阶段、多模态等 15 个方向。每条包含论文机构与场景、核心方法、关键结果、收益归因、与业务的关联、风险与局限。周一至周六每日更新,周日合并为周报。

### 每日重点简报

面向判断与实验的决策简报,包含:

- 今日最重要的 3 件事
- 昨日搜广推论文重点引用
- AI 模型 / Agent / Coding
- 关键人物观点 / 播客
- 公司 / 市场 / Quant
- 趋势与反共识信号；周日附过去 7 天核心判断变化

## 使用

- 顶部切换「每日重点简报 / 搜广推论文报告」
- 左侧为本页目录,右侧为历史归档
- 点击归档项查看往期报告

## 如何生成

每天北京时间约 06:17 生成重点简报、17:47 生成论文报告。流水线自动完成:采集 arXiv、官方发布、行业 RSS、GitHub Trending 等来源 → 去重 → 大模型结构化抽取 → 程序规则校验(领域准入、优先级上限、跨天去重)→ 渲染 Markdown → 发布本静态站点。
