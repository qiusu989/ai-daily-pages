生成式召回

P1｜Difficulty-Aware Semantic-ID Optimization for Generative Recommendation

论文、机构与场景

  • 机构：未披露

  • 作者：未单列

  • 来源：未单列

  • 场景：语义ID生成式推荐，在 Amazon 两个品类和内部工业推荐任务上验证

  • 论文主要内容： 未披露

  • 原始身份说明：Meta 与宾州州立大学研究者提出 DASO 方法，面向语义ID生成式推荐，在 Amazon 两个品类和内部工业推荐任务上验证。

主要创新或优化点

  • 该工作解决语义ID生成式推荐中 GRPO 在目标缺失提示上奖励退化问题，将难度感知 rollot 分配引入树结构生成，并在工业规模数据验证，为生成式推荐 RL 训练提供新思路。

核心方法

  • DASO 为树感知 GRPO 后训练方法：对每组 rollout 建前缀深度画像，定位目标 SID 路径瓶颈层级，将有限引导预算分配到瓶颈深度，保留原始 rollout 作对比，并用 SID-prefix 奖励与 SFT 锚定提升信号。
  • 在 Qwen2.5-1.5B/3B 上，DASO 在 12 个 Amazon 指标中 11 个优于 MiniOneRec 风格 GRPO，9 个最佳；内部四层 SID 任务 Top-20 lv0 召回从 47.21% 升至 54.23%。
  • 代码公开于 github.com/LucasXinYu/DASO。

关键结果

  • Amazon 两个数据集+两个 Qwen 骨干：11/12 指标超过 MiniOneRec 风格 GRPO，9/12 最优。
  • 内部四层 SID 任务：Top-20 lv0 召回 47.21%→54.23%，lv3 召回 4.23%→4.67%，Top-1 各层均改善。
  • 消融：在线画像、SID-prefix 奖励、SFT 锚定均贡献增益；Bmax=9 为最优预算。

收益归因

  • 主要：收益主要来自训练方法改进，即前缀深度画像与瓶颈导向 rollot 重分配，而非模型架构变化。
  • 次要：GRPO 后训练稳定性
  • 次要：工业生成式推荐部署参考
  • 次要：代码开源可复现

与你的关联

  • 与生成式推荐、语义ID、GRPO 后训练方向直接相关；对工业级生成式推荐训练有借鉴价值。

风险或局限

  • 报告为单次运行，无多种子显著性检验。
  • 内部数据集专有，仅提供聚合统计，无法复现；公共 Amazon 数据集较小。
  • Easy 提示上 DASO 有时低于 SFT-only，存在回归权衡。

P1｜From a Static Multi-Level Small Semantic Codebook to a Dynamic Single-Level Large Semantic Codebook for Generative Recommendation

论文、机构与场景

  • 机构：未披露

  • 作者：未单列

  • 来源：arXiv:2608.21012

  • 场景：短视频消费场景的生成式推荐，提出以单级大语义码本替代多级残差码本的 SID 设计方案

  • 论文主要内容： 未披露

  • 原始身份说明：arXiv 2608.21012 来自快手科技团队，面向短视频消费场景的生成式推荐，提出以单级大语义码本替代多级残差码本的 SID 设计方案。

主要创新或优化点

  • 首次针对工业三级SID的条件稀疏问题，提出单级大码本加固定消歧码的两级SID，并用曝光感知动态更新应对码本漂移，附带工业A/B与解码效率量化，对生成式召回落地有实践价值。

核心方法

  • 基于约15亿工业样本分析发现三级SID中二级语义码全局利用率93.31%，但每个一级码下平均仅使用2.48%词表，形成条件稀疏；新结构改为一个语义码加一个固定消歧码，解码从三步降为两步。
  • 提出曝光感知动态码本更新：时域衰减曝光权重、EMA中心更新和曝光加权换码惩罚，并构建覆盖重建质量、码利用率、簇负载、全SID碰撞和时间稳定性的离线评测框架。
  • 公开数据上两级SID使OneRec-V1/V2平均Recall@10提升5.0%-8.8%/7.1%-8.7%，NDCG@10提升4.1%-5.1%/3.8%-8.5%；5天线上A/B（2.5%流量）消费主指标+0.792%。

关键结果

  • 两级SID在Amazon Beauty与KuaiRec上较三级SID：OneRec-V1平均Recall@10提升5.0%-8.8%、NDCG@10提升4.1%-5.1%；OneRec-V2对应7.1%-8.7%和3.8%-8.5%。
  • 动态更新在固定日期KuaiRec评测中额外提升OneRec-V1/V2 Recall@10 1.4%/2.7%、NDCG@10 7.0%/2.7%；工业码本评测动态PV-S2重建相似度相对静态+1.50%。
  • 缩短SID使decoder/LazyAR/MTP三种服务架构自回归解码FLOPs降低47.93%-48.70%，单卡QPS提升28.57%-47.0%。

收益归因

  • 主要：缩短自回归解码步数带来的推理开销下降，以及曝光感知动态码本带来的推荐质量提升（作者工业A/B证实消费指标+0.792%）。
  • 次要：单级大码本降低解码步骤和搜索空间，便于部署。
  • 次要：离线码本评测框架可在完整重训前快速筛选码本候选。
  • 次要：动态更新机制可迁移到其他物料ID/索引系统。

与你的关联

  • 对生成式召回、语义ID码本、物料索引更新和推理成本优化团队直接相关；两级SID结构、曝光加权动态更新和离线码本评测框架均可迁移至短视频、电商、广告场景。

风险或局限

  • 动态更新仅在KuaiRec单一数据集的固定日期评测上验证，且部分模型/尺度无增益或下降，仅报告均值。
  • 线上A/B仅2.5%流量、5天，主消费指标含义与显著性未披露。
  • FLOPs/QPS为估算或单卡测试，未给端到端延迟；TIGER在Amazon上两级反而不如三级，收益与模型相关。

  • 所有样本级分数离线计算，骨干模型不改变，推理时无需知识图谱访问。

关键结果

  • 在标准序列推荐器和多个行为去噪序列推荐器上取得增益，具体指标未披露。
  • 提出的校准知识图谱证据方法在实验中得到验证。
  • 实验覆盖多个去噪基线，但无在线或工业 A/B 数据。

收益归因

  • 主要：未核实
  • 次要：序列建模
  • 次要：去噪
  • 次要：知识图谱

与你的关联

  • 与推荐系统去噪任务相关，可指导提升序列建模的鲁棒性。

风险或局限

  • 具体数据集和性能提升幅度未在摘要中提供。
  • 未提供在线或工业部署验证。
  • 依赖固定知识图谱，可能不适用于无图谱场景。

模型结构与特征交互

P1｜One Hierarchy, Two Systems: Semantic Product IDs for Discovery-Surface Ranking and Search-Page Query Reformulation

论文、机构与场景

  • 机构：未披露

  • 作者：未单列

  • 来源：arXiv:2608.20640v1

  • 场景：DoorDash 多商家电商的 discovery carousel 个性化排序与搜索页查询改写

  • 论文主要内容： 未披露

  • 原始身份说明：arXiv 2608.20640v1（USRW '26 workshop）为 DoorDash 团队提出的 Semantic Product ID（SID）共享层级论文，场景是 DoorDash 多商家电商的 discovery carousel 个性化排序与搜索页查询改写。

主要创新或优化点

  • 单一语义产品层级同时服务精排特征与搜索查询改写，且带生产环境在线 A/B；把 SID 从生成式检索拓展为跨应用可复用表示，是工业搜广推中可复用语义层的典型案例。

核心方法

  • 排序侧在既有 CTR/ATCR/CVR 多任务精排模型中新增 SID 特征：L1/L2/L3 前缀上的稠密行为聚合，以及 SentencePiece(SPM) token 的候选与消费历史共享嵌入序列特征。
  • SID 由 gemini-embedding-001 文本编码（3072 维）经 3 级残差量化 K-means（每级 512 个质心）生成，形成 L1/L2/L3 前缀层级。
  • 搜索侧将查询按 ATC 证据映射到 SID 概念，构建 L2 横向转移图与 L3 下钻，最后经 LLM 渲染查询文案并按商家在售选品过滤；排序与搜索不共享模型参数或服务架构。

关键结果

  • 排序离线相对生产基线：FC-A（去 SID 特征）MRR@5 +2.10%、NDCG@5 +2.92%，FC（含 SID）MRR@5 +6.98%、NDCG@5 +6.76%；在线 21 天：subtotal +0.31%，ATC rate 位置1/2/3 分别 +8%/+16%/+6%，首屏首位商品历史热度 -18.1%。
  • 搜索在线：SID 查询改写模块相对无改写控制，Purchase MRR +0.558%（95%CI +0.294~+0.823%），ATC 位置 -1.571%，滚动深度 -1.866%，均显著。
  • 离线：专家分类法使 18.8% 意图改变转移坍缩为自环，SID 仅 10.9%；rank-one 建议质量（LLM judge 0/0.5/1）从 0.522 提升到 0.734。

收益归因

  • 主要：SID 派生特征（前缀聚合与 SPM token 共享嵌入）是排序收益的主要来源，查询改写的收益来自 SID 概念转移图；线上排序增益为 bundle 观测，SID 单独归因未隔离。
  • 次要：跨商家行为聚合与偏好迁移
  • 次要：查询改写降低搜索成本
  • 次要：同一语义表示避免两套内容模型重复建设

与你的关联

  • 对精排特征工程可直接复用 SID 前缀聚合与 SPM token 共享嵌入；多商家电商可用同一层级做跨商家偏好迁移与查询改写，降低表示建设成本。

风险或局限

  • 排序在线实验为 SID 与非 SID 更新的 feature bundle，未单独隔离 SID 归因，正文以离线消融和事后分析推断。
  • 语义压缩有量化边界与宽前缀混意图风险，可能丢失对个别消费者重要的属性，需要额外上下文恢复。
  • 查询改写依赖 ATC 证据与 NPMI 阈值，LLM 仅做渲染；具体品类、冷启动与跨平台可迁移性未在文中验证。

P1｜Profiling What Matters: Context-Aware Item Profiles from Large-Scale Metadata for LLM Recommenders

论文、机构与场景

  • 机构：未披露

  • 作者：未单列

  • 来源：未单列

  • 场景：LLM重排的电商/商品推荐场景，代码位于github.com/rgbeing/CAIRO

  • 论文主要内容： 未披露

  • 原始身份说明：CAIRO由韩国高丽大学与KT Corporation研究者提出，发表于CIKM 2026，面向LLM重排的电商/商品推荐场景，代码位于github.com/rgbeing/CAIRO。

主要创新或优化点

  • 在LLM重排中，物品侧信息如何给比给多少更关键：直接把海量元数据塞入prompt（+Feat）会全面掉点，CAIRO的结构化加用户化选择带来稳定增益且在线成本可控，对精排输入工程有直接借鉴价值。

核心方法

  • 方法将物品元数据与评论离线结构化为客观特征与主观特质：先用k-means聚类并让LLM生成/合并领域键，再按键抽取特征并验证证据，评论归纳为多面主观特质，包含购买目的、使用场景、满意度等。
  • 在线阶段用轻量控制器（softmax权重+k-max池化）挑选每用户每物品的客观特征，并基于用户画像与特质嵌入余弦相似度选一个主观特质，构造用户个性化重排prompt；画像模块离线准备，在线仅矩阵运算。
  • 可选refinement阶段用下一项预测代理任务收集错误案例，由LLM诊断缺陷并基于客观特征修正主观特质，全程离线，进一步提升物品画像质量。

关键结果

  • 在Amazon Video Games上，CAIRO的nDCG@5/HR@5为0.1839/0.2761，CAIRO+Refine为0.1895/0.2827，均高于最强LLM基线M-LLM3Rec（0.1674/0.2578）；Electronics上CAIRO+Refine达0.1866/0.2693。
  • 在Electronics与Sports上，CAIRO在线画像时间0.25-0.32秒，REAP 1-hop需315.87-346.63秒、5-hop需736.94-815.70秒；CAIRO在多数指标上与REAP持平或更优（如Electronics HR@10 0.5214 vs 0.4657）。
  • 在Llama3.2-3B、Llama3.1-8B、Qwen2.5-7B/32B四种LLM上CAIRO均一致超过LLMRank、EXP3RT和M-LLM3Rec，说明画像可迁移到不同规模与家族。

收益归因

  • 主要：LLM重排效果提升（Amazon离线），收益来源是物品画像的结构化与用户相关选择；工业在线/收入影响未核实。
  • 次要：避免在线RAG多次LLM调用，画像时间仅0.25-0.32秒
  • 次要：画像可跨LLM家族与规模迁移（3B-32B）
  • 次要：特征grounding与refinement降低幻觉并提高可信度

与你的关联

  • 与LLM增强精排和广告/电商商品侧画像直接相关；若团队在用LLM重排或面临海量商品元数据注入prompt的延迟与效果问题，本文方法可作重要参考。

风险或局限

  • 仅Amazon三个垂直品类离线评估，无工业在线A/B或多路召回验证，候选集规模仅20个（1正例+19个BPR负样本）。
  • 离线画像依赖GPT-4o-mini多次调用和BGE-M3编码，用户画像沿用已有方法，大规模类目下的离线成本与数据新鲜度未充分讨论。
  • 与RAG基线REAP的对比仅抽样700个用户，且未覆盖短视频、直播或广告竞价等更复杂场景。

P2｜SIREN (Luring LLMs onto the Rocks): PAIR-Driven Preference Manipulation in Web-RAG Recommenders

论文、机构与场景

  • 机构：未披露

  • 作者：机构未披露

  • 来源：未单列

  • 场景：未披露

  • 论文主要内容： 未披露

  • 原始身份说明：论文提出 SIREN，针对 web-augmented LLM 作为推荐系统时的对抗性排名操纵攻击，作者机构未披露。

主要创新或优化点

  • 首次在固定来源上下文中系统研究生产 LLM 的竞争性排名操纵，揭示了 web-RAG 推荐系统的安全漏洞，对推荐系统的鲁棒性评估具有重要参考价值。

核心方法

  • SIREN 基于 PAIR 越狱循环的 attacker-judge 方法，通过 23 种内容投毒技术迭代编辑已检索网页，目标是将特定实体提升至 LLM 生成推荐的第 1 位。
  • 实验使用 Anthropic web 工具检索网页，并在保持相同来源和顺序的 custom-RAG 回放平台上测试，以隔离内容变更对排名的影响。

关键结果

  • 在两种生产 Claude 模型上，124 次技术试验中有 62 次达到排名第 1。
  • 达到排名第 1 的载荷在新会话中复现，平均成功率为 0.805。
  • 声明式排名声明和种子列表通常比指令式注入更有效，但效果因目标模型而异。

收益归因

  • 主要：安全评估
  • 次要：鲁棒性提升
  • 次要：攻击检测

与你的关联

  • 与 LLM 增强的推荐系统相关，但主要涉及安全攻击而非推荐效果提升，对工业推荐链路的价值在于安全防护和鲁棒性评估。

风险或局限

  • 仅测试了 Claude 模型，未覆盖其他 LLM。
  • 实验环境为模拟回放，可能无法完全反映真实生产环境。
  • 未探讨防御措施或缓解策略。

今日最值得立项的实验

SID 前缀聚合特征在精排模型中的离线消融与在线隔离验证

  • 假设：在现有精排多任务模型中引入 SID 前缀聚合（L1/L2/L3 稠密聚合）与 SPM token 共享嵌入，可提升排序指标，且 SID 归因可被隔离确认。
  • Control：现网精排模型，无 SID 派生特征。
  • Treatment：在原有特征基础上新增 SID 前缀聚合特征和 SPM token 共享嵌入序列特征。
  • 保持变量：模型结构、训练数据、任务权重、服务架构均不变。
  • 离线指标：MRR@5；NDCG@5；离线 CTR/ATC/CVR 预估 AUC
  • 线上 Guardrail：确保 feature bundle 更新不引入数据泄露；监控首屏首位商品热度变化，避免头部集中度过度上升

两级 SID（语义码+固定消歧码）替换三级残差码本并附加曝光感知动态更新

  • 假设：单级大语义码本加固定消歧码可缓解三级 SID 的条件稀疏，改善生成式召回质量并降低解码成本。
  • Control：现网三级残差 SID 码本（静态更新）。
  • Treatment：改为两级 SID（语义码+固定消歧码），并采用曝光感知动态码本更新（时域衰减+EMA 中心+曝光加权换码惩罚）。
  • 保持变量：生成式模型结构、训练数据、服务架构、流量分配均保持不变。
  • 离线指标：Recall@10；NDCG@10；码利用率；簇负载均衡；全 SID 碰撞率
  • 线上 Guardrail：监控消费主指标（如时长、互动率）不下降；控制码本更新频率与稳定性，避免在线推理不一致

LLM 重排中物品画像结构化与用户化选择替代全量元数据注入

  • 假设：将海量物品元数据离线结构化为客观特征与主观特质，并在在线阶段按用户选择少量特征构造 prompt，可比全量注入提升重排效果并降低延迟。
  • Control：LLM 重排直接注入全部元数据（+Feat 模式）。
  • Treatment：采用 CAIRO 式画像：离线构建客观特征+主观特质，在线用轻量控制器选择个性化特征构造 prompt。
  • 保持变量：LLM 底座、候选集大小、重排排序规则均不变。
  • 离线指标：nDCG@5；HR@5
  • 线上 Guardrail：监控重排延迟（画像在线计算时间上限）；控制 LLM 调用成本与离线画像更新频率

一句话总判断

本期生成式召回领域 SID 设计出现两组独立推进：DoorDash 用 SID 同时服务精排特征与搜索改写，快手用单级大码本解决条件稀疏并验证动态码本，说明语义 ID 正从生成式检索走向跨应用复用，但归因不隔离仍是主要证据短板。LLM 重排的 CAIRO 证明物品画像的结构化与用户化选择比特征数量更重要，且在线成本可控，是精排输入工程可快速落地的方向。工业在线证据仍集中于 SID 系论文，其余均需离线验证后谨慎采纳。
