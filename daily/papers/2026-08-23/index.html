P0｜Once Generated, Ranked: End-to-End Generative Slate Recommendation with Unified Semantic-Collaborative IDs

论文、机构与场景

  • 机构：Kuaishou Technology、北京大学、南京大学

  • 作者：机构为Kuaishou Technology、北京大学、南京大学

  • 来源：arXiv:2608.17613v1

  • 场景：快手短视频平台生成式slate推荐

  • 论文主要内容： 未披露

  • 原始身份说明：arXiv 2608.17613v1论文，作者机构为Kuaishou Technology、北京大学、南京大学，场景为快手短视频平台生成式slate推荐。

主要创新或优化点

  • 将生成式推荐从先生成后排序推进到端到端直接产出有序slate，统一SID构造、slate级偏好规划与策略对齐，并在快手工业环境获在线验证，是生成式召回与候选生成一体化方向的重要参考。

核心方法

  • TUSID用MLLM语义主干与Brand/Category/B-tags/C-tags属性门控融合，经CountSketch协同注入和置信加权CAW后由RQ-KMeans量化为分层SID。
  • GL2P用listwise偏好规划器建模slate全局偏好与跨位置依赖，位置级SID解码与后续位置规划流水线重叠，辅以曝光序与反馈序双监督。
  • SPA用主奖励（观看/完成/点赞/分享/跳过/不喜欢）与辅助奖励（多样性/新颖度）校准后做clip+KL保守策略优化，使生成slate对齐用户偏好。

关键结果

  • 离线相对NDCG@5提升48.2%（工业）和27.2%（公开数据），KuaiRec上TUSID Recall@5 0.1475、NDCG@5 0.1303优于所有SID基线。
  • 快手3%流量线上A/B：Effective Views +1.120%、Comments +2.954%、Likes +0.505%、Forwards +1.255%。
  • 流水线解码将顺序依赖深度从O(KD)降至O(K+D)，实测吞吐较TIGER-Beam和OneRec-Beam提升2.43倍和2.49倍且NDCG@5最高。

收益归因

  • 主要：主要收益来自TUSID推荐感知SID与GL2P+SPA slate级生成对齐的组合；消融显示去掉listwise planner或SPA会使工业NDCG@5从0.0633降至0.0359或0.0419。
  • 次要：CAW置信加权使冷启动与稀疏item更多依赖语义、减少噪声协同信号
  • 次要：流水线解码重叠带来关键路径缩减与2.4倍以上吞吐提升

与你的关联

  • 与生成式召回和SID方向高度相关，TUSID的协同注入、GL2P的slate级解码和SPA偏好对齐可直接借鉴到短视频或广告的候选生成与排序协同探索。

风险或局限

  • SPA奖励仅基于曝光日志中已有的slate，新生成或反事实slate不参与奖励分配，探索性受限。
  • 线上A/B只覆盖3%流量、时长为1周，未给出统计显著性；工业奖励权重因保密未完整披露。
  • 训练需beam宽度20的候选rollout与多阶段调参，未充分披露与简单端到端方案的训练和部署成本对比。

P1｜Beyond Uniform Token Training: A Multi-Target Framework for Learning Token-Weighted Objectives in Generative Recommenders

论文、机构与场景

  • 机构：未披露

  • 作者：合作

  • 来源：未单列

  • 场景：使用RQ-VAE语义ID的生成式顺序推荐场景

  • 论文主要内容： 未披露

  • 原始身份说明：CIKM '26论文，由卡内基梅隆大学、台湾大学、国立清华大学与中研院作者合作，面向使用RQ-VAE语义ID的生成式顺序推荐场景。

主要创新或优化点

  • 直击生成式召回中token均匀训练与语义ID层级/长尾结构的错配，提出的信息增益token加权与课程多目标训练可无缝套用到现有SID生成式推荐骨干，且不需要改解码结构。

核心方法

  • 提出Front-Greater层级token加权（按prefix对item空间语义离散度缩减量赋权）与Frequency加权（基于有效样本数提升低频token），并以带课程学习的多目标框架与标准交叉熵联合优化。
  • 在Amazon乐器、工业科研、Yelp、MovieLens 1M上以TIGER为骨干，采用leave-one-out评估，代码公开于GitHub。
  • 实验还验证了在PQ语义ID与LLaMA3.2-3B骨干上的泛化性，并对head/tail item分别评测，尾部提升更大。

关键结果

  • 平均相对TIGER提升：Hit@5 +6.11%，NDCG@5 +7.14%，Hit@10 +3.39%，NDCG@10 +5.52%，统计显著p<0.05。
  • Yelp上收益最大，Hit@5 +10.0%、NDCG@5 +13.3%；消融与课程进度分析支持各组件必要性。
  • PQ语义ID与LLaMA3.2-3B（8-bit LoRA）下仍有稳定提升；head/tail分拆显示长尾item提升更明显。

收益归因

  • 主要：生成式召回训练信号改进：token级信息增益加权与课程式多目标损失，可直接迁移到SID生成式模型训练，无需改动解码或模型结构。
  • 次要：语义ID层级结构感知的token加权
  • 次要：缓解流行度偏差与长尾预测
  • 次要：跨ID构造与模型规模的泛化性

与你的关联

  • 对自营生成式召回（SID/ID token生成）团队有直接借鉴价值，尤其是token加权、课程学习与长尾缓解部分；可低成本在TIGER类模型上复现。

风险或局限

  • 仅学术benchmark离线评估，未见线上A/B或工业部署证据。
  • Hit@10等指标平均提升约3.4%量级，且最优课程速率c需调参，过大过小均掉点。
  • 未分析超大词表/海量物料下的训练吞吐与分布式实现成本；仅在T5与LLaMA3.2-3B规模验证。

P1｜Bridging the Structural Gap: Adapting Autoregressive Generation for Recommendation

论文、机构与场景

  • 机构：腾讯平台与内容事业群、深圳大学与中山大学

  • 作者：未单列

  • 来源：arXiv:2607.21028v3

  • 场景：腾讯商业媒体平台的工业级推荐

  • 论文主要内容： 未披露

  • 原始身份说明：arXiv cs.IR 论文（arXiv:2607.21028v3）提出 BARGE；作者来自腾讯平台与内容事业群、深圳大学与中山大学，场景为腾讯商业媒体平台的工业级推荐。

主要创新或优化点

  • 生成式召回的工业落地结构性问题有了系统解法：ICA/HPR/DPD 分别修复物品边界丢失与层级码本语义漂移，模块正交可叠加且不增加参数量，并有大规模离线与线上 A/B 双重证据。

核心方法

  • BARGE 面向生成式召回，用 ICA 跨注意力池化加门控残差融合恢复物品级结构，用 HPR 逐层双塔对比路径重排和 DPD 正交旋转 OSQ-VAE 双通道解码加 OR 融合抑制层级码本语义漂移。
  • 公开实验覆盖 Amazon Beauty/Sports 与腾讯数亿用户规模离线测试，BARGE 在 Recall/NDCG 上超过 TIGER、HSTU、COBRA、APAO、OneRec 等基线。
  • 腾讯商业媒体平台线上 A/B（6% 流量）显示 CTR +0.60%、点击去重用户 +1.34%、总阅读时长 +1.70%，均统计显著。

关键结果

  • Beauty 上 R@10/N@10 为 0.0927/0.0547，Sports 上为 0.0544/0.0308，R@10 较最强基线分别 +16.6%/+8.8%。
  • 腾讯离线 Hit@5/10/20/50=0.6015/0.6510/0.6967/0.7520，全面优于 OneRec 的 0.5459/0.6132/0.6729/0.7348。
  • 在线 A/B 带来 CTR +0.60%、点击 UV +1.34%、总阅读时长 +1.70%。

收益归因

  • 主要：生成式召回候选质量与命中率提升；论文离线与线上 A/B 佐证，但未独立核实。
  • 次要：模型轻量：BARGE 参数 19.91M，低于 TIGER 的 22.71M，训练与推理耗时相近
  • 次要：工业部署信号：已在腾讯商业媒体平台部署并带来一致线上指标提升
  • 次要：机制可复用：ICA 门控注入与 HPR 路径重排可迁移到其他层级语义 ID 召回架构

与你的关联

  • 与生成式召回和 SID 检索工作直接相关，三个模块可迁移到自有 RQ-VAE 或 LLM token 化召回链路；线上 A/B 数据可为业务收益评估提供对标。

风险或局限

  • 公开数据集仅 Amazon Beauty/Sports 两个小规模 benchmark，缺少更多品类或差异化业务的泛化验证。
  • 线上 A/B 仅 6% 流量，未披露置信区间、收入口径指标以及长期稳定性。
  • 两阶段训练（OSQ-VAE 预训练加双解码器训练）与码本配置复杂，迁移到新物料库需重训 tokenizer 并重新调参。

P1｜ClockRoPE: Random Fourier Rotations for Temporal Routine Modeling

论文、机构与场景

  • 机构：YouTube 与 Google DeepMind

  • 作者：未单列

  • 来源：arXiv:2607.26369v2

  • 场景：大型视频平台生产级生成式检索中的用户 routine 与时间周期性建模

  • 论文主要内容： 未披露

  • 原始身份说明：《ClockRoPE: Random Fourier Rotations for Temporal Routine Modeling》(arXiv:2607.26369v2)，作者来自 YouTube 与 Google DeepMind，面向大型视频平台生产级生成式检索中的用户 routine 与时间周期性建模。

主要创新或优化点

  • 把 RoPE 频率从对数线性推广到傅里叶随机采样，给出可证明的周期注意力调制框架，并在生产级生成式召回的短视频场景同时改善有效观看时长与 serving 成本，对工业时序建模有直接借鉴。

核心方法

  • 提出 Random Fourier Rotations：任意归一化连续正定注意力调制函数可由其自身傅里叶变换分布采样的 RoPE 频率无偏逼近；ClockRoPE 依此用余弦/周期高斯先验采样旋转频率，编码日/周周期，并用折半分布获得方向感知。
  • 基座 Transformer 以用户历史交互序列预测下一交互，为观看页和主页从海量视频库做 top-k 召回，并作为更细粒度精排的上游；ClockRoPE 与 RoPE 各作用一半特征维度。
  • 作者报告已在大型视频平台主页/观看页随 RoPE 部署，在线 A/B 14 天、每变体 1% 流量；核心部署指标显示有效观看时长 +0.08%、TPU serving cost -0.63%、延迟中性。

关键结果

  • 离线 MAP：无位置编码分组中 gaussian-fold 相对生产控制 MAP@1 +3.61%、MAP@50 +2.25%；与 RoPE 结合时相对 RoPE-only +2.39%/+2.00%。
  • 在线 A/B：RoPE+ClockRoPE 有效观看时长 +0.08%，主页触发观看时长 +0.11%，主页浏览 -0.51%，日均唯一曝光视频 -0.19%，TPU serving cost -0.63%，延迟中性。
  • 消融：周期高斯 σ=2h、截断 s=6 最优；可学习频率用 ClockRoPE 初始化与固定频率性能接近（gaussian-fold MAP@1 +3.23% vs +3.61%）。

收益归因

  • 主要：作者归因：ClockRoPE 周期注意力调制提高生成式检索的 routine 感知，减少无效曝光与 serving 量，带来有效观看时长提升和 0.63% TPU 成本下降；未经独立核实。
  • 次要：无需新增输入特征或增加模型维度；
  • 次要：TPU serving cost 下降 0.63% 且延迟中性；
  • 次要：主页触发式观看时长提升 0.11%。

与你的关联

  • 与搜广推生成式召回链路直接相关：可作为序列 Transformer 的位置编码增量改进，不需新增输入特征或增加维度即可引入日/周 routine 先验，其 A/B 与部署成本数据对短视频/直播/电商有参考价值。

风险或局限

  • arXiv 预印本且未显示同行评审信息，A/B 与部署数字全部为作者方自报，无第三方独立复现。
  • 平台名、视频语料规模、模型参数量与 serving 架构等关键工业细节未披露，外部可迁移性难判断。
  • 周期先验需人工选择 T、σ 与截断 s；未见跨周期自适应或对不规则时间序列的推广验证。

P1｜From Token Generation to Item Ranking: Direct Generative Recommendation with Semantic IDs

论文、机构与场景

  • 机构：未披露

  • 作者：提出

  • 来源：arXiv:2602.07847v2

  • 场景：Amazon 2018 音乐器材、工艺美术、电子游戏三个品类的 next-item 推荐

  • 论文主要内容： 未披露

  • 原始身份说明：DiGR（arXiv:2602.07847v2）由中南大学、香港理工大学、国防科技大学、澳门城市大学和格里菲斯大学作者提出，面向 Amazon 2018 音乐器材、工艺美术、电子游戏三个品类的 next-item 推荐。

主要创新或优化点

  • 论文给出了 token 级生成式推荐的排序信息论分析，并提出了直接对完整目录打分的 item-atomic 生成式推荐，为生成式召回提供了无需 token 解码的新范式，可能影响后续 SID 类生成式推荐的设计。

核心方法

  • 论文证明 SID token 接口的二分性：ranking-insufficient 时任何解码器无法精确恢复排序，ranking-sufficient 时精确解码输出等价于直接 item-level 打分；DiGR 将 SID 作为 item representation，用 LLM 编码用户历史后以统一 item-level 打分函数直接对完整目录排序。
  • 默认骨干为 Qwen3-4B，训练采用 item-level NLL；对比 Caser、SASRec、LC-Rec、RPG 等基线，在 15 个 dataset-metric 组合全部最优，平均相对提升 4.85%。
  • 推理上，DiGR 在 Instruments 上 NDCG@10=0.0868，平均每用户 0.074s，比 beam search 配置快 9 倍以上，略快于 parallel generation。

关键结果

  • 在三个 Amazon 品类的 15 个 HR/NDCG 设置上全部取得最佳结果，平均相对提升 4.85%（最强基线多为生成式推荐器）。
  • DiGR 在 Instruments 上 NDCG@10=0.0868，超过 LC-Rec exhaustive scoring 3.09%，并保持 0.074s/用户的推理延迟。
  • 在 GPT-2、Qwen3-1.7B、Qwen3-4B 三种骨干上均一致优于 LC-Rec，小骨干下优势更明显。

收益归因

  • 主要：未核实
  • 次要：避免 beam search 解码的高延迟与排序近似误差
  • 次要：训练与推理共用 item-level 打分函数，减少分布偏移
  • 次要：保留 SID 语义结构，支持对新物品的归纳打分

与你的关联

  • 若团队关注 LLM/SID 生成式召回，该工作提供理论依据和可直接借鉴的统一打分框架；但收益基于学术离线指标，需在小规模自建数据复现后再评估工业 A/B 价值。

风险或局限

  • 实验仅覆盖 Amazon 三个品类，目录规模约 1–2 万 item，未验证超大规模工业目录下的全目录打分可行性。
  • 对超大型目录需要全目录打分，论文仅提及可用近似项目级检索，未给出具体算法或实验。
  • 评估为 leave-one-out 离线指标（HR/NDCG），无在线 A/B；相对最优基线平均提升 4.85% 的泛化性待验证。

P1｜LLM-Based Generative Retrieval for Snapchat Content Recommendation

论文、机构与场景

  • 机构：未披露

  • 作者：未单列

  • 来源：未单列

  • 场景：Snapchat短视频内容推荐的LLM生成式召回系统

  • 论文主要内容： 未披露

  • 方法：将 Forward-Forward 的 detachment 作为调度原语，模块输出 detach 后消除下游梯度依赖，每个子图 forward 结束后即可单独 stream 早发 backward，并与后续 forward 重叠；子图内仍保留精确梯度，未使用 FF 的 goodness 目标。

收益归因

  • 主要：通过早发 backward 与后续 forward 重叠提升 CTR 模型训练吞吐（p90 QPS +7.38%~9.51%）。
  • 次要：无需修改损失或子图内梯度语义
  • 次要：对资源未饱和的轻量/代理模型更有效
  • 次要：CUDA Graphs 降低 CPU dispatch 开销

论文、机构与场景

  • 作者：未单列

  • 来源：未单列

主要创新或优化点

  • BRIDGE 把多模态内容约束为候选几何形成来源，行为证据只做候选内局部排序校准，缓解跨视图对齐过强对排序的伤害；其 NDCG 增益大于 Recall，说明主要改善候选内排序质量，对两段式检索-精排流水线有直接借鉴意义。

核心方法

  • BRIDGE 分三部分：DFGE 把图平滑后的 ID/视觉/文本通道做奇异值频带分解并门控融合，BEN 将训练期共用户重叠转成符号化行为证据，CRI 仅在基座打分出的 top-200 候选集内加残差校准，且训练与推理使用同一候选范围。

关键结果

  • Amazon Baby/Sports/Electronics 上 Recall@20 为 0.1128/0.1262/0.0778、NDCG@20 为 0.0525/0.0594/0.0385，较最强基线最多提升 Recall@20 7.3%、NDCG@20 14.9%，五种子均值且 p<0.01。
  • 消融显示去除行为证据或 top-K 候选校准会明显掉点，全局校正弱于候选内校正；去掉频带分解使 Baby R@20 从 0.1128 降至 0.1110，Gram/DCT/随机正交基差异很小。
  • 按流行度分层，BRIDGE 提升 Mid/Tail/Cold 召回并降低 Head 曝光，如 Sports Head Exp 从 0.9073 降至 0.8429，无显式抗流行度目标。

收益归因

  • 主要：未核实（离线消融显示主要收益来自 BEN/CRI 的候选内行为残差校准，频带分解贡献相对较小）
  • 次要：候选 scope 掩码避免残差扰动整个物料空间
  • 次要：行为图仅用训练交互，降低标签泄漏风险
  • 次要：固定 λ_b 残差可解释且便于复现

与你的关联

  • 工业推荐可从三点借鉴：行为证据作为候选内残差校准、训练与推理保持同一 top-K 范围、固定 λ_b 加缓存图降低部署代价；该方法不要求改多模态基座，可叠加在现有精排打分之上。

风险或局限

  • 仅在 Amazon 三个品类和 BEIT3 特征上验证，未覆盖短视频、直播或广告链路。
  • 未评估端到端延迟与吞吐，item 图和 behavior 图需缓存，行为残差只作用于基座短列表。
  • 依赖基座候选质量，未进入短列表的相关 item 无法被校准恢复；共用户重叠稀疏或局部交互爆发时 BEN 精度下降，且无线上 A/B 结果。
