## 生成式召回

### P0｜[VARG: Value-Aware and Ranking-Aligned Generative Retrieval for Dynamic E-commerce Search](https://arxiv.org/abs/2609.14493)

**论文、机构与场景**

- **机构：中国科学技术大学、阿里巴巴淘天集团、南开大学**
- 作者：Xiaopeng Chu、Jianbo Zhu、Mingmin Jin、Jing Wang、Xing Fang、Wenyi Zhang
- 来源：arXiv:2609.14493v1
- 场景：Tmall App电商搜索召回与预排序整合，生成式检索直接向现有精排输送候选

**核心方法**

- VARG-ID用RQ-VAE构建两级语义前缀，并以经验贝叶斯CVR排序生成第三token，形成无冲突的物品地址与业务价值先验
- 双向query-item对比学习将搜索相关性注入前缀。
- 三阶段SFT依次学习Item→SID、Query→SID、User+Query+History→SID
- 个性化阶段用Q2I样本加权、层级token加权、扩展用户上下文和LO-SFT局部序数监督。
- Prefix-GRPO用合法性、行为、精排优势和相关性的门控多源奖励，结合前缀感知token加权做GRPO对齐
- Trie约束beam搜索保证生成SID合法并映射为物品候选。

**主要创新或优化点**

- 把生成式召回作为额外通道直接接入精排并跑出电商GMV正收益，验证了value-aware SID与RL对齐在工业搜索候选生成中的可行性。

**关键结果**

- 14天线上A/B覆盖20%搜索流量：GMV +1.45%，人均IPV +0.22%，PCTR +0.31%，UCTR与UCTCVR各+0.13%。
- 相对SFT Base，Prefix-GRPO将GMV Recall@1提升5.47个百分点、Q2I-GMV Recall@1提升2.48个百分点、HR@1提升0.05个百分点。
- VARG-ID SFT Base相比三级RQ-VAE标识符，Q2I-GMV Recall@1/10/20分别提升15.50/13.65/0.93个百分点
- Trie约束使合法率从93.73%升至100%。

**收益归因**

- 主要：生成式召回通道提升候选价值覆盖与线上GMV
- 次要：GMV
- 次要：Q2I-GMV Recall
- 次要：候选配额效率

**与你的关联**

- 与用户关注的生成式召回、SID设计、RL对齐候选生成、电商搜索召回-精排一体化直接相关，方法与在线结果可复用或对照。

**风险或局限**

- 轻量并行解码器仅探索：平均延迟从10.41ms降至0.94ms、单卡QPS约11.1倍，但HR@1/20/100分别下降1.13/8.38/10.77个百分点，未上线主链路。
- 每日商品更新会冻结已有SID并允许新商品复用槽位，产生受控SID共享
- 每月重建SID版本，长期标识稳定性与新商品冷启仍受约束。
- 线上收益来自VARG-ID、三阶段SFT、Prefix-GRPO和配额策略的组合，未做组件级线上归因
- A/B仅14天20%流量，无外部复现。


### P1｜[Self-Evolving Memory for Generative Recommendation](https://arxiv.org/abs/2609.15598)

**论文、机构与场景**

- **机构：National University of Singapore、Meta AI**
- 作者：Xinyu Lin 等
- 来源：arXiv:2609.15598v1
- 场景：在 Amazon Reviews 的 Games/CDs/Toys 上做流式持续生成式推荐（next-item prediction）

**核心方法**

- 识别出 evolution conflict：在完全共享的自回归参数空间中持续适应，主导行为模式会逐步压制 underrepresented 偏好模式。
- 提出 LION：在 T5/TIGER 生成式推荐骨干的中间层插入 sparse Key-Value memory layer，通过 query 驱动的 Top-K 稀疏激活隔离不同行为模式。
- 设计 consolidation loss 对 memory-enhanced representation 施加辅助监督，总损失为 L_rec+λL_con
- 并用 full-sequence memory query 路由，骨干只处理近期序列。

**主要创新或优化点**

- 指出生成式推荐持续演化中的 evolution conflict，并用稀疏 KV 记忆隔离不同行为模式，为长尾/非活跃用户召回退化提供新解法；若成立对持续学习式生成式召回有参考价值。

**关键结果**

- 在 Games 数据集上，LION 的 R@10/N@10 达 0.0724/0.0454，较 TIGER 的 0.0558/0.0336 提升 29.8%/35.3%。
- 在 CDs 数据集上，LION 的 R@10/N@10 达 0.0449/0.0306，较 TIGER 的 0.0331/0.0213 提升 35.5%/43.7%。
- 在 Toys 数据集上，LION 的 R@10/N@10 达 0.0769/0.0495，较 TIGER 的 0.0666/0.0418 提升 15.6%/18.4%。

**收益归因**

- 主要：未核实
- 次要：离线 R@10/NDCG@10 提升
- 次要：非活跃用户组长尾收益更明显
- 次要：记忆参数不随用户规模增长，具备可扩展性

**与你的关联**

- 与生成式推荐、召回侧持续学习、长尾/冷门偏好建模直接相关；可评估稀疏记忆隔离是否适用于当前工业生成式召回架构。

**风险或局限**

- 仅在 Amazon Reviews 离线数据集上评估，无线上 A/B 或生产部署结果，无法确认工业收益。
- 实验只在 T5/TIGER 骨干上验证，未覆盖 LLM-based 或其他生成式推荐架构。
- 记忆路由采用固定 Top-K 激活，自适应路由仍为未来工作
- Theorem 4.1 的隔离效果依赖后续经验验证（Corollary 4.1 非保证）。

### P2｜[Contextual Scalarisation Thompson Sampling for multi-objective decisions in public media](https://arxiv.org/abs/2605.31291)

**论文、机构与场景**

- **机构：Théo Maëtz 与 Luc Guillet 属 Radio Télévision Suisse（日内瓦，瑞士），Andrea Cavallaro 属 EPFL（洛桑，瑞士）**
- 作者：Théo Maëtz、Luc Guillet、Andrea Cavallaro
- 来源：arXiv 2605.31291v2
- 场景：瑞士国家广播公司 Radio Télévision Suisse 公共媒体节目编排/推荐中的多目标权衡

**核心方法**

- 提出 Contextual Scalarisation Thompson Sampler（CSTS），一种多目标上下文 bandit 方法，按观测到的上下文学习各目标的权重，而非固定权重组合

- 在 RTS 真实节目数据上评估 CSTS，对比固定权重与标准上下文 bandit 方法

**主要创新或优化点**

- 多目标动态加权是搜广推多目标建模中的常见痛点，用上下文 bandit 在线学习目标权重提供了可迁移思路；但仅有摘要级离线证据，无线上 A/B。

**关键结果**

- 在 RTS 真实节目数据上报告上下文相关性提升，且与专家编排实践的一致性更好
- 对比对象为固定权重方法和标准上下文 bandit 方法

**收益归因**

- 主要：未核实
- 次要：多目标动态权重
- 次要：上下文 bandit

**与你的关联**

- 公共媒体多目标权衡场景与短视频/直播/电商推荐的多目标（时长、互动、生态）融合有方法层面相似性，但其场景与指标需迁移验证。

**风险或局限**

## LLM 增强与对话推荐

### P1｜[TATK: Triple-Aware Top-K Learning with Knowledge-Grounded Verification for LLM-based Sequential Recommendation](https://arxiv.org/abs/2609.14565)

**论文、机构与场景**

- **机构：华东理工大学、中国科学院香港创新研究院人工智能与机器人中心、中国科学院深圳先进技术研究院、西湖大学**
- 作者：Yuchen Guan、Jiaye Liu、Yifei Han、Zhenxi Zhang、Yixuan Weng、Bin Li
- 来源：arXiv:2609.14565v1（cs.CL 预印本，2026-09-13）
- 场景：Amazon Reviews 2023 三个类目上的 LLM 序列推荐全目录 top-K 排序

**核心方法**

- TATK 复用同一份由商品元数据（store/category/main category，类目组上限 350）构建的物品图，分别承担提示侧上下文接地、训练侧位置感知奖励、推理侧结构感知重排三个角色。
- Top-K Learning 的位置感知奖励 rpos(r)=(K−r+1)/K（r≤K，否则 0），在 batch/rollout 组内中心化为相对优势，并与 token 级损失、item 级推荐损失结合
- 训练用 LoRA rank 4/alpha 128、3 epoch、lr 1e-5、batch 4、group size 4。
- KGV 在单次 LLM 前向产出的 top-M=100 候选上，用同一物品图计算支撑度 raw=min(γ, m+βn)（γ=2.5、β=0.15）并归一化后以 λ=0.01 加回生成分，按历史长度/KG 支持/band/不确定性门控，重排不增加 LLM 前向次数。

**主要创新或优化点**

- 指出 LLM 序列推荐把全目录 top-K 排序当作文本生成的三个错配（输入弱接地、训练目标与排序指标错配、生成候选缺验证），并用同一元数据图在训练奖励与推理重排两端对齐排序效用，且不增加 LLM 前向。

**关键结果**

- 在 Gemma-2-2B-It 与 Qwen2.5-3B-Instruct 两个 backbone（5 seed，mean±std）上，TATK 相对匹配协议下自跑的 R2ec 在全部 36 个报告指标上提升
- NDCG@10 提升幅度 Qwen 为 8.05%/4.26%/3.78%，Gemma 为 27.03%/10.52%/10.23%（MI/CDs/VG）。
- 3 seed 组件消融（Gemma）平均 N@10：Base RecPO 0.0317，仅上下文 KG 接地 0.0338，仅位置感知奖励 0.0334，仅结构重排 0.0329，完整 TATK 0.0358（TKL +0.0029，KGV 再 +0.0012）。
- 效率：Base RecPO 单次 LLM 前向 420 ms/用户，完整 TATK 490 ms/用户（1.17×），显存 14.8 GB→15.0 GB
- M 从 100 增至 200 平均 N@10 仅 0.0359→0.0361，延迟 490→540 ms/用户。

**收益归因**

- 主要：top-K 排序质量提升（NDCG@10/HitRate@10），主要来自训练目标与排序位置对齐以及用元数据图对 top-M 候选做结构化重排
- 次要：训练目标与 top-K 指标对齐（位置感知奖励）
- 次要：同一元数据图同时服务提示、训练与推理，复用成本低
- 次要：重排引起的候选升降级可追溯到 store/category 关系

**与你的关联**

- 与 LLM 排序链路改造相关：位置感知 top-K 奖励可用于对齐训练目标，top-M 候选的元数据图重排可在不增加 LLM 前向的前提下接入现有链路，但收益依赖元数据质量与覆盖率。

## 今日阅读顺序

- [LazFormer: Scaling Transformers for Industrial Recommendation via Transferable Generative Pre-training](https://arxiv.org/abs/2609.14978)：本期唯一给出工业精排线上A/B（IPV +5.21%、GMV +9.85%）的生成式预训练迁移工作，含长序列压缩、零初始化残差适配与非对称多epoch训练，与精排缩放路线直接对应。
- [VARG: Value-Aware and Ranking-Aligned Generative Retrieval for Dynamic E-commerce Search](https://arxiv.org/abs/2609.14493)：生成式召回作额外通道直接接入精排，14天20%流量A/B GMV +1.45%，value-aware SID与Prefix-GRPO对齐可对照现有GR链路；与电商搜索召回-精排一体化高度相关。
- [Addressing Cross-Stage Decoupling of Semantic and Collaborative Signals in Generative Recommendation](https://arxiv.org/abs/2609.13678)：直击SID/tokenization与生成阶段语义-协同信号脱节痛点，协同增强tokenization与流形对齐思路对当前SID构建有直接参考；但仅有摘要级证据，需按低置信度阅读。
- [Self-Evolving Memory for Generative Recommendation](https://arxiv.org/abs/2609.15598)：已核验PDF，三个Amazon类目R@10提升15.6%–35.5%，稀疏KV记忆隔离不同行为模式，对持续学习式生成式召回与非活跃用户长尾召回有直接借鉴价值。
- [Native Multimodal Representation Learning for Click-Through Rate Prediction in E-Commerce Scenarios](https://arxiv.org/abs/2608.24091)：给出端到端联合训练无收益反降的工业负面证据（CIKM '26），并给出Mine-Then-Train替代路径与淘宝展示广告线上CTR +1.5%/RPM +0.5%，对多模态表征注入与训练范式选型有对照价值。
- [TATK: Triple-Aware Top-K Learning with Knowledge-Grounded Verification for LLM-based Sequential Recommendation](https://arxiv.org/abs/2609.14565)：已核验PDF，位置感知top-K奖励与元数据图重排不增加LLM前向（1.17×延迟），对LLM排序链路的目标对齐与top-M重排有工程可复用性；但统计强度有限，需注意局限。
- P3Rec与CRAMER等其余LLM增强方向：P3Rec v2无实质更新、CRAMER仅摘要级证据，均无线上A/B，作为方向储备快速略读；不优先投入精读。

## 今日最值得立项的实验

### SID token化显式注入协同信号

- 假设：在现有生成式召回两阶段链路中，对物品token化阶段显式注入文本化协同信号，可提升生成候选的相关性与SID质量，而不需要额外对齐任务。
- Control：沿用现有纯文本语义tokenization与SID构建流程，生成阶段与下游精排不变。
- Treatment：按Cross-Stage Decoupling思路，对SID token构建加入协同增强tokenization，并在生成阶段用可学习code embedding做语义先验校准与流形对齐。
- 保持变量：训练数据窗口、用户历史构造、生成式模型结构与超参、下游精排模型与特征、评测口径保持一致。
- 离线指标：Recall@k/NDCG@k召回指标；SID合法率与槽位冲突率；生成候选下游通过率
- 线上 Guardrail：线上召回覆盖率与CTR/GMV不劣化；token化与生成阶段额外训练/推理开销在预算内；SID版本切换不引入冷启商品不可召回

### 轻量交互级稀疏记忆隔离

- 假设：在生成式召回骨干中间层插入query驱动的Top-K稀疏KV记忆，可缓解持续适应中主流行为压制长尾偏好的evolution conflict，提升非活跃用户召回。
- Control：按周期流式数据持续微调现有生成式推荐骨干，不引入记忆层。
- Treatment：在T5/TIGER式骨干中间层加入稀疏KV记忆层与consolidation loss（L_rec+λL_con），按query路由激活不同行为模式。
- 保持变量：骨干结构与参数量、数据流式切分与更新周期、评测数据集与指标口径保持对齐。
- 离线指标：R@10/N@10总体与分活跃度分层；非活跃/长尾用户组NDCG@10；记忆参数规模与单步训练时间
- 线上 Guardrail：线上A/B CTR/人均时长不劣化；记忆层推理延迟与显存增量可控；固定Top-K路由在高流量下不引发长尾通道挤占

### 端到端多模态联合训练的反例验证

- 假设：在已充分预训练的多模态编码器上做端到端联合训练不带来CTR提升，通过数据层挖掘三元组微调编码器可低风险提升多模态表征质量。
- Control：保持现有SCL多模态编码器冻结，仅按当前管线注入精排模型。
- Treatment：按Mine-Then-Train用标注模型挖掘高置信三元组，以triplet margin loss+SCL loss微调编码器（NMR），不做端到端联合训练。
- 保持变量：物品集合、精排模型结构与特征、训练样本窗口、线上模块不做改动，保持SCL已有部署管线不变。
- 离线指标：离线GAUC/AUC相对基线增量；挖掘三元组高置信组人工一致性；编码器微调训练成本与显存峰值
- 线上 Guardrail：线上CTR/RPM不劣化；编码器表征更新后冷启/新品特征覆盖不下降；不引入端到端联合训练所需的高显存与步时开销


## 一句话总判断

本期主线是生成式预训练与排序表征的迁移落地：LazFormer把自回归预训练参数加零初始化残差适配接入工业精排并给出GMV正收益，VARG把value-aware SID与GRPO对齐用于电商搜索召回，二者共同指向生成式方法从纯召回向精排/排序链路渗透。第二主线是跨阶段信号一致性成为显式问题：Cross-Stage Decoupling与LION分别从token化协同增强和稀疏记忆隔离两端处理语义-协同脱节与持续演化冲突，但前者仅摘要级证据，后者为离线验证。第三，多模态端到端联合训练出现明确反例（NMR在淘宝广告E2EM降GAUC），提示强预训练编码器加数据层挖掘微调是更低风险路径。
