## 生成式召回

### P1｜[华东师范大学、复旦大学｜MuSID-KD: Multigranularity Knowledge Distillation for Generative Recommendation with Semantic IDs](https://arxiv.org/abs/2610.35218)

**论文、机构与场景**

- **机构：华东师范大学（Fengshi Zhang、Xiyan Ding、Wei Zhang）、复旦大学（Shuxiao Xie）**
- 作者：Fengshi Zhang、Xiyan Ding、Shuxiao Xie、Wei Zhang
- 来源：arXiv:2610.35218v2
- 场景：基于语义 ID 的生成式推荐下一物品预测（Amazon Beauty/Toys/Video Games、Steam-100K）
- **论文主要内容：** 针对多token语义ID生成式推荐蒸馏监督不足，提出层级候选分布对齐与排序影响加权的位置蒸馏。

**主要创新或优化点**

- 已有 SID 蒸馏多关注 token/前缀条件分布或叶子物品分布，对中间层共享前缀候选组的排序缺少直接监督；HCDA 将 item 概率按每个 SID 前缀聚合成组分布并逐层 KL 对齐，使粗粒度候选组也进入训练目标。
- 已有 token 级蒸馏对所有 SID 位置均匀施加教师匹配，但不同位置对最终物品对排序的作用可能相反；RIGD 用替换教师分数贡献后成对排序损失的下降量给位置赋权，只强化有正收益的层级（最后 SID 位置不参与）。
- 两个目标仅在离线训练阶段增加计算，学生在线仍执行原有约束 SID beam search，因而不改变推理架构，面向多 token SID 生成的轻量在线推理。

**核心方法**

- HCDA 在同一教师候选集上计算教师与学生的物品概率，按长度 d 共享 SID 前缀聚合为候选组概率，并在全部 L 个 SID 层级用 KL 散度对齐从粗候选组到叶子物品的分布
- RIGD 对教师 top-K 内（1–10）与 K 外（11–40）的物品对，从首个不同 SID token 到倒数第二个位置逐位置将学生该位置的分数贡献替换为教师值，计算 Softplus 成对排序代理损失的下降量；仅正下降量归一化为权重，再用 Huber 损失对齐各位置贡献，最后位置仅用于识别物品、不进入 RIGD
- 训练目标为 CE + λ_H HCDA + λ_R RIGD，教师固定，学生共享冻结 T5 历史编码器与 token 嵌入并接 MLP/GRU/CNN 读出头及四个前缀条件预测头；蒸馏只在离线训练计算，在线仍用约束 SID beam search

**关键结果**

- Amazon 三个数据集、三种学生架构的 36 项指标比较中均取得最佳学生结果；九个设置上 NDCG@10 相对 Base KD 平均提升 8.31%，相对最强其他学生提升 1.59%–5.13%
- 改用 R-KMeans SID 后，在四个数据集、三种学生架构共 24 个指标设置中均排名第一；NDCG@10 相对 Base KD 平均提升 5.50%，相对 Base KD/SmartGR 中较强者平均提升 3.61%
- Beauty-MLP 的 200 个 epoch（含 beam 验证）训练从 Base KD 的 27 分钟增至 49 分钟，峰值 GPU 显存从 7.4GB 增至 9.2–9.5GB；作者称在线推理不计算蒸馏目标

**收益归因**

- 主要：整包 MuSID-KD 在论文所测四个数据集、三种轻量学生架构上提升排序指标，且不改变在线 SID beam-search 推理架构；消融显示 HCDA-only 与 RIGD-only 均高于 CE/Base KD，但未做线上 A/B，也未验证单模块的在线因果收益。
- 次要：HCDA 改善中间 SID 层候选组边际分布与教师的一致性，RIGD 将监督集中到对物品对排序有正收益的层级；消融中完整模型的 NDCG@10 高于 HCDA-only 与 RIGD-only，支持组合增益。
- 次要：论文报告 RQ-VAE 与 R-KMeans 两种 SID 分词器下 NDCG@10 均有提升；未做跨分词器切换或独立复现。
- 次要：在线吞吐与 Base KD 大体相当（MLP 2769/3036 req/s 等），说明整包收益并非在线推理加速；未拆分单模块对吞吐的贡献。

**与你的关联**

- 适用于已有强生成式 SID 教师、需蒸馏到轻量学生并保持在线 beam-search 推理架构的推荐系统；迁移前提是固定 item-SID 映射、可缓存教师候选，并能接受离线蒸馏训练开销增加。

**风险或局限**

- 仅有离线数据集实验，未提供线上 A/B、生产部署或真实流量指标；结果为论文自报，未独立复现，排序收益不能直接外推到工业系统
- 训练开销增加：Beauty-MLP 200 epoch 从 27 分钟升至 49 分钟，峰值显存从 7.4GB 升至 9.2–9.5GB；需额外教师候选缓存与成对替换计算，大规模成本未评估
- RIGD 默认只采样教师排名 1–10 与 11–40 的跨界物品对，并排除最后 SID 位置；附录仅报告 Beauty–MLP 对候选数、边界、RIGD 系数与温度的敏感性，未覆盖全部数据集/学生架构，对更靠后候选和候选集截断的行为仍有限

### P2｜[Xi’an Jiaotong-Liverpool University、University of Liverpool｜CEU｜Explain, Then Forget: Recommendation Unlearning under Asymmetric Access Constraint](https://arxiv.org/abs/2610.40658)

**论文、机构与场景**

- **机构：Xi’an Jiaotong-Liverpool University、University of Liverpool**
- 作者：Haichao Zhang、Chong Zhang、Wen Wang、Shi Qiu、Peiyu Hu、Jia Wang
- 来源：arXiv:2610.40658v1
- 场景：MLaaS 下仅通过 API 访问推荐模型时，按用户请求移除历史交互影响并重排 top-K 推荐
- **论文主要内容：** 提出CEU，用因果解释识别历史交互贡献并局部调整排名分数，实现API-only推荐卸载。

**主要创新或优化点**

- 针对 MLaaS 中 SO 只能通过 API 使用模型、不能重训练或微调的限制，CEU 把 SO 侧卸载从参数更新改为输出层排序分数干预；MP 侧 CCI 仍使用冻结模型内部参数计算归因。CCI 用反事实解释学习稀疏连续 mask，搜索使目标推荐翻转的最小支持集并给出逐交互贡献权重，只把归因结果经 API 暴露给 SO。URA 只对因果支持集包含遗忘交互的候选做乘性降分并重排，未受影响候选保持原分；作者称该不更新模型参数的设计可支持连续请求并减少重复参数更新的误差累积。将解释-遗忘拆成 MP 侧 CCI 与 SO 侧 URA 的职责分工，使归因可预计算缓存、在线只做轻量重排，设计上适配 API-only 服务边界。

**核心方法**

- CCI 对用户历史学习连续 mask P_u∈[0,1]^{|H_u|}，冻结推荐模型，最小化翻转损失 max(0,m+f(u(P_u),i)-f(u,i_{K+1})) 与 L1 稀疏项，使目标 item 分数降到原 top-K 边界以下；P_{u,h}<1-δ 的交互构成最小因果支持集 S*_{ui}，贡献权重 w_{ui}(h)=1-P_{u,h}。
- URA 收到遗忘交互 h_f=(u,i_f) 后，从缓存读取当前候选列表 L_u 的解释；仅当 h_f∈S*_{ui} 时按 y'_{ui}=y_{ui}-α·y_{ui}·w_{ui}(h_f) 降分，其余候选保持原分，再按修正分数重排 top-K。
- 服务流程上，MP 侧为每用户 top-50 候选预计算解释、每 item 最多保留5个因果交互并缓存（约22KiB/用户），SO 仅经 API 获取归因并在线调分；不更新模型参数，因此作者称可支持连续卸载请求。

**关键结果**

- 在 ML-1M+LightGCN、1%遗忘比例下，表 I 报告 CEU HR@10=0.7584、NDCG@10=0.2671，Origin=0.7680/0.2715，Retrain=0.7649/0.2672；正文另写 Origin=0.7603/0.2682，存在数值不一致。
- 表 III 中 ML-1M+LightGCN、1%遗忘时 CEU MIA ACC@1=0.4789，低于 Origin 0.9678、接近 Retrain 0.5126；但 10%遗忘时 CEU ACC@10=0.6429，未接近 Retrain 0.5015。
- 表 V 报告单次卸载延迟 CEU 为0.34–6.37s，Retrain 为141.92–4209.05s；表内相对次优方法加速9.31×–52.74×，正文却写10.06×–55.64×。

**收益归因**

- 主要：SO 侧不访问模型内部：MP 托管的 CCI 在冻结模型上计算因果归因，SO 仅经 API 取得归因并由 URA 在输出分数层面干预，避免 SO 重训练/微调及重复参数更新的误差累积。
- 次要：CCI 的最小因果支持集提供受影响候选定位；消融中 CEU-Random 在 LightGCN/BPR 上使 NDCG@10 分别下降约19.4%/20.8%，CEU-Full 在 LightGCN 上仅降约0.4%，支持因果定位对避免破坏性卸载的作用；CEU-Reverse 也显著退化但原文未给具体数值。
- 次要：解释可离线预计算并缓存，在线 URA 仅读取归因、降分并重排；论文报告单请求延迟0.34–6.37s，较次优基线有表内9.31×–52.74×加速。

**与你的关联**

- 适用于推荐排序链路中需要按用户请求移除历史交互影响、且模型只能通过 API 访问的场景；迁移需具备可缓存的因果归因接口、候选级贡献权重和在线重排能力，并需在自有数据上验证 MIA 与效用损失。

**风险或局限**

- 仅在三份公开数据集上离线评估，无工业 A/B、生产部署或独立复现；线上 CTR/GMV 与高并发延迟未验证。
- 关键数值存在正文与表格不一致：ML-1M LightGCN 的 Origin 指标在正文写0.7603/0.2682、表 I 写0.7680/0.2715；加速比正文写10.06×–55.64×、表 V 为9.31×–52.74×。
- CCI 仅对每用户 top-50 候选、每 item 至多5个因果交互预计算，未验证全目录候选、缓存失效下的归因成本与可扩展性；附录明确增大遗忘比例实验不是严格连续请求流模拟。


### P2｜[Georgia Institute of Technology｜Intersection-Fitting｜Fair Recommender Systems for Intersecting Groups](https://arxiv.org/abs/2610.40936)

**论文、机构与场景**

- **机构：Georgia Institute of Technology**
- 作者：Christine Ling、Juba Ziani
- 来源：arXiv:2610.40936v1
- 场景：重叠人口群体下的动态 K-slate 推荐与群体/交叉 regret 优化
- **论文主要内容：** 研究交叉群体动态 K-slate 推荐的公平与 regret，提出交叉拟合及两种池化 UCB。

**主要创新或优化点**

- 将重叠群体下的动态 K-slate 推荐形式化为总/群体/交叉福利 regret；证明 Assumption 4 下任何 group-blind 策略有严格线性总 regret，并给出显式常数差距实例。提出 Intersection-Fitting UCB（Upper Confidence Bound）逐交叉独立估计，交叉级/群体级 sublinear 界，状态 O(nH)、群体级界随 H_k 增长；两种池化启发式 Inner–Outer/Group–Item UCB 无一般 regret 保证。Goodreads/BoardGameGeek（BGG）离线仿真显示池化与交叉拟合权衡，非部署结论。

**核心方法**

- Intersection-Fitting UCB：为每个实际出现的精确人口交叉独立维护一套 UCB 物品统计，用该交叉的局部到达时钟计算每个物品的置信上界，按上界选 K 个不同物品；不跨交叉共享数据，只更新本交叉被推荐物品的均值与计数。
- Inner–Outer UCB：为每个基础群体（含全活跃 g0）维护 UCB 物品表，先对每个醒着群体算出其 top-K slate 及平均 UCB 路由分 Q_k，再选 Q_k 最高的群体整张 slate 推荐，并且只更新被跟随群体的统计。
- Group–Item UCB：把每个醒着的 (group,item) 对视为独立臂，物品得分为其在所有醒着群体 UCB 指数中的最大值，选 K 个最高分物品组成 slate，并只更新每个被服务物品对应的获胜 (group,item) 对。

**关键结果**

- 理论结果：在 Assumption 4（总体最优 K-slate 对至少一个群体严格次优）下，任何 group-blind K-slate 策略满足 R_total(T) ≥ T(B_G^R − B_pop^K) 且 B_int > B_pop^K，即产生严格 Θ(T) 总 regret；两组质量 2/3 与 1/3 的实例给出 R_total(T) ≥ r Vmax/3 · T，r=min{K,n−K}。
- Goodreads 仿真（n=15, K=1, T=200,000, 5 seeds 平均）：交叉级最终 |regret| 为 Group-Blind 728.4、Intersection-Fitting 513.8、Inner–Outer/Group–Item UCB 均 44.1，显示交叉偏好继承基础群体时池化 UCB 明显降低交叉 regret。
- BoardGameGeek 仿真（n=15, K=1, T=10,000,000, 5 seeds 平均）：交叉级最终 |regret| 为 Intersection-Fitting 36,947.7，Inner–Outer/Group–Item UCB 均 61,128.1，Group-Blind 89,014.4，显示交叉偏好异质时精确交叉拟合更稳。

**收益归因**

- 主要：工业收益未核实；离线整包仿真显示池化启发式在 Goodreads 继承结构下降低交叉 regret，Intersection-Fitting 在 BGG 异质交叉下降低交叉 regret；无线上 A/B 或模块消融，不能归因单模块。
- 次要：Group–Item UCB 以 (group,item) 独立臂允许同一 slate 组合不同群体偏好；Goodreads 交叉级仿真中其 |regret| 低于 Group-Blind 与 Intersection-Fitting，但同数据 K 较大时组级结果可高于 Intersection-Fitting，不能概括为全面更优。
- 次要：Intersection-Fitting 为每个交叉独立估计，避免异质交叉的池化干扰；BGG 交叉级仿真中其 |regret| 低于两种池化启发式，Goodreads 继承结构下则常高于池化，体现偏好结构依赖。
- 次要：Inner–Outer UCB 只用 O((G+1)n) 个群体-物品统计，少于精确交叉的 O(nH)；Goodreads 小目录 K 较大时其组级/常见交叉 regret 可超过 Intersection-Fitting，作者称整组 slate 路由刚性是可能原因，但扩展目录同 K 排序反转，不能作一般结论。

**与你的关联**

- 适用于有重叠人口群体或多属性用户分层的推荐、广告与内容 slate 排序；可迁移到需按群体/交叉评估福利 regret 的 UCB/bandit 探索、重叠群体冷启动统计共享与离线 regret 评估。需具备群体标签和 slate 反馈，并先验证交叉偏好是否可由基础群体继承；不构成线上部署依据。

**风险或局限**

- 仅有 arXiv 预印本与离线仿真证据，无在线 A/B 或生产部署，不能把 regret 降幅外推为工业收益。
- 两种池化启发式无一般 regret 上界；K=1 时二者等价，附录 B.3 构造实例可产生线性群体 regret，其优势依赖偏好结构。
- 实验仅覆盖 n=15/72、K=1/3/5，且 B_G^R=B_int（人口身份为唯一用户特征），未检验交叉内个体信息缺失造成的不可约总 regret；Goodreads 用 Lancaster 合成估值，BGG 过滤通用热门物品，真实群体结构与偏好异质性可能不同。


## 训练优化与蒸馏

### P1｜[University of Illinois Urbana-Champaign、Shopify、Amazon等｜TINTCF｜Time Will Tell: Harness Time to Denoise Collaborative Filtering](https://arxiv.org/abs/2411.09181)

**论文、机构与场景**

- **机构：University of Illinois Urbana-Champaign、Shopify、Amazon、Alchedata AI**
- 作者：Xinyu He、Jose Sepulveda、Mostafa Rahmani、Alyssa Woo、Fei Wang、Hanghang Tong
- 来源：arXiv:2411.09181v2
- 场景：基于隐式/显式反馈的时序图协同过滤去噪与Top-N推荐
- **论文主要内容：** 针对图协同过滤中隐式反馈噪声，提出时间感知嵌入，并用邻接矩阵重加权与损失重加权两种去噪策略。

**主要创新或优化点**

- 新增机制：时间戳嵌入与用户/物品嵌入相加，使点积同时含全局与时间偏好，并将交互时间用于图协同过滤去噪；TINT-A新增零层时间感知嵌入余弦相似度作可靠性分数，对邻接矩阵软加权/硬剪枝；TINT-L新增时间感知嵌入接入损失重加权，但沿用BOD（梯度匹配去噪基线）的三层多层感知机与梯度匹配交替训练框架，非全新框架；作者消融支持时间信息有助降权噪声边，整包离线收益不能单独归因于某一模块。

**核心方法**

- 时间感知嵌入：将同一时间戳嵌入分别加到用户/物品嵌入，e_t^u=e_u+e_t、e_t^i=e_i+e_t，使点积分解为全局偏好与时间偏好；时间戳按[日,时,分,秒]等离散维度one-hot后经可学习矩阵拼接编码。
- TINT-A（时间感知邻接重加权）：以零层时间感知嵌入的余弦相似度生成交互可靠性分数，按阈值软加权/硬剪枝邻接矩阵；时间戳编码器与简单图对比学习骨干以贝叶斯个性化排序（BPR）、对比学习（CL）和对齐-均匀性（AU）损失联合训练。
- TINT-L（时间感知损失重加权）：沿用BOD（梯度匹配去噪基线）的梯度匹配与交替训练框架，新增时间感知嵌入；用三层多层感知机（MLP）对拼接的用户、物品、时间戳嵌入生成样本权重，重加权BPR/CL/AU损失。

**关键结果**

- 在Tmall与Music4all两个隐式反馈数据集上，作者报告相对8个基线的按指标平均相对提升为12.88%；20%随机噪声下归一化折损累计增益（NDCG）@20相对提升接近20%；结果为4轮随机种子平均。
- 消融显示去掉时间感知嵌入后Tmall上TINT-L的NDCG@10从0.0326降至0.0235（无噪声），在20%噪声下从0.0281降至0.0208。
- 在20%噪声的Music4all上，TINT-L的NDCG@20为0.0654，高于BOD的0.0553；TINT-A为0.0625。

**收益归因**

- 主要：时间感知嵌入的消融支持（作者报告：去掉后TINT-A/TINT-L性能下降）；整包离线收益来自时间嵌入与邻接/损失重加权组合，未独立核实，不能单独归因于某一模块。
- 次要：TINT-A：用零层时间感知嵌入余弦相似度作可靠性分数，在消息传递前软加权/硬剪枝邻接矩阵；属机制解释，未做单模块线上因果验证。
- 次要：TINT-L：把时间感知嵌入接入三层MLP权重生成器，沿用BOD梯度匹配与交替训练；作者称可插拔，未独立复现。

**与你的关联**

- 适用于有交互时间戳的隐式反馈推荐、图协同过滤训练数据去噪；可评估时间感知嵌入与邻接/损失重加权。仅离线结果，线上收益及阈值/损失权重需另行验证。

**风险或局限**

- 实验均为离线公开数据集；噪声通过随机注入20%交互构造，未测试真实恶意攻击、线上A/B或生产部署，不能由离线结果推导线上收益。
- 部分数据集提升有限：ML-100K无噪声上TINT-L的NDCG@10为0.2672、BOD为0.2652；作者仅报告4轮随机种子平均，未提供独立复现。
- 显式反馈数据的时间戳不一定代表真实交互时间；方法只处理用户-物品交互边噪声，未覆盖用户画像或物品属性噪声。


## 今日最值得立项的实验

### SID生成式召回教师-学生多粒度蒸馏离线验证

- 假设：在固定item-SID映射与同一强教师下，叠加HCDA逐层前缀候选组KL对齐与RIGD位置加权蒸馏，可提升轻量学生生成式召回的NDCG@10，且不改变在线约束beam search推理。
- Control：仅用CE与Base KD训练的同架构学生模型。
- Treatment：CE + λ_H·HCDA + λ_R·RIGD 训练同架构学生，教师固定，最后SID位置不参与RIGD。
- 保持变量：同一教师模型与候选集、同一item-SID分词器、同一学生架构（MLP/GRU/CNN之一）、同一训练样本与评估切分、同一beam search参数。
- 离线指标：NDCG@10与Recall@K；HCDA-only、RIGD-only与完整目标的消融对比；蒸馏训练时长与峰值显存
- 线上 Guardrail：在线请求吞吐不低于Base KD；SID映射与beam约束不变导致输出格式一致；蒸馏训练显存与时长在预算内

### 时间感知嵌入去噪在图协同过滤训练中的增益拆分

- 假设：对带交互时间戳的隐式反馈数据，时间感知嵌入与邻接/损失重加权组合能降低噪声边影响，去掉时间嵌入后性能下降。
- Control：无时间嵌入的BOD梯度匹配去噪基线。
- Treatment：TINT-L（时间嵌入+三层MLP样本重加权）与TINT-A（时间余弦相似度软加权/硬剪枝邻接）。
- 保持变量：同一用户-物品-时间交互图、同一注入噪声比例、同一BPR/CL/AU损失配置与训练轮次、同一评估切分与随机种子数量。
- 离线指标：NDCG@10/@20；不同噪声比例下的相对提升；去掉时间嵌入的消融差值
- 线上 Guardrail：无噪声场景指标不显著下降；邻接剪枝后的图规模与训练时长可控；仅在离线评估，不作线上收益承诺
