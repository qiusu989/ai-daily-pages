### P2｜[Distilling Lexical Product Associations into Deep Transformers: An Extreme Multi-Label Approach for Natural Language E-Commerce Search](https://arxiv.org/abs/2609.26921)

**论文、机构与场景**

- **机构：International Institute of Information Technology Bangalore（数据科学与人工智能系）**
- 作者：Sunnidhya Roy, Samarpita Bhaumik
- 来源：arXiv 2609.26921v1
- 场景：电商对话式商品推荐，将商品关联蒸馏进 DistilBERT 并建模为 53,923 类极端多标签分类

**核心方法**

- 将 TF-IDF 累计元数据余弦相似度的 K=50 最近邻物品-物品稠密相似拓扑，用伪标签知识蒸馏为 DistilBERT 深度上下文表征
- 使用 Amazon Reviews '23 中 54,000 商品、27 个均衡零售类目，按精确 85/15 切分出 8,089 个留出商品，并强制自身排除
- 摘要称分析 >10^6 商品规模下极端分类投影层的架构与内存扩展权衡，并给出向双塔向量检索的部署路径

**主要创新或优化点**

- 把词法物品关联蒸馏进深度编码器，用 XMLC 形式缓解电商搜索的词汇不匹配问题，并讨论向双塔向量检索迁移，属于排序/召回表征训练侧的技术进展。

**关键结果**

- DistilBERT 学生模型在留出集达 P@1=93.15%、P@5=90.08%、NDCG@10=0.8845、MRR@10=0.9545
- 修正后的 TF-IDF 教师上限为 P@1=98.10%、NDCG@10=0.9419、MRR@10=0.9882
- 摘要称跨十类自然语言查询原型的定性基准中，Transformer 学生显著超越关键词匹配并解析隐含意图
- 完整数据未在摘要给出

**收益归因**

- 主要：未核实
- 次要：蒸馏
- 次要：serving_efficiency

**与你的关联**

- 与电商搜广推链路的商品表征与语义召回相关，蒸馏思路可迁移到候选生成或粗排阶段的语义召回；但当前证据为摘要级离线结果。

**风险或局限**

- 仅有摘要级证据，未核验 PDF 正文、超参与数据集划分细节
- 无在线 A/B 或生产部署数据，离线 P@1 等指标不能外推至线上收益
- 摘要中的定性查询基准未给出具体数字与评测协议
- 教师为 TF-IDF 词法模型，蒸馏目标本身可能继承词法偏差

### P2｜[A Systematic Benchmark of Explainable Methods for Temporal Attribution in Sequential Recommendation Systems](https://arxiv.org/abs/2609.27201)

**论文、机构与场景**

- **机构：Capital One, AI Foundations**
- 作者：Akash Pandey, Kanisha Shah, Addrish Roy, Dwipam Katariya, Hongyangyang Shi, Amanda Ding, Kalanand Mishra, Pranab Mohanty
- 来源：arXiv 2609.27201v1
- 场景：序列推荐中时间归因可解释性方法的系统性评测

**核心方法**

- 提出双模型掩码指标：一个模型给出逐时间步归因分数，另一个单独训练的掩码鲁棒探针测量预测概率变化，以此衡量解释忠实性。
- 在 CNN、Transformer、SASRec、BERT4Rec 四种骨干网络上评测十种 XAI 方法。
- 数据集为 KuaiRand 与 MovieLens，并补充时间归因模式、物品流行度混杂与输入扰动鲁棒性分析。

**主要创新或优化点**

- 为序列推荐的可解释性方法提供统一的忠实性评测协议与实证结论，指出注意力权重不可靠，对模型审计与推荐理由生成有参考价值。

**关键结果**

- 梯度类方法（GradientSHAP、Integrated Gradients）给出最忠实且稳健的归因。
- 原始注意力权重不可靠
- 梯度加权注意力在短序列上恢复忠实性，长序列上随 softmax 注意力概率趋于均匀而退化。
- 忠实方法的归因模式反映真实任务结构，而非近因或流行度偏差。

**收益归因**

- 主要：为序列推荐解释方法的忠实性提供可复用的双模型掩码评测协议与选型结论
- 次要：模型审计
- 次要：推荐理由生成

**与你的关联**

- 若需为短视频/电商推荐提供归因解释或做模型审计，可作为方法选型与验证协议的参考，但不直接改动召回、粗排或精排链路。

**风险或局限**

- 评测限于离线数据集 KuaiRand 与 MovieLens，无线上 A/B 或生产部署证据。
- 未披露作者机构，归属与工业环境适用性无法核实。
- 仅覆盖 CNN/Transformer/SASRec/BERT4Rec 四类骨干，结论向其他架构迁移需验证。

### P1｜[Offline A/B Testing of Slate Recommendation Systems with LLMs: Reducing the Dependency on Pre-Collected User Interaction Data](https://arxiv.org/abs/2511.04541)

**论文、机构与场景**

- **机构：Mila（Quebec AI Institute）、Université Laval、CIFAR AI Chair（首页 affiliation 与通讯邮箱 @ulaval.ca 一致）**
- 作者：Baptiste Bonin、Maxime Heuillet、Audrey Durand
- 来源：arXiv:2511.04541v2（cs.IR）
- 场景：slate 推荐系统（歌单、新闻流等）的离线合成 A/B 测试与 RecSys 候选排序

**核心方法**

- 方法：用 LLM 作合成评估器 f，输入用户历史与两个 slate，输出成对偏好（0 偏好 L、1 偏好 L'、0.5 平局），替代人工偏好喂入统计模型。
- 排序：合成偏好用广义 Rao-Kupper 模型做极大似然拟合，得到各 RecSys 候选强度 ξ、归一化分差矩阵 Z 与边际置信区间，据此恢复候选排序。
- 验证协议含两轴：外部一致性（与 nDCG/多样性/新颖性/惊喜度线性标量化经验效用对齐）与内部一致性（反自反、非对称、传递性偏好公理）
- 集成 M=6 多数投票，半数以 (L,L')、半数以 (L',L) 查询以消位置偏差。

**主要创新或优化点**

- 把 LLM 当作可套统计模型的合成用户偏好来源，插入 off-policy 评估与线上实验之间的筛选层，探讨离线评测对日志曝光/倾向数据的替代路径。

**关键结果**

- 在 SPOTIFY 与 MIND 上（K=10、N=100 用户、C=6 个 RecSys），LLM 集成正确率与 |效用差| 呈显著负相关，Spearman ρ∈[-0.69,-0.50] 且 p<0.001，投票置信度可作可靠性信号。
- DeepSeek-Math 外对齐原始精度最高 0.66，但反自反性近零（把 slate 判为劣于自身）导致累计分下滑
- 集成 M=6 相比单查询在每个模型至少提升 1.0 累计分，温度多样化增益最大。
- 排序实验：LLM judge 在 Accuracy/Uniform/Diversity 三种效用权重下 Kendall τ∈{0.00,+0.40,+0.40}（波动 0.40），IPS 与 PI 从 +0.80/+1.00 反转为 -0.40/-0.20（波动 1.20）
- 主实验仅 15 对比较，τ 绝对值 p∈[0.08,1.00] 不显著。

**收益归因**

- 主要：作为 offline evaluation 与线上 A/B 之间的筛选层，减少进入线上实验的候选数量并降低对候选日志曝光/倾向数据的依赖（作者主张，未线上验证）。
- 次要：给出 LLM judge 配置经验：M=6 位于精度-成本拐点、温度多样化优于 prompt 多样化
- 次要：由 Z 分差矩阵经 KPCA 得到候选不可区分性几何，可用于裁剪冗余候选、优先做有信息的比较

**与你的关联**

- 对搜广推离线评测链路直接相关：给出 LLM-as-judge 评测协议、偏好公理校验与投票置信度校准的可复现实验设计，可作为线上 A/B 前的预筛选思路。

**风险或局限**

- 未做真实在线 A/B
- 作者明确其为筛选层而非替代，尚需线上实验验证合成偏好能否恢复人类观测排序。
- 主排序实验仅 C=6 个候选、15 对比较，Kendall τ 绝对值不显著（p∈[0.08,1.00]），扩展到 C=30 才出现显著性。
- 方法要求 item/slate 可渲染为自然语言文本，对纯 ID/embedding、无语义描述的工业管线不适用（需额外 item 特征化）。


### P2｜[The Recall Ceiling of LLM Recommendation Reranking](https://arxiv.org/abs/2609.27953)

**论文、机构与场景**

- **机构：University of Southern California, Viterbi School of Engineering**
- 作者：Zhaohui Wang
- 来源：arXiv 2609.27953v1
- 场景：LLM 推荐重排的离线评测协议与召回天花板分析

**核心方法**

- 指出 oracle 评测协议（把 ground-truth 注入候选或对采样负例打分）在三个 Amazon 主数据集上高估真实 NDCG@10 达 92–95%
- 提出召回天花板不等式：留一评估下 E[NDCG@k] ≤ Recall@|Wπ|，Wπ 为重排器候选窗口
- 提出 Recall-Aware Evaluation Protocol（RAEP）：先判定检索召回区间，再在存在区分空间的区间内评估重排

**主要创新或优化点**

- 把 LLM 重排的收益多数归因于 oracle 候选注入而非模型能力，说明低召回区间下提升检索比升级重排器更关键，对推荐评测协议设计有直接影响。

**关键结果**

- 在三个域八个数据集上，真实检索在 K=100 时仅覆盖 2–19% 的相关物品，决定任意闭候选重排器的 top-k NDCG 上界
- 在真实检索下，提示工程、168 倍参数规模扩展、序列模型、监督神经重排、LoRA 微调、混合检索、score-aware prompting、LLM+CF 融合均未在主 Amazon 数据集上显著优于协同过滤基线
- 文本感知检索在一个数据集上提升召回，但端到端 NDCG 未提升
- 提供上游 CF 分数主要使 LLM 复现 CF 顺序

**收益归因**

- 主要：评测协议与召回上界约束，可校正 LLM 重排收益归因
- 次要：检索侧投入优先级判断
- 次要：离线评估指标校准

**与你的关联**

- 可直接用于校正当前 LLM 重排/评测流程中的候选注入式评估偏差，并指导在低召回区间优先投入检索侧优化。

**风险或局限**

- 结果为离线离线复现与留一评估，未提供线上 A/B 或生产系统验证
- 仅在 Amazon 公开数据集上测得，召回区间与结论未必外推到高召回、富特征或在线反馈的生产系统
- 仅摘要级证据，未核验 PDF 正文与机构信息


### P2｜[Tie Handling Is Part of the Evaluation Protocol: An Order-Invariance Audit for Tie-Heavy Recommender Scores](https://arxiv.org/abs/2609.26977)

**论文、机构与场景**

- **机构：四位作者均标注 Independent Researcher，邮箱为 gmail.com 公共域名，无法推断所属机构**
- 作者：Chengkun Guo、Han Chen、Yilin Zhu、Yingrui Li
- 来源：arXiv:2609.26977v1（FRAME'26 Workshop @ RecSys 2026，已接收版本）
- 场景：离线采样 top-k 推荐评测中精确分数平局对 NDCG/Hit Rate 的影响审计

**核心方法**

- 方法：保持每行候选物品、标签与分数不变，仅更换平局处理规则
- 候选行按“相关物品在前 + 30 个采样负例”构造，稳定排序沿用输入顺序，使相关物品赢下所有平局。
- 形式化 row-order invariance：在不改变物品身份、标签与分数的前提下置换输入候选会改变最终排序，则该评测器不满足该性质
- 确定性 hash 平局（种子 + user ID + item ID，item ID 兜底）满足该性质。
- 推导相关物品在平局块内均匀随机排列时的 E[Hit@k] 与 E[NDCG@k] 解析公式，并给出六项报告清单：候选集、排序前候选顺序、平局比例、平局规则、置换检验、敏感性分析。

**主要创新或优化点**

- 证明离线采样式 top-k 评测中平局规则是未声明的排序特征：同一候选与分数下 NDCG@10 可相差约 0.55–0.68，会直接扭曲模型对比结论与可复现性。

**关键结果**

- Amazon Beauty & Personal Care 30,000 行：评分加权属性重叠分 NDCG@10 由输入顺序平局的 0.8474 降到 hash 平局的 0.1702，Hit@10 由 0.9997 降到 0.3526
- 99.94% 的行存在跨越 top-10 边界的平局。
- MovieLens 25M + Tag Genome：标签-属性重叠分 NDCG@10 由 0.8380 降到 0.2332，Hit@10 由 0.9390 降到 0.4358
- item popularity 几乎不变（0.5905→0.5905）。
- 均匀随机平局下的解析期望 0.1693 与 100 个独立 hash 种子均值 0.1694±0.0012 接近
- 残差化 Amazon 分数仅 0.39% 行存在精确平局，NDCG@10 变化 0.0004。

**收益归因**

- 主要：离线评测协议的可复现性与指标有效性；线上收益未核实
- 次要：降低实验对比中的假阳性提升
- 次要：提供可落地的评测报告清单与置换检验方法

**与你的关联**

- 对搜索/推荐/广告团队：需在离线评测协议中显式规定并报告平局处理（确定性 hash 或平局期望），并做置换检验，避免评测器实现差异导致的错误选型结论。

**风险或局限**

- 仅覆盖两个公开数据集、单相关物品、30 个采样负例的离散属性分数，未估计该问题在真实 benchmark 或生产系统中的发生频率与量级。
- MovieLens 只保留聚合结果，行级候选与分数数组缺失，无法做行级与置换分析
- 全目录评测未做实证。
- Amazon 属性为词法元数据代理，分数族作为组件而非完整生产推荐模型评估，结论不能直接外推到线上系统。

## 今日最值得立项的实验

### 离线评测平局处理规则对排序结论的影响审计

- 假设：在候选分数存在跨 top-k 边界平局的采样式评测中，平局规则（输入顺序 vs 确定性 hash）会显著改变 NDCG@10/Hit@10，进而改变模型选型结论。
- Control：沿用当前评测器默认稳定排序（平局沿用输入顺序，等价于相关物品赢下平局）。
- Treatment：改用确定性 hash 平局（种子+user ID+item ID，item ID 兜底），并补充均匀随机平局期望与置换检验。
- 保持变量：候选物品、标签、分数、负例采样数量与切分、top-k 取值、指标计算代码路径保持一致。
- 离线指标：同一候选与分数下 NDCG@10 与 Hit@10 在两种平局规则下的差值；存在跨 top-k 边界平局的行占比；置换检验下排序是否改变（row-order invariance）
- 线上 Guardrail：评测耗时增量与存储增量在离线预算内；修正后模型 A/B 排序结论不变时不触发线上配置变更；报告需显式列出候选集、平局比例与平局规则

### LLM 重排评测的召回天花板校准与候选注入偏差检查

- 假设：若上游检索在 K=100 下相关物品覆盖率很低，则任何闭候选重排器的 top-k NDCG 上界受 Recall@窗口 约束，oracle 式候选注入会系统性高估重排收益。
- Control：沿用现有 oracle/候选注入式 LLM 重排评测协议（ground-truth 注入或对采样负例打分）。
- Treatment：改为先测检索召回区间，再在存在区分空间的区间内评估重排，并显式报告 E[NDCG@k] ≤ Recall@|Wπ| 的上界。
- 保持变量：同一数据集与用户切分、同一重排提示词与模型、同一候选窗口大小、同一 NDCG@10 计算口径。
- 离线指标：真实检索 Recall@100 与 oracle 注入 Recall@100 的差距；两种协议下 NDCG@10 的差值；重排相对协同过滤基线的显著性
- 线上 Guardrail：不因评测改动直接调整线上召回或重排模型；低召回区间结论不用于否决重排模型上线；仅在离线报告层标注评测偏差

### LLM 合成偏好筛选层的候选排序恢复能力预研

- 假设：以 LLM 集成多数投票生成成对偏好、经广义 Rao-Kupper 拟合得到的候选排序，与基于日志倾向数据的 off-policy 排序在足够比较对数下方向一致。
- Control：现有基于日志曝光与倾向数据的 off-policy / IPS 候选排序流程。
- Treatment：在候选排序前插入 LLM judge 合成偏好层：M=6 集成、半数查询交换 (L,L') 顺序、温度多样化，经 Rao-Kupper 拟合候选强度并输出归一化分差矩阵。
- 保持变量：候选 RecSys 集合与版本、用户切分、slate 展示内容与顺序生成方式、统计模型与置信区间算法。
- 离线指标：LLM 合成排序与 off-policy 排序的 Kendall τ；LLM 集成正确率与 |效用差| 的 Spearman 相关；偏好公理通过率（反自反、非对称、传递性）与投票置信度校准
- 线上 Guardrail：比较对数不足或 τ 不显著时不得作为线上筛选依据；仅要求 item/slate 可渲染为自然语言文本的候选进入该流程；LLM 调用成本与延迟在离线预筛预算内


## 一句话总判断

本期 6 篇集中在评测与评估侧：两篇（Recall Ceiling、Tie Handling）从召回上界与平局规则两个角度指出离线评测协议本身会系统性扭曲 LLM 重排与模型对比结论，其中 Tie Handling 有 PDF 核验的实测差异，是当前最可落地的方法趋势。评测工程上的直接含义是：在讨论 LLM 重排或新模型收益前，应先固定候选集、召回区间与平局处理规则并做置换检验与上界报告，否则指标差异可能来自协议而非模型能力。召回与精排正文侧本期仅摘要级证据，不构成部署依据。
