## 跨阶段协同与工业效率

### P2｜[Personalized and Multi-View Representation for Federated Cold-Start Recommendation](https://arxiv.org/abs/2608.27826)

**论文、机构与场景**

论文身份：arXiv 2608.27826v1，标题为 Personalized and Multi-View Representation for Federated Cold-Start Recommendation，作者来自 POSTECH 和 Korea University 等韩国机构，面向联邦推荐中的冷启动物品场景。

**核心方法**

核心方法：提出 PMFRec，学习个性化表示生成器从属性特征生成用户特定物品表示，并用全局多视图编码器（item-adaptive gating + 正交目标）捕获互补语义视图、降低冗余；系统设计：将协同与属性知识融合进单一交换的物品表示，消除客户端显式正则化，减少通信开销；实验验证：在真实数据集的冷物品推荐上优于强基线，并改善用户级公平性、热场景适应性和 LDP 下的鲁棒性。

**主要创新或优化点**

该工作为联邦推荐在冷启动场景下提供了新的个性化多视图表示方法，融合属性和协同知识于单一表示，提升效率并兼容隐私约束，对隐私敏感型推荐系统有参考价值。

**关键结果**

在冷物品推荐任务上一致优于强基线（具体指标未在摘要中量化）；相比现有联邦冷启动方法，训练和通信效率更高；在本地差分隐私（LDP）下表现出鲁棒性，并提升用户级公平性。

**与你的关联**

涉及推荐系统冷启动和联邦学习，与工业搜广推中隐私保护下的物品冷启动场景有相关性，但未直接面向短视频/直播/电商广告的主链路。

**可信度**

technical_report

**风险或局限**

摘要未提供具体实验数据，性能增益幅度不明；未说明实际数据集规模与工业部署验证；未能验证在广告或电商场景中的直接适用性。


## LLM 增强与对话推荐

### P2｜[REPREC: Representation Driven Parameter-Efficient Recommendation System](https://arxiv.org/abs/2607.24845)

**论文、机构与场景**

REPREC 是 arXiv 论文 2607.24845v4，机构未披露，面向序列推荐的 LLM 轻量框架，通过用户级表示条件化冻结 LLM

**核心方法**

REPREC 用 MLP 注入器将冻结序列编码器的定长嵌入映射为少量学习软 token，仅训练注入器，冻结两个预训练主干；相比 v3，v4 明确以冻结 LLM 为设定，新增对多个序列编码器和 LLM 骨干的扩展实验，训练速度提升从 1.51X 改为平均 1.50X，性能保持从 85-100% 改为 94-99%

**主要创新或优化点**

提供参数高效的 LLM 序列推荐方案，不需微调 LLM，降低部署成本，短历史训练可加速，适合工业级应用

**关键结果**

短历史训练长上下文评估保留全历史性能 94-99%，每轮训练平均加速 1.50X；在不同序列编码器、LLM 骨干和用户活跃度下一致提升推荐性能；仅训练 MLP 注入器，训练和推理计算高效

**与你的关联**

与搜广推 LLM 增强精排相关，但未涉及广告或线上 A/B，可作为精排 LLM 增强的候选方法参考

**可信度**

technical_report

**风险或局限**

具体数据集和基线未详述，无法核实性能提升幅度；未提供工业 A/B 或系统数字，结论基于离线实验；冻结 LLM 的软 token 注入可能受限于 LLM 上下文长度，长历史场景未充分验证


## 出价与竞价机制

### P2｜[Budget-Constrained Causal Bandits: Bridging Uplift Modeling and Sequential Decision-Making](https://arxiv.org/abs/2604.26169)

**论文、机构与场景**

arXiv 预印本 2604.26169v2《Budget-Constrained Causal Bandits》，作者 Abhirami Pillai，邮箱 arp220005@utdallas.edu 指向德克萨斯大学达拉斯分校；场景为数字广告预算约束下的增量效果（uplift）用户投放分配。

**核心方法**

BCCB 将在线双模型 HTE 估计、Thompson 采样式乐观探索与自适应预算 pacing 结合，对每个到达用户计算 (τ̂(x)+探索项)/c 并与影子价格阈值比较，决定是否展示广告；该逐用户规则由预算因果分配目标拉格朗日松弛的 KKT 条件导出；在 Criteo Uplift 数据（10万用户评估流、20 seeds）上，离线两阶段管线在 n=7,500 历史样本处开始显著反超 BCCB（paired one-sided t-test p=0.043），n≥15,000 后 p<0.001；作者自述局限：成本为合成 LogNormal 而非真实竞价成本，HTE 模型为线性分类器，未提供 regret 界；硬预算约束由可行性检查单独保证，理论最优性仅针对期望预算松弛。

**主要创新或优化点**

首次给出离线 uplift 分配与在线因果 bandit 之间数据效率交叉的经验检验证据，提供约 7,500 历史样本的切换阈值，让冷启动广告、新市场或新客群可直接选择在线范式并兼顾预算约束与低波动。

**关键结果**

BCCB 在 $1,000-$8,000 五档预算下转化数均最高，$8,000 时较 Uplifting Bandits 为 63.5 vs 35.7（+78%，p<0.001），其余在线基线也均 p<0.001；数据效率交叉点：n=7,500 时离线开始反超（p=0.043），n=10,000 时 p=0.004，n=50,000 时离线转化约为 BCCB 的 2.2 倍；运行稳定性：BCCB 转化数标准差为 16.2，离线管线在 2,000-50,000 训练样本下为 37.8-58.7，波动低 2.3-3.6 倍。

**与你的关联**

与搜广推广告侧相关，可用于冷启动 campaign 的预算受限用户选择与 pacing，为离线/在线投放范式选择提供可执行阈值；不直接解决物料召回或精排。

**可信度**

technical_report

**风险或局限**

历史样本超过约 7,500 后离线管线转化更高，BCCB 的适用优势集中在冷启动/数据不足场景；实验成本为合成的 LogNormal 分布而非真实竞价成本；replay 协议下各方法有效样本量不等，跨方法比较部分受 ESS 混淆；HTE 估计仅用线性分类器，预算 pacing 为启发式且无 regret 界，Proposition 1 只对期望预算松弛成立。


## 精排与排序

### P2｜[SG-UMP: Sequence-Guided Universal Multimodal Prioritization Calculation Framework](https://arxiv.org/abs/2608.28503)

**论文、机构与场景**

SG-UMP 是 arXiv 论文 (2608.28503v1)，作者 Xinyi Zhang、Yutong Li、Peijie Sun，机构未披露。

**核心方法**

SG-UMP 是用于多模态序列推荐 (MSR) 的即插即用插件，包含模块组合器和模块路由器，动态调整模块顺序；SG-UMP 在四个真实数据集上验证，旨在适应不同用户偏好和数据集模态偏差；代码公开在 GitHub (esemsc-xz524/SG-UMP)。

**主要创新或优化点**

提出面向多模态序列推荐的通用插件框架，通过动态模块排序解决用户级偏好异质性和数据集级模态偏差，可能提升多模态推荐系统的跨场景适应能力。

**关键结果**

在四个真实数据集上一致提升推荐性能，覆盖不同骨干网络和多模态设置；具体性能提升数值未在摘要中披露；模块组合器和模块路由器实现动态模块排序，适应数据集特征。

**与你的关联**

属于多模态推荐方向，与搜广推的多模态表征处理相关，但未聚焦工业级链路。

## CV 与多模态

### P2｜[Information-Guided Selective Modality-Interest Alignment for Multimodal Recommendation](https://arxiv.org/abs/2608.27950)

**论文、机构与场景**

该论文提出 AMUR 框架，用于多模态推荐，作者机构未在摘要中明确披露，但代码在 GitHub 上提供。

**核心方法**

AMUR 通过信息论视角选择性对齐用户兴趣相关的模态信号，并抑制弱对齐信号，包含图结构细化和跨模态共享语义对齐；论文在三个真实世界数据集上进行实验，对比多个基线，展示有效性。

**主要创新或优化点**

多模态推荐中模态选择与兴趣对齐缺乏明确目标，AMUR 提供信息引导的选择性对齐方法，可能提升推荐效果。

**关键结果**

在三个真实数据集上，AMUR 优于竞争基线，但具体数值未在摘要中给出。

**与你的关联**

对于多模态推荐场景，尤其是涉及图像和文本内容的短视频或电商推荐，可能提供改进思路。

## 今日阅读顺序

- Budget-Constrained Causal Bandits：唯一有 PDF 核验且证据最强的广告侧论文，提供冷启动预算约束投放与离线/在线切换阈值（约7,500样本），直接可用于广告 pacing 与用户选择，价值最高。
- [REPREC: Representation Driven Parameter-Efficient Recommendation System](https://arxiv.org/abs/2607.24845)：与 LLM 增强精排相关，冻结 LLM 仅训练注入器，大幅降低部署成本，短历史训练加速1.5X，适合工业评估。
- [SG-UMP: Sequence-Guided Universal Multimodal Prioritization Calculation Framework](https://arxiv.org/abs/2608.28503)：多模态序列推荐即插即用插件，动态模块排序，与短视频多模态链路相关，代码开源，值得深读。
- PMFRec: Personalized and Multi-View Representation for Federated Cold-Start Recommendation：冷启动+联邦+跨阶段共享表征，与隐私保护和物品冷启动相关，虽非主链路但方法可借鉴。
- AMUR: Information-Guided Selective Modality-Interest Alignment：多模态兴趣选择对齐，与电商/短视频内容理解相关，但证据较泛，优先级靠后。

## 今日最值得立项的实验

### 冷启动广告预算受限投放：在线因果bandit vs 离线uplift分配

- 假设：在历史样本小于约7,500时，在线BCCB式pacing比离线uplift模型转化更高且波动更低；样本充足后离线反超。
- Control：离线 uplift 两阶段管线（先训练HTE模型再预算分配）。
- Treatment：在线BCCB：Thompson采样式乐观探索+自适应预算pacing，按 (τ̂(x)+探索项)/c 与影子价格阈值决策。
- 保持变量：同一广告主预算档位（如$1k-$8k）、同一用户特征集、同一Criteo Uplift数据（10万评估流，20 seeds）。
- 离线指标：转化总数；数据效率交叉点（约7,500样本时的p值）；运行波动（转化数标准差）
- 线上 Guardrail：预算约束可行性检查（每轮不超预算）；使用真实竞价成本而非合成LogNormal成本；报告有效样本量差异（ESS）以避免混淆

### LLM 精排参数高效适配：冻结LLM+软token注入

- 假设：仅训练小型注入器将序列编码器嵌入映射为软token，可保留全历史性能94-99%，训练加速约1.5X，适合工业LLM推荐部署。
- Control：全参数微调或LoRA微调的LLM序列推荐模型。
- Treatment：冻结序列编码器与LLM，仅训练MLP注入器生成少量软token条件化LLM。
- 保持变量：相同用户历史序列、相同LLM骨干（如7B）、相同评估数据集与基线配置。
- 离线指标：推荐命中率/NDCG@K；训练时间（每轮）；推理延迟
- 线上 Guardrail：长历史场景下的性能不退化监控；注入器参数量限制（例如<LLM参数的1%）；与现有精排链路的兼容性测试

### 多模态表征动态路由：模块顺序自适应

- 假设：按用户偏好和数据集模态偏差动态调整多模态模块顺序，比固定顺序提升冷启动跨域推荐效果。
- Control：固定模块顺序的多模态序列推荐模型。
- Treatment：SG-UMP即插即用插件：模块组合器+模块路由器动态选择模块顺序。
- 保持变量：相同骨干网络、相同多模态特征（文本/图像/交互）、相同数据集划分。
- 离线指标：推荐命中率/召回率提升；跨数据集适应度（按模态偏差分组）
- 线上 Guardrail：计算开销增量控制（路由器额外时延）；在弱模态对齐场景下的稳定性验证


## 一句话总判断

本期方法趋势：多模态与跨阶段表征复用（SG-UMP、PMFRec、AMUR）热度上升，LLM 增强向参数高效方向发展（REPREC），广告侧注重因果与预算约束结合（BCCB）。工程判断：REPREC 与 BCCB 证据较扎实，值得试点；多模态插件仍缺定量细节，需深读后再定。
