## 生成式召回

### P0｜[快手、复旦大学、Unaffiliated｜AGR: Agentic Generative Retrieval with Tool-Augmented Search](https://arxiv.org/abs/2610.26831)

**论文、机构与场景**

- **机构：复旦大学、快手科技、Unaffiliated**
- 作者：Ming Yang, Yaqi Yin, Zhibo Wang, Xiaoze Jiang 等
- 来源：arXiv:2610.26831v1
- 场景：快手搜索的生成式召回与异构特征按需注入
- **论文主要内容：** 将异构特征封装为工具，在SID解码中按需调用并注入观测，解决生成式召回的静态特征注入问题。

**主要创新或优化点**

- 针对生成式召回中静态特征注入的两个瓶颈：特征效用随请求变化、固定方案无法匹配 SID 的粗到细层级；AGR 将特征封装为工具，在解码 prefix 条件下决定是否调用、调用哪个工具，并用观测 token 重塑后续 SID 分布，使注入同时具备请求自适应和层级自适应。
- 为使工具调用可监督，AGR 不依赖人工指定调用位置：用正样本判断工具是否适用，并以特征在 SID 前缀下判别度 ρ 的增益选择插入深度；再用 SID 预训练加工具增强微调，配合按步缩放工具 token loss，避免新 token 破坏已学 SID 语义。
- 推理侧把工具调用纳入 trie beam search，每条 beam 独立配额并在活跃/完成路径间按长度归一化分数比较；相对直接拼接 400 个 GSU token，工具化序列特征在保持接近 Recall@50 的同时大幅降低训练与 serving 成本，并已用于 35ms 线上搜索。

**核心方法**

- AGR 将工具 token 和观测 token 加入词表，使 SID 生成与外部特征获取在同一自回归解码过程中交错；工具 token 只作决策触发，观测 token 以独立位置编码注入且不推进 SID 深度。
- 训练数据按“是否适用、插入何处”构造：结构化工具要求请求侧抽取与正样本属性一致且输入中未出现，序列工具用 Vote 命中下一 SID；插入深度取 SID 层级中特征判别度 ρ 增益最大处，再用 SID 预训练和工具增强微调及自适应 loss 缩放训练。
- 推理采用工具增强的 trie beam search：每条 beam 维护独立工具调用配额 M，可在未完成 SID 深度选择合法 SID 后继或工具，最终按长度归一化分数比较并移除工具 token 还原 SID 输出空间。

**关键结果**

- 工业数据离线：AGR 的 Recall@50 为 0.3264，TIGER 为 0.2863，相对提升 +14.01%；MRR@50 为 0.2699 对 0.2254，相对 +19.74%，配对 bootstrap 检验 p<0.05。
- 三个公开基准：Qilin、JDSearch、KuaiSAR 的 Recall@50 相对 TIGER 分别提升 +6.71%、+8.32%、+9.64%，并在各 cutoffs 上优于 TIGER、UniSearch、GLASS 与 GEMs。
- 线上 A/B：7天A/A后7天A/B，AGR与基线各10%流量；相关度 +0.205% [0.12,0.28]，改写率 -0.690% [-1.13,-0.20]，搜索渗透率 +0.060% [0.03,0.14]，服务延迟 35ms。

**收益归因**

- 主要：按需调用特征工具减少全量静态注入的噪声和 serving 成本，并让特征在 SID 解码的合适深度影响生成，提高召回与请求特征的一致性。
- 次要：工具化序列特征把长行为序列压缩为单个观测 token，相比直接编码 400 个 GSU token，训练时间降低 81.8%、每千请求 serving GPU 降低 42.9%，Recall@50 0.3237 接近 0.3241。
- 次要：prefix 条件工具调用和自适应插入位置把特征影响集中到最判别层级，消融显示自适应注入 Recall@50 0.3264，高于固定位置 0.3174 和 query-guided gating 0.3161。
- 次要：工具增强 beam search 保持 SID-only 输出空间，可按 beam 独立配额调用，并以 35ms 服务延迟支持线上部署。

**与你的关联**

- 与生成式召回、SID 解码和异构特征 serving 直接相关；可按需工具调用、插入位置选择和 beam 集成方式可迁移，但线上收益需按自身流量复核。

**风险或局限**

- 工具调用监督由预定义规则和 golden SID prefix 构造，与自由运行推理时由模型生成 prefix 存在 exposure gap，且尚未用强化学习优化调用策略。
- 工具生态仅覆盖意图、位置、时效和行为序列等少量类型，跨域、更多工具及工具选择冲突下的扩展性未验证。
- 线上 A/B 的绝对增益较小且仅覆盖 10% 流量；论文为 arXiv 预印本，尚无同行评审或独立复现。


### P0｜[Entertainment Group、电子科技大学、中国科学技术大学等｜SPAR: Stepwise Personalized Autoregressive Recommendation with Prefix-Balanced Semantic IDs](https://arxiv.org/abs/2610.27898)

**论文、机构与场景**

- **机构：电子科技大学、中国科学技术大学、HUJING Digital Media & Entertainment Group、西南交通大学**
- 作者：Chunrui Zhang、Gaoyun Lin、Chang Zhou、Zheng Hu、Qiran Song、Shimin Cai、Tao Zhou
- 来源：arXiv:2610.27898v1
- 场景：优酷首页视频推荐中的 SID 生成式召回
- **论文主要内容：** 针对SID生成推荐逐步个性化不足与分支负载失衡，提出PATH解码器、RQ-PIB构造及偏好对齐。

**主要创新或优化点**

- 针对 SID 解码中固定用户表征难以随前缀变化的问题，PATH Decoder 按 SID 深度构造粗到细长期历史视图，用 Q-Former 压缩为记忆库，并以当前解码状态和已生成前缀做 cross-attention 读取，再把近期行为、画像与事件上下文融入每一步 token 决策。
- 针对同一父前缀下兄弟分支历史交互负载不均衡、全局码字均衡忽视局部热度的问题，RQ-PIB 在残差 K-Means 冻结码本后按父前缀设负载上限，以最小重构失真增量贪心迁移物品，尽量保留语义结构并压低局部主导分支。
- 将 beam search 候选经冻结排序模型构造偏好对，联合 SFT 与 DPO 做偏好对齐，使生成器在保持下一物品监督的同时偏向近期请求偏好，并与 SID 构造、逐步记忆读取组合成统一生成式召回框架。

**核心方法**

- PATH Decoder 将长期历史按 SID 深度构造成粗到细视图，用共享 Q-Former 与各视图 query 压缩成记忆库；解码时以近期 SID 序列和已生成前缀为 query 做 cross-attention 取回前缀相关证据，再融合画像 User Token、事件 Event Token 预测下一 SID token。
- RQ-PIB 先用残差 K-Means 学习并冻结各层语义码本，按父前缀统计兄弟分支历史交互负载并设每前缀上限，在超载分支中反复迁移增加重构失真最小的正权重物品到可行子分支，直至满足上限并保留有效 trie。
- 训练分 SFT 与偏好对齐：SFT 对目标物品三层 SID token 做下一 token 最大似然；DPO 用 trie 约束 beam search 生成候选、由冻结排序模型打分，取 top-M/bottom-M 组成偏好对，联合 SFT 与 DPO 损失更新生成器。

**关键结果**

- 在优酷首页生产日志上，SPAR 相对最强基线 OneRec 的 HR@10/20/50/100 从 0.4648/0.5492/0.5828/0.6013 提升到 0.4831/0.5662/0.5947/0.6108，四个截断平均相对提升 2.66%。
- 7 天线上 A/B 中，SPAR 覆盖优酷约 10% 生产流量，相对生产 Base 将播放转化率提升 3.38%、人均观看时长提升 3.95%、总观看时长提升 3.98%。
- RQ-PIB 在各 SID 层级将流量加权最大子分支占比从 9.8%/36.4%/65.7% 降至 6.4%/23.2%/47.6%，平均相对降低 32.84%。

**收益归因**

- 主要：整包 SPAR 线上 A/B 相对生产 Base 提升播放转化与人均观看时长；单模块线上因果未核实，离线消融仅支持各组件贡献。
- 次要：PATH 逐步记忆读取在离线消融中高于 First-step Reuse，前缀保留改善为整体模型分析；线上单模块因果未核实。
- 次要：RQ-PIB 在离线流量加权最大子分支占比上降低集中度，支持局部均衡机制；线上单模块因果未核实。
- 次要：DPO 在离线消融中提升 HR@1 等截断，且不改 SID 映射与架构；线上单模块因果未核实。

**与你的关联**

- 相关于生成式召回与 SID 分支解码，可用于视频推荐召回阶段的 SID 构造和用户条件解码；线上收益来自优酷首页特定场景与生产 Base，迁移前需复现。

**风险或局限**

- 线上 A/B 为作者在优酷首页、约 10% 流量、7 天的内部实验，未提供独立审计或复现，结论仅限该生产 Base 与短期窗口。
- 离线与消融均基于优酷单场景生产日志；SID 负载权重来自训练期交互计数，论文明确不保证未来曝光平衡，也未讨论冷启动或新物品分配。
- RQ-PIB 为按父前缀的贪心最小失真迁移，作者承认不保证全局最优或严格负载均衡；DPO 还依赖冻结排序模型和 beam 候选质量。


### P0｜[WeGR: Towards Unified Generative Retrieval via Behavior-aware Tokenization and Preference Alignment](https://arxiv.org/abs/2610.16979)

**论文、机构与场景**

- **机构：未披露**
- 作者：Jiajun Han、Guoxin Ma、Felix、Liangsheng Xu、Ruiqi Yu、Yingdi Guo、Zongbing Wang、Xinhua Ye、Chenyan Hua、Xin Xie、Pengcheng Yang、Haijun Wu
- 来源：arXiv:2610.16979v3
- 场景：大规模工业电商搜索的生成式召回与偏好对齐
- **论文主要内容：** 针对工业搜索生成式召回的码本塌缩与奖励稀疏，提出协同感知 SID 分词和动态视野偏好对齐。

**主要创新或优化点**

- CoCo-VAE 将 Q2I/I2I 协同对比约束放在量化前，而非直接约束码本；结合首层 random-restart 变体码本重启，以及样本级多码字保真和码字级碰撞惩罚 FAR，改善协同信息保留与码本使用。
- DHPO 在 GRPO 框架内逐步扩展 SID 奖励匹配与策略更新范围：保持 outcome reward 不变，用前缀匹配奖励计算组相对优势，只更新当前范围内的 token，不依赖辅助奖励模型。
- MSFT 对同会话多个正例 SID 联合监督，在组内奖励差异不足时补充下一 token 学习信号；以上是作者提出的组合与改造，不将 RQ-VAE、GRPO 或随机重启本身视为首次提出。

**核心方法**

- CoCo-VAE 在量化前对 query-item 与 item-item 历史共现做 InfoNCE 对比学习，把协同信号注入连续表征，避免直接在码本上施加协同约束而干扰量化。
- CoCo-VAE 对第一层码本按 EMA 使用量检测死码字，用活跃码字加小高斯扰动重启（random-restart 策略变体）；深层用残差保真项聚合多个相似码字扩大梯度，并以码字分配碰撞正则抑制样本向少数码字集中。
- DHPO 沿 SID 层级逐步扩展 horizon，用前 h 个 token 的匹配奖励计算组相对优势，并只对前 h 个 token 做策略更新；MSFT 对同一会话多个正例 SID 联合做下一 token 监督，在组内奖励差异不足时维持检索能力。

**关键结果**

- 2026-06-22 至 08-04 的线上 A/B 中，V1.2 配置移除其他召回通道 80% 候选后，订单、CTR、CVR 分别相对提升 2.539%、1.508%、1.381%，论文称均 p<0.05。
- 同一 V1.2 配置下，进入粗排的候选数为基线 61.90%（减少 38.10%），CPU/GPU 用量降至 74.5%/73.9%（节省 25.5%/26.1%），平均时延下降 21.7ms。
- 离线 Click/Order 各 20k 测试中，RL 方法均由 CoCo-VAE 初始化；DHPO 的 HR@6 为 0.2810/0.4217，高于 TPMA-GRPO 的 0.2750/0.4133；CoCo-VAE 的 HR@6 为 0.2759/0.4103，高于 SFT 类最强基线 RQ-Kmeans 的 0.2641/0.4051。

**收益归因**

- 主要：整包 V1.2 配置的线上 A/B（WeGR 替换其他召回 80% 候选）带来订单 2.539%、CTR 1.508%、CVR 1.381% 的相对提升，以及 CPU/GPU 与平均时延下降；这属于整包配置收益，不能据此推导单模块因果。
- 次要：离线消融为模块级证据：移除 q2i、i2i、fid、coll、refresh 均降低 HR@6，其中移除码本重启降幅最大（Click 0.2759→0.2371，Order 0.4103→0.3712，作者自述）。
- 次要：DHPO 不引入辅助奖励模型，只改奖励匹配粒度与更新范围；论文另设 GRPO-Ranker 稠密奖励对照，DHPO 仍占优，但未做控制变量拆解各设计的具体作用。
- 次要：线上 CPU/GPU 与时延下降被作者归因于进入粗排的候选减少、逐条特征处理与推理开销降低，并指出资源降幅小于候选降幅源于检索与请求处理的固定开销。

**与你的关联**

- 直接命中生成式召回、SID 分词与 RL 偏好对齐；线上候选压缩、CPU/GPU 与时延收益对工业搜索链路有参考，但为单一平台自述结果，迁移需自行验证。

**风险或局限**

- 线上为作者自述的单一工业电商搜索平台 6 周 A/B，只报告相对变化，未给各指标绝对值、置信区间与具体 p 值，也无公开数据或独立复现；PDF 首页未列出机构名称，正文对平台名做了泛化。

- 作者报告 CAPE 仅增加小部分延迟，但摘要未给出具体延迟数值与硬件配置

**收益归因**

- 主要：利用共现记忆在 beam 外补回长尾候选并以共现证据校准排序，提升长尾准确率
- 次要：保持或改善整体准确率，未以长尾换取头部性能
- 次要：免训练插件形式，可附加于冻结生成器，额外计算仅少量延迟

**论文、机构与场景**

- **机构：University of Amsterdam、Johns Hopkins University**
- 作者：David Vos、Andrew Yates、Maarten de Rijke
- 来源：SIGIR-AP 2026（arXiv:2610.23510v1）
- 场景：新闻文章推荐的首阶段检索/召回

- 候选文章编码与用户无关，可离线预计算并用倒排索引做稀疏内积召回；用户编码仅聚合预计算表示，因而索引远小于未压缩稠密索引，用户侧编码也快于 STAR。

- 效率：MIND 索引 11.33MB 对未压缩 NRMS 208.06MB，EBNeRD 2.41MB 对31.84MB；MIND 用户编码 0.97ms 对 STAR 6.86ms。

**收益归因**

- 主要：主要收益来源为文章独立稀疏编码与注意力用户聚合带来的短历史召回提升，以及稀疏倒排索引的紧凑存储和离线候选预计算。
- 次要：短历史用户召回
- 次要：索引体积压缩
- 次要：用户编码延迟降低
- 次要：用户兴趣词级可检查

**与你的关联**

- 与内容/新闻推荐的首阶段召回和稀疏索引直接相关；可借鉴其短历史用户建模、文章独立编码和倒排索引部署，但需在短视频/电商等非长文本场景验证迁移。

**风险或局限**

- 仅两个公开小规模数据集、离线评测，无在线 A/B 或生产部署证据。

- DS仅用用户特征对历史事件打分并保留Top-K原始记录（生产K=10,000，原始L约100K），记录保留item ID、时间戳与side features，线上请求不执行DS或重扫全序列

- 次要：选择机制与下游骨干解耦：在MLP、RankMixer、MixFormer三种骨干上相对TWIN均有一致离线GAUC增益。
- 次要：部署侧：紧凑记录编码把每条记录压到43字节并给出十亿用户规模存储外推（估算，未实测）；key侧投影吸收避免缓存随历史长度增长。

**与你的关联**

- 与短视频推荐精排的超长行为序列建模直接相关，可借鉴候选无关的用户级选择加目标感知检索的两级预算、教师蒸馏监督与参数复用；线上为作者自报的7天5%流量A/B，且接入的是已含长序列能力的生产系统，迁移需自行验证延迟与成本。

### P2｜[Università degli studi di Bari Aldo Moro、Otto-von-Guericke University、Leibniz Institute for Educational Media｜Decision4Rec: A Jev-Inspired Framework of Decision Models on Knowledge and Active Graphs for Multi-Agent Recommender Systems](https://arxiv.org/abs/2610.26035)

- 次要：模块化接口可一行配置替换Jev/Kev，并用存储答案复算，便于离线对比与更换模型。
- 次要：场景知识图谱与多智能体池可在无训练推荐器时仅用日志给出候选，支持冷启动/新域探索。

**与你的关联**

- 对 LLM 精排/候选池设计有参考：概率化 decision model、知识图谱陈述、多智能体候选池与防泄漏训练记录；但离线学术数据、无工业 A/B，需自行复现验证。

- 所有结果为离线开发测试用户（每域2,000）上的批量流水线，未报告线上A/B或生产部署；ActiveGraph运行时尚未与批量实验对齐。

### P1｜[Technology of China、National University of Singapore、University of Science｜FLMNet: Self-Ensemble Distillation from Masks to Seeds for Single-Tower CTR Prediction](https://arxiv.org/abs/2610.26143)

**论文、机构与场景**

- **机构：National University of Singapore、University of Science and Technology of China**
- 作者：Yifan Wang、Yifei Du
- 来源：arXiv:2610.26143v1
- 场景：推荐/广告单塔 CTR 预测排序
- **论文主要内容：** 针对自集成蒸馏需采样且机理不清，推导无限掩码极限并设计闭式惩罚单塔和跨种子蒸馏。

**主要创新或优化点**

- 已有 FinalNet/QNN 把自集成蒸馏当作经验性辅助损失，未说明其正则对象，且需多次随机 dropout 前向。本文推导无限掩码极限，证明它等价于均值 logit 的标签损失加 mask 间 Jensen 间隙惩罚，普通 dropout 只是 penalty 系数为 1 的特例。
- 为让该极限可训练，作者把 gate 限制为只读未掩码输入，配合仿射读出和坐标级重标定，设计 field-local gate + mixer 的单塔，使均值 logit 有闭式表达、方差可用截断递推近似；训练以高斯代理 + 求积替代采样，保持推理单次前向。
- 进一步把不同随机种子的塔视为另一层集成成员，用池化 logit 蒸馏把 seed 噪声增益压进一个学生塔；作者报告 mask penalty 与跨 seed 蒸馏的增益在可测数据上大体可加，但绝对 AUC 增益仍小且只在部分 benchmark 超过 seed 波动。

**核心方法**

- 将 QNN-α 等自集成蒸馏在掩码数趋于无穷时化为均值 logit 的标签损失加 softplus 的 Jensen 间隙惩罚，并证明普通 dropout 对应该惩罚系数为 1，从而分离蒸馏增量与 dropout 正则。
- 设计 FLMNet 单塔：field-local gate 只读未掩码输入嵌入，经学习 mixer 映射到塔宽并做 field recalibration；满足 gate 输入无掩码、仿射读出和坐标级重标定，使均值 logit 等于无 dropout 前向。
- 用闭式/截断方差构造高斯代理，经三点 Gauss-Hermite 积分计算 penalty，训练无需采样掩码；FLMNet-KD 再从 K=3 个 FLMNet-CF 塔的池化 logit 向单学生塔蒸馏。

**关键结果**

- 五个公开 benchmark、十七个基线上，FLMNet-CF 与 FLMNet-KD 在 AUC 和 Logloss 均列前二；Criteo 测试均值 AUC 0.8169、Logloss 0.4351，优于 QNN-α two heads 的 0.8156/0.4363（六 seed 均值）。
- 五 benchmark 平均 RelaImpr：FLMNet-CF 1.36±0.02%，FLMNet-KD 1.62%，QNN-α two heads 0.66±0.07%；后者区间与 CF 不重叠。
- Criteo 消融中，让 QNN-α gate 读输入嵌入可使闭式 penalty 与 Monte Carlo gap 的中位比率从 0.609/0.039 提升到约 1.000/0.998，但无 penalty 时验证 AUC 下降 10.5×10^-4；FLMNet 无 penalty 仅比原 QNN-α 低 0.9×10^-4。

**收益归因**

- 主要：无采样闭式自集成正则与跨 seed 蒸馏带来的单塔 CTR 离线排序精度提升。
- 次要：跨 seed 蒸馏把多个独立训练塔的池化 logit 迁入学生塔，可回收部分集成增益，代价是 K+1 次训练。
- 次要：field-local gate 与闭式方差递推使训练无需多次掩码前向，降低自集成蒸馏的训练采样开销。

**与你的关联**

- 直接相关：精排 CTR 单塔训练可借鉴其无采样自集成正则和跨 seed 蒸馏，降低多次前向成本并提升离线 AUC；需在自有数据复现并做线上 A/B。

**风险或局限**

- 全部结果为五个公开数据集上的离线实验，无工业线上 A/B、生产部署或真实广告/推荐系统指标。
- 论文以 ACM TOIS 模板发布但卷期/DOI 仍为占位符，当前仅见 arXiv 预印本，同行评审状态未确认。
- 闭式矩依赖 gate 读未掩码输入等结构条件；恢复精确性会损失 QNN-α 的 AUC，且方差使用截断，跨 seed 增益可加性并非所有 benchmark 都成立。

### P2｜[Truthful by Omission: Click Thinning for LLM-Native Advertising](https://arxiv.org/abs/2610.30999)

**论文、机构与场景**

- **机构：未披露**
- 作者：Junhua Liu、Zhicheng Liang、Zejun Zhang、Langzhou He、Feng Qian
- 来源：arXiv 2610.30999v1
- 场景：生成式 AI 助手答案中嵌入赞助广告的点击分配与竞价机制设计
- **论文主要内容：** 针对生成式答案内嵌广告的点击竞赛问题，用随机省略广告的点击稀疏化机制使点击概率与顺序无关，再以匹配…

**主要创新或优化点**

- 已有竞价机制在福利保证与真实性之间存在取舍：要么仅达最优福利的常数比例但真实性未知，要么真实但保证随段落数增长而退化。
- 本文提出随机点击稀疏化机制，使广告总体点击概率与顺序解耦，从而把福利最大化转化为可精确求解的匹配问题，并结合 VCG 式支付同时取得真实性与近似最优福利保证。
- 进一步刻画省略策略可达的点击概率集合，给出随 K 与 δ 收紧的近似因子，并证明其为保序类规则的最优，界定了真实性与计算效率的代价边界。

**核心方法**

- 问题建模：广告 CTR 取决于承载其的答案段落，且用户首个点击后即停止，后续广告点击被前置广告夺走，导致高报价者可能把竞争者排到前面反而减少自身点击。
- 核心机制 click thinning：以随机方式省略部分广告、降低前置广告的曝光，使每个广告的总点击概率不再依赖其在答案中的位置。
- 在点击概率可独立、顺序无关的假设下，将福利最大化化简为可处理的匹配问题，并以 VCG 式支付精确求解，使真实报价在期望上最优。

**关键结果**

- 给出计算高效机制，在允许自由重排时达到最优福利至少一半，且仅在期望意义上满足真实报价。
- 当至多展示 K 条广告、单条 CTR 不超过 δ 时，近似比从 2 提升到 2-(1-δ)^{K-1}。
- 论文证明该近似因子是对任何保序规则（即使忽略激励与计算约束）的最优上界，故真实性与效率未带来额外最坏情形损失。

### P2｜[MAPS: A Multi-Agent Personalized Script-Driven Video Advertising System Enhanced by Reinforcement Learning](https://arxiv.org/abs/2610.25748)

**论文、机构与场景**

- **机构：未披露**
- 作者：Zhongyu Wang, Chen Zuo, Qingxuan Sun, Jiayang Qiao, Qiuhao Qian, Songyan Cui, Guocheng Chen
- 来源：arXiv 2610.25748v1
- 场景：快手广告系统中的个性化脚本驱动视频广告生成与投放
- **论文主要内容：** 针对检索式视频广告创意预生产导致的个性化粒度受限问题，用多 Agent 闭环生成个性化脚本与视频，…

**主要创新或优化点**

- 已有检索式视频广告系统的候选创意是预先生产的，只能做特征空间匹配，个性化粒度受限且不同用户群体效果差异大；本文改为按用户实时生成脚本再合成视频，把个性化下沉到创意内容生产环节。
- Scripter Agent 以强化学习训练，多维奖励同时约束用户偏好对齐与商品信息传达，并通过反馈驱动迭代形成闭环；但摘要未披露奖励构成与训练细节，该设计有效性仅有作者声称与汇总指标支撑。

**核心方法**

- 系统由四个协作 Agent 组成闭环：用户画像建模、脚本生成、视频合成、反馈驱动的迭代优化
- Scripter Agent 使用强化学习训练，奖励函数为多维设计，同时对齐用户内容偏好与目标商品信息
- 摘要仅给出系统级流程描述，未披露各 Agent 的结构、视频合成模型、奖励函数的具体维度与权重等实现细节

**关键结果**

- 离线实验：在代表性数据集上生成与整合个性化创意取得作者所称的积极效果，具体数值未披露
- 快手广告系统特定场景线上 A/B：相对生成式基线 CTR +2.87%，CVR +2.74%，ARPU +9.85%

**收益归因**

- 主要：未核实
- 次要：脚本生成与视频合成闭环可能提升创意与用户偏好的匹配度，进而影响 CTR/CVR
- 次要：反馈驱动迭代可能缩短创意优化周期

## 本周 Top 论文

- **AGR: Agentic Generative Retrieval with Tool-Augmented Search**：生成式召回里少见的完整工程证据链：工具调用监督、前缀自适应插入、工具增强beam search，离线+三公开基准+7天A/B齐全，并给出35ms服务与序列特征训练/服务成本下降。
- **SPAR: Stepwise Personalized Autoregressive Recommendation with Prefix-Balanced Semantic IDs**：短视频首页SID召回，同时处理逐步个性化（PATH）、前缀负载失衡（RQ-PIB）与偏好对齐（DPO），7天约10%流量A/B给出播放转化+3.38%、人均观看时长+3.95%。
- **WeGR: Towards Unified Generative Retrieval via Behavior-aware Tokenization and Preference Alignment**：电商搜索召回替换级证据：订单+2.539%、粗排候选-38.10%、CPU/GPU与平均时延下降，是本周唯一同时量化效果与链路成本的召回替换结果。
- **ECHO: Efficient Cascade with Homogeneous Operators for Distillation-Guided 100K-Sequence Modeling**：把超长序列从‘每候选取全历史’改为用户级有界记录+目标检索，快手最大短视频场景7天5%流量A/B，工程范式清晰且与现有骨干解耦。
- **UniRec: Cross-stage Multi-Task Fusion with Preference Optimization for Cascaded Recommender Systems**：粗排-精排融合模块联合训练的代表性工业工作，双agent部分共享embedding与AGRR属性组归一化思路稀缺，九周A/B提供跨阶段协同的实证参照。

## 本周最值得做的实验

### SID解码特征按需注入：固定位置注入 vs 前缀自适应工具注入

- 假设：在生成式召回SID解码中，让模型依据当前解码前缀决定是否调用特征工具并注入观测token，可在不扩大输出空间的前提下提升候选与请求特征一致性。
- Control：现行SID自回归召回，静态特征在序列起点一次性拼接，不做分层注入。
- Treatment：加入工具token与观测token，插入深度按特征在SID前缀下的判别度增益选择；推理用工具增强trie beam search，每条beam独立工具配额。
- 保持变量：相同SID码本与分词器、相同训练数据与负例采样口径、相同候选池与评测集、相同学习率与训练步数。
- 离线指标：Recall@50 / MRR@50；自适应注入 vs 固定位置注入的Recall@50差值；工具化序列特征后的训练时长与每千请求serving GPU消耗
- 线上 Guardrail：服务延迟增量在预算内（参考35ms量级）；工具调用率与观测token占比不异常膨胀；头部相关度与改写率无显著回退

### 前缀负载均衡：全局码字均衡 vs 父前缀上限约束

- 假设：在SID构造中按父前缀统计兄弟分支交互负载并设上限，可降低局部主导分支集中度，且不牺牲下一物品预测精度。
- Control：现有残差K-Means码本，仅做全局码字使用均衡或不做前缀级约束。
- Treatment：冻结码本后按父前缀上限，把超载分支中重构失真增量最小的物品迁移到可行子分支，保留有效trie。
- 保持变量：相同码本层数与码字规模、相同SID分配数量、相同骨干解码器与训练预算。
- 离线指标：各SID层级流量加权最大子分支占比；HR@10/20/50/100；重构失真与唯一ID比例
- 线上 Guardrail：新物品与冷启分支召回不下降；trie合法性校验通过率保持接近100%；线上重排后播放转化与人均观看时长不劣化

### 超长序列预算：全历史教师路径 vs 用户级选择+目标检索两级预算

- 假设：用无候选输入的选择器保留Top-K原始记录、下游再做目标感知检索，可在序列长度10万级时保持排序精度并显著降低序列分支计算。
- Control：现有全历史检索式长序列建模（每次请求按候选在全历史上检索并聚合）。
- Treatment：用户级选择器按用户特征保留K条带ID与side features的原始记录，下游按共享相关性参数检索至多M条再聚合。
- 保持变量：相同排序骨干与多任务头、相同训练数据与标签、相同候选集与评测口径。
- 离线指标：GAUC（各任务）；长尾目标命中率与有效历史覆盖；序列分支训练/推理FLOPs估算值
- 线上 Guardrail：线上延迟与显存不超预算；总使用时长与人均使用时长不下降；选择刷新周期内的尾部效应可观测
