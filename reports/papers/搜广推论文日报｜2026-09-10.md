## 生成式召回

### P2｜[LoopMemGR: From Behavior Logs to Evolving Memory for Generative Recommendation](https://arxiv.org/abs/2607.27647)

**论文、机构与场景**

论文身份与机构：arXiv 2607.27647v2，替换版，作者含 Hui Qian、Changfa Wu、Chang Liu、Binbin Cao、Jian Wu、Yuliang Yan、Han Zhu、Bo Zheng、Shiye Wang；机构未披露，据候选摘要场景为生成式推荐，实验使用工业淘宝数据集。

**核心方法**

核心问题：现有生成式推荐采用 history-as-context 范式，每次请求从行为历史重建用户偏好，但丢弃系统侧已有的推荐决策，形成记忆不对称，无法跨请求复用偏好验证信号、负向证据与历史探索信息；方法：提出 LoopMemGR 闭环推荐经验记忆框架，在常规行为日志外维护推荐经验日志记录过去的推荐—反馈轨迹，通过 recency、frequency、global 三个互补视图抽取请求相关经验信号；输出形式：将抽取信号压缩为固定数量的 experience tokens，在有限输入预算下条件化生成式骨干网络，生成 Semantic ID 序列候选。

**主要创新或优化点**

针对生成式推荐中系统侧推荐决策与反馈未被跨请求复用的记忆不对称问题，提出可压入固定 token 预算的经验记忆闭环，为生成式召回引入历史探索与负向证据信号提供了一种实现路径。

**关键结果**

在工业淘宝数据集上的实验表明闭环经验积累与多视图经验抽取有效，但摘要未给出具体指标数值或提升幅度。

**与你的关联**

与生成式召回/Semantic ID 推荐方向相关，其经验记忆与多视图抽取机制可迁移到需要跨请求复用决策反馈的推荐链路，但未涉及具体工业部署或在线收益。

**可信度**

peer_reviewed_paper

**风险或局限**

摘要仅报告工业淘宝数据集上的有效性，未披露具体指标、提升幅度或在线 A/B 结果；无正式接收信息，仅 arXiv 替换版，未经同行评审确认；缺少与既有生成式召回方法在同等实验设置下的量化对比细节。


## LLM 增强与对话推荐

### P1｜[Dear Algo: A Precision-First Agentic Intent Layer for Unified Search and Recommendation](https://arxiv.org/abs/2608.15877)

**论文、机构与场景**

Meta Platforms Inc. 的 arXiv 论文(arXiv:2608.15877v3)，介绍已部署于 Threads 的 Dear Algo 意图层，用户可用 more NBA news / less politics 等自然语言指令持续调控信息流推荐。

**核心方法**

核心为 SilverTorch Agentic Recommender (STAR)，将显式/推断/负向/复合意图编译为受控词表 grounding 的 STQL(JSON 检索 DSL) 计划，驱动常规候选检索与可选语义/多模态 LLM 重排，遵循 compile-once-execute-many；评测：300 条公开请求-物料对盲审(296 可评)，严格 Relevant 门控精确率 94.4% [88.8%,98.9%]；72 个请求簇上完整配置 7.73 vs LLM 派生查询基线 6.61 合格候选@20，+1.11 [0.12,2.12]；候选随机化服务路径研究(限 72h TTL 窗口)：judge-Irrelevant 准入占比 2.80% vs 4.78%(-1.97 点 [-3.02,-0.94])，Exact-Relevant +2.24 点 [0.08,4.41]。

**主要创新或优化点**

展示显式自然语言意图如何在精度优先框架下进入信息流推荐，并给出统一意图-检索契约与分层评测(人工盲审+配对离线+候选随机化在线)的工业实践与度量教训。

**关键结果**

盲审严格门控 exact-Relevant 精确率 84/89=0.9438 [0.8876,0.9888]，at-least-Partial 89/89=1.0000；judge 门控框架准入率 66.55%；离线配对配置级对比：C–B 合格候选@20 +1.11 [0.12,2.12]；0.8/0.9/1.0 三阈值下 C–B 与 C–A 区间均不含零；重排开启路径降低 Irrelevant 占比并提高 Exact-Relevant 占比；全判 sensitivity 更强，同会话 sensitivity 两区间含零。

**与你的关联**

为搜广推链路中 自然语言意图→可执行检索计划→LLM 重排 的落地方案、在线随机化设计与 LLM-as-judge 评测协议提供直接参考。

**可信度**

online_ab

**风险或局限**

行为分析为观察性，用小时级代理会话，未控制自选择、时间趋势与回归均值；离线配对三臂均使用 grounded tags 与 STQL，无法隔离 grounding 等单一机制贡献；重排研究仅观测已准入候选，TTL 窗口为代理，无法估计召回或重排前排序变化；精度门控阈值事后确定。


## 评测与评估

### P2｜[Should I Be Polite to My LLM Relevance Judge? Tone as a Severity Operating-Point Shift](https://arxiv.org/abs/2609.09703)

**论文、机构与场景**

arXiv 论文 2609.09703v1（作者 Tian Zhang、Meng Li，机构未披露），研究 LLM-as-relevance-judge 的提示语气效应对 TREC DL19/DL20 相关性标注的影响，属搜索排序评测场景。

**核心方法**

实验规模：3,498 个 TREC DL19/DL20 query-passage 对、8 个 judge 模型、5 个分类器校准的礼貌程度、每档 3 个改写；效应强依赖模型：一个 judge 呈结构化 U 形响应，多数模型仅有小幅变化；作者将语气导致的一致性变化解释为 judge 的 severity operating point（整体评分宽松度）漂移，而非判断质量改善；query-disjoint cross-fit 保留该关联（Spearman rho=-0.683，exact model-block permutation p=0.019）。

**主要创新或优化点**

把提示语气识别为 LLM relevance judge 的潜在 validity threat：当需要绝对相关性标签时，judge 的宽松度漂移会系统性改变标注口径，而常规排序指标几乎察觉不到。

**关键结果**

32 个 model-tone 对比中 NDCG@10 最大绝对平均变化为 0.011，说明语气主要影响基于校准的一致性而非排序结果；Kendall's tau 最低达 0.743，表明排序重排被削弱但并未消失；语气使 judge 更接近或远离人类标注严格度时，其与人类的一致性随之升降。

**与你的关联**

对使用 LLM judge 做离线评测、标注或相关性数据的搜广推团队有直接方法论价值，提示需控制 prompt 语气并校准 judge 的 severity。

**可信度**

technical_report

**风险或局限**

仅在 TREC DL19/DL20 检索相关性数据上验证，未覆盖推荐、广告等其它排序评测场景；无线上 A/B 或生产部署证据，结论来自离线实验；PDF 正文未提供，方法细节与统计检验流程无法完整核验。


## 生成模型与内容生成

### P0｜[AgenticGen: Reward-Guided Agentic Video Generation for Advertising](https://arxiv.org/abs/2609.09187)

**论文、机构与场景**

arXiv:2609.09187v1，标题 AgenticGen: Reward-Guided Agentic Video Generation for Advertising，作者主体来自 ByteDance，另有清华大学与香港中文大学；应用场景为 TikTok 广告系统的广告视频生成，以 CTR/CVR/Advv 为线上指标。

**它解决的旧问题**

首次把广告视频生成建模为奖励引导的 agentic 框架，并用 TikTok 广告系统在线 A/B 验证 DPO+GRPO 能用线上业务反馈同时优化策略选择与草稿生成，为生成内容到线上反馈再到策略优化的闭环提供工业级范式。

**核心方法**

方法将广告视频生成拆成两个可训练推理阶段：策略选择（从十余个内部策略族中选可行策略组）与草稿生成（产出可执行 draft，再调用 Seedance 2.0 与 CapCut 渲染成片）；奖励侧用 impression-balanced 投放日志训练 Bradley-Terry pairwise 性能奖励模型，并用内部专家 rubric 与三人标注一致样本训练 Qwen2.5-Omni-7B 质量奖励模型；先用 DPO 做离线偏好预热，再用 GRPO 以全局/局部过程奖励与性能/格式结果奖励交替优化两阶段策略；线上数据来自专门流量池：每商品 12 条生成视频随机投放、绕过召回与排序，单视频累计至少 1000 曝光才计入训练；SFT 基座为 Qwen3-VL-8B-Thinking，由 Qwen3-VL-235B 教师蒸馏轨迹训练。

**主要创新或优化点**

首次把广告视频生成建模为奖励引导的 agentic 框架，并用 TikTok 广告系统在线 A/B 验证 DPO+GRPO 能用线上业务反馈同时优化策略选择与草稿生成，为生成内容到线上反馈再到策略优化的闭环提供工业级范式。

**关键结果**

TikTok 广告系统在线 A/B：DPO+GRPO 相对 SFT 提升 CTR 2.72%、CVR 2.63%、Advv 9.61%；SFT 相对非 agentic 的 Pre-Agent 提升 CTR 3.48%、CVR 2.30%、Advv 9.83%；性能奖励模型在 impression-balanced 验证集上 pairwise 准确率 60.85%，比 pointwise 高 7.93%；多模态特征逐项加入使准确率从纯视频 56.55% 升至 60.85%，其中音频贡献 1.88%；DPO 偏好准确率：策略选择 49.72%→56.48%，草稿生成 50.64%→58.34%，平均 50.18%→57.41%；GRPO 加权融合性能/质量奖励的 win rate 为 60.52%/55.86%，平均 58.19%。

**收益归因**

主要来自 生成内容与商业目标对齐：用印象均衡线上反馈训练奖励并做 DPO/GRPO，使生成广告视频的 CTR/CVR/Advv 明显优于 SFT 基线；次要因素为 印象均衡投放构造可比偏好数据；多模态（视频/音频/叙事/广告要素）奖励特征；按阶段拆分过程奖励与结果奖励的 RL 优化。

**与你的关联**

其 impression-balanced 投放协议、pairwise 性能奖励建模与从线上反馈优化生成决策的两阶段策略优化，可迁移到广告创意生成与业务指标对齐；但不涉及召回、粗排、精排的候选打分链路。

**风险或局限**

性能奖励模型绝对准确率仅 60.85%，作者称因其看不到生产 CTR 模型使用的用户行为序列与用户-广告交互特征，奖励信号偏弱；rubric 奖励模型在 impression-balanced 集仅 53.30%，人类质量标准不能完全决定线上偏好；单独用 rubric 奖励时性能 win rate 反降至 50.78%，存在业务与质量目标权衡；线上反馈取自绕过召回与排序的专用印象均衡流量池，且策略目录因商业敏感未公开，结论向标准投放链路的泛化与复现受限。


### P2｜[MADS: Multi-Agent Dialogue Simulation for Diverse Persuasion Data Generation](https://arxiv.org/abs/2510.05124)

**论文、机构与场景**

MADS 为多智能体对话自博弈生成说服性多轮对话的框架，作者所属机构未披露，应用于真实营销场景以提升小模型说服能力与自然流量转化率。

**核心方法**

框架含三类协调智能体：User Agent 以星座、MBTI 等人格标识模拟多样化角色行为，Dialog Agent 执行任务导向说服策略，Optimization Agent 评估并优化对话结果；通过用户 Chain-of-Attitude 建模与专用 LLM 说服评估验证有效性，声称无需人工标注即可低成本生成训练数据；目标是缓解用户数据缺乏、冷启动评估困难与提示效率低等业界问题，输出面向用户的对话内容而非推荐候选。

**主要创新或优化点**

多智能体对话自博弈生成说服性内容，并给出真实营销转化率数字，代表生成式对话内容与业务反馈闭环结合的案例；但摘要证据，需正文核验数字口径。

**关键结果**

真实营销场景中，MADS 提升小 LLM 说服能力，声称自然流量转化率从 1.83% 提升至 2.24%，即 22.4% 相对提升；采用 Chain-of-Attitude 建模与 LLM 说服评估作为验证手段，未披露离线评测数据集规模与基线细节；非人工标注生成训练数据，声称降低数据获取成本。

**与你的关联**

与推荐/广告链路中的生成式营销文案、对话式推荐内容生成相关，属于用户可见内容生成方向；不涉及召回排序候选构造。

**可信度**

peer_reviewed_paper

**风险或局限**

仅有摘要证据，转化率口径、A/B 设计与样本量未披露；星座、MBTI 等人格模拟的有效性与泛化性未在摘要中说明；LLM 说服评估与 CoA 建模的可靠性与偏差未经独立验证。

## 今日最值得立项的实验

### LLM-judge提示语气校准对离线相关性/评测一致性的影响

- 假设：在自有离线相关性标注任务中，系统化改写judge提示语气会改变judge的severity operating point，导致与人工标注的一致性升降，而排序类指标变化很小。
- Control：固定中性语气提示，使用当前LLM relevance judge协议对同一query-passage集合打分。
- Treatment：对同一judge叠加5档礼貌程度改写（每档3个改写、多个judge模型），并做分类器校准；比较一致性指标与排序指标。
- 保持变量：同一query-passage样本集、同一judge模型版本与解码参数、同一标注口径与人类参考标签。
- 离线指标：judge与人工标签的Kendall tau/一致性；NDCG@10绝对变化；各档语气下的严格度(score分布均值/通过率)
- 线上 Guardrail：不得用语气变化替代真实标注质量提升；改写不得引入任务指令类信息泄漏；评测差异不放大到全量人工标注成本

### 生成式召回引入跨请求经验记忆token的离线验证

- 假设：在生成式召回骨干上，除行为日志外维护推荐经验日志并以recency/frequency/global三视图抽取固定数量experience tokens，可在不增加输入预算的前提下提升SID候选质量。
- Control：仅用history-as-context行为历史条件化的生成式召回基线，输入预算与骨干一致。
- Treatment：附加经验日志与三视图经验抽取，压缩为同预算experience tokens条件化同一生成式骨干。
- 保持变量：同一SID词表与生成式骨干、同一输入token预算、同一训练数据切片与负采样。
- 离线指标：Recall@K/NDCG@K的SID候选质量；负向样本(历史探索/负反馈)相关指标；同预算下的训练与推理FLOPs对比
- 线上 Guardrail：经验日志不得引入未来信息泄漏；缓存与记忆更新频率对线上延迟的增量在预算内；冷启动用户指标不下降


## 一句话总判断

本期两条主线：一是把业务反馈直接变成生成/排序的优化信号——AgenticGen用印象均衡流量池与pairwise奖励做DPO+GRPO闭环，Dear Algo用自然语言意图编译成STQL计划并可选LLM重排，两者都有候选随机化或线上A/B级证据；二是评测侧风险显性化——LLM judge的语气会改变严格度而排序指标几乎不变，提示离线评测协议需先校准judge口径。生成式召回侧LoopMemGR指出history-as-context丢弃系统侧决策历史造成记忆不对称，方向值得跟，但本期仅摘要、无指标，不能据此判断收益。
