## 召回

### P2｜[Hamiltonian Spectral-Temporal Dissipative Dynamics for Sequential Recommendation](https://arxiv.org/abs/2608.25755)

**论文、机构与场景**

arXiv 论文（RecSys '26）由香港科技大学 Shuiying Liao 与 P. Y. Mok 完成，面向电商、短视频、音乐与广告等场景的序列推荐 next-item 预测。

**核心方法**

HSR 将偏好演化建模为相空间中阻尼哈密顿系统，位置代表稳定偏好、动量代表短期趋势，频域闭式解支持 O(T log T) FFT 传播；模型含可学习质量/阻尼/刚度参数、局部脉冲精修模块和单步相空间外推，并在 MovieLens-1M、Amazon-Beauty、Amazon-Video-Games 上评测；训练目标是完整物品空间上的 softmax 打分并排序，输出 top-K 候选；代码开源在 github.com/asaander719/HSR。

**主要创新或优化点**

将二阶动力系统与频域传播引入序列推荐，同时建模惯性、周期与突变，复杂度 O(T log T)，为搜广推长序列建模提供新范式。

**关键结果**

Amazon-Beauty 上 Hit@10=0.0952、MRR@10=0.0448；Video-Games 上 Hit@10=0.1348、MRR@10=0.0573，NDCG/MRR 相对增益最高约 10-17%；参数 4.74M、单用户延迟 0.014ms、吞吐 60,113 QPS，训练每轮 6.8s，较 Mamba4Rec 有 20-58% 的效率增益；消融显示移除哈密顿结构或局部脉冲模块下降最明显；注入 0-30% 噪声时 HSR 降幅最缓。

**与你的关联**

可迁移到短视频/电商/广告长序列召回或粗排：频域传播低复杂度、动量外推可解释兴趣演化；但仅学术 benchmark，无工业 A/B，需在线验证收益归因。

**可信度**

peer_reviewed_paper

**风险或局限**

仅用 leave-one-out 学术数据集（MovieLens-1M、Amazon 两个域），无线上规模或工业部署验证；全文用完整物品空间 softmax 打分，缺少负采样或索引方案，超大规模物料库可扩展性未验证；未见与真实广告/短视频场景端到端收益数据；GPU 峰值内存 3.71GB，比 DIFF 高约 113%。

**主要创新或优化点**

### P2｜[TransRetrieval: Scaling Up Transformer-Based Retrieval for Industrial Recommendation](https://arxiv.org/abs/2608.25528)

**论文、机构与场景**

TransRetrieval是面向工业推荐召回的Transformer检索框架，作者团队机构未披露，应用于视频/电商推荐场景。

**核心方法**

提出加权平均聚合恢复同质token假设，使Transformer层数可按计算预算和跨域数据扩展；引入目标token压缩，将每候选FLOPs降低85%，并保持交叉注意力表达能力；使用位置风格域嵌入统一多域数据，以低成本将跨域数据转为扩展资产。

**主要创新或优化点**

通过权重聚合、目标压缩、域嵌入三项机制突破特征异构性瓶颈，呈现确定性对数线性扩展能力，同时压缩计算开销并在在线环境验证收入提升，是工业召回规模化的重要进展。

**关键结果**

在400亿交互工业数据集上，计算量从0.1扩展到2 MFLOPs/target，Recall@2000提升19.3pt；在KuaiRand公开基准上，同等扩展下Recall@2000提升22.2pt，确认对数线性扩展；在线A/B测试显示，在与生产基线相同端到端延迟约束下，平台收入提升2.53%。

**与你的关联**

直接命中大规模召回阶段扩展和计算效率优化需求，收益增量明晰且方法可迁移到多域工业场景。

**可信度**

online_ab

**风险或局限**

机构身份未披露，作者归属和系统来源不可核实；在线A/B测试具体平台、视频或电商的域名和流量范围未在摘要中说明；跨域扩展收益依赖具备海量多域数据的场景，小型或单域系统适用性未知。


## 跨阶段协同与工业效率

### P1｜[An Event is Worth One Token: Event Tokenization for Industrial-scale LLM Recommendation](https://arxiv.org/abs/2608.25546)

**论文、机构与场景**

技术报告 arXiv:2608.25546v1 由 Meta AI 团队发布，面向 Facebook 工业级推荐系统，覆盖 ranking 与 ANN retrieval 两个阶段。

**核心方法**

提出 AMBER：统一 Event Tokenizer 将每个事件的全量异构特征压缩为单个 Event Token，与 1B Llama 用户 LLM 端到端联合训练；token 异步预计算并缓存，使快照分辨率与在线计算解耦；系统设计含三阶段训练（预对齐/联合/循环重训）、DANN+EMA 缓解表示漂移、Matryoshka Dropout 与 INT4 量化感知训练实现约 8x 存储缩减；统一 tokenizer 通过角色掩码服务 ranking/retrieval/target 等角色；评估显示 AMBER 相对 Incumbent(fair) ranking NE 降低 0.40%，融合后 Ensemble NE 在 1 分钟特征延迟下降低 0.16%；retrieval Soft Recall 提升 0.31~0.51%；生产环境非 LLM ranker 接入 Event Tokens 后 NE 降低 0.06%。

**主要创新或优化点**

提出 snapshot resolution（每事件信息量）作为 LLM 推荐新的 scaling 维度，通过异步缓存 Event Token 将高分辨率历史特征移出在线路径，在工业级 ranking+retrieval 上推进 compute-quality Pareto 前沿，并证明表征可跨模型架构迁移复用。

**关键结果**

AMBER 相对 Incumbent(fair) 的 ranking NE 降低 0.40%，优于 Pointwise 0.30%、HSTU-style 1.00%、SID+CU emb 1.60%；与 Incumbent 线性融合时，1 分钟特征延迟下 Ensemble NE 额外降低 0.16%，SID+CU emb 仅 0.05%；retrieval 在 Day1~8 保持 Soft Recall +0.31%~+0.51%；生产全流量评估中 Event Tokenizer（3.84M 稠密参数）为非 LLM ranker 提供历史特征，NE 降低 0.06% 且统计显著；异步缓存使在线服务避免全量特征物化。

**与你的关联**

对搜广推 LLM 推荐与工业排序同学直接相关：提供事件级 token 化范式、总计算（训练+服务）视角的 scaling 分析、可复用跨阶段历史特征方案，以及 drift 缓解与量化压缩工程经验。

**可信度**

technical_report

**风险或局限**

ranking 端到端 LLM 实时服务未落地，KV cache 与长历史服务挑战超出本文范围；生产验证只将 Event Tokens 作为非 LLM ranker 的附加特征；特征物化计算被折算进总 FLOPs 依赖经验功率比与模型假设，跨平台绝对值只能在 Meta 基础设施上复现；未开源代码与数据；异步 tokenization 引入特征延迟（约 1~5 分钟），作者仅模拟延迟训练未见端到端在线收益；检索指标仅用 Soft Recall 相对提升，绝对效用未披露。


## 多任务与目标建模

### P1｜[DCEO: Direct Causal Effect Optimization for Long-Term User Value Modeling in E-commerce Search](https://arxiv.org/abs/2608.25635)

**论文、机构与场景**

DCEO 论文来自阿里巴巴淘宝天猫集团，arXiv 2608.25635v1，场景为淘宝/天猫大规模电商搜索排序，目标是用户级长期价值（如 n 日累计 GMV）。

**核心方法**

方法：将 item 级代理分数按用户展示聚合成用户级代理指标，用相对因果效应（RCE）衡量其与最终目标的对齐，并以 actor-critic 直接优化 RCE；actor 依据用户与请求特征对 17 个上游预测分数生成上下文化融合权重，构造代理分数加入现有多目标融合公式；线上仅部署 actor；离线用 14 天日志训练、次日评估；完整损失 RCE 0.053，41 天在线 A/B 较常规 GMV proxy 提升 GMV 0.36%。

**主要创新或优化点**

直接以相对因果效应为目标，从用户级长期目标端到端学习 item 级代理分数，解决粒度鸿沟与手工融合权重局限；线上仅部署轻量 actor，41 天 A/B 实证 GMV 提升，方法可迁移到电商搜索排序。

**关键结果**

41 天在线 A/B：GMV +0.36%、点击 +0.36%、购买 +0.12%，GMV 提升未以点击或购买下降为代价；离线 RCE：预测关联优化 0.022，纯因果效应损失 0.031，完整 actor 损失 0.053（2.41x）；仅 impr2gmv 集合 0.027，完整 17 分数集合 0.053；权重随目标和窗口自适应：4 日 GMV 下 click2pay1000 权重 0.205；1 日 GMV 的 impr2click 权重 0.331，4 日升至 0.404，提示更长目标鼓励探索。

**与你的关联**

对电商搜索/推荐排序团队高度相关：框架可直接叠加到现有融合公式，线上开销小，可复用长期价值、多目标权衡与个性化排序；离线因果对齐指标设计也有借鉴价值。

**可信度**

online_ab

**风险或局限**

RCE 基于观察日志与 critic 的局部模型估计，依赖用户特征覆盖主要混杂；未观测混杂与 critic 设定偏差可使因果识别有偏，A/B 不直接验证 RCE 数值；固定展示数校准排除排序引起的活跃度与展示数变化路径，离线 RCE 仅是参考展示数下的对齐指标，不是总部署效果；未来需联合建模展示数；actor 仅对上游分数做凸组合，无法引入上游缺失信息；评估限于单一电商搜索系统、目标窗口最长 4 天，泛化性待验证。

### P2｜[MOTIF: Motivation-guided Topology Inference for Cold-start Multimodal Recommendation](https://arxiv.org/abs/2608.25381)

**论文、机构与场景**

MOTIF 是面向冷启动多模态推荐的动机引导拓扑推断框架，作者包括 Yurui Shi 等，机构未披露。

**核心方法**

MOTIF 结合语义动机推理、知识增强图重构、加权图对比学习和语义结构对齐，利用离线 LLM 推理推断动机语义，不将生成文本注入预测；方法重构可迁移的物品-物品拓扑，学习鲁棒图嵌入以缓解冷物品拓扑孤立和相似性图语义漂移问题；在三个多模态基准上对比图、多模态、冷启动和 LLM 增强基线，相对最强基线最高提升 6.07%。

**主要创新或优化点**

针对冷启动多模态推荐提出动机引导的拓扑推断方法，结合 LLM 推理与图学习，改善冷物品孤立和语义漂移问题，为多模态推荐提供新思路。

**关键结果**

多个多模态基准上一致优于图、多模态、冷启动和 LLM 增强基线；相对最强近期基线最高相对提升 6.07%。

**与你的关联**

与短视频/直播/电商等工业多模态推荐链路相关，冷启动场景具有实际应用价值，但实验规模与部署信息未知。

**可信度**

peer_reviewed_paper

**风险或局限**

未提供在线 A/B 或大规模工业部署证据；实验结果基于离线基准，跨领域泛化性未明确；LLM 推理的离线开销和实时性未讨论。

## 今日最值得立项的实验

### RCE 代理分数优化验证

- 假设：以相对因果效应为训练目标学习 item 级代理分数并加权融合，能提升用户级长期价值指标且不损害短期行为信号。
- Control：现有多目标融合公式使用固定或手工权重和常规 GMV proxy。
- Treatment：actor 依据用户与请求特征对 17 个上游预测分数生成上下文化融合权重，构造代理分数加入融合公式，离线以 RCE 为损失训练，线上仅部署 actor。
- 保持变量：候选集合、精排模型架构、流量分配、目标窗口定义均不变。
- 离线指标：RCE 对齐指标；离线 GMV/点击/购买预估 AUC
- 线上 Guardrail：GMV、点击、购买率不下降；线上推理额外延迟小于 5ms

### 事件 token 化历史特征注入排序模型

- 假设：将全量事件特征压缩为单个 Event Token 并异步缓存，可为非 LLM ranker 提供高分辨率历史特征，提升排序质量而不显著增加在线成本。
- Control：现有非 LLM ranker 使用原始或简单聚合历史特征。
- Treatment：训练 AMBER 风格 Event Tokenizer，异步预计算并缓存事件 token，作为 ranker 的附加特征输入。
- 保持变量：ranker 主架构、训练数据、评估协议不变。
- 离线指标：NE；AUC；Soft Recall
- 线上 Guardrail：在线 p95 延迟增幅不超过 10%；特征存储成本增幅可控；NE 不上升


## 一句话总判断

本期方法趋势从单点模型优化转向可复用表示层与跨阶段协同：Meta AMBER 统一事件 token 化覆盖 ranking 与 retrieval，阿里 DCEO 以因果效应直接优化长期价值，结合上期 WeMM 多模态嵌入，表明工业界正集中构建跨场景共享特征基础设施。但多数在线收益为自报、未独立复核，采纳前需线下复现与独立验证。
