## 生成式召回

### P0｜[阿里巴巴、浙江大学｜PFA: Attention Can Be Progressively Focused in Long-Sequence Generative Recommendation](https://arxiv.org/abs/2610.39273)

**论文、机构与场景**

- **机构：阿里巴巴国际数字商业集团、浙江大学（Pengjie Zhou 邮箱域名为 buaa.edu.cn，指向北京航空航天大学，与首页所列 Alibaba International Digital Commerce Group 不一致）**
- 作者：Pengjie Zhou、Weiqin Yang、Haibo Xing、Hao Deng、Jinxin Hu
- 来源：arXiv:2610.39273v1
- 场景：电商广告场景的长序列生成式推荐（SID自回归beam search召回）解码加速
- **论文主要内容：** 面向长序列生成式推荐解码延迟，提出PFA：跨beam共享关键token排序并几何缩减注意力预算。

**主要创新或优化点**

- 实证发现（作者观察）：GR 解码中历史注意力随步数向少数 token 集中，关键 token 的排序跨步较稳定，为复用早期排序提供依据。新机制一：第 1 步用各 beam 归一化生成概率加权聚合注意力，得到跨 beam 共享排序，并将选中 token 的 KV 重排为连续缓存。新机制二：后续步不做全历史重检索，按几何比例收缩预算形成嵌套关键集；步级 KV 投影为各 SID 解码步提供独立语义子空间。

**核心方法**

- 解码第0步对完整用户历史做全注意力，以BOS查询获取全局偏好并生成首token，随后保留top-B语义前缀进入beam search。
- 第1步对每个历史token按各beam归一化生成概率加权聚合注意力权重，得到跨beam共享重要性排序，选top-k并重排KV为连续缓存。
- 第t≥2步复用共享排序并按k_t=max(1,ceil(k·r^{t-1}))几何缩减token预算，只对排序前缀做注意力；同时为每个解码步设置独立KV投影参数。

**关键结果**

- 在 Kindle Store、Tmall 和 Industry 三个数据集上，PFA 相对各指标最强基线平均提升 Recall@10 5.75%、NDCG@10 7.18%（相对提升）；Industry 上相对 Full Attention 的 Recall@10 提升 3.16%。
- 在5×NVIDIA L20、BF16、每GPU batch 512、beam width 100下，Industry数据集PFA延迟62ms/batch，Full Attention为90ms，Dynamic Top-k为212ms；PFA相对Full Attention约1.45×加速。
- 7天线上A/B（电商广告，实验组序列512、对照组128，各10%流量）：REV +3.76%、CTR +0.34%、GMV +2.56%，在线RT 11ms，低于直接输入512序列的15ms。

**收益归因**

- 主要：降低长序列生成式推荐beam search解码的注意力计算与KV访存开销
- 次要：支持更长用户历史：线上实验组序列512、对照组截断128，REV+3.76%、GMV+2.56%（整包配置效果，未拆分到单模块）
- 次要：机制解释（表4消融支持）：去掉跨beam共享或几何缩减后，Industry延迟明显上升而精度变化很小，说明收益主要来自减少重复top-k选择与离散访存
- 次要：机制解释（表4消融支持）：去掉步级KV投影后Industry Recall@10明显下降、延迟几乎不变，说明其为分层SID解码提供语义区分且开销很小

**与你的关联**

- 适用于生成式召回和长序列GR的在线解码加速，尤其在beam search下历史KV访问成为瓶颈的场景；迁移时需核验自身注意力分布是否满足渐进聚焦与跨步排序一致性，并在目标硬件重测延迟。

**风险或局限**

- 线上A/B为作者自报，仅覆盖单一电商广告平台、7天和10%流量，未给置信区间、显著性检验和长期效应，且缺少独立复现。
- 效率结论依赖5×L20、BF16、每GPU batch 512、beam width 100、序列长度512和SID长度4等设置；Kindle Store上移除步级KV投影的变体延迟为16ms，说明模块相对开销随配置变化，换硬件、beam宽度或序列长度需重测。
- 注意力性质证据仅覆盖SID长度4的Step 0–3解码，附录只以20% tokens在Kindle Store复现（Step 3累计注意力94.13%）；未报告重复运行方差，也未讨论码本更新或分布漂移下的排序稳定性。


### P1｜[香港城市大学、独立研究者、清华大学｜ComeIR｜Conditional Memory Enhanced Item Representation for Generative Recommendation](https://arxiv.org/abs/2605.11447)

**论文、机构与场景**

- **机构：香港城市大学（Ziwei Liu、Yejing Wang、Xiangyu Zhao）、独立研究者（Shengyu Zhou）、清华大学（Xinhang Li）**
- 作者：Ziwei Liu、Yejing Wang、Shengyu Zhou、Xinhang Li、Xiangyu Zhao
- 来源：arXiv:2605.11447v2
- 场景：基于语义 ID 的生成式推荐（Yelp、Amazon Industrial、Amazon Instrument 序列推荐）
- **论文主要内容：** 针对 SID 表示语义丢失与结构关系不足，ComeIR 用物品引导打分和双层条件记忆重构表示。

**主要创新或优化点**

- 语义 ID（SID）量化后的表示桥接长期被忽视；ComeIR 用物品嵌入对每个 SID code 打分形成语义锚点，属表示阶段语义恢复而非改量化器。哈希 n-gram 条件记忆沿用既有 Engram 思路，本文新增点在双层 SID 前缀建模：item 内前缀组合与 item 间同层前缀转移分别检索。Memory Merge 以语义锚点门控注入双层记忆并残差保留锚点，避免无条件线性合并。Memory-restoring Prediction Head 在自回归解码每级复用前缀与历史转移证据，使结构证据覆盖表示与生成两端。

**核心方法**

- Item-guided Token Scoring 将量化器使用的物品嵌入 m_n 投影到 LLM 隐空间作为 query，对每个 SID code 嵌入做 softmax 加权求和得到语义锚点 s0_n，用于记忆检索与 Memory Merge。
- Dual-level Conditional Memory 用多头哈希 n-gram 查表：Intra-item Memory 以 item 内前缀 κ_{n,t}=Σ c_j C^{j-1} 为地址，Inter-item Memory 将同层前缀按时间重排并取局部窗口 query，经上下文门控输出记忆向量。
- Memory Merge 以语义锚点门控融合两层记忆并残差保留 s0_n，输出 item-level 表示；Memory-restoring Prediction Head 在自回归解码每级 SID 时复用前缀 intra 记忆与历史 inter 转移证据，经门控融合产生 code logits，训练用 teacher forcing、推理用 beam search 与 catalog trie。

**关键结果**

- 在 Yelp、RQ-VAE、Qwen3-0.6B 下，ComeIR 的 H@5/H@10/N@5/N@10 为 0.0305/0.0524/0.0198/0.0266，高于 +TM 的 0.0292/0.0470/0.0177/0.0239；论文称该设置跨架构平均增益 8.06%（Qwen3-0.6B）与 7.91%（LLaMA3-1B）。
- 在三个数据集、RQ-VAE/RQ-KMeans、Qwen3-0.6B/LLaMA3-1B、Vanilla GR/NEZHA 的组合中，所有 +ComeIR 变体均标 *，即相对 runner-up architecture 的单侧 t 检验 p<0.05；例如 Qwen3-0.6B+RQ-VAE 下 Industrial H@5=0.1031、Instrument H@5=0.0834。
- 效率：Yelp/Qwen3-0.6B/Vanilla GR 每 batch 延迟从 flattened 的 23.673ms 降至 ComeIR 的 9.161ms，低于 IntRR 的 11.734ms、高于 +TM 的 7.684ms；论文报告相对 flattened 平均 2.5× 加速。峰值显存与延迟边界见 limitations。

**收益归因**

- 主要：整包 ComeIR 在离线 top-K 的命中与排序上优于 +TM 等构造器，跨量化器、骨干和架构实验支持整包配置收益；模块消融仅支持互补性，不能据此推导单模块因果。
- 次要：输入长度由 N×L 降为 N，带来相对 flatten 约 2.5× 推理加速；但稀疏记忆增加显存，延迟仍高于 +TM。
- 次要：intra/inter 前缀证据在表示与解码两端复用，案例中 LCP 相关历史物品注意力由 +TM 的 24.4%、IntRR 的 36.3% 升至 59.9%，提供可解释的结构保持信号。

**与你的关联**

- 适用于已有 SID 量化与自回归生成链路的生成式推荐系统，尤其是需要在不改量化器的前提下增强物品表示、恢复量化语义并利用前缀结构证据的场景；迁移时需按 SID 长度、码本大小和稀疏记忆容量重新调参。

**风险或局限**

- 仅在 Yelp、Amazon Industrial、Amazon Instrument 三个公开数据集做离线 top-K 评测，无在线 A/B 或生产流量验证，不能确认工业链路收益。
- 主实验以单侧 t 检验标注显著，但未报告多次随机种子方差/置信区间，模块消融的绝对差距较小（如 Yelp H@10 0.0524 vs w/o All Memory 0.0486），稳健性有限。
- 条件记忆依赖固定 L=3、codebook=128 与哈希表容量，作者也指出大数据集上碰撞会削弱增益；训练峰值显存 19.48GB 高于 +TM 的 9.26GB，推理峰值显存也高于 +TM，且延迟仍慢于 +TM。


### P1｜[Swinburne University of Technology｜DeepInterestGR: Mining Deep Multi-Interest Using Multi-Modal LLMs for Generative Recommendation](https://arxiv.org/abs/2602.18907)

**论文、机构与场景**

- **机构：Swinburne University of Technology（通讯作者 Jinze Wang 邮箱 jinzewang@swin.edu.au，首页作者区未另列机构）**
- 作者：Yangchen Zeng、Guangyuan Dong、Zhenyu Yu、Zhiyuan Hu、Jinze Wang、Rongfeng Guo
- 来源：arXiv:2602.18907v3
- 场景：Amazon Beauty/Sports/Instruments 的下一物品 SID 生成推荐
- **论文主要内容：** 用多LLM挖掘深层兴趣并量化为SID，结合SFT-GRPO训练生成式推荐。

**主要创新或优化点**

- 指出现有生成式推荐只用标题、描述等浅层文本、难以刻画潜在兴趣的“Shallow Interest”问题，并把深层兴趣挖掘前移到物品离散化与生成训练之前。
- 提出 MLIM：用多个前沿 LLM 及多模态变体按“表层属性—潜在动机—兴趣标签”结构化提示抽取兴趣，再按跨模型共识与置信度聚合，而非单一 LLM 一次性打标。
- 提出 IEID：把聚合兴趣文本经 Qwen3-Embedding-4B 编码后再用 RQ-VAE 量化，使 SID 空间按兴趣语义而非仅表层文本邻近组织物品。
- 设计 Interest-Aware Reward：用 RLDI 的正/负兴趣标签给 GRPO 奖励增加语义偏好项，在匹配目标 SID 的 0/1 奖励之外引导策略偏向高质量兴趣物品。

**核心方法**

- MLIM 用 GPT-4o、Gemini-1.5-Pro、Kimi、Grok 及其多模态变体，按结构化推理提示从物品的标题、描述、图像和用户历史中挖掘兴趣标签及置信度，再聚合同一兴趣在至少两个 LLM 中出现且语义相近的结果。
- IEID 先把聚合兴趣文本拼接后用 Qwen3-Embedding-4B 编码，再交给 RQ-VAE（4 层、每层 256 个码字）量化成兴趣增强 SID，使物品在 SID 空间按潜在兴趣邻近组织。
- 训练分两阶段：先用 Qwen2.5-7B-Instruct 做下一 SID 的 SFT；再用 RLDI（同一模型零样本判兴趣正/负）构造奖励 r=目标 SID 匹配的 0/1 奖励 + 0.5×正向兴趣奖励，并用 GRPO 加 KL 正则优化。

**关键结果**

- 在 Beauty/Sports/Instruments 的 leave-last-out 离线评测中，DeepInterestGR 的 HR@10 为 0.1032/0.0703/0.0972，N@10 为 0.0558/0.0376/0.0513，均高于表内最强基线 MiniOneRec。
- Beauty 消融：去掉 MLIM 后 HR@5 从 0.0678 降至 0.0598，去掉 IEID 后降至 0.0621，去掉 Interest-Aware Reward 后降至 0.0635，仅保留 SFT 后降至 0.0567。
- 跨域迁移 Beauty→Sports、Sports→Instruments、Instruments→Beauty 相对 MiniOneRec 的平均 HR@10/N@10 提升为 +24.8%/+27.3%。

**收益归因**

- 主要：深层兴趣增强的 SID 语义与兴趣感知 RL 奖励共同提升离线下一物品 SID 预测的 HR/NDCG；线上收益未核实。
- 次要：MLIM 的多 LLM 共识聚合可降低单一模型兴趣描述波动：论文报告 5 种配置下 HR@10 为 0.101–0.105，词面差异未破坏离线效果。
- 次要：IEID 将兴趣嵌入量化进 SID，消融中去掉后 Beauty HR@5 从 0.0678 降至 0.0621，说明兴趣增强离散化对离线排序有贡献。

**与你的关联**

- 若在电商或内容推荐中已有 SID 生成式召回，并能在离线预处理阶段调用多个 LLM 做兴趣抽取，可借鉴把兴趣文本注入 SID 及用兴趣标签塑造 RL 奖励的设计；迁移前需评估 API 成本、兴趣标签质量、SID 码本与现有生成式模型的一致性，以及离线特征刷新到线上的时延。

**风险或局限**

- 仅在三个 Amazon 评论数据集（Beauty/Sports/Instruments）做离线 leave-last-out 评测，未给出线上 A/B、生产部署或真实流量指标，跨域结论也限于这三个子域。
- 表 1 标注的相对提升与表中绝对值不完全一致：例如 Beauty HR@10 为 0.1032，较 MiniOneRec 的 0.0975 约高 5.8%，论文却标注 +12.4%，统计口径需核验。
- 兴趣挖掘依赖 GPT-4o/Gemini/Kimi/Grok 在线 API，论文报告三数据集总 API 成本约 120 美元、单机预处理 48 小时；线上服务虽不调用 API，但离线刷新成本、失败重试和模型版本漂移未系统评估。


### P1｜[快手、北京邮电大学｜RoFiGR: Coarse Routing, Fine Refinement via Level-Adaptive Distillation in Multimodal Generative Recommendation](https://arxiv.org/abs/2610.39470)

**论文、机构与场景**

- **机构：北京邮电大学、快手科技**
- 作者：Ji Dai, Zhipeng Wei, Zhuang Zhuang, Rongfeng Guo, Jie Chen, Quan Fang, Fei Pan
- 来源：arXiv:2610.39470v1
- 场景：Amazon Instruments/Arts/Games 多模态生成式推荐
- **论文主要内容：** 针对多模态生成式推荐早期SID路由易错，提出双树协同对齐与层级自适应分支蒸馏，提升粗路由准确率。

**主要创新或优化点**

- 把协同偏好注入SID粗粒度码空间：对累计L1–L2码向量与冻结协同物品嵌入做对比对齐，使早期路由分支更贴近行为相似性，L3–L4保持内容细化。生成器在首层自注意力于原生token距离偏置上增加物品距离与来源层级/距离桶偏置，缓解扁平化SID历史中位置相同但来源/物品关系不同的问题。面向合法分支做层级自适应蒸馏：用教师聚合的软分支分布替代仅一热子码监督，固定粗层锚点并用有界需求残差调节层级权重，将额外监督集中到教师相对学生和目录先验更有信息量的层级。

**核心方法**

- 在MACRec文本/图像双SID树上先以多模态残差量化构造四级码；再将累计L1–L2码向量与冻结MISSRec协同物品嵌入做批内对比对齐，L3–L4不受该约束，碰撞在L4或L3–L4修复。

### P2｜[Georgia Institute of Technology｜Merge and Branch: Efficient Tree-Structured Supervised Fine-Tuning of LLMs for Recommendation](https://arxiv.org/abs/2610.37973)

**论文、机构与场景**

- **机构：Georgia Institute of Technology**
- 作者：Yunqin Zhu, Yao Xie
- 来源：arXiv:2610.37973v1
- 场景：Amazon Beauty/Sports/Toys 全目录下一物品生成式推荐
- **论文主要内容：** 针对LLM生成式推荐历史编码昂贵且监督不足，提出交互token合并、多目标树训练与树注意力缓存。

**主要创新或优化点**

- 交互 token 合并：以物品 SID 嵌入构造 anchor 并生成物品内查询，用共享 cross-attention 将每个历史的 SID 与文本压成少量 soft token；保留物品顺序、缩短 LLM 前缀，区别于共享 query 的 Q-Former 和线性合并的 GenRec。
- 多目标树训练：在共享历史上并列 next-item、未来观测与教师合成 SID 分支，分支互不可见而梯度共同回传；每条历史获得多份监督，且推理时不需要其他目标物品。
- Tree FlashAttention 与共享前缀 KV cache：用树可见性规则在分块 online softmax 中执行前向/反向并汇总分支梯度，解码时历史 KV 只存一份、beam 仅复制短 SID 状态，支持约束 beam search 的长历史复用。

**核心方法**

- Merge 模块对每个历史物品先由各级 SID 嵌入构造 SID anchor，再以 anchor 加共享 learned offset 形成查询，对 SID 与文本 token 做 cross-attention，压缩为 Nq 个 soft token 并按时间顺序替换原字段作为 LLM 前缀。
- Branch 训练将下一物品、最多一个额外未来观测物品和两个由同一冻结 SASRec-CE 教师提出的合成 SID 作为并列分支，各分支可见共享前缀及自身前序 SID、不可见兄弟分支，按 λF=0.25、λS=1.0 分组归一化损失联合训练 merger 与 LLM。
- Tree FlashAttention 按 prefix 因果、branch 仅见 prefix 与自身因果前缀的可见性规则，在分块 online softmax 中完成前向/反向并把各分支梯度汇总到共享前缀；解码时共享前缀 KV cache 只存历史一次，GPU trie 约束 beam 的合法 SID 扩展。

**关键结果**

- Amazon Beauty/Sports/Toys 全目录 Recall/NDCG@5/10 的 12 个指标上 M&B 均优于基线，相对最强基线提升 2.48%–16.19%；其中 Sports Recall@5 0.0436 对 SASRec-CE 0.0375（+16.19%），Beauty NDCG@10 0.0597 对 SASRec-CE 0.0577（+3.46%）。
- Beauty 上 Nq=4 组件消融（5 次运行）：SID+Text 仅下一物品监督 NDCG@10=0.0500；仅加 token 压缩降至 0.0459；加合成目标升至 0.0589；再加未来目标达 0.0598，显示压缩单独不保留 SID+文本优势而多目标监督带来增益。
- H200、有效 batch=128、Beauty Nq=1 全监督下，M&B 训练步时 192.34±2.57 ms、峰值内存 31.59 GB；未压缩 SID+Text 参考为 3650.01±55.51 ms、99.58 GB（后者 micro-batch 16、累积 8）。

**收益归因**

- 主要：整包配置收益：在 Beauty 全监督设置下，压缩历史、多目标分支与 Tree FA 的整包训练成本明显低于未压缩 SID+Text 参考；组件消融支持合成目标的排序增益，但不支持 token 合并单独增益，多目标分支本身也增加步时，故成本优势不能归因于单一模块。
- 次要：多目标监督提升离线排序质量：未来观测与同一冻结 SASRec-CE 教师合成的额外 SID 分支不增加推理输入，组件消融中合成目标带来的 NDCG@10 提升最大。
- 次要：约束 beam search 降低解码内存与延迟：共享前缀 KV cache 只保留一份历史状态，各 beam 仅维护短 SID 分支，并用 GPU trie 限制合法扩展。
- 次要：机制解释（未单独消融）：历史只算一次并用 Tree FlashAttention 汇总各分支梯度可减少重复前缀计算；注意力基准中 Tree FA 与 Causal FA 时间接近，端到端训练加速不能单独归因于该模块。

**与你的关联**

- 适用于 LLM 生成式召回/语义 ID 推荐的 SFT 与解码优化；若线上历史以 SID+文本表示且需全目录 SID 生成，可借鉴物品内 token 合并、多目标训练和共享前缀缓存。迁移前需在自有数据上验证压缩是否损失内容信号，并确认教师目标与线上目录约束一致。

**风险或局限**

- 公开实验仅覆盖 Amazon 2014 5-core 的 Beauty/Sports/Toys 三个离线数据集，平均交互长度约 8–9，未提供工业长历史或线上 A/B 结果。
- 主结果按验证 NDCG@10 从五个 M&B 随机种子中选最佳 checkpoint 后报告测试指标，可能使与基于单次运行或文献引用基线的比较偏乐观。
- 效率测量限定 H200、BF16 与特定 batch/序列布局；训练对比中未压缩参考使用 micro-batch 16、累积 8，尚未给出生产吞吐、成本或不同硬件上的扩展结果。

### P1｜[University of Amsterdam｜RRC｜Relevance-Guided Residual Calibration for Spectral Compression of Dense Retrieval Embeddings](https://arxiv.org/abs/2610.37707)

**论文、机构与场景**

- **机构：University of Amsterdam**
- 作者：Yongkang Li, Panagiotis Eustratiadis, Evangelos Kanoulas
- 来源：arXiv:2610.37707v1
- 场景：稠密检索嵌入压缩与首阶段候选检索
- **论文主要内容：** 提出闭式残差校准，用相关性判断修正稠密检索谱压缩的方向权重，兼容多种谱先验。

**主要创新或优化点**

- 问题：PCA/Whitening/SpecTemp 等谱压缩用共享幂律趋势给所有保留方向定权，不能按方向对相关性的贡献单独调整。
- 新算法：闭式 RRC 用训练查询的正负文档对估计方向级 margin 均值与方差，以 e_i=(m_i)_+/v_i 定正支撑；在 log 空间拟合幂律趋势并取残差，把残差加到任意正谱先验的 log 权重上，支撑外置零。
- 新原则：残差对谱坐标的幂律重标定不变，同一残差可复用于 PCA、Whitening、SpecTemp；校准折入文档与查询共享的单一固定映射，无迭代训练或额外推理阶段。
- 实证发现：消融显示支撑选择与残差加权各自提升均值；幂律拟合优度越高，校准增益倾向越小。
- 边界：margin 权重的均值-方差形式与 diagonal LDA 相关（既有思想），SpecTemp 与谱基沿用前序工作；新增在用于谱先验的残差校准与跨先验复用。

**核心方法**

- RRC 在固定谱基的每个保留方向上，用训练查询的正负文档三元组计算 margin contribution z_i=c_i(q)(c_i(d+)-c_i(d-))，并按查询均衡估计均值与方差，得到 e_i=(m_i)+/v_i 作为方向权重估计。
- 对正 e_i 的支撑集，RRC 在 log 空间用最小二乘拟合 log e_i 对 logλ_i 的幂律趋势，取残差 u_i=log e_i-(a-γ_e logλ_i)，再令校准权重 w_i=p_i e^{u_i}（支撑集外 w_i=0），其中 p_i 为 PCA/Whitening/SpecTemp 的谱先验。
- 校准后的权重折入 diag(√w)U_k^T(x-μ) 的单一固定映射，同时用于文档索引和查询压缩；过程只需矩估计与最小二乘，无迭代训练或额外推理阶段。

**关键结果**

- 在 3 个编码器、9 个数据集、4 个目标维度上，SpecTemp+RRC 在 BEIR 组和 BRIGHT 的每个目标维度取得测试压缩方法中的最高平均效果；BEIR 组 k=768 仍低于全维参照，BRIGHT 组 k=768 高于全维参照。BRIGHT 五数据集在 k=768 时比 SpecTemp 平均高 2.34 nDCG@10 点。
- BRIGHT 15 个编码器-数据集配置上，k=768 时 SpecTemp+RRC 平均 nDCG@10 为 32.53，SpecTemp 为 30.19（+2.34，11/15 胜）；k=512 为 31.96 对 29.75（+2.21，11/15 胜）。
- 量化实验中，SpecTemp+RRC 在 FP32/FP16/SQ8/SQ4 下均优于 SpecTemp，SQ4 增益缩小；SQ8 每文档 768 字节时平均 nDCG@10 为 32.49，原始全维嵌入经 SQ8、平均每文档 3413 字节时为 32.02。

**收益归因**

- 主要：在论文所测离线配置中，用相关性判断校正谱压缩的方向权重，提升压缩嵌入的平均检索效果并改善每文档存储-效果权衡；该收益为 SpecTemp+RRC 整包配置结果，模块级归因仅由消融实验支持。
- 次要：闭式矩估计与最小二乘拟合免去迭代训练，校准后复用单一压缩映射，不增加测试时相关性反馈。
- 次要：残差对幂律重标定不变，可复用到 PCA、Whitening、SpecTemp 等不同谱先验。
- 次要：与标量/乘积量化叠加时多数编码配置保持增益；SQ4 下增益缩小，匹配存储预算的对比来自离线 Pareto 前沿，未含共享矩阵与码本成本。

**与你的关联**

- 适用于固定编码器的稠密检索或首阶段召回：在已有谱压缩基线上，用目标域带相关性判断的训练查询离线校准权重，再以单一固定映射压缩文档与查询；迁移需目标域标注并对目标语料重估谱基与残差，论文未报告跨域迁移实验。

**风险或局限**

- RRC 需要目标检索任务的带相关性判断训练查询；BRIGHT 每折仅 60–114 个 judged queries。RRC 无学习率与停止准则，但标签规模对校准质量的影响未单独分析，跨域迁移未测。

- 所有结果来自离线跨折评测，未报告线上 A/B 或生产部署；存储对比不含共享变换矩阵与码本摊销。

### P1｜[DoorDash｜PALATE: Pretrained Autoregressive LATent Embeddings](https://arxiv.org/abs/2610.39090)

**论文、机构与场景**

- **机构：DoorDash（PDF 首页作者署名区为每位作者标注了 DoorDash，且作者邮箱后缀均为 @doordash.com）**
- 作者：Sizhang Zhao、Praveen Gondhi、Bin Li、Utsaw Kumar
- 来源：arXiv:2610.39090v1（GRAIL @ CIKM '26 workshop）
- 场景：DoorDash 本地生活/外卖广告，Discovery 与 Search 两个广告面的 DCNv2 精排个性化
- **论文主要内容：** 用GPT式序列模型建模DoorDash用户门店行为，导出冻结用户向量作广告精排特征

**主要创新或优化点**

- 生产 ranker 原先只有手工聚合与无序池化历史；本文训练 GPT 式下一 business 预测模型，把末位隐状态冻结为 256 维向量交给独立 DCNv2 精排，序列建模从各 ranker 内部搬到单个离线作业，区别于 TIGER/HSTU 直接生成候选与 DIN 式 in-model 模块。
- 针对复购主导历史提出探索加权损失（新 business 权重 0.9、重复 0.1），离线显示以整体 recall 换新 business recall 的权衡。
- 两阶段课程：先点击预训练保持浏览广度，再从该 checkpoint 热启动做转化微调。
- 负样本：约 60K 热门 business 固定池与曝光未下单 business 作硬负，混合随机与 in-batch 负；全 softmax 降点击困惑度并提点击召回，转化召回持平，故保留 sampled softmax。

**核心方法**

- 输入表示：每次门店交互为 256 维 store id 与 business id 查表嵌入，加 5 个各 4 维的学习上下文特征（时段、周末标志、本地小时、星期几、是否广告曝光），拼成 532 维后投影到 768 维主干并叠加 200 位学习位置嵌入。
- 主干与目标：3 层 3 头×256 的 decoder-only 因果 Transformer 预测未来若干 business（非 store）；因全词表精确 softmax 过贵改用 sampled softmax，硬负为约 60K 热门 business 固定池与曝光未下单 business，另加随机与 in-batch 负，较远预测步固定降权 0.5。
- 训练与复用：点击序列预训练后从该 checkpoint 热启动微调转化序列；损失新 business 0.9、重复 0.1。末位隐状态导出为 256 维冻结用户嵌入（无梯度回传），输出层每 business 同空间 256 维向量一并导出；经 φ(u,c)=[u,c,u⊙c,cos] 供 DCNv2，每日一次推理作业服务 Discovery 与 Search。

**关键结果**

- 离线 ladder：在重训 DCNv2 与 +0.33% 的 store 嵌入/近 N 转化门店均值池化之上，9:1 探索加权用户嵌入再加 +0.59% 相对 Eval-AUC（Discovery），Search 为 +0.57%；均匀加权版本约 0.00%，内置 DIN 注意力仅再 +0.03%。
- 线上 A/B（各一周、按 consumer_id 50/50 分流）：Discovery 收入 +0.79%、CVR +1.17%、eCPM +0.66%（均 p<0.001），CTR −0.10% 与 ROAS +0.13% 不显著；Search 收入 +0.94%、CVR +1.50%、CTR +1.38%、eCPM +1.56%，ROAS −0.01% 不显著。
- 内在评测消融：硬负样本使 R@10 +14.3%、R@30 +9.0%；9:1 探索加权整体 R@10 −20.4% 但新 business R@10 +29.1%；去掉重复序列后整体 R@10 −67.5%；全 softmax 使点击困惑度降 26% 但转化召回持平。

**收益归因**

- 主要：离线训练一次、冻结复用的 256 维生成式用户嵌入作为精排稠密特征；离线加性 ladder 中 9:1 探索加权嵌入是最大单特征增量（Discovery +0.59%、Search +0.57% 相对 Eval-AUC），均匀加权版 ≈0.00%；线上增益属捆绑重训，未单独归因
- 次要：探索加权损失把表征拉向新商家发现：9:1 下新 business R@10 +29.1%，代价是整体 recall 下降，属显式权衡。
- 次要：输出层 business 向量与用户向量同空间一并导出，下游可直用其交互，无需另训 item 嵌入。
- 次要：序列建模集中到一个每日离线作业、两广告面共享，避免每个 ranker 各自训练与部署序列编码器。
- 次要：硬负样本提升整体 recall（R@10 +14.3%），而全 softmax 在转化目标无额外召回收益，支撑用 sampled softmax 控制成本。

**与你的关联**

- 适用任务：已有或可建独立离线序列模型、且下游有多个精排模型可共享同一用户表征的搜广推链路。迁移条件：能接受日级刷新的非实时表征、有足够曝光未下单日志构造硬负、且业务复购占比高（外卖、生鲜、本地生活）。不适用于需要会话内实时意图或无法承担每日全量推理的场景。

**风险或局限**

- 两次线上 A/B 都是捆绑式 ranker 重训（同时改动多项），作者明确说明线上涨幅不能单独归因于用户嵌入。
- 离线 ladder 与内在评测均为 single-run 点估计，未给置信区间或多种子重复。
- 未披露每日嵌入刷新作业的算力与成本、线上推理开销，也缺训练样本规模与负样本池更新策略等复现细节；硬负中的曝光未下单样本本身为噪声负（作者承认消费者可能仍喜欢）。

### P0｜[腾讯、内容事业群｜CCFormer: Efficient Cross-Field Interaction and Hierarchical Sequence Compression for Industrial Recommendation at Tencent](https://arxiv.org/abs/2607.28070)

**论文、机构与场景**

- **机构：腾讯平台与内容事业群（Platform and Content Group, Tencent）**
- 作者：Yunlong Wang, Huizhe Zhang, Haonan Hu, Yudong Li, Bing Wen, Jianchao Tu, Chengxiang Zhuo, Zang Li
- 来源：arXiv:2607.28070v2
- 场景：视频推荐、广告排序等四个生产场景的候选排序与CTR/观看/收入预测
- **论文主要内容：** 面向工业候选排序，解耦跨字段检索与历史内建模，并用分层压缩降低长序列成本。

**主要创新或优化点**

- 将候选排序中的跨字段检索与历史内部建模解耦：用三条有向交叉注意力替代拼接字段的稠密自注意力，并让不同关系独立softmax，避免用户与历史在共享归一化池中竞争。
- 对长历史做局部时空编码与“行为×通道”联合子空间门控混合，使混合宽度不随序列长度增长而增长，为长序列排序提供线性成本的结构化token交互。
- 提出先交互再压缩的分层历史：在块边界逐级降低历史token数，使用户和目标query能在不同深度读取由细到粗的历史证据，压缩同时改变后续交互粒度并降低计算。
- 推理侧将同一请求的全部候选目标打包一次前向以复用候选无关计算；这属于系统与部署设计，可与结构创新共同提升吞吐，但论文未把线上增益归因到该优化。

**核心方法**

- 输入被划分为用户、行为序列、目标物品三个语义字段；每个CCFormer块用用户→历史、目标→历史、目标→用户三条有向交叉注意力，各关系使用独立query投影和独立softmax，输出融合后经RMSNorm残差更新用户与目标表示。
- 长序列先按m个相邻行为分组，用指数幂时间核与共享有符号相对位置表做局部时空编码，再在“m个行为×n个通道”联合子空间内通过通道组特定的门控FFN混合并还原序列布局；混合宽度与序列长度无关，计算随长度线性增长。
- 默认8个块中在零基索引第1、3、5、7块后（即每两个块后）以Conv1D(k=3,s=2)压缩历史token，形成由细到粗的候选无关历史层次，供用户/目标query逐层读取；线上同一请求把所有候选目标打包一次前向，复用用户与历史计算，多任务头对候选分别输出分数。

**关键结果**

- 两个公开集：Taobao AUC 93.67%、KuaiRec 83.35%，均高于所评测基线，分别比STCA/OneTrans高0.86/0.59个百分点；但Taobao以0.5概率原位替换目标构造合成负样本，KuaiRec保留原始观看反馈负样本，二者均非自然曝光CTR。
- 工业集：AUC 77.94%、GAUC 71.36%，较HSTU高0.28/0.50个百分点，较HSTU+TokenMixer高0.18/0.33个百分点；GFLOPs/样本16.64，较HSTU 36.89和HSTU+TokenMixer 41.45分别低54.9%/59.9%，训练吞吐为HSTU的2.21倍。
- 四场景线上A/B（每组每日曝光用户超百万、两周）相对各自生产基线最高CTR +3.57%、Page View +3.86%、广告收入 +1.71%，QPS提升11.1%-34.5%，已全量部署；作者称是系统级结果，未隔离单模块贡献。

**收益归因**

- 主要：整包CCFormer在工业集上相对HSTU/HSTU+TokenMixer取得更高AUC/GAUC和更低GFLOPs，四场景线上为整包系统级业务与QPS收益；消融支持跨字段交互对精度、分层压缩对吞吐的作用，但不支持线上单模块因果。
- 次要：训练效率：完整配置训练吞吐为HSTU的2.21倍；消融中去掉分层压缩后吞吐明显下降，支持压缩对吞吐的贡献，但token mixing的独立因果未由整包A/B隔离。
- 次要：服务效率：四场景QPS相对各自基线提升11.1%-34.5%；其余三个场景的基线已使用候选并行预测，首个场景还同时改变序列长度、架构与并行方式，不能把QPS增益单独归因于候选打包。
- 次要：业务效果：四场景CTR、Page View、广告收入等指标提升，属整包系统级A/B，未隔离各模块贡献。

**与你的关联**

- 适用于已有较长用户行为序列、需在严格时延预算下做多场景候选排序的推荐/广告系统；可迁移的是跨字段交叉注意力、线性成本token mixing与分层压缩组合，需具备候选并行打分和Conv1D压缩实现条件。

**风险或局限**

- Taobao公开集以0.5概率原位替换目标构造合成负样本，KuaiRec保留原始观看反馈负样本；公开集结果不是自然曝光CTR，AUC优势不能直接外推为线上CTR提升。

- 论文未给出各业务指标的置信区间、多重比较校正或长期留存结果，统计仅报告用户级two-sample t检验p<0.05；复现依赖腾讯内部>4B样本工业数据和16卡H20环境。


### P0｜[阿里巴巴｜UGR: Unified Generative Ranking for Heterogeneous E-commerce Recommendation](https://arxiv.org/abs/2610.39426)

**论文、机构与场景**

- **机构：Alibaba Group, Hangzhou, China**
- 作者：Zonghe Shao, Huabin Chen, Sitong Lu, Fangmei Zhu, Yingcai Ma, Ge Fan, Jinguo Gao, Wei Shi, Yanfang Liu, Huiping Chu
- 来源：arXiv:2610.39426v1
- 场景：淘宝猜你喜欢电商推荐中多业务异构候选的列表生成排序与广告价值融合
- **论文主要内容：** 针对多业务电商候选，UGR用候选感知自回归解码直接生成排序列表，并联合反馈监督与广告去偏。

**主要创新或优化点**

- 把生成式重排从“单业务截断候选+后置 mixrank”推进到请求级多业务全候选集直接生成最终列表；同一生产基线的在线对照显示统一生成优于“单业务生成+跨业务混排”的分阶段方案。
- 在曝光序列 NTP 之外引入互补反馈监督：WSFT 按曝光后 IPV/CVR 反馈重加权逐项似然，PermPO 用反馈 DCG 构造同一曝光集合的排列偏好对，分别提供 item 级与 list 级监督。
- 把历史广告曝光/竞价选择效应拆到仅训练时使用的广告去偏塔，线上移除该塔并把当前 eCPM 加性融入生成分数，在沿用现有分配与 GSP 计价规则的前提下建模商业价值。
- 多值序列检索共享一次请求与候选编码，按累计融合分数保留 top-N 前缀生成多个候选列表交下游评估器选择。

**核心方法**

- 请求上下文编码器把用户属性、请求上下文和历史行为token经masked self-attention聚合成单一request context token；异构候选经Candidate_Embed映射到共同嵌入空间，并用rank=8的低秩候选注意力一次性上下文化请求级约1000个候选。
- 候选感知自回归解码器以会话token和已选候选表示序列为输入，位置相关投影后与候选表示计算缩放余弦logit，再在合法候选集上softmax逐项选候选；已选项从后续合法集移除，从而生成多业务排序列表。
- 训练联合NTP、WSFT与PermPO：WSFT按IPV与CVR反馈的加权和重加权曝光项逐项似然，PermPO用反馈DCG构造同集合不同排列的偏好对；训练时广告去偏塔以广告item特征与历史eCPM产生ad专用logit调整，线上移除后按S_t=z_t+αeCPM融合当前广告价值，多值序列检索按累计分数保留top-N路径并返回至多N个列表。

**关键结果**

- 线上A/B（淘宝猜你喜欢，处理组≥5%流量、>14天，对照为生产基线）：UGR整包 Core IPV +1.76%、Transaction Volume +3.29%、GMV +2.10%（均p<0.05）；同期分阶段方案UGR-Single+Mix为+1.13%/+2.84%/+1.38%。
- 同一线上A/B：Ad Cost +0.08%、Ad PVR -0.93%（均满足广告护栏）；UGR整体serving平均推理延迟增加12 ms，原文未按模块拆分该延迟。
- 离线两个30天日志数据集：Scenario 1 IPV NDCG较UniRank +4.86%、IPV MAP较DEGR +7.53%、CVR MAP较DEGR +2.05%；消融中去掉PermPO使六项排序指标均下降。

**收益归因**

- 主要：主要收益来自统一多业务全候选集生成：在相同生产基线的在线对照中，直接生成多业务完整列表的UGR优于单业务生成后再mixrank的UGR-Single+Mix，支持省去后置跨业务混排、消除生成列表与最终列表的上下文错位；该结论限于淘宝猜你喜欢、≥5%流量、>14天的设置，属整包配置收益。
- 次要：互补反馈监督的收益由Scenario 1离线消融支持：去掉WSFT或PermPO后IPV与CVR的NDCG、MAP下降；但去掉WSFT时IPV与CVR的AUC反而略高于完整UGR，作者亦承认WSFT带来轻微AUC下降。
- 次要：广告去偏塔：训练时用广告item特征与历史eCPM产生ad专用logit调整、上线前移除，使生成logit与eCPM的相关性由正转负、塔调整与eCPM正相关，属机制性证据而非线上模块级因果证据。
- 次要：12 ms为UGR整体serving相对基线的延迟增量，不构成多值序列检索单独的延迟归因；请求编码、候选嵌入与候选注意力每请求只计算一次并复用于各检索路径，是该设计的实现事实。

**与你的关联**

- 适用于已有上游召回/粗排、单请求候选约千级，并需要在精排/重排阶段统一多业务混排且兼容GSP计价的电商推荐；迁移前需具备请求级全候选、曝光后IPV/CVR反馈、当前eCPM输入与低延迟服务约束。

**风险或局限**

### P2｜[杭州电子科技大学、三亚市中医院、火箭军工程大学作战保障学院等｜PHKT:Personalized Dynamic Hypergraph-enhanced KAN-Transformer for Multi-behavior Sequential Recommendation](https://arxiv.org/abs/2606.05537)

- （作者主张）标准 FFN 对所有潜在行为模式共享同一激活模板，只能折中拟合，而不同潜在模式对购买预测的贡献-响应形状不同；故用 KAN 层（每维 K 个径向基函数加可学习权重组合）替换 FFN 的一层线性变换与激活，使各隐维度拥有独立响应函数。个性化动态权重超图：按行为类型初始权重 [0.3,0.7,1,0.4] 构造对角阵，对物品余弦相似度两端加权 W·Sim·W，再取 top-k 组成超边，使超边随用户行为序列变化。分析判断：相对 MBHT 等方案的真正增量是 FFN 的 KAN 替换与行为加权动态超边，而非 Transformer 加超图的组合本身。

- 个性化动态权重超图（PHDW）：为行为类型设初始权重（view/add-to-cart/purchase/others 为 [0.3,0.7,1,0.4]），据此构造对角矩阵 W，对物品余弦相似度矩阵做 W·Sim·W 两端重加权，再对每个物品取加权相似度 top-k 组成超边，得到用户级超图，经 HGNN 传播 G=Dv^-1·H·De^-1·H^T 输出结构表征

### P2｜[Meta｜mixture-weighted reward modeling｜Beyond IPS: Reliable Counterfactual Evaluation in Multi-Stage Ad Systems without Logged Propensities](https://arxiv.org/abs/2610.40112)

**论文、机构与场景**

- **机构：Meta Platforms, Inc.**

- 用多分类域分类器估计候选混合分布与日志分布的密度比，将候选回放样本转成训练权重，并配合裁剪与 ESS 诊断；与逐候选训练 N 个模型的方案不同，它只训练一个共享模型并让权重覆盖候选混合。
- 将 replay-DM 价值误差拆成 overlap、cold-start 与有限样本 replay 三项，给出 Top-1 选择 regret 界及以 cold-start mass 为判据的离线选择/线上 A/B 路由规则，为评估结果的可信度提供可计算诊断。

**核心方法**

- 将每个候选策略在日志上下文上回放，构造目标混合分布 Pmix=ΣjβjPπj（默认βj=1/N），并以混合分布对日志分布的密度比 Ω(z)=pmix(z)/p0(z) 对奖励模型的监督损失加权，训练一个共享奖励模型。
- 用多分类域分类器区分日志曝光与各候选策略回放动作，在均衡类先验下用 q(j|z)/q(0|z) 估计逐策略密度比，再合成混合权重，并对权重做上限裁剪，以有效样本量 ESS 诊断重叠程度。
- 在独立回放上下文上对每个候选策略计算奖励模型均值，得到直接法（DM）价值估计；理论将误差分为 overlap、cold-start mass 与有限样本 replay 项，并用 cold-start mass 给出是否信任离线选择或转线上 A/B 的渐近判据。

**关键结果**

- 模拟器使用70,000条日志、10,000用户、1,000广告和k=10候选，50个种子共350次试验；低ESS区间Weighted DM的Top-1准确率0.81、regret0.0014、Value MAE2.65%，优于Unweighted DM的0.67、0.0044、7.20%，Weighted DR进一步达0.90、0.0005、1.71%。

- 次要：混合加权使单一奖励模型覆盖多个候选策略，减少逐候选训练成本并缓解低重叠区域的分布偏移。
- 次要：域分类器密度比、权重裁剪和 ESS 可作为重叠诊断，帮助识别离线评估不稳定情形。
- 次要：误差界与 cold-start mass 可把离线筛选和线上 A/B 资源分配连接起来。

**与你的关联**

- 适用于缺少曝光倾向分、需从多个广告或推荐排序候选中筛出少量上线 A/B 的场景；可复用其域分类器密度比加权、ESS 与 cold-start 诊断来评估离线策略选择可信度。

## 今日最值得立项的实验

### 生成式召回解码的历史KV渐进聚焦

- 假设：在SID自回归beam search召回中，历史注意力随解码步向少数token集中且排序跨步稳定，因此用早期步跨beam共享排序加几何缩减预算，可在保持召回指标的同时降低解码延迟。
- Control：现有全历史注意力解码：每步对所有历史token做完整注意力并重算beam。
- Treatment：第1步按各beam归一化概率聚合注意力得共享token排序并重排KV缓存，第t≥2步按几何比例缩减top-k预算只在排序前缀上做注意力。
- 保持变量：同一编码器与SID词表、同一用户历史长度上限、同一beam宽度与硬件、同一评测数据集与beam约束trie。
- 离线指标：Recall@10与NDCG@10；解码每batch延迟与峰值显存；不同序列长度与beam宽度下的延迟曲线
- 线上 Guardrail：线上广告收入、CTR与GMV不出现负向；在线推理RT不超过现网预算；长尾/冷门SID的召回覆盖不出现系统性下降

### 多业务全候选集统一生成重排

- 假设：在已有上游召回粗排、单请求候选约千级的电商场景，直接对多业务全候选集做候选感知自回归列表生成，优于单业务生成后再跨业务混排。
- Control：单业务生成式重排加后置跨业务mixrank，候选集、下游评估器与计价规则一致。
- Treatment：请求级约1000候选一次编码，自回归逐项在合法候选集上选择生成最终列表，线上把当前eCPM加性融入生成分数。
- 保持变量：同一召回粗排候选集与特征、同一列表长度与检索宽度、同一广告分配与GSP计价规则、同一评估流量口径。
- 离线指标：IPV/CVR的NDCG与MAP；列表级排序指标；推理延迟增量
- 线上 Guardrail：线上GMV与广告收入不出现负向；Ad Cost与Ad PVR在护栏内；serving延迟增量不超过预算

### 日更物品嵌入跨日对齐与热启动尺度管理

- 假设：多日日志混训CTR时，对日更物品嵌入做锚点正交对齐并按全词表平均范数每日重缩放继承表，可降低跨日方向与尺度漂移并提升GAUC。
- Control：现有日更Word2Vec嵌入直接热启动继承item与context表，无对齐与重缩放。
- Treatment：加入锚点正交映射到前一日处理版本，并叠加每日全词表范数重缩放；另设仅对齐、仅重缩放两个子臂。
- 保持变量：同一嵌入维度与词表、同一CTR DNN结构与训练天窗、同一评估队列且锚点与评估不重叠。
- 离线指标：跨日余弦相似度与版本内检索排序一致性；GAUC与LogLoss；日匹配平均范数相对变化
- 线上 Guardrail：线上CTR与广告收入不出现负向；特征尺度漂移监控不告警；对齐与重缩放引入的批处理时间在预算内


## 一句话总判断

证据概况：收录 19 篇，全文核验 15 篇；标记为线上 A/B 证据 3 篇。

本期主线是生成式召回与序列排序同时改造服务成本与监督信号：PFA与UGR给出带线上A/B的解码加速与全候选集列表生成，CCFormer用跨字段交叉注意力加分层压缩在长序列排序上换吞吐，PALATE与PRISM则把用户表征做成离线批量计算、下游复用的工程形态。另一条线索是围绕SID表示与蒸馏的精细化：ComeIR、RoFiGR与DeepInterestGR分别从条件记忆、层级蒸馏和多LLM兴趣挖掘修正离散化语义，多为离线消融支撑。工程判断：带线上证据的三篇均为整包或捆绑配置，不能拆成单模块因果；PALATE与PRISM虽把同一表征供多个模型消费，但跨召回、粗排、精排多阶段复用的证据仍不足，不能据此称为Foundation Feature。
