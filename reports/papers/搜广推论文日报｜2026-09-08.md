## 召回

### P2｜[Beyond Co-purchase Relation: Evolution of Complementary Recommendations at Allegro](https://arxiv.org/abs/2609.05063)

**论文、机构与场景**

该论文发表于 arXiv，作者来自波兰电商平台 Allegro，研究互补商品推荐（Complementary Product Recommendation）的工业部署场景。

**核心方法**

论文提出 AlleCompanion 召回框架（Allegro.com 生产环境运行），结合数据级过滤启发式与类别约束双塔架构（Category Adapter 在嵌入空间约束候选）；引入 ComCat（互补类别映射）作为翻译层，整合专家规则、人类反馈、LLM 推理与统计挖掘，从噪声共购信号中提炼语义兼容性。

**主要创新或优化点**

该方法在大型电商平台（Allegro）用类别约束双塔架构与 LLM 推理，从共购噪声中提取语义互补性，实现召回侧生产级可维护的语义兼容候选过滤，对电商互补推荐召回实践有参考价值。

**关键结果**

服务于超过 2000 万月活用户；框架在归因 GMV（有机发现）方面带来显著提升；带动了赞助位广告收入的实质性增长。

**与你的关联**

该工作针对电商互补商品推荐场景，与推荐系统链路中召回阶段（候选生成）相关的双塔架构、类别约束和噪声过滤方法高度相关。

**可信度**

technical_report

**风险或局限**

摘要只给出上线结论和 GMV 提升，未披露离线或在线 A/B 的具体量化数字；论文强调工程实践，未展示模型架构或损失细节的完整技术验证；未详细描述专家规则与 LLM 推理在流程中的具体交互或成本控制。


## 模型结构与特征交互

### P1｜[UniCon: A Unified Context-Centric Modeling Paradigm for CTR Prediction](https://arxiv.org/abs/2609.03290)

**论文、机构与场景**

arXiv 2609.03290v2 论文提出 UniCon；作者均标注美团，落地场景为美团搜索广告精排 CTR 预估。

**核心方法**

UniCon 以曝光/请求为单位构造 context unit，候选反馈用可学习占位符对齐历史点击反馈；intra-context attention 建模同屏局部耦合，inter-context attention 建模跨上下文动态演化，并叠加点击/曝光/绝对位置多任务监督；训练与推理采用 padding-free 变长注意力、逐层上下文级 TopK 压缩（Gumbel-TopK 训练、硬 TopK 推理）及 AOTInductor 编译服务；线上目标分片上限 300 候选，超过则哈希切分；离线 AUC 0.8558 提升至 0.8697（+0.0139）；线上 7 天 A/B 实验（20% 流量）RPM +3.09%、CTR +2.07%、收入 +2.95%，p≤0.01，延迟满足 SLA。

**主要创新或优化点**

把 CTR 统一建模从 token 级序列/非序列拼接收敛为 context-unit 结构化组织，兼顾同屏局部竞争与跨上下文动态，并给出完整线上验证与压缩部署方案，是工业精排统一建模的重要进展。

**关键结果**

离线对比生产 Base 及 OneTrans/HyFormer/RankMixer 等统一基线：压缩版 UniCon-Large AUC 0.8697 vs Base 0.8558，GAUC 0.8194，LogLoss 0.1991；七天线上 A/B 占 20% 流量：RPM +3.09%，CTR +2.07%，收入 +2.95%，三项均 p≤0.01，延迟在 SLA 内；上下文压缩将计算从 801.29 降至 197.14 GFLOPs，AUC 几乎不变；结合变长注意力后服务吞吐较定长未压缩基线提升 258.1%。

**与你的关联**

对搜广推精排与 CTR 团队直接相关：可借鉴请求上下文结构化建模、同屏候选耦合、曝光/位置多任务监督以及上下文级压缩部署；对搜索广告、瀑布流等高上下文场景参考价值高。

**可信度**

online_ab

**风险或局限**

结果依赖美团搜索广告单一产品线及其内部生产基线与数据，未公开数据且尚未经正式同行评审，外部难以复现；曝光与绝对位置辅助目标由既有生产策略日志生成，只向当前曝光分布正则化，不能从因果上优化最终展示列表；候选分片缩减会削弱上下文信号：分片从 300 降到 64 时 AUC 降至 0.8683；超大请求需切分，可能切断相关候选间的局部竞争。


## 多任务与目标建模

### P1｜[Personalized Task Dependency Graphs for Mitigating Signal Erosion in Multi-Task Recommendation](https://arxiv.org/abs/2609.04862)

**论文、机构与场景**

CIKM 2026论文，作者Fuyuan Liu、Tiandeng Wu等共11人，标注单位Huawei Technologies（上海/东莞/南京/北京）；场景为应用分发平台精排，优化点击/下载/支付等多步转化目标与eCPM。

**核心方法**

核心方法PTDG用低秩矩阵为每个item动态生成任务依赖图，并注入用户与场景偏置，再经硬因果掩码与GCN传播建立自适应捷径，缓解固定转化漏斗导致的深层稀疏目标信号衰减；另提出Adaptive Progressive Masking，按任务标签正样本率自适应掩码解耦共享参数，并结合EMA损失均衡稳定训练；推理时无额外开销，线上相对MMoE端到端延迟仅增加8ms；离线评估在KuaiRand1K（8.4M样本，6任务）与工业数据集（13.2M样本，7任务）上进行，20个随机种子平均AUC均优于MMoE/PLE/STEM/MoCoGrad/PMTRec/MIT等基线。

**主要创新或优化点**

用实例级低秩任务依赖图替代固定转化漏斗，在保留Click到Pay等因果约束的同时动态重连任务路径，直接处理工业多任务精排中稀疏深层目标的信号衰减；离线与大规模线上A/B均验证，且延迟仅增加8ms，具备工业可迁移性。

**关键结果**

离线PTDG在KuaiRand1K平均AUC达0.9081，工业7任务平均AUC 0.8878，均高于全部对比基线；稀疏深层目标上工业Task 3相对PMTRec AUC提升1.45%，KuaiRand Follow相对MMoE提升1.77%；线上A/B在服务超1亿DAU的应用分发平台进行两周，10%基线对10%实验组且p<0.05，得到CVR相对提升1.2%、eCPM相对提升1.9%；消融显示移除个性化依赖图平均AUC下降1.21%，用Concat替换GCN下降0.93%，禁用APM下降0.59%，验证动态图、因果消息传递与结构掩码各自的贡献。

**与你的关联**

属于工业搜广推精排阶段的多目标转化建模，可直接与MMoE/ESMM/ESCM2类方案对照；若关注应用市场、社区或广告场景的深层CVR优化，可作为排序模型升级与消融设计参考。

**可信度**

peer_reviewed_paper

**风险或局限**

公开离线指标以AUC为主，未给出校准、NDCG等排序口径验证；工业数据集任务定义与详细特征保密，外部复现受限；线上A/B仅两周且实验流量各10%，基线只对比已上线MMoE，未与其他先进MTL方法在线比较，也未披露置信区间和具体p值；低秩维度q与掩码率依赖经验选择（q=2，rmax=0.7/rmin=0.2），作者自认缺乏正式scaling理论分析；场景以应用分发下载路径为主，向短视频/电商/广告迁移需进一步验证。


## 评测与评估

### P2｜[Necessary or Sufficient? Evaluating LLM Explanations With Behavioural Evidence](https://arxiv.org/abs/2609.05385)

**论文、机构与场景**

论文来自 arXiv（cs.AI），作者机构未披露，研究 LLM 决策组件在 agent 工作流中的解释（top 三影响因素）与实际行为的一致性评估。

**核心方法**

提出黑盒干预方法，分别以必要性（改变因子改变输出）和充分性（保留因子保留输出）分数量化因子影响，与模型引用的因子排名做 Spearman 相关比较；两处合成实验场景：给客户推荐顾问、判断提示词的危害性。测试 Claude、GPT、Gemini 八款模型；结果显示引用排名与必要性/充分性分数相关性低（0.349 至 0.580），未引用因子分数常高于最低引用的因子（advisor 必要性 57.6%）。

**主要创新或优化点**

为 agent 监督和 LLM 解释可靠性提供了黑盒验证框架，可诊断依赖因子说明的线上监控与升级决策风险。

**关键结果**

八模型上 advisor 推荐场景引用排名与 necessity 分数的平均 Spearman 相关 0.349，与 sufficiency 分数为 0.354；prompt 监控场景相关性较高，necessity 0.431、sufficiency 0.580，说明解释质量随场景差异大；advisor 响应中未引用因子分数超过最低引用因子的比例，necessity 下为 57.6%，sufficiency 下为 58.1%。

**与你的关联**

可用于 LLM-as-judge 打分或精排打分解释的可信度审计，辅助排查依赖 top 因素作诊断的上游推荐链路。

**可信度**

technical_report

**风险或局限**

仅评估 LLM 单步决策，未扩展到多轮 agent 工作流整体行为；必要性/充分性分数依赖黑盒干预估计，对输入扰动敏感且无理论偏好保证；场景为合成数据，非工业推荐或排序链路中的真实样本。


## CV 与多模态

### P2｜[Latent-Aligned Reasoning for Multimodal Recommendation](https://arxiv.org/abs/2609.04645)

**论文、机构与场景**

论文 LARK 由 arXiv 提交，作者 Jiarui Jin 和 Anyang Ji，机构未披露，面向多模态推荐场景。

**核心方法**

LARK 是两阶段潜在推理框架，在单一 VLM 内交替可学习潜在 token 与多步思维链推理，并与冻结视觉编码器对齐作为视觉检查点；第二阶段通过桥接 MLP 将潜在表示投影，用 item-to-item 对比学习训练，并将中间特征与第一阶段的思维链隐藏状态对齐以保持推理语义；在三个公开基准和一个工业数据集上测试，声称实现多推荐架构上的 SOTA，消融实验验证各组件贡献。

**主要创新或优化点**

针对多模态推荐中跨模态信息在推理中衰减的问题，提出可学习潜在 token 与推理对齐的新机制；但场景为通用多模态推荐，与工业短视频/直播/电商链路距离较远。

**关键结果**

在三个公开基准和一个工业数据集上达到 state-of-the-art 性能；消融实验确认视觉检查点和对齐机制各自有独立贡献；未提供具体数值或工业部署细节。

**与你的关联**

潜在可作为多模态表征或兴趣提取的方法参考，但未验证对 CTR 等工业指标的实际效果。

**可信度**

technical_report

**风险或局限**

未提供具体量化结果，核心结论仅来自摘要；工业数据集细节未披露，无法核实可迁移性；未公开代码或模型，复现难度未知。


### P2｜[MURAL: Multimodal Uncertainty-aware Recommendation via Adaptive edge Learning](https://arxiv.org/abs/2609.04574)

**论文、机构与场景**

论文提出 MURAL 框架，作者来自 American University、Ulsan National Institute of Science and Technology 等机构，面向多模态推荐场景。

**核心方法**

MURAL 用 Adaptive Edge Learner 结合可微检索和 ANN 搜索进行动态图拓扑发现，复杂度 O(NlogN)；MURAL 用 Uncertainty-Aware Fusion 建模模态不确定性和对比 teacher-student 对齐，抑制跨模态噪声；实验在 TikTok 和 Amazon 数据集上对比结构及生成式基线，声称准确率更优且有可解释性。

**主要创新或优化点**

MURAL 将多模态推荐从静态增强转向动态拓扑学习，并用不确定性融合处理噪声模态信号，属多模态模型创新。

**关键结果**

声称在 TikTok 和 Amazon 基准上显著超过结构和生成式 SOTA 基线；不确定性加权旨在对抗数据损坏，声称鲁棒性好；结构模糊时未提供外部核验。

**与你的关联**

可能改进短视频或电商等多模态内容推荐，但复用成熟的图文表征，直接工业落地取决于动态图计算的工程可行性。

**可信度**

technical_report

**风险或局限**

证据强度仅为基础预印本，无 peer review 或在线 A/B 结果；未附外部转载或官方公告，具体系统数字与部署细节缺失；适用性仅限于发布声明语言。
