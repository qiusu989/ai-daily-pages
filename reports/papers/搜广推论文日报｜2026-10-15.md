## 生成式召回

### P0｜[UniRec: Bridging the Expressive Gap between Generative and Discriminative Recommendation via Chain-of-Attribute](https://arxiv.org/abs/2604.12234)

**论文、机构与场景**

- **机构：Shopee**
- 作者：Ziliang Wang, Gaoyun Lin, Xuesi Wang, Shaoqiang Liang, Yili Huang, Weijie Bian, Li Zhang, Mingchen Cai, Jian Dong, Guanxing Zhang
- 来源：arXiv:2604.12234v5
- 场景：Shopee 电商平台主 Feed 与落地页推荐，统一生成式召回与排序，评估 PVCTR、订单和 GMV
- **论文主要内容：** 未披露

**主要创新或优化点**

- 现有 GR 在 SID 上解码时缺少物品侧特征，作者用贝叶斯 p(y|f,u)∝p(f|y,u)p(y|u) 论证差距来自特征覆盖而非建模不对称，提出 CoA 在 SID 前先解码类目/卖家/品牌属性 token，用额外自回归步换取逐层条件熵下降和 beam 稳定；理论为作者推导，缺乏第三方验证。
- 针对曝光长尾导致 SID 码本坍塌与 Matthew 效应，Capacity-constrained SID 在残差量化中按曝光权重约束每簇容量并重分配过载样本，使三级码本 top-1% token 曝光占比从 57.33% 降至 26.04%；消融显示换回 RQ-KMeans 时 HR@50 由 0.537 降至 0.481。
- 为统一多场景多目标生成，CDC 用 Task-Conditioned BOS 注入点击/购买与主 Feed/搜索等条件，用哈希 Content Summary 显式编码路径 token 对的笛卡尔积交互以避免 4000^2 级参数爆炸；消融显示去掉两组件在 HR@100 分别相对下降 7.8% 和 8.6%。

**核心方法**

- 核心机制 Chain-of-Attribute 在 SID 序列前先自回归生成类目、卖家、品牌等粗粒度属性 token，再条件生成 SID，以在生成轨迹中恢复物品侧特征交叉；作者用贝叶斯等价 p(y|f,u)∝p(f|y,u)p(y|u) 和逐层条件熵下降 H(s_k|s<k,a)<H(s_k|s<k) 论证其可缩小生成式与判别式的表达差距。
- Capacity-constrained SID 把曝光量作为聚类权重，在残差量化聚类中施加每簇容量上限 τ=1.05，并把过载簇样本重分配到最近的未满簇；论文报告生产数据 top 10% 的 (s0,s1) 组合占 87.9% 曝光，三级码本 top-1% token 曝光占比从 RQ-KMeans 的 57.33% 降至 26.04%。
- Conditional Decoding Context 由 Task-Conditioned BOS（联合编码点击/购买/加购等行为目标与主 Feed/搜索/相似品等场景）和 Content Summary（用 3 个哈希函数在共享嵌入表上显式建模路径 token 对的笛卡尔积交互）组成；训练采用 NTP，再用 GMV 加权的 RFT 与 DPO 联合对齐业务目标。

**关键结果**

- 离线全部样本：UniRec 0.05B 的 HR@50 为 0.537，较最强基线 OneRec-V2 的 0.438 相对提升 22.6%；HR@100 相对提升 18.2%，HR@200 相对提升 17.2%。
- 离线订单样本：UniRec 的 HR@50 为 0.672，较 OneRec-V2 的 0.582 相对提升 15.5%；HR@100 和 HR@200 分别提升 10.3 和 11.5 个百分点。
- 线上 A/B：Shopee 20% 流量分桶，整体 PVCTR +5.37%、订单 +4.76%、GMV +5.60%；主 Feed 订单 +4.27%、GMV +5.42%，落地页订单 +5.78%、GMV +6.19%；端到端延迟 110ms，传统多阶段链路 266ms。

**收益归因**

- 主要：统一生成式召回与排序，线上 GMV/订单/PVCTR 提升；离线消融支持 CoA 与容量约束 SID 的独立贡献，但各模块对线上收益的贡献未拆解。
- 次要：端到端延迟 110ms 低于传统 266ms 链路
- 次要：缓解 SID 码本曝光集中与长尾坍塌
- 次要：多场景多目标任务统一建模
- 次要：RFT/DPO 业务目标对齐

**与你的关联**

- 与搜广推工业链路高度相关：直接面向电商主 Feed/落地页的生成式召回与排序统一建模，CoA、容量约束 SID、任务条件 BOS、哈希组合特征、RFT+DPO 均可迁移；线上 A/B 和 110ms 延迟数据对工业落地有参考价值。

**风险或局限**

- 离线与线上实验均来自 Shopee 单一平台、主 Feed/落地页场景，未提供公开数据集或第三方复现，跨平台泛化未知。
- 论文为 arXiv 预印本 v5，会议与 DOI 未定；线上 A/B 未披露分流方式、实验周期、显著性检验和置信区间，工业结论强度有限。
- CoA 增加 m 个属性 token 的自回归步数，论文未量化精度收益与 token 预算/在线延迟的 tradeoff；贝叶斯等价与熵下降是在特征全覆盖假设下的理论推导，实际近似误差边界未给出。

### P2｜[AlignPoison: Conditional Targeted Poisoning of Generative Recommenders via Decoding-Aligned Prefixes](https://arxiv.org/abs/2610.14487)

**论文、机构与场景**

- **机构：University of North Carolina at Chapel Hill、University of Notre Dame、Meta**
- 作者：Zhuoxuan Zhang、Jinhao Duan、Xinyu Zhao、Jinduo Guo、Shuai Shao、Rui Li、Luke Simon、Zhun Deng、Tianlong Chen、Bo Sun
- 来源：arXiv:2610.14487v1
- 场景：生成式推荐模型的自回归解码与条件目标数据投毒攻击
- **论文主要内容：** 未披露

**主要创新或优化点**

- 已有生成式推荐安全性研究多聚焦建模质量与效率，对其在数据投毒下的鲁棒性缺乏系统刻画，本文把威胁模型明确为黑盒 API、有限注入与条件触发器，界定了可研究的攻击面。
- 已有投毒方法多依赖白盒梯度或与解码过程无关的前缀构造，本文提出从解码对齐与前缀流行度两个视角合成恶意交互，指出短且符合模型诱导转移动态的前缀是关键，改变了前缀搜索空间的选择依据。
- AlignPoison 不访问模型参数，仅从 API 输出中挖掘并采样上下文对齐前缀，使攻击框架可用于真实黑盒推荐服务，相对需要内部信息的方案降低了假设强度。
- 摘要层面只给出相对基线的 ASR lift，未披露机制消融与绝对指标，创新点与实际作用仍需正文核验。

**核心方法**

- 攻击设定：黑盒场景下攻击者仅能注入有限恶意交互并查询推荐 API，注入少于 1% 合成交互即可在触发器条件下显著提升恶意目标被推广的概率。
- 分析维度一：解码对齐（decoding alignment），即恶意交互前缀需与模型诱导的转移动态一致，使解码路径更容易命中目标。
- 分析维度二：前缀流行度（prefix popularity），短且与上下文对齐的前缀在频繁触发器关联下持续放大目标推广效果，AlignPoison 据此从 API 输出中采样上下文对齐前缀。

**关键结果**

- 在单模态与多模态生成式推荐基准上，AlignPoison 前缀方法优于竞争基线，ASR lift 最高提升 16.3 个百分点。
- 注入少于 1% 合成交互即可显著提升触发器条件下的恶意目标推广概率。
- 摘要级证据未披露具体数据集名称、基线清单与绝对 ASR 数值。

**收益归因**

- 主要：未核实
- 次要：未核实

**与你的关联**

- 生成式召回（自回归物品/SID 生成）是当前推荐链路的新范式，本文的投毒脆弱性分析直接关系到生成式召回在生产环境的数据安全、交互日志清洗与触发器检测策略。

**风险或局限**

- 仅有摘要级证据，未提供 PDF 正文，方法细节、数据集划分与统计显著性无法核验。
- 实验为离线基准攻击评测，缺少在线 A/B 或生产部署验证，距工业推荐系统实际风险仍有距离。
- 未披露机构信息，作者所属单位与产业合作背景无法核实。

### P2｜[Learning Across Temporal Graph Representation Silos](https://arxiv.org/abs/2610.19576)

**论文、机构与场景**

- **机构：韩国首尔建国大学（Konkuk University）计算机科学与工程系 Smart Computing Laboratory（依据论文首页作者 affiliation 及作者邮箱域名 @konkuk.ac.kr 佐证）**
- 作者：Minwoo Yu, Young-guk Ha
- 来源：arXiv:2610.19576v1
- 场景：跨连续时间动态图与时序知识图谱表征的可复用预测结构（推荐与安全检测概念验证）
- **论文主要内容：** 未披露

**主要创新或优化点**

- 针对的是时序图学习长期被表征边界割裂的问题：CTDG与TKG通常各自独立训练、知识无法跨表征迁移，本文检验预测结构能否跨边界复用并保留原有接口。
- 改变机制的方式是不要求实体或关系语义对齐，而在分数层面融合独立预训练的TKG与CTDG学习器，使异构时序源无需统一词表即可互相增强。
- 对源历史的受控重组揭示复用收益依赖于源-目标条件的组织方式，说明“同表征即更可复用”的直觉不成立，为选择外部预训练源提供了实验性判据。
- 证据边界：仅摘要级信息，复用与融合的具体机制、对比基线和提升幅度未披露，推荐与安全检测仅为概念验证。

**核心方法**

- 研究问题为关系历史中学到的预测结构能否在CTDG与TKG两种表征之间双向复用，且保留各自输入与预测接口及独立词表
- 对源历史的受控重组实验显示，促进复用的组织方式随源-目标条件变化，同一表征的源未必更有用
- 独立预训练的TKG与CTDG学习器可在分数层面融合，在第三个数据集上提升预测，且无需实体或关系语义对齐

**关键结果**

- 双向复用被观察到，同时保留不同输入与预测接口及独立词表，但摘要未给出具体指标数值
- 独立预训练的TKG与CTDG学习器在分数层面融合后，在第三个数据集上预测改善，摘要未披露具体提升幅度
- 源历史受控重组显示，对复用有贡献的组织方式随源-目标条件不同而变化
- 推荐与安全检测两个概念验证显示，无直接对齐的外部时序源可作为预训练资源，摘要无量化的推荐指标

**收益归因**

- 主要：未核实
- 次要：跨表征知识复用
- 次要：无对齐分数级模型融合

**与你的关联**

- 与推荐链路关系为间接：论文只以推荐作为概念验证场景之一，未给出面向工业召回、粗排或精排的具体建模与线上指标；可作为外部时序源做预训练与模型融合的探索性参考。

**风险或局限**

- 仅有摘要级证据，未披露复用与分数融合的具体方法、对比基线与指标数值，无法复现
- 推荐与安全检测均为概念验证，无线上A/B、生产部署或系统级指标
- 是否适用于工业大规模物料库的候选生成或排序流水线未经验证，迁移价值不确定

### P2｜[SimInter: Evidence-Grounded User Simulation with Interview-Based Profile Enrichment for Conversational Recommender Systems](https://arxiv.org/abs/2610.18308)

**论文、机构与场景**

- **机构：University of Tehran 电气与计算机工程学院（College of Engineering）与伊朗基础科学研究所（IPM）**
- 作者：Erfan Shahabi, Amirhossein Roshandel, Mohammad Sadegh Sadeghi, Azadeh Shakery
- 来源：arXiv:2610.18308v1
- 场景：对话式推荐系统的用户模拟器构建与评估
- **论文主要内容：** 未披露

**主要创新或优化点**

- 已有用户模拟器多依赖显式评分、人口统计等表层偏好画像，忽略决策风格、方面级偏好与领域专长等隐式行为特征，导致模拟对话偏好表达多样性不足。
- 本文用两个 LLM agent 的合成访谈从统计画像与历史对话证据中主动引出上述属性，改变了画像构建的信息来源与生成机制，而非仅改写既有画像。
- 在画像增强前引入轮级审计 agent，显式标记捏造与刻板印象，属对模拟数据可信度的前置约束，与常见只用后置人类评估的做法不同。
- 效果验证限于电影与 ReDial 离线模拟，未涉及真实在线推荐链路或系统级指标。

**核心方法**

- 方法通过两个 LLM agent 进行合成访谈，基于用户统计画像与历史对话证据，抽取决策风格、方面级偏好、领域专长等隐式行为属性
- 画像增强前设置审计 agent，在对话轮级别显式标记潜在捏造与刻板印象内容，再用于下游模拟
- 在电影推荐场景实例化：模拟 300 名 ReDial 用户，并在匹配的 100 名用户子集上与仅统计画像基线对比

**关键结果**

- 过滤后方面熵由统计基线的 0.859 提升至 1.619，配对 d=0.96，Holm 校正后 p<0.001
- 与两个训练好的推荐器 KBRD 和 UniCRS 对话时增益持续，在两个独立评估判官下提升 +0.28 至 +0.56 nats，均 p<0.001
- 人工评估显示 94.3% 的增强属性断言被支持或部分支持；分层样本上人工判断与审计二分类决策一致率 95.2%

**收益归因**

- 主要：未核实
- 次要：提升模拟用户偏好表达方面多样性
- 次要：提升模拟属性断言的可信度
- 次要：为对话推荐离线评估提供低成本用户模拟

**与你的关联**

- 用户模拟器可用于对话推荐系统与 LLM 驱动排序评估的低成本离线实验，但其直接作用对象是评估用用户行为生成，而非线上召回、粗排或精排模型，工程迁移价值有限。

**风险或局限**

## 今日最值得立项的实验

### 属性 token 前置解码（CoA）对 SID 生成式召回的离线增益验证

- 假设：在 SID 序列前先自回归生成类目/品牌等粗粒度属性 token，可降低逐层条件熵并提升候选排序质量，且增益不依赖单一平台数据。
- Control：现有 SID 直接自回归解码的生成式召回配置（同码本、同骨干、同训练步数），不插入属性 token。
- Treatment：仅在 SID 前增加 m 个属性 token 的自回归解码步，属性词表由现有类目/品牌特征构造，其余保持与 control 一致。
- 保持变量：同一 SID 码本与层级、同一用户行为序列输入、同一骨干与参数量、同一训练数据与 batch、同一 beam 宽度与候选预算。
- 离线指标：整体与订单样本的 HR@50/100/200；逐层条件熵与 beam 命中率；平均解码 token 数与单请求时延
- 线上 Guardrail：线上端到端延迟不超过现有链路上限；长尾 item 与目录覆盖不下降；属性 token 错误不引发候选集空返回

### SID 码本容量约束对曝光集中度的消融

- 假设：在残差量化聚类中按曝光量施加每簇容量上限并重分配过载簇样本，可降低 top token 曝光占比、缓解码本坍塌，并提升整体召回。
- Control：现有 RQ-KMeans 或同类无容量约束的 SID 构造。
- Treatment：在相同码本层级与码字预算下引入曝光加权容量上限（如 τ=1.05）与过载簇最近未满簇重分配。
- 保持变量：同一训练数据与曝光统计窗口、同一码本层级与总码字数、同一生成器结构与训练步数、同一评测集。
- 离线指标：三级码本 top-1% token 曝光占比；整体与订单样本 HR@50/100；长尾簇命中的目标物品数
- 线上 Guardrail：头部 item 召回不显著下降；码字利用率不低于原基线；重新训练码本的一次性成本在上限内

### 生成式召回的交互日志触发器检测作为数据安全门禁

- 假设：在训练数据入口对短且频繁关联同一触发器的交互前缀做统计检测，可降低条件目标投毒在离线评测中的目标推广率，而不过度误伤正常交互。
- Control：现有数据清洗流程，不加前缀条件化触发器检测。
- Treatment：对交互前缀长度与触发器共现频次做分布检测，对高共现短前缀样本施加隔离或降权后再训练同配置生成器。
- 保持变量：同一生成器与 SID 构造、同一训练步数与优化器、同一干净评测集与触发器集合、同一注入比例设定。
- 离线指标：触发器条件下恶意目标推广率（ASR）；干净样本的整体 HR@50/100；被隔离/降权的样本比例
- 线上 Guardrail：正常用户行为召回指标不显著下降；检测与隔离的离线计算成本可控；清洗规则不误杀新用户或冷门前缀的正常交互


## 一句话总判断

本期生成式召回的方法重心从上一期的 SID 监督目标与接口诊断，转向属性前置解码（CoA）、码本曝光约束与解码期前缀安全：UniRec 用类目/卖家/品牌 token 前置与容量约束 SID 把生成式与判别式的表达差距拉到工业 A/B 层面（PVCTR +5.37%、订单 +4.76%、GMV +5.60%、端到端 110ms vs 266ms），但其贝叶斯等价与熵下降为作者推导，各模块对线上收益的贡献未拆解，且仅 Shopee 单平台、未披露分流与显著性。工程上可核实的仍主要是生成式召回统一多阶段链路带来的效率与业务收益；其余论文多为摘要级证据，冷启动蒸馏、图表征跨源复用与 LLM 品牌审计协议只能作为探索性参考，迁移前需自行核验正文与指标口径。
