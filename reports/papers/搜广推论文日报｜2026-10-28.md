## 生成式召回

### P0｜[阿里巴巴、浙江大学｜KL-MOPD: Discrepancy-Aware Multi-Objective On-Policy Distillation for Generative Recommendation](https://arxiv.org/abs/2610.36973)

**论文、机构与场景**

- **机构：浙江大学、阿里巴巴集团**
- 作者：Weiqin Yang、Yandong Wang 等
- 来源：arXiv:2610.36973v1
- 场景：电商广告生成式推荐的多目标点击与价值优化
- **论文主要内容：** 针对生成式推荐多目标蒸馏的逐词元教师失衡，提出按学生-教师KL分配词元权重的KL-MOPD。

**主要创新或优化点**

- 已有 item-wise 多目标方法在生成式推荐中缺少逐 token 监督；论文揭示即使引入等权 MOPD，仍存在 token 级教师难度不平衡与跨 token 更难教师切换，导致各目标在部分解码步欠拟合。
- 提出 KL-MOPD：按初始学生到各教师的逐 token 期望 KL 归一化分配教师权重，强化当前更难蒸馏的教师；只需训练前预计算一次，不引入额外前向或结构改动，属于可插拔的蒸馏损失重加权。
- 给出双目标加性联合目标下的理论下界，证明满足 S_KL>D_T L^3/β^3 时严格优于 vanilla MOPD，把权重设计与联合目标增益建立可检验联系。

**核心方法**

- 将每个物品编码为离散语义 token 序列，学生策略按 token 自回归分解；从学生当前策略采样轨迹，两个冻结的单目标教师（点击、价值）在每个前缀给出下一 token 分布，原始多目标同策略蒸馏（MOPD）以 1/2 等权最小化逐 token 反向 KL。
- 论文先测量初始学生到各教师在各 token 的 KL，发现 token 级不平衡（某 token 上某教师明显更难蒸馏）且跨 token 更难教师会切换；等权 MOPD 因此在不同解码步欠拟合不同目标。
- KL-MOPD 用初始学生到教师 j 在 token t 的期望 KL d_{j,t} 归一化为 α_{j,t}=d_{j,t}/(d_{c,t}+d_{v,t})，替换等权系数；权重只在训练前用初始学生预计算一次，不增加训练前向，蒸馏时按 token 加权反向 KL。

**关键结果**

- 在 TencentGR、YooChoose、Taobao 三个公开数据集及 TIGER/REG4Rec 两个骨干上，联合目标 u_cv@K 相对最强基线及单目标教师平均提升 +4.12%。
- 十亿级工业离线数据集（1.49B 交互、49M 用户、158M 广告）上，联合目标 u_cv 平均提升 +3.19%，top-100/top-200 分别 +3.07%/+3.30%。
- 生产电商广告平台 5 天、10% 对照/10% 实验流量的在线 A/B 中，广告收入 +1.63%、GMV +2.20%，p<0.05。

**收益归因**

- 主要：逐 token 初始学生-教师 KL 归一化权重模块；消融显示该加权优于 item-wise KL、MSE 与 Top-K 替代，整包配置在公开数据联合目标平均 +4.12%，机制解释为强化每步更难蒸馏的教师；线上单模块因果未单独量化。
- 次要：权重训练前一次性预计算，不增加蒸馏阶段前向与结构改动，可直接作为现有 MOPD 损失的重加权模块接入。
- 次要：给出双目标加性目标下优于等权 MOPD 的下界条件，为 token 级教师权重设计提供可检验的理论解释。

**与你的关联**

- 适用于已有 item/语义 token 自回归生成式召回且能训练单目标教师的多目标蒸馏场景；迁移前需能按 token 估计初始学生-教师 KL，并确认双目标可加性聚合与训练分布稳定性。

**风险或局限**

- 教师权重由初始学生与教师一次性预计算，训练中分布漂移后不再更新；论文未评估周期性重算或动态校准的影响。
- 理论保证只覆盖双目标加性联合目标及条件 S_KL>D_T L^3/β^3；三目标以上作者列为未来工作，非加性聚合未证明。
- 线上验证仅来自单一电商广告平台 5 天、对照组与实验组各 10% 流量的 A/B；工业离线受资源限制只与 vanilla MOPD 比较，缺少独立复现与更广平台验证。


### P0｜[阿里巴巴｜PailitaoMMSearch｜PailitaoMMSearch2.0 Technical Report: Scaling Generative Retrieval to Unified End-to-End Multimodal Search](https://arxiv.org/abs/2610.36958)

**论文、机构与场景**

- **机构：Taobao & Tmall Group of Alibaba**
- 作者：Xiaohan Ye、Zihan Gong、Jingqian Zhao、Lianyu Du、Yunmeng Shu、Xu Chen、Zesheng Zhou、Renchun You、Bocheng Chen、Jinsong Lan、Haihong Tang、Bo Zheng
- 来源：arXiv:2610.36958v1
- 场景：淘宝拍立淘的相似、编辑、搭配图文商品搜索
- **论文主要内容：** 针对多意图开放图文商品检索，用原生VLM生成商品SID并以CPT、混合预算SFT和统一RL训练。

**主要创新或优化点**

- 将生成式检索从固定场景、固定意图与固定资源配置解耦为统一开放图文商品搜索：单一原生VLM直接从原图与自由文本指令推断隐含检索关系并生成商品SID，训练与服务均不需意图分类器或按意图路由的专家模型。
- 用可组合工具集（粗滤、精滤、查询生成与修复、CoT生成、终端质控）按意图与生命周期编排出冷启动合成、真实流量精炼、持续生产三类工作流，新增意图只需关系规范、评分标准与工作流配置。
- 三阶段训练：CPT对齐电商商品与SID空间，多意图、混合预算SFT同时学相似、编辑、搭配与No-think、Low-think、High-think，意图平衡采样加按意图奖励的统一RL联合优化所有意图。
- 提出Sample–Beam rollout：采样N个推理前缀、每个前缀beam解码B个SID，在N×B分支内归一化候选级奖励，对齐训练自回归采样与线上beam多候选解码。
- 场景维度用模型规模0.8B/2B/4B（粗粒度）与推理预算（细粒度）组合成可部署质量-成本操作点，不引入独立路由模型。

**核心方法**

- 基于Qwen3.5原生VLM构建0.8B/2B/4B模型；商品用三级SID（每级8192码本），模型从原图与自由文本指令生成可选think块后beam解码SID，合法序列确定性映射商品并形成候选集。
- 可组合工具集含Coarse-Filter、Fine-Filter、Query-Text-Gen、CoT-Gen与Quality-Control；按冷启动合成、真实流量精炼、持续生产三类工作流编排，并用成本级联先粗筛再调用强多模态验证。
- 训练先以电商商品标题、属性、SID预测、行为及通用语料做CPT，再做多意图混合预算SFT；随后用意图平衡采样和专属奖励做统一GRPO RL，并以Sample–Beam rollout（采样N个推理前缀，每个前缀beam出B个SID，按N×B分支奖励归一化）对齐线上beam解码。

**关键结果**

- 在淘宝拍立淘Multimodal Search的线上A/B（实验组约10%流量、约14天）中，item page views +17.90%、transactions +27.04%、GMV +8.94%，均p<0.05，随后在对应生产场景全量上线。
- 离线2B Low-think配置（人工校准的多模态评审器打分、macro平均）macro NDCG 0.918、macro ER 55.1%，较内部多召多排基线macro ER +5.6点，但similar与editing ER低于该基线，优势集中在matching。
- 在匹配初始化、意图混合与奖励评测的消融中，Sample–Beam RL较SFT的macro ER +5.97点；标准RL较SFT +3.67点，Sample–Beam在标准RL上再+2.30点。

**收益归因**

- 主要：统一端到端多模态生成式检索上线带来的整套业务增益；线上A/B未将商品页浏览量、交易和GMV提升归因到CPT、RL或数据工具等单模块。
- 次要：Sample–Beam rollout把rollout中的SID生成换成beam搜索以贴近线上解码；在与SFT匹配的初始化、意图混合和奖励评测下，2B模型macro ER较SFT +5.97点，属固定配置消融而非线上归因。
- 次要：CPT以商品标题、属性、SID预测、用户行为与通用语料初始化；在与下游SFT相同配置下，相对Base VLM+SFT使macro GR +0.8、macro ER +1.2点。
- 次要：数据量从30%到100%（保持来源与意图分布）使2B SFT模型macro ER +2.71点，边际收益随规模与意图不同；真实流量与质控为表内单独消融项，不并入该数据量增益。

**与你的关联**

- 适用于需要统一处理图文查询、多意图商品检索的电商搜索或推荐系统；可迁移的是SID生成式召回、可组合数据生产、CPT+SFT+RL训练配方和Sample–Beam训练-服务对齐，但需具备商品SID体系、多意图标注或合成数据以及beam解码服务。

**风险或局限**

- 离线指标由自动多模态评审器按人工校准的评分标准给出并macro平均；校准集虽与训练和测试不重叠（Good 92.4%–93.5%，Excellent 93.6%–93.9%），评审器仍可能与数据过滤和奖励模型共享相关误差。
- 线上A/B衡量整套部署配置：部分应用中本系统结果与既有召回排序链路在最终展示阶段混排，无法把item page views、交易和GMV增益归因到CPT、多意图SFT、RL或Sample–Beam等单个组件。
- 只覆盖一个电商域的similar、editing、matching三类关系（论文自述open-ended仅指查询接口而非关系全覆盖）；主要消融用2B，0.8B/2B/4B为独立checkpoint而非弹性共享权重，跨规模交互与更广关系未验证。


### P0｜[Google、YouTube｜TokenMinds: Pretrained User Tokens and Embeddings for User Understanding in Large Recommender Systems](https://arxiv.org/abs/2606.25147)

**论文、机构与场景**

- **机构：Google DeepMind、YouTube**
- 作者：Qingyun Liu、Bo Yan、Yang Liu 等
- 来源：arXiv:2606.25147v2
- 场景：YouTube 长短视频推荐中为排序/召回/预排序提供用户表征
- **论文主要内容：** 针对固定维用户向量表达受限，用LLM编解码器同时产出稠密嵌入与SID用户token。

**主要创新或优化点**

- 把 SID 从物品检索扩展到用户侧生成式建模：encoder 输出稠密用户状态，decoder 在物品 SID 空间自回归生成多条未来兴趣前缀，作为通用用户特征而非仅用于候选召回，缓解单一池化向量的兴趣平均化。提出面向离散用户 token 的下游适配：将预测 SID 前缀视为可学习子词/协同身份，用共训练嵌入表替代静态内容映射，并支持用户侧池化与候选感知 target attention，使 token 能进入既有连续向量排序器。用共享 SID 词表统一长短视频并交错搜索查询；统一 LFV/SFV 训练相对两个独立模型降低上游训练计算，multi-context decoding 在一次 encoder pass 上并行解码场景特定 token 以降低服务计算，论文报告核心指标中性并提升 Fresh Eng。

**核心方法**

- 视频用 RQ-VAE 编码为 8 层、每层 2048 码字的分层 SID；输入只保留前缀 4 个 SID 硬 token，非 SID 特征分桶或经 MLP 投影为软 token，最近 50 条搜索查询以 <Search> 文本 token 与观看历史按时间交错，并用 <LFV>/<SFV> 标记场景。
- TokenMinds 以 Gemini V1.5 的 encoder-decoder 为基础：encoder 对完整未池化历史做双向自注意力并池化出 1152 维用户向量，decoder 用 cross-attention 自回归生成未来兴趣 SID 前缀，服务时 beam search 输出 40 条 prefix-4 用户 token。
- 下游把预测 SID 前缀作为可学习子词嵌入，经用户侧池化或候选感知 target attention 聚合；训练先 CPT 对齐 SID 词表再 SFT，从截止后 24h 窗口按参与度奖励采样最多 15 个目标，单次 decoder pass 联合预测各目标 prefix-4 SID，服务端异步缓存并 multi-context decoding 共享 encoder。

**关键结果**

- Shortspage 在线 A/B 对无 TokenMinds 特征基线：+Emb,+Token 使 User WT +0.08%*、Satisfied Eng +0.13%*、Eng Users +0.11%*；单独 +Token 使 Satisfied Eng +0.08%*。
- LEM 对比：在已有 LEM 的 Homepage/Watchpage 上加 +Token 再增 User WT +0.10%*/+0.03%*、Satisfied Eng +0.11%*/+0.03%*；移除 LEM 后保留双输出的直接对照 95% CI 均跨 0，而仅留稠密嵌入会使 Watchpage Satisfied Eng -0.04%*。
- 跨场景统一：统一 LFV/SFV 训练相对两个独立模型降低训练计算 50%；multi-context decoding 使服务计算降低 31%（481 vs 698 chips）；在线 Fresh Eng Shortspage +0.33%*、Homepage +0.19%*，核心指标中性。

**收益归因**

- 主要：在论文所测 YouTube Homepage/Watchpage 排序器上，双输出用户表征在既有特征上提供互补信号，并使原 LEM 用户模型可退役。
- 次要：统一 LFV/SFV 训练把两个独立模型合并为单模型，降低训练计算；multi-context decoding 用一次 encoder pass 并行解码场景特定 token，降低服务计算。
- 次要：离散 SID 前缀用户 token 为 1280B，稠密嵌入为 4608B；配合异步 KV 缓存把生成推理移出在线关键路径。
- 次要：搜索查询与观看历史共享预训练文本词表并交错输入，为排序器补充显式意图信号。

**与你的关联**

- 适用于已有大规模用户序列与下游多阶段排序/召回系统的团队，可迁移其双输出用户表征、SID 前缀生成、异步缓存和共享词表思路；需要具备物品内容 SID 管线、LLM CPT/SFT 训练与低延迟 KV 缓存基础设施。

**风险或局限**

- 线上指标为 YouTube 专有变体，正文只报相对变化和 95% 显著性，未给原始日志、完整流量划分与绝对指标，外部难以复现或横向比较。
- 跨场景统一把 LFV/SFV 放入同一固定长度序列，几乎减半可用 LFV 历史；论文推测核心指标中性由 SFV 信号补偿，未给长历史损失、场景权重与冷启动边界的敏感性分析。
- 方法依赖 RQ-VAE SID、Gemini CPT 检查点、JAX/Pathways 与 UBS 异步缓存；生成约 339 ms/用户且 24 小时刷新，迁移到低资源或强实时场景的成本与收益未验证。


### P1｜[浙江大学｜JevRec: Linguistic Encoding with Jev-like Decision Modeling for LLM-based Generative Recommendation](https://arxiv.org/abs/2610.36937)

**论文、机构与场景**

- **机构：浙江大学（Zhejiang University, Hangzhou, China）**
- 作者：Qiyong Zhong、Jiajie Su、Ming Yang、Li Zhang
- 来源：arXiv:2610.36937v1
- 场景：Amazon Reviews 2023 三类目上的下一物品序列推荐与生成式 SID 召回
- **论文主要内容：** 按交互频率分配变长 SID，并用分离的长度与内容头做生成式推荐。

**主要创新或优化点**

- 固定长度 SID 让高频物品反复支付细粒度编码成本，压缩长尾代价又作用于全目录，故按训练频率分组给变长 SID：各组共享同一残差量化码本，热门物品截断末尾语义码，长尾保留更多码，再追加组内冲突消解 token 保唯一；长度计入语义码与冲突 token，不含长度 token、START、EOS。论文另把长度作为序列级显式预测任务：长度头在合法长度集合上打分，内容头以长度为前缀条件生成，二者共享历史表征、按联合负对数似然同权重训练；推理用最大余数法分配分支配额，并按长度概率×条件概率跨长度排序，而非只解码单一长度。

**核心方法**

- 语言编码：按训练交互频率将物品分 N 组，SID 长度 ℓ_v=M+g(v)-1，组规模按 Gamma 先验比例确定；各组共用 Q=M+N-2 级固定码字数的残差量化码本，高频物品截断末尾语义码，长尾保留更多码，再追加组内冲突消解 token；长度计入语义码与冲突 token，不含长度 token、START、EOS。
- Jev 式决策建模：共享 T5 编码器-解码器编码序列化历史，取解码器首位置状态与候选长度嵌入经共享三层 MLP 在合法长度集合上打分；内容头沿用 T5 原生、与词嵌入绑定的线性输出头，以 [START, L_ℓ] 为前缀生成 SID 与 EOS，两目标按联合负对数似然同权重单阶段训练，仅真实长度分支计内容损失。
- 长度感知推理：保留长度分布 q(ℓ|X)，用最大余数法把预算 K 分给各长度分支，分支内 beam search 只保留能映射到该长度目录物品的 SID；合并后按 q(ℓ|X)·r_ℓ(v|X) 跨长度排序，分支候选不足时用其他分支最高分未选候选补位，配额先于排序生效。

**关键结果**

- 在 Amazon Reviews 2023 的 Instrument/Scientific/Game 三数据集、留一法全目录无负采样评测下，JevRec 在 12 个数据集-指标组合均为最优；相对各列最强基线的平均相对提升 6.52%，相对 TIGER 的平均相对提升 12.04%；p<0.05 指相对各列最强基线的配对 t 检验，并非对 13 个基线逐一显著。
- 消融（各组重训，两个推理变体复用完整模型及其候选池）：随机长度较完整模型平均低 8.70%，共享 LM head 平均低 7.50%，去掉长度 token 在该组降幅最大，支持按频率定长与显式长度决策的组件贡献。
- 效率：相比 TIGER 每 epoch 训练时间平均降低 15.75%，三数据集完整测试集总推理时间均下降；Instrument 上验证 NDCG@10 最优检查点比 TIGER 早 20 个 epoch，且各记录点均更高。

**收益归因**

- 主要：离线 Recall/NDCG 与训练、推理效率提升来自整包配置（频率相关变长 SID＋长度/内容分离头＋长度感知解码）；单组件贡献由替换式消融支持，模块级因果与线上业务收益未核实。
- 次要：长度感知配额使列表构成贴合预测长度分布，去掉配额在 12 个指标全降；去掉长度排序按构造保持 R@10 不变，但降低 R@5 与全部 NDCG，属机制级证据而非线上收益。
- 次要：分离长度头与内容头降低梯度冲突（池化余弦均值由 -0.105 升至 -0.015），该结论仅针对所测共享解码参数与训练前中期检查点窗口。

**与你的关联**

- 适用于使用语义 ID 的生成式召回/检索：可按物品频次设计变长 SID 与长度条件解码；迁移需有物品文本、训练频次和可接受的多分支 beam 成本。

**风险或局限**

- 仅三个 Amazon 类目离线评测，无在线 A/B、部署或业务指标；留一法全目录无负采样下绝对值偏低（如 Instrument R@10 0.0643），业务意义未验证。
- 对比基线为 13 个（含 TIGER、LETTER、ActionPiece），未纳入论文相关工作提到的其他变长/自适应编码 SID 方法，故相对这类方法的增益未建立。
- 频率分组与 SID 由训练交互一次性确定，分组比例由 Gamma 先验固定且三数据集共用同一套长度配置；未评估新物品、频次漂移、码本更新或按数据集重标定，多分支 beam 与配额仅在公开目录、K=10 下评测。

- 新算法：生成式语义检索（GSR）预训练——编码器输入源物品完整语义ID（SID），解码器生成余弦Top-K语义近邻的SID，按token交叉熵（CE）更新SID嵌入与T5编解码器，使生成器在交互训练前继承内容语义邻接。

- GSR预训练以物品文本嵌入的余弦Top-K语义近邻为监督：编码器输入源物品完整SID，解码器自回归生成近邻物品SID，按token级CE联合更新SID token embedding与T5编码器-解码器，并以验证集推荐性能选初始化。
- ITSA在每层编码器混合token-global双向头与item-local头，两类头比例为逐数据集选择的超参；局部头按SID边界把每个token的可见范围限于当前物品与前一物品完整SID，输出拼接，参数量与标准T5相同；RQ-VAE分词与T5骨架为沿用设置。

**收益归因**

- 主要：整包配置（GSR+ITSA+HCPD）在六个Amazon离线数据集相对生成与混合基线报告一致R/N提升（2014三域全部指标最优，2023多为最优或次优）；单模块因果仅由组件消融支持，无线上验证。
- 次要：GSR：消融移除后Beauty/Sports/Toys的R@5与N@5均下降，支持语义预训练初始化带来的模块级贡献。
- 次要：ITSA：替换为标准双向自注意力后三数据集R@5/N@5均下降，支持SID边界局部注意力的模块级贡献。
- 次要：HCPD：消融中降幅最大；在TIGER上替换训练目标的对比中优于TCA、TCA-Aux、APAO-pointwise与GFlowGR两变体，属同骨干同教师下的训练目标对比。

**与你的关联**

- 适用于已有RQ-VAE物品SID和T5式生成器的生成式召回：可复用GSR语义预训练、ITSA局部掩码与HCPD前缀树蒸馏；迁移需能构造语义近邻、冻结可比教师并维护合法token前缀约束。

**风险或局限**

- 仅在六个Amazon Reviews离线数据集评测（2014与2023各三域），无在线A/B、生产部署或业务指标，线上收益与推理服务成本未验证。
- 效率仅在Beauty、单卡L40、FP32、batch=256且关闭KV缓存下测得，2023数据集未报告效率；硬件或商品目录规模变化后成本不可外推。

### P2｜[重庆大学、Griffith University｜LESSRec: Level-Specific History Modeling for Semantic ID-Based Recommendation](https://arxiv.org/abs/2610.37286)

**论文、机构与场景**

- **机构：重庆大学、Griffith University**
- 作者：Shangxin Yang、Zongwei Wang、Jing Long、Junliang Yu、Min Gao
- 来源：arXiv:2610.37286v1
- 场景：Amazon Games/Software/Beauty 上基于语义ID的下一物品生成式推荐
- **论文主要内容：** 针对语义ID生成式推荐跨层历史干扰，提出分层隔离历史并融合物品语义的LESSRec及高效变体。

**主要创新或优化点**

- 识别并实证语义ID生成式推荐中的同层历史优势：通过固定参数只改解码器cross-attention mask的推理时实验，发现预测某层token时同层历史比跨层历史更有信息量，且在编码端先隔离层间混合后差异更明显。提出LESSRec：用LIS在编码端按语义层隔离历史，用LAC让解码器只访问目标层历史，并用ILS加双交叉注意力补足物品整体语义，解决只依赖单层会丢失跨层互补信息的问题。提出LESSRec+：将编码器层按语义层分组并各自编码短序列，在不增加参数总量下降低编码注意力、收敛时间和显存；论文在所测较长历史桶中观察到更大增益，未验证生产长历史。

**核心方法**

- LIS（Level-Isolated Self-Attention）：对每个语义层级的历史token仅允许同层token相互做self-attention，EOS可访问全部有效位置但历史token不能访问EOS，使各层编码状态在编码端保持隔离。
- LAC与双交叉注意力：解码器预测第r层目标token时，level-aligned分支只访问历史第r层token及共享EOS；同时将每物品各层编码状态均值池化后经残差MLP得到item-level语义序列，由第二交叉注意力分支与level分支按系数α加权融合。
- LESSRec+：把原编码器D层划分为L个不重叠的层级专用编码器组，每组仅编码该层历史序列（含EOS），编码后恢复各token位置并平均各层EOS状态；参数总量不变，编码注意力从O(D L^2 T^2 d)降至O(D T^2 d)。

**关键结果**

- 在Games、Software、Beauty三个公开数据集和RQ-VAE、RQ-Kmeans、LETTER三种tokenizer下，LESSRec相对TIGER的Recall/NDCG提升6.2%–39.2%，LESSRec+提升6.0%–54.3%，最佳配置在全部数据集-指标列最高。
- Games上R@10：TIGER 0.0371、+ILS 0.0408、+LIS 0.0418、+LIS+LAC 0.0422、LESSRec 0.0457；Beauty上对应0.0331、0.0344、0.0374、0.0395、0.0440，说明LIS、LAC、ILS逐项互补。
- 在单张RTX 4090上，LESSRec+参数61.12M（较TIGER 60.86M +0.4%），收敛时间0.79h（-65.2%），每epoch 65.95s（-33.7%），峰值训练内存5.35GiB（-39.2%）；LESSRec每epoch +5.8%、峰值内存 +7.5%。

**收益归因**

- 主要：组件消融支持 LIS、LAC、ILS 的逐项增益；完整 LESSRec 在离线 Recall/NDCG 上优于 TIGER 对应配置。“减少跨层干扰”是作者对机制的解释，未做单模块因果识别或线上收益验证。
- 次要：LESSRec+将编码器按层分组并行编码短序列，在参数总量不变下降低编码计算、收敛时间和峰值训练显存。
- 次要：ILS通过均值池化加残差MLP提供按时间排序的物品级语义，与层对齐历史互补；消融中在LIS+LAC基础上继续提升Games和Beauty的R@10。

### P0｜[UCLA、Roblox｜Exploratory creative pre-ranking: Hierarchical empirical-Bayes Thompson sampling for real-time creative optimization](https://arxiv.org/abs/2610.36020)

**论文、机构与场景**

- **机构：UCLA 与 Roblox（Jiale Han、Xiaowu Dai 属 UCLA；Ajith Moparthi、Dan Xie 属 Roblox）**
- 作者：Jiale Han, Ajith Moparthi, Dan Xie, Xiaowu Dai
- 来源：arXiv:2610.36020v1
- 场景：Roblox Sponsored-ads 的广告创意预排序与短名单生成
- **论文主要内容：** 用分层经验贝叶斯Thompson采样做广告创意预排序，按受众段压缩创意池并保留探索。

**主要创新或优化点**

- 把创意预排序显式建成探索问题：已有创意选择器多为确定性点预测，本文在排序前用 Thompson 采样让新创意有机会进入短名单，从而获得被学习的反馈。每层浓度由闭式矩估计从日志拟合，冷启动创意按父层回退，作者称每层仅一个参数且无需调参。用单属性边际计数重建受众段后验，避免维护指数级联合计数；离线拟合共享池化权重处理属性相关和重复，在线只做 K 项加权和与每个候选一次 Beta 采样。配额按 campaign 池大小分配并用 round robin 满足全局预算，使大池获得更多探索且不因上传更多创意直接获得曝光优势。

**核心方法**

- 将创意置于平台均值、受众段、广告物品、campaign、creative 的层级随机效应模型中，用 Beta-Binomial 经验贝叶斯把节点 PTR 向父层收缩；每层浓度 κ 由 DerSimonian–Laird 矩估计从历史日志闭式拟合，冷启动节点按父层逐级回退。
- 在线只维护每个节点按单属性切分的曝光/播放计数，将各属性 bucket 率向节点率收缩成 log-odds lift，再用离线拟合的 K 维池化权重 ψ 线性组合重建请求受众段的 PTR；有效样本数取最稀缺属性的计数下限 n_eff。
- 对每个候选创意从重建的 Beta 后验抽一次 Thompson 样本作为分数，按 campaign 池大小取配额 E_g=max(1,⌊ρ|C_g|⌋) 内最高分创意，超过全局预算 B 时跨 campaign 轮转填充，仅把短名单送入广告排序。

**关键结果**

- Roblox Sponsored-ads replay（ρ=0.8、B=600、contested pools）中，TS-RR 的预测 PTR 相对 Uniform +8.14%（95% CI [7.64,8.65]），回收 Oracle +18.36% 的 44.3%；RR-Random +2.80%，TS-One 在与 Uniform 相同转发量下 +6.09%。
- 单进程 x86-64 CPU 计时中，TS-RR 每请求 41.6 ms，RR-Random 41.5 ms（+0.2%）；预排序打分约 79 µs、打分+选择约 2.2 ms，转发约 600 个创意，而 Oracle 需 83.1 ms（其 ranker 条目为外推）。
- 在第二个部署排序模型 L1 上，TS-RR 相对 Uniform +4.54%（95% CI [4.16,4.91]），RR-Random +1.62%，gap 44.0%，与主模型 44.3% 基本一致。

**收益归因**

- 主要：在 replay 的同配额对照中，后验收缩与受众段重建是主要收益来源：与 Uniform 同转发量时 TS-One +6.09%，同配额随机填充的 RR-Random 仅 +2.80%，TS-RR 高于该随机对照，且按后验均值排序还高于单次抽样 1.37 个百分点；这些是冻结 replay 的预测 PTR，不等同线上 A/B 的单模块因果。
- 次要：边际计数重建把在线打分压到约 79 µs，使对每个 recalled creative 做 Thompson 采样在延迟预算内可行。
- 次要：按池大小配额和 round robin 控制全局预算，减少送入重排器的创意数（比全池少 40% 以上）并保持每个 campaign 至少一个名额。
- 次要：层级回退让 n_eff=0 的冷启动候选仍从父层先验获得分数和探索机会。

**与你的关联**

- 适用于广告/推荐漏斗中召回后、重排前的素材或创意预排序，尤其是单候选反馈稀疏、候选池远大于广告池且下游排序成本随候选数增长的系统；迁移需具备可实时维护的分属性计数、离线可拟合的层级先验和可配置的短名单预算。

**风险或局限**

- 主结果来自历史日志 replay，奖励为已部署排序模型预测的 PTR，不是线上真实 PTR；replay 冻结后验，作者承认 +8.14% 可能低估探索收益，但也说明这不是线上因果 A/B 指标。
- 论文仅声明 live A/B 后已在 Roblox 生产服务，未报告 A/B 设计、样本量、置信区间、线上 PTR/GMV、长期影响或回滚细节。

**论文、机构与场景**

- **机构：中国科学院大学（University of Chinese Academy of Sciences）**
- 作者：Zesheng Li, Chengchang Pan, Honggang Qi
- 来源：arXiv:2610.36000v1

**主要创新或优化点**

- 提出单查询双角色的共享历史选择：同一组注意力权重既聚合语义偏好，又路由直接历史与转移证据到候选分数，使表示学习与候选打分共享同一个历史选择，而不是分开建模历史编码和转移记忆。

- 给出记录排除的全目录似然训练：训练时从转移计数中减去当前记录自身贡献，并证明用top-(B+1)缓冲可精确恢复top-B邻居，缓解聚合转移统计与训练标签之间的依赖；该机制属于训练统计修正，不是线上部署验证。
- 采用单次前向的紧凑全目录打分：缓存候选SID向量，先算语义基础分，再只在最多m(B+1)个支持点上叠加记忆修正，避免重复目录级神经评估；相对生成式SID解码路线强调低预测器参数与低推理成本。

**收益归因**

- 次要：直接历史与转移记忆只在m(B+1)个有证据的目的地上修正分数，其余候选保留语义分，降低全目录打分的额外计算。

- 作者在OneTrans/KuaiRand上实证：六种位置编码均未超过NoPE，而目标相对时间组内双向交互优于事件级因果和全局双向；据此把问题重述为CTR需要何种位置信息与交互粒度。
- 提出FRE：用共享基向量和秩特定系数低秩分解历史位置嵌入，保留序数差异同时显著压缩位置参数，区别于完整可学习APE或仅改注意力分数的旋转编码。
- 提出TRTE：以预测请求时刻为锚，按对数时距构造头部特定可学习时间偏置并做区间密度校正，或改用目标相对时间旋转，补足仅有序数或仅事件时间戳的不足。
- 提出TGCI：按目标相对时距分组，组内双向、组间因果，并加掩码物品重建与组摘要压缩；相对统一因果或全局双向注意力，兼顾组内兴趣聚合、兴趣演化和后续层效率。

**核心方法**

- FRE把历史行为序列秩映射为低秩分解嵌入：共享基向量B、秩系数A和公共向量μ生成每个秩的表示并加到历史token；参数量由LD降为D+LK+KD，约为完整APE的3.8–21.6分之一，仅用于历史token。
- TRTE用目标请求时间T减去事件时间ti得到相对时距，取对数离散为粗到细的时间坐标；TRIP-B把头部特定可学习时间势能加为注意力偏置并按区间事件数做密度校正，TRIP-R则用目标相对时间旋转查询/键。
- TGCI按目标相对时距把历史划分为若干对数时间组，组内双向注意力、组间保持因果掩码；训练时对组内部分物品做掩码重建作为辅助损失，推理关闭，随后将每组事件均值池化为组摘要供后续Transformer层使用。

**关键结果**

- 四个公开CTR数据集（KuaiRec、KuaiRand、TAAC、TaobaoAd）对11个基线，TRIP-B在全部数据集AUC最优；平均相对AUC提升1.47%，TAAC最大提升4.45%，但KuaiRand的LogLoss高于部分基线。
- 去掉TGCI、仅比较FRE+TRTE与八种位置编码配置，在OneTrans、HyFormer、MixFormer三个骨干上，TAAC相对AUC最高提升4.20%（OneTrans）；每个设置至少一个TRTE变体取得最高AUC。
- 组摘要压缩在四个数据集上同时提高AUC并降低单步训练时间6.3–32.8%；TaobaoAd从141.31降到95.01 ms/step、AUC从0.6297升到0.6304（单次运行）。

**收益归因**

- 主要：整包TRIP-B在四个公开数据集AUC最优；消融支持FRE、TRTE、TGCI各组件的贡献，机制上由目标感知秩-时间编码与时序组交互提升排序区分度。
- 次要：FRE以低秩共享基向量压缩秩嵌入，在性能相当或更优时把位置参数量缩减为完整APE的3.8–21.6分之一。
- 次要：组摘要压缩将历史从L个事件降为G个组，降低后续层计算并节省6.3–32.8%单步训练时间。
- 次要：TRTE的密度校正缓解密集时间区间因事件数量获得过多注意力，使时间偏好与内容相关性共同引导历史读取。

**与你的关联**

- 适用于已有Transformer式行为序列CTR精排的团队，可在不改召回链路的前提下试验目标相对时间编码、组内双向/组间因果掩码与组摘要压缩；需具备事件时间戳和目标请求时间，并重新调分组边界、掩码率和重建权重。

**风险或局限**

- 候选仅提供arXiv预印本，未见正式接收信息；且只有四个公开数据集离线实验，无线上A/B或生产部署结果，AUC提升不能直接外推为线上收益。
- 作者指出固定对数时间组可能不匹配个体兴趣切换，组均值池化也会抹平后续层的细粒度事件差异。
- KuaiRand上TRIP-B正例概率高估（预测46.74%对观测37.67%），未校准LogLoss偏高；验证集拟合仿射校准可降至0.5471并使与MixFormer差距从0.0300缩至0.0011，原文称这主要反映可纠正的校准问题，未证明校准是必要前置。


### P1｜[Criteo AI Lab、Sorbonne Université/CNRS/ISIR｜DARTS｜When Diffusion Recommenders Stop Sampling: Preserving Generative Diversity](https://arxiv.org/abs/2610.36954)

**论文、机构与场景**

- **机构：Criteo AI Lab（巴黎）与 Sorbonne Université/CNRS/ISIR**
- 作者：Louis Castres Saint Martin、Alain Rakotomamonjy、Patrick Gallinari
- 来源：arXiv:2610.36954v1
- 场景：Amazon Reviews 2023 三个类目的序列推荐下一物品排序
- **论文主要内容：** 针对扩散推荐采样坍缩，提出三阶段解耦框架DARTS，冻结潜空间、潜回归训练去噪器并微调解码器。

**主要创新或优化点**

- 指出目标物品扩散推荐器存在采样崩塌：同一历史重复采样得到近乎相同的排序，并把原因定位为潜空间与去噪器联合学习、以及在扩散轨迹中用离散排序损失监督两个常见设计。
- 提出三阶段解耦框架 DARTS：先学习并冻结序列自编码器潜空间，再只用潜变量回归训练去噪器，最后仅微调解码器完成离散排序，把图像与语言模型中的“固定潜空间 + 最终离散化”迁移到序列推荐。
- 引入潜空间与解码后空间的互补多样性诊断：生成方差比 R 衡量重采样方差占比，参与率 PR 衡量采样方向数，top-10 Jaccard 不相似度 J 衡量解码后列表差异；并说明这些指标不能替代 NDCG。
- 提出后验预测聚合：在固定展示位下对多次独立采样的物品分布取平均再排序，将采样多样性转化为离线排序增益；同时用并集召回实验说明单纯扩大展示位不等于同等预算的精度提升。

**核心方法**

- Stage 1 预训练序列自编码器：物品表示由冻结的 sentence-t5-base 标题/描述语义向量与可学习 id 向量按 ω=0.5 混合，编码器与解码器以 0.4 掩码率的 masked item modeling 训练，并始终掩掉最后物品以对齐下一物品预测，解码输出投影复用混合物品矩阵。
- Stage 2 在冻结潜空间训练条件去噪器：条件 c 取掩掉末位后的前缀编码，目标 z0 取完整序列末位编码并 stop-gradient；去噪器以 z_t 为 query 对 c 做交叉注意力，仅用 latent RMSE 回归，不使用 catalogue 级损失。
- Stage 3 与推理：冻结编码器和去噪器，仅用 temperature=0.07 的 BPR 与 300 个自挖掘 hard negatives 微调解码器；推理从高斯噪声跑 200 步反向扩散得到 z0，解码器拼接 [c,z0] 输出全目录 logits，并可对 M 次采样的物品概率取平均后排序。

**关键结果**

- 在 Amazon Reviews 2023 的 Instrument/Scientific/Game 三个类目、leave-one-out 评测中，DARTS 在 Recall@5/10 与 NDCG@5/10 共 12 个组合上均优于基线，逐列相对最强基线提升 6.8%–12.0%。
- Scientific 上 K=10 次采样诊断：DARTS 的 J=0.30、R=0.30、PR=4.7、NDCG@5=0.0207；DiffuRec+T5 为 J=0.019、R=4.8e-5、PR=5.0、NDCG@5=0.0190，ADRec+T5 在潜空间与物品空间均接近完全坍缩。
- Scientific 上后验预测聚合 M=1→4 使 DARTS 的 NDCG@10 提升约 3.2%，但吞吐由 2,102 降至 629 samples/s（约 3.3×）；M=1 时 DARTS 的 2,102 samples/s 高于 DiffuRec+T5 的 590 samples/s，且 NDCG@10 高 11.1%。

**收益归因**

- 主要：整包配置收益：DARTS 在论文所测三个 Amazon 类目离线评价中所有报告列领先最强基线；消融支持冻结物品表示与第二阶段仅用潜变量回归对保持采样多样性和排序精度的作用，但未逐阶段拆解三阶段各自贡献。
- 次要：后验预测聚合：对多次独立采样按物品概率平均，在固定 top-k 下将额外采样转化为 NDCG/HR 的小幅提升（Scientific 上 M=1→4 约 +3.2% NDCG@10）。
- 次要：推理效率：去噪器每步只用单个潜查询对历史做交叉注意力，M=1 吞吐 2,102 samples/s，高于 DiffuRec+T5 的 590 samples/s。

**与你的关联**

- 适用于序列推荐或生成式排序中需要多样化下一物品候选且保持精度的场景；可迁移到需要多次采样、在固定展示位聚合概率的召回或精排实验，但需评估推理算力成本。

**风险或局限**

- 仅报告 Amazon Reviews 2023 三个类目的离线 leave-one-out 结果，没有在线 A/B 或生产部署数据，无法确认工业链路收益。
- leave-one-out 只观察单个下一交互，无法判断多次采样产生的不同列表是否对应真实可行的多个未来，作者也将其列为未来工作。
- 多采样推理成本显著：在 Scientific 上 M=1→4 吞吐约降 3.3×，M=5 时低于 DiffuRec+T5 的单次吞吐；吞吐实验只在单张 V100、批大小 1024 下测量。

### P1｜[深圳大学计算机、软件学院，深圳技术大学｜DuTri: Dual-Branch Modeling with Triadic Factorization for Multimodal Multi-Scenario Recommendation](https://arxiv.org/abs/2610.36836)

**论文、机构与场景**

- **机构：深圳大学计算机与软件学院（Jintao Huang、Chaohua Yang、Kailiang Hao、Dugang Liu、Zhong Ming），深圳技术大学（Xing Tang）**
- 作者：Jintao Huang, Chaohua Yang, Kailiang Hao, Dugang Liu, Xing Tang, Zhong Ming
- 来源：arXiv:2610.36836v1
- 场景：Alipay AntM2C 五场景与 Amazon 三品类的多模态多场景点击率（CTR）预测
- **论文主要内容：** 面向多模态多场景 CTR，提出协同与多模态双分支框架，用 CP 三分解加权重量化偏好引导自适应融合

**主要创新或优化点**

- 实证指出：把图文特征直接拼入原有 MSR（多场景推荐）参数共享骨干并非最优；在 AntM2C 上，ID-only 下占优的 STAR/HMoE/HierRec 融合多模态后被 Scenario MLP 在各场景反超，Amazon 附录报告类似趋势。
- 提出双分支 DuTri：协同分支用 CANDECOMP/PARAFAC（CP）三分解把 user–scenario–item 交互拆为跨场景共享的用户/物品因子与场景因子调制，再用实体专属残差量化得到结构化偏好表示，区别于仅靠参数共享或专家网络做场景特化。
- 以偏好因子耦合两个分支：用户/场景投影驱动 ID/文本/视觉的自适应融合门控，物品偏好经物品级对比损失与各模态表示对齐，使跨场景协同信号显式进入多模态建模，而非只在输入层拼接。
- 跨场景共享/特化主要在协同偏好表示层组织（共享用户/物品因子+场景因子调制），预测仍用场景专属多层感知机（MLP）；这为多场景多模态精排提供了不同于仅复用骨干参数共享的组织方式。

**核心方法**

- 协同分支用 CANDECOMP/PARAFAC（CP）三分解对 user–scenario–item 打分 a=Σρ p_uρ·q_kρ·r_iρ，作为辅助 logit 以二元交叉熵（BCE）监督；p_u、q_k、r_i 各经实体专属四级残差量化（用户/物品每级 256 码字、场景 8 码字，量化维度 32）重构，直通估计端到端训练，重构因子替代原因子进入下游。
- 协同表征构造：用户、场景、物品重构因子各经线性层投影到 64 维；将 e_pu、e_qk、e_ri 逐元素相乘后经线性层+层归一化+GELU 得 f_tri，再与物品投影 e_Q 逐元素相乘并做层归一化得调制向量 c，最后与用户、场景投影拼接经 FFN 输出 hCF。
- 多模态分支用 [e_U‖e_S] 经门控网络 softmax 得到 ID/文本/视觉三模态权重，逐模态层归一化后加权求和再归一化得 hMM，并以物品级对比损失把协同物品偏好 e_Q 与各模态表示对齐；hUSR、hCF、hMM 拼接后送入场景专属多层感知机（MLP），推理时丢弃对齐投影头与辅助损失。

**关键结果**

- 在 AntM2C 五场景与 Amazon 三场景上，DuTri 的样本加权 AUC（WAUC）分别为 0.8632 与 0.7437，均高于表中 AMS（0.8598/0.7400）、Scenario MLP、SSIM、STAR、HMoE 等全部基线；五次随机种子均值，AntM2C 相对最强基线提升约 0.34 个百分点。
- 消融中，移除整个多模态分支使 AntM2C WAUC 由 0.8632 降至 0.8516，移除多模态表征输入降至 0.8528；移除整个协同分支降至 0.8552；移除跨分支对齐、CP 监督、残差量化与门控也均使两数据集 WAUC 下降。
- 效率对比（AntM2C）：每 batch 训练时间低于 Diff-MSIN 与 PLE、高于 AMS，推理时间与 AMS 相当，参数量少于 PLE 与 HierRec 但多于多数基线；Amazon 上参数量为对比方法中最大，推理时间仍与 AMS 相当。

**收益归因**

- 主要：离线消融中，移除整个多模态分支的 WAUC 降幅最大（AntM2C 0.8632→0.8516），移除多模态表征输入次之（→0.8528）；移除整个协同分支降至 0.8552，移除 CP 监督、对齐、残差量化与门控也下降。该归因仅基于模块/整分支消融，无在线 A/B，实际业务收益未核实。
- 次要：用户与场景偏好作为门控条件，使 ID/文本/视觉权重随用户和场景变化，替代固定或拼接式融合
- 次要：残差量化将连续 CP 因子正则化为可复用码字，在论文所测设置下优于直接使用连续因子
- 次要：场景因子调制共享用户/物品因子，使跨场景共性与场景差异在同一分解结构中表达，而非额外场景分支

**与你的关联**

- 适用于多场景/多业务统一精排模型的架构设计：若线上已把图文特征直接拼进共享骨干，可参考其协同偏好因子、条件融合门控与跨分支对齐的组织方式；迁移需具备离线编码的物品文本/图像特征与场景标签，并权衡训练时间与参数量上升。

**风险或局限**

- 证据仅来自两个公开数据集的离线实验（AntM2C 沿用 AMS 协议的五场景点击日志与时间切分，Amazon 为三品类构造场景、按用户-场景内时间切分，非同一时间截断），无在线 A/B 或部署结果，WAUC 小幅提升对应的业务收益未验证。

- 场景：展示广告多日CTR训练中的日更物品共现嵌入跨日兼容与尺度管理
- **论文主要内容：** 研究日更物品共现嵌入跨日漂移，比较初始化、对齐、热启动与尺度管理，并用CTR编码器适配。

**主要创新或优化点**

- 工业实证而非新算法：新增认识是日更物品嵌入在多日CTR训练中存在方向/范数不兼容，并以几何、行为召回和CTR在同一离线工业协议下联合评估；ID-init、OP、warm、SVD和低维编码器多为既有或适配组件。机制性更新是warm_norm按全词表平均物品范数每日同时重缩放继承的item/context表、保留相对范数，区别于导出端逐物品归一化，以及用同维对照检验CTR编码器的额外方向适配；范围限于所测展示广告数据。

**核心方法**

- OP对齐：用锚点方向拟合当前日嵌入到前一日处理版本的正交映射，再作用于全量物品向量，保持版本内内积、范数与余弦检索排序；拟合锚点与评估队列不重叠。
- warm_norm：热启动继承前一日item和context表后，每日按全词表平均物品范数与参考均值之比s_t同时缩放两张表，保留当前物品方向与相对范数，输出给次日训练和CTR特征。
- CTR适配编码器：冻结各日预计算嵌入，用跨日期共享的低维编码器映射后接DNN做CTR训练，并在推理模式输出编码向量用于跨日余弦诊断；对照包括同维随机正交投影、仅用训练日的SVD和同结构未训练编码器。

**关键结果**

- 在共同协议32个CTR配置中，相对普通Word2Vec，ID-init将跨日余弦提高51.2%、GAUC提高2.2%；OP将余弦提高93.4%、GAUC提高2.6%，其中OP保持版本内余弦检索排序。
- 热启动将相邻日余弦提高127.0%、GAUC提高3.5%，但日匹配平均范数相对Word2Vec的变化到第8天为+102.5%；warm_norm把该日匹配平均范数相对变化限制到+8.2%，取得观测最高GAUC+4.0%与Recall@100+15.9%。
- CTR训练编码器在6种上游方法中4种的跨日余弦最高；Word2Vec+OP的train-to-test余弦相对变化+131.4%，高于未训练编码器+120.6%和SVD+127.4%，分别高10.8和4.0个百分点。

**收益归因**

- 主要：离线观测到跨日兼容性与GAUC改善；OP的GAUC增益有配对区间支持，warm_norm仅最高观测点估计且相对warm/warm_unit区间跨零；下游编码器只支持编码器空间余弦改善，未证明对GAUC的因果贡献。
- 次要：论文建议将OP作为现有日更Word2Vec管线中改动较小的初始对齐基线：它保留训练流程与版本内余弦检索排序，但需增加对齐步骤和参考版本管理。
- 次要：warm_norm通过缩放继承的item/context表限制范数累积并保留相对范数，可能降低多日特征尺度漂移。
- 次要：CTR训练的低维共享编码器可在冻结上游嵌入的前提下进一步适配残余漂移，为下游增加任务学习环节。

**与你的关联**

- 适用于已有日更item embedding、多日日志混训CTR的推荐/广告系统；可迁移的是对齐、热启动尺度管理和共享编码器对照协议，落地前需在自有数据做在线A/B。

**风险或局限**

- 所有预测结果均为离线；论文明确未报告在线CTR提升，只覆盖一个工业场景和一个主时间窗，配置含复用上游产物与小型试点、并非独立复现，多数仅单次训练，后续选择受测试结果影响。

### P0｜[阿里巴巴、大连理工大学、香港城市大学｜SWAG-Bid｜Beyond Single-Episode Optimization: Sliding-Window Aware Generative Auto-Bidding for Long-Term Advertising Effectiveness](https://arxiv.org/abs/2607.25233)

**论文、机构与场景**

- **机构：大连理工大学、阿里巴巴国际数字商业集团、香港城市大学**
- 作者：Binglin Wu、Chuan Yue、Yingyi Zhang、Xianneng Li、Ruyue Deng、Weiru Zhang、Xiaoyi Zeng

**主要创新或优化点**

- 问题认识与形式化：把滑动窗口效率约束下的自动出价建模为跨 episode 耦合，指出单 episode 独立优化与窗口级评测的错配，给出每 episode 预算独立、每个 W 窗口效率受限的问题形式。新算法一：复用 Masked Trajectory Model 的掩码重建与策略/预测双重角色（沿用 [42]），新增 episode 级四阶段掩码 rollout 生成 N 个候选计划，并由 MWMS 对含当前 episode 的全部 W 个窗口按指数置信衰减加权评分选优。新算法二：在 DiT 式 AdaLN（沿用 [32]）上扩展 PSG-AdaLN，用全局指导向量与每步状态 token 经 MLP 门输出门控值，在 CFG 训练的条件/无条件模式间逐步插值后注入各 Transformer 块；RTG/CTG 双通道沿用约束解耦 DT 接口（[41]），承载预算与效率目标。

**核心方法**

- MTM 规划器把历史与未来 episode 轨迹编码为状态、动作、成本、价值序列，用 MAE 式编解码 Transformer 加模态嵌入训练：随机掩码后做加权掩码重建，状态/成本/价值用 MSE、动作模态用随机头加熵正则，并把因预算耗尽而截断的 episode 按历史日内流量分布重标定为整 episode 等价值；推理时依次对动作、状态、成本、价值做四阶段掩码 rollout，4 次批前向并行生成 N 个候选计划。

### P1｜[Han Chen 属 University of Texas at Austin，Yingrui Li 属 Unaffiliated｜UnKD｜Preserving rare-item recall under a storage budget: quantization, distillation, and the limits of teacher fidelity](https://arxiv.org/abs/2610.36267)

- 来源：arXiv:2610.36267v1
- 场景：固定嵌入存储预算下的推荐系统稀有物品召回与压缩评测
- **论文主要内容：** 在固定嵌入存储预算下比较量化、蒸馏与低秩分解，并检验教师保真度能否代表稀有物品召回。

**主要创新或优化点**

- 在本文七个数据集-骨干单元、共同存储上限下，比较“把字节花在秩还是精度”与“直接训练小模型还是蒸馏”，给出低秩量化在尾物品召回上优于低维模型的实证边界，而不仅是平均 NDCG；五个扩展单元采用预注册比较；把 teacher-hit retention 与 total tail recall 分开，指出保真度会漏计教师未命中的相关尾物品，并可能误排压缩模型；用 full-catalog top-20 评测组织压缩推荐实验，提出报告 retained/off-list 贡献与显式存储账本的评估清单。

**核心方法**

- 在每用户或物品行 168 字节的公共预算内比较七种候选：40 维 BPR、两个 40 维 UnKD 蒸馏学生，以及把 300 维教师评分矩阵分解为 rank 40/FP32、80/FP16、155/INT8、300/INT4。
- 对教师评分矩阵做平衡低秩分解：先对用户和物品因子做薄 QR，再对小核心矩阵做 SVD，并把奇异值平方根分配到两侧；这些因子不做任务微调，按等字节预算选择秩与精度。
- 以训练频率最低 80% 物品为尾物品，对全目录排序取 top-20，计算 tail recall@20、NDCG@20 及 teacher-hit retention；所有留出比较用五训练种子，五个扩展单元另用预注册配对 bootstrap/Holm 分析。

**关键结果**

- 同一存储上限下，rank-300 INT4 仅用教师 13.4% 存储，在七个数据集-骨干单元保留教师 tail recall@20 的 94.8–102.8% 和 NDCG@20 的 93.4–97.3%；同预算的 rank-40 FP32 在每个单元 tail recall 最低，INT4 为其 1.24–12.70 倍，但每评分乘加量为 7.5 倍。
- 五个扩展单元的十个预注册比较中，INT4 的 tail recall 均高于两个 UnKD 学生，差值 0.12–4.11 个百分点，所有同时 95% 区间排除 0；学生在 10 个比较中仅 6 个满足 3% NDCG 非劣边界。
- teacher-hit retention 与 tail recall 在 147 个候选对中有 23 对（15.6%）排序不同，并在 3/7 单元选错 tail 召回领先者；Steam 与 MovieLens-20M 上 BPR 的 tail recall 达教师的 108.2% 和 121.7%，其尾命中超过一半为教师未检索到的 off-list 命中。

**收益归因**

- 主要：在本文七个数据集-骨干单元的共同存储上限下，将字节优先分配给更高秩、再以低精度存储，可比同预算低维全精度模型保留更多稀有物品召回；代价是评分算术量增加。
- 次要：用 total tail recall 及 retained/off-list 拆分评估压缩模型，可发现教师保真度漏掉的相关尾物品，避免 retention 单指标误排。
- 次要：对蒸馏前的适用性检查：当小模型验证尾召回已接近教师时，UnKD 蒸馏对尾召回的增量有限；该模式为作者基于七单元的待检验假设。
- 次要：预注册比较、五种子与配对 bootstrap 提供可复现的离线评测流程，可用于比较量化与蒸馏方案。

**与你的关联**

- 适用于需要压缩用户或物品嵌入的召回或排序服务，尤其是存储受在线特征库限制、且关心长尾供给的场景；迁移时需按本文口径记录存储上限、尾定义、全目录排序与 retained/off-list 拆分，并自行测延迟。

**风险或局限**

- 证据主要来自 MF：六个留出数据集均用 MF，只有 Amazon Video Games 另有 LightGCN；每个数据集仅一个转导、非时序切分，不覆盖冷启动或未来交互。
- 只测 UnKD 一种蒸馏族、40 维学生和统一逐行量化；未测 product quantization、哈希或混合精度，也未测实际延迟。
- INT4 评分需 rank-40 的 7.5 倍乘加，且依赖已训练教师，教师训练成本未计入候选预算；因此存储节省不必然转化为延迟受限系统的收益。

- **机构：科罗拉多大学博尔德分校（University of Colorado, Boulder）**
- 作者：Meysam Varasteh、Elizabeth McKinnie、Robin Burke
- 来源：arXiv:2610.36208v1
- 场景：MovieLens 1M、Yahoo Music、Pinterest 上的推荐反事实解释复现与评测
- **论文主要内容：** 复现LXR反事实推荐解释，扩展至Top10并比较流行度与隐因子基线，用绝对扰动指标评测。

**主要创新或优化点**

- 把解释目标从每位用户的 top-1 推荐扩展到 top-10 列表中的其他物品，并用从 top-10 采样目标训练的 LXR10 检验该任务上的可行性。
- 以绝对移除物品数定义 MPNR、以存在有效扰动的用户比例定义 Coverage，并指出按画像百分比报告会掩盖扰动的实际长度。
- 新增 Pop（训练集评分频次）与 LF（矩阵分解物品隐因子相似度）两个非学习型对照，用暴力子集搜索估计最优扰动下界，并用 RBO 衡量不同解释器扰动的重合度。

**核心方法**

- LXR 解释器 e 输入用户二值画像 x 和目标物品 one-hot y，输出画像各物品的解释分数掩码 m；训练时推荐器固定，仅更新解释器。
- LXR10 将训练目标从 top-1 扩展为从每个用户 top-10 推荐中采样一个目标物品，再按原 LXR 流程训练解释器。
- 对照解释器 Pop 按训练集物品评分频次排序，LF 用矩阵分解物品隐向量与目标物品的相似度排序；MPNR 为使目标物品在推荐列表中下降 k=10 位所需的最少移除物品数，Coverage 为存在该扰动的用户比例，另用 RBO 比较扰动列表重合度。

**关键结果**

- Top10 任务、ML1M+VAE 下，LXR10 达到 Coverage 100%、MPNR 12，LXR 为 Coverage 100%、MPNR 18。
- Top10 任务、ML1M+MF 下，LF 达到 Coverage 95%、MPNR 12，LXR10 为 Coverage 92%、MPNR 18。
- Top10 任务、Yahoo+MF，过滤 15% 最流行物品（训练集与测试画像同时移除）后，LXR10-filter 相对 LXR10 的 MPNR 由 6 降至 3、Coverage 由 98% 降至 33%。

**收益归因**

- 主要：提供离线评测证据：以绝对移除物品数计量的 MPNR/Coverage 口径，加上 LXR10、LF、Pop 的对照，说明反事实画像扰动解释在 Top10 任务上的效果与代价；未提供在线 A/B 或部署依据。
- 次要：LXR10 从每个用户 top-10 推荐中采样单一目标物品训练，作者报告其在 Top10 任务上总体不劣于 LXR，属解释器模块级对比，非线上收益。
- 次要：LF 复用推荐器矩阵分解的物品隐向量与目标物品做相似度排序，作者称可省去单独训练解释器；但仅在 MF 下可直接取用其参数，VAE 下效果随数据集波动。
- 次要：热门物品过滤实验显示流行度是影响扰动长度与覆盖率的变量，可用于判断哪些目标物品不适合个体化反事实解释，需配合其他解释形式。

**与你的关联**

- 适用于推荐解释/透明度模块的离线评测：当需要比较反事实解释器在绝对扰动长度、覆盖率与最优性差距上的表现时，可复用 MPNR、Coverage、RBO 及子集穷举协议，并需把扰动规模对用户可理解性的约束纳入选型；不提供召回或排序模型的效果增益。

**风险或局限**

- 论文为 arXiv 预印本（2610.36208v1），PDF 使用 ACM 模板但无明确会议接收信息，方法尚未经同行评审确认。
- 未开展用户研究，作者仅推测超过 5 项物品的扰动不易被用户理解，而多数条件下多数用户的扰动大于该值，可理解性与实际可用性未验证。
- 最优性暴力搜索只覆盖 ML1M 中 LXR 扰动 ≤20 的用户子集（原文亦写作 <20，口径不明），未在 Yahoo、Pinterest 或更大扰动空间复现；LF 在 MF 推荐器下可直接读取推荐模型隐向量，属非黑盒对照，黑盒场景可比性受限。


## 精排与排序

### P1｜[北京邮电大学、浙江大学、中南大学｜MAGE｜Can Complementary Signals Bridge Similarity Islands? Manifold-Augmented Graph Embedding for Multimodal Recommendation](https://arxiv.org/abs/2610.37409)

**论文、机构与场景**

- **机构：北京邮电大学、浙江大学、中南大学**
- 作者：Zhenye Yang, Jinpeng Chen, Wenbo Fu, Jun Ma, Huan Li, Qimin Zhou, Tao Wang, Li Sun, Senzhang Wang
- 来源：NeurIPS 2026 / arXiv:2610.37409v1
- 场景：Amazon Baby/Sports/Clothing/Electronics 上的个性化多模态商品推荐排序
- **论文主要内容：** 针对多模态推荐中互补信号被相似度图割裂的问题，提出离线流形增强与在线非对称双流图传播框架。

**主要创新或优化点**

- 针对相似度图传播偏好替代品、互补信号在原始多模态空间形成相似性孤岛，论文在既有互补/异质图研究上引入拓扑传播前的几何整形：按种子局部相对分位划强/弱邻居代理，用局部 SVD 与 Soft Conceptor 软抑制替代品主导子空间，再从弱邻居去投影残差并对种子正交化；增量在局部间隙保持的自适应注入与非对称双流/自校准门的组合。论文自述设计组合既有算子，故应写成组合与实证贡献而非模块均原创。LLM 文本抽取为冻结预处理，训练/推理不调用；原始文本对照与 backbone 迁移用于区分文本精炼和几何整形贡献，但结果并非全部一致。

**核心方法**

- Phase I：对每个种子商品按局部余弦相似度的相对分位把共购邻居划为强/弱集合，用局部 SVD 和 Soft Conceptor 权重构造替代品主导子空间，聚合弱邻居去投影残差并对种子正交化，得到互补感知文本残差
- 注入：由强/弱集合均值定义局部间隔，按 keep ratio ρ 与 αmax=0.35 计算自适应残差系数，L2 归一化后若归一化间隔低于目标则回退，输出增强文本嵌入供在线流使用
- Phase II：视觉原特征在视觉-文本 kNN 交集相似图上传播，增强文本在 kNN+共购混合图上以 k=10、ωco=0.4 传播；注意力共享原型、ID 调制残差与双向门融合后，以内积输出用户-商品偏好分，并用 BPR、对齐和对比正则训练

**关键结果**

- 在四个 Amazon 数据集全排序测试上，MAGE 的 Recall@10/20 与 NDCG@10/20 均为表内最佳；相对最强基线，Recall@20 分别提升约 2.77%、4.81%、6.25%、6.53%（Baby/Sports/Clothing/Electronics），作者称五个随机种子 paired t-test p<0.01
- 在按共购关系且图文相似度均处后30%构造的 hard-complement 子集上，相对较强的 GUME/MENTOR，16 个数据集-指标组合全部提升，平均相对提升 9.87%（数据集均值 6.08%、14.00%、11.71%、7.69%）；作者明确该子集是针对性诊断而非独立全排序基准
- 块级消融显示，去掉 Phase I、非对称传播、互补拓扑或自校准门控后，四个数据集的 R@20 与 N@20 均下降；例如 Baby R@20 从 0.1077 降至 0.1045/0.1070/0.1061/0.1050，Electronics 从 0.0587 降至 0.0570/0.0580/0.0552/0.0566

**收益归因**

- 主要：主要收益来自离线流形增强与在线非对称双流图传播的整包组合；块级移除 Phase I、互补拓扑、非对称传播或门控均降低所测指标，但作者仅称累积贡献/描述性支持，未把整包增益因果拆到单一模块，亦无在线 A/B。
- 次要：视觉稳定锚与非对称传播用于减少互补边对视觉表征的污染；去掉非对称传播会降低所测数据集的 R@20/N@20，但原文仅支持模态角色有别，不证明污染机制。
- 次要：局部间隙保持与归一化回退控制几何扰动幅度；细粒度消融中 gap constraint 的平均贡献最大，但差异描述性且未单独检验显著性。
- 次要：冻结的 LLM 证据约束文本可复用为离线特征；单独替换 LLM 文本的迁移收益不稳定，原文称主要收益不是文本精炼本身，但 Baby 迁移混合限制泛化。

**与你的关联**

- 适用于商品推荐中的互补品挖掘、多模态冷启与长尾排序；若已有共购元数据和可冻结的多模态商品特征，可把 Phase I 作为离线表征增强接入现有 GNN 排序器，但需先验证迁移；共购边只是不完美证据，不能假设可靠。

**风险或局限**

- 互补边来自 also_bought/bought_together 等共购元数据，是不完美证据；强/弱集只是局部几何代理而非语义标签，残差几何约束也不保证单个残差语义为互补；30% 删边/重连实验不能外推到任意图噪声、极端稀疏或时间漂移
- 证据仅为四个 Amazon 数据集的离线全排序与针对性 hard-complement 子集，无在线 A/B 或生产部署；子集按动机关系构造，Baby 上迁移到已有 backbone 的结果混合，不能据此断言普遍收益
- 文本侧依赖 Qwen3-32B-AWQ 一次性抽取并冻结，未证明跨后端生成不变性；Phase I 1.89/4.39/4.36 秒与低于 0.4GB 的测量不含文本抽取和嵌入生成，且部分超参按数据集选择


## 今日最值得立项的实验

### SID生成式召回的多目标蒸馏逐token教师重加权

- 假设：在已有单目标教师的多目标生成式召回中，用初始学生到各教师的逐token期望KL归一化权重替代等权蒸馏，可使更难蒸馏目标在对应解码步得到更强监督，提升联合排序指标且不增加蒸馏前向。
- Control：现有等权MOPD蒸馏损失，学生结构、教师、采样轨迹数与训练步数不变。
- Treatment：在蒸馏损失中按预计算α_{j,t}对各token反向KL加权；另设仅item级KL加权与固定均匀token权重两个子臂，用于区分逐token机制贡献。
- 保持变量：['同一学生骨干与SID词表', '同一两个冻结单目标教师及checkpoint', '同一训练日志、采样trajectory数与batch', '同一评测集与beam配置']
- 离线指标：联合目标u_cv@K与各单目标@K；top-100/top-200召回；教师-学生逐token KL随训练步变化
- 线上 Guardrail：线上广告收入、GMV与CTR不出现负向；蒸馏阶段前向与训练时长不超预算；不同目标间曝光/成交结构不出现系统性偏移

### CTR序列精排的目标相对时间编码与时序组交互

- 假设：以请求时间为锚的对数时距编码，配组内双向、组间因果的历史交互与组摘要压缩，可在不扩序列口径的前提下提升CTR排序区分度并降低单步训练时间。
- Control：现有事件级因果掩码加可学习绝对位置编码的序列精排骨干，参数量与训练步数对齐。
- Treatment：替换为低于秩分解的秩位置嵌入加目标相对时间偏置（含密度校正），并按对数时距分组做组内双向注意力与组均值池化。
- 保持变量：['同一行为序列长度上限与特征口径', '同一训练日志时间窗与验证集', '同一多任务头与优化器设置']
- 离线指标：AUC与GAUC；LogLoss与校准偏差；单步训练时间与位置参数量
- 线上 Guardrail：预测正例概率不出现系统性高估；分组边界调整后长序列用户指标不回退；线上服务延迟与显存不超预算

### 日更物品嵌入的跨日对齐与热启动尺度管理

- 假设：在多日日志混训CTR时，用锚点拟合的正交映射对齐日更物品嵌入并每日按全词表平均范数重缩放继承表，可降低跨日方向与尺度漂移，提升GAUC而不改变训练流程。
- Control：现有日更Word2Vec物品嵌入直接热启动继承item与context表，无对齐与重缩放。
- Treatment：加入锚点正交映射到前一日处理版本，并叠加warm_norm每日全词表范数重缩放；另设仅对齐、仅重缩放两个子臂。
- 保持变量：['同一嵌入维度与词表', '同一CTR DNN结构、特征与训练天窗', '同一评估队列与锚点/评估不重叠划分']
- 离线指标：跨日余弦相似度与版本内检索排序一致性；GAUC与LogLoss；日匹配平均范数相对变化
- 线上 Guardrail：线上CTR与广告收入不出现负向；特征尺度漂移监控不告警；对齐与重缩放引入的批处理时间在预算内


## 一句话总判断

证据概况：收录 24 篇，全文核验 21 篇；标记为线上 A/B 证据 5 篇。
