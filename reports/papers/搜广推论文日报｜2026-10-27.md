## 生成式召回

### P0｜[Pinterest｜PinGER: Token-Efficient Generative Retrieval with Semantic IDs](https://arxiv.org/abs/2610.33435)

**论文、机构与场景**

- **机构：Pinterest（PDF 首页作者署名区明确列出，作者邮箱域名 @pinterest.com 佐证）**
- 作者：Xinyi Li、Sujan Reddy Ale、Yi-Ping Hsu 等
- 来源：arXiv:2610.33435v1
- 场景：Pinterest Related Pins 与通知的生成式召回
- **论文主要内容：** 针对SID召回历史过长，提出SID与稠密token交错掩码及高效服务栈并线上验证。

**主要创新或优化点**

- 生成式检索（GR）内首次的角色依赖非对称掩码：语义ID（SID）token 训练时逐层监督、不被后续位置读取，服务每物品仅一个稠密 token；GR 外已有类似掩码。层次感知 beam 多样性：按最长公共前缀深度逐个选 beam 扣分，语言生成只罚同步 token。SID 宽 beam 服务栈：Hydragen 式共享前缀 cascade、STATIC 式向量化 trie 与 host-local 索引组合，cascade/trie 属沿用。直接偏好优化（DPO）后训练：用排序器日志 slate 效用构造偏好对，不训额外 reward model 并保留 next-token 锚点。

**核心方法**

- 交错序列与不对称掩码：训练初始每物品含 L=5 个语义ID（SID）token 后接 1 个稠密 token 并共享物品位置索引；实现再丢弃第 L 层 SID 输入 token，使训练输入为每物品 L 个 token 但保留逐层 SID 监督。稠密 query 只读先前稠密 key，SID query 读稠密历史及自身浅层码，后续位置不读过去 SID；服务时丢弃历史 SID，只保留每物品 1 个稠密 token。
- 前缀多样性惩罚：beam 选择改为逐个挑选，对与已选 beam 共享前缀的候选按最长公共前缀深度乘 λ 扣分，使 beam 分散到不同 SID 前缀；论文同时报告温度采样会降低 distinct@1 与合法 SID 比例。
- 服务栈：采用 Hydragen 式共享前缀注意力的 cascade decode，把 W 个 beam 折进 query 维，使共享历史每请求只读一次；用 GPU 常驻、STATIC 式向量化 SID trie 做逐层约束解码，并用 host-local CSR 索引解析候选物品，beam 不足时回退到更粗前缀。

**关键结果**

- Related Pins 线上 A/B（替换 PinRec，两周，固定候选预算，5% 双侧显著）：surface saves +0.62%、grid clicks +0.94%、site-wide saves +0.61%、28 天内新 Pin saves +3.60%，端到端延迟 -0.7%。
- 离线 Recall@100（beam width 100）：相同 1,024 服务 token 下 PinGER 4.00%，TIGER 3.65%（+9.5%），PinRec 1.01%（约 3.9 倍）；匹配 TIGER 召回仅需 170 服务 token（约 6 倍更少）。
- 服务延迟（AWS g6e/L40S，约 200 QPS/主机，W=100）：PinGER e2e p50 54ms、p99 81ms，PinRec 79/110ms；检索 p99 12ms 对 31ms；W=400 时 cascade 比 paged attention 快 32 倍、KV 少 48.7 倍。

**收益归因**

- 主要：整包系统收益：用 PinGER 替换 Related Pins 的 PinRec ANN 召回后，线上 saves 与新内容 saves 提升、延迟下降；单模块对线上 lift 的因果贡献未在线拆分。
- 次要：非对称掩码与交错布局：机制解释是训练保留 SID 监督、服务每物品一个稠密 token；离线整包在相同 1,024 服务 token 下 R@100 相对 TIGER +9.5%，匹配 TIGER 召回约需 1/6 服务 token。该对比是整包离线对照，未单独消融掩码或布局，不能作单模块因果。
- 次要：前缀多样性惩罚：λ=3 时 100 个 beam 的 distinct level-1 前缀从 11.9 升至 93.6；线上较强惩罚臂 novel interests +0.56%、interest domains +0.43%，但 R@100 降至 1.42%。线上不同惩罚强度有对照，仍非对惩罚模块的完全隔离。
- 次要：约束解码与 cascade：微基准 W=400 时 cascade 比 paged attention 快 32 倍、KV 少 48.7 倍；trie 约束使生成的 SID 都能解析，代价是 W=100 时解码增加 0.30ms；cascade 共享前缀注意力沿用 Hydragen、trie 沿用 STATIC，属组合工程收益。
- 次要：DPO 后训练：用排序器日志的 slate 内效用排序构造偏好对，不训练额外 reward model；离线 recall +2.3%，线上最终 slate 候选存活率 +10%，并保留 next-token 锚点防止召回崩塌。

**与你的关联**

- 适用于大规模生成式召回/相关推荐，尤其是 SID 生成式检索的上下文成本、宽 beam 服务成本与新内容冷启动；迁移需复现其 SID tokenizer、排序器日志偏好数据和线上约束解码/索引栈。

**风险或局限**

- 线上主 A/B 只与 PinRec 整包对比，未在线拆分非对称掩码、约束解码、cascade 与 DPO 的独立因果贡献；虽有强/弱前缀惩罚的在线臂比较，主 A/B 的整包 lift 不能归因到单一模块。
- 离线主要用 Pinterest 内部 UniPinRec 会话数据与生产语料，未给公开数据复现；RQ-VAE tokenizer、PinCLIP/OmniSage 特征和索引均为内部依赖。
- 多样性惩罚在 λ=3 时把 R@100 从 4.00 降到 1.42，说明覆盖提升以召回为代价；通知场景更强惩罚还提高退订，需按场景调参。


### P1｜[腾讯、中山大学、内容事业群｜LoopGR: Parameter-Efficient Scaling for Generative Recommendation via Recurrent Depth](https://arxiv.org/abs/2610.34157)

**论文、机构与场景**

- **机构：中山大学、腾讯平台与内容事业群**
- 作者：Huizhe Zhang、Yudong Li、Liang Chen、Chengxiang Zhuo、Zang Li
- 来源：arXiv:2610.34157v1
- 场景：基于语义ID的生成式下一物品推荐（Amazon与腾讯工业推荐离线评测）
- **论文主要内容：** 提出LoopGR，用分层循环深度和轨迹自蒸馏做参数高效的SID生成式推荐。

**主要创新或优化点**

- 作者称首次将循环深度用于SID生成式推荐：共享层反复迭代增加有效计算深度，而不按循环步数扩参，区别于固定层数的Encoder-Decoder、Decoder-only与Lazy Decoder-only骨干。提出分层循环：高层解码循环预测目标SID，低层上下文更新循环用新预测状态修正历史上下文，使上下文在生成过程中动态演化，针对历史建模与目标生成争用有限计算预算的冲突。更新器与骨干解耦且可替换：默认GRU做物品级双向更新；也可用token级MLP/线性注意力或物品级Mixing等；以初始上下文M(0)作残差锚点，支持多个低层循环上的稳定优化。提出RTSD：把高预算教师的逐循环预测分布和演化方向蒸馏到低预算学生，将轨迹形成与推理预算压缩解耦，作者认为可避免中间步直接监督造成的表征停滞，面向严格延迟约束的生成式召回。

**核心方法**

- 用户历史物品的SID token序列经T5编码器得到初始上下文M(0)，共享Transformer解码器与轻量上下文更新器在高、低层循环间交替，逐步生成目标SID token。
- 默认GRU更新器按物品对H个SID token均值池化，注入由上一轮BOS隐状态生成的预测感知query，经双向GRU和投影得到物品级更新并广播回各token，再以M(0)残差和归一化稳定多层循环。
- RTSD先以最后一步监督训练高预算教师；学生从教师初始化并减少高层循环，联合任务损失、KL分布对齐和余弦方向损失；学生循环按比例映射到教师轨迹，对齐各层预测分布及相邻循环log概率的一阶变化方向。

**关键结果**

- Amazon Beauty/Sports/CDs离线评测中，LoopGR与LoopGR-RTSD合计在12项设置中8项最佳；Beauty的R@5和NDCG@5较最强基线相对提升2.4%和2.1%，Sports的R@5和NDCG@10相对提升5.4%和4.2%。
- 腾讯工业离线集主表的LoopGR R@5/R@10/R@100为0.5691/0.6458/0.7675，高于BARGE的0.5477/0.6277/0.7496和TIGER的0.5465/0.6125/0.7164；该主表数值对应Mixing更新器，而非默认GRU。
- RTSD把16-loop教师压到4-loop学生：GFLOPs由17.408降至3.918，batch1延迟由211.08ms降至49.82ms（约4.2×），4-loop学生在Sports四项指标均超过教师。

**收益归因**

- 主要：机制解释（非单模块因果）：共享解码器与轻量上下文更新器的分层循环复用，在不按步数扩参的情况下增加有效深度，并让历史上下文在生成SID过程中被动态修正；整包配置的离线收益见key_results。
- 次要：RTSD将高预算教师的分布与轨迹方向迁移到低预算学生，降低循环步数和推理延迟；该收益来自轨迹蒸馏整包配置，未分离各损失项的独立贡献。
- 次要：更新器消融中Identity变体在各项指标上均低于默认LoopGR，作者据此归因于动态上下文更新而非特定序列算子；该消融仅支持模块层面，不能外推为整包收益的唯一来源。
- 次要：分层循环提供可调的高层/低层预算，论文显示在参数或算力受限时可作为生成式召回骨干的扩展维度；迁移需重搜预算。

**与你的关联**

- 适用于SID生成式召回的骨干设计与低延迟推理；迁移需具备RQ-VAE类语义ID、可控循环预算、离线行为序列日志，并重新验证线上延迟与收益。

**风险或局限**

- 全部结果来自离线评测，未报告线上A/B、生产部署或真实业务收益；腾讯工业集也只是离线R@K。
- 腾讯工业数据未披露用户/物品规模、时间窗口、基线调参预算，也未给出推理延迟与成本对照，难以判断工业可迁移性。
- RTSD需先训练高预算教师再蒸馏，教师训练成本与端到端训练预算未披露；高层循环加深后收益呈非单调，最优预算需重搜。


### P2｜[DPE-Rec: Diversity-Preserving and Efficient Diffusion Language Model Recommendation for Bundle Construction](https://arxiv.org/abs/2610.34700)

**论文、机构与场景**

- **机构：未披露**
- 作者：Pingchuan Ma, Bohan Jiang, Chengshuai Zhao, Dawei Li, Zhen Tan, Huan Liu
- 来源：arXiv 2610.34700v1
- 场景：基于大规模商品目录的生成式捆绑包构建（补全缺失商品）
- **论文主要内容：** 用扩散语言模型结合语义分叉感知 GRPO 与伪轨迹蒸馏，少步生成多样化捆绑包缺失商品。

**主要创新或优化点**

- 针对置信度引导解码推迟语义分叉决策、导致捆绑包多样性下降的问题，提出语义分叉感知 GRPO，用自回归 rollout 优先学习分叉决策，属于对扩散 LLM 解码偏置的训练侧修正。
- 针对多 token 解码损害推荐质量、难以加速的问题，提出伪轨迹蒸馏，把庞大随机加噪空间压缩到高质量解码轨迹子空间，使少步去噪下的多 token 解码更可靠。

**核心方法**

- DPE-Rec 采用扩散语言模型（DLM）做无序捆绑生成：双向注意力与迭代去噪作为归纳偏置，每步可显现多个 token 以降低推理延迟。
- 引入 semantic-fork-aware GRPO：通过自回归 rollout 优先处理语义分叉决策，避免置信度引导解码把分叉决策推迟到细化 token 阶段而削弱多样性。
- 引入伪轨迹蒸馏：把随机加噪空间的学习集中到高质量解码所访问的紧凑轨迹诱导子空间，从而支持可靠的多 token 解码并减少去噪步数。

**关键结果**

- 论文在多个捆绑包构建基准上报告，DPE-Rec 平均提升推荐性能 63%（相对提升口径，正文未核验）。
- 快速变体平均推理速度约为现有生成式推荐方法的 25.6 倍，且推荐质量损失很小（硬件与候选规模未在摘要中给出）。

**收益归因**

- 主要：扩散 LLM 少步多 token 解码下的捆绑包生成质量与推理效率
- 次要：语义分叉感知 GRPO 提升捆绑包多样性
- 次要：伪轨迹蒸馏降低去噪步数需求

**与你的关联**

- 仅适用于以扩散语言模型做生成式捆绑包或无序商品集合补全的场景；若需在商品/SID 空间做生成式候选，可参考其多 token 解码训练策略，但需自行核验目录规模与线上延迟。

**风险或局限**

- 仅摘要级证据，未核验 PDF 正文中的基线设置、评测指标与 63% 提升的统计口径。
- 25.6 倍加速未说明硬件、批次、候选目录规模与解码步数配置，难以判断实际服务收益。
- 捆绑包构建为独立性较强的商品集合生成任务，向常规推荐召回/精排链路的迁移性未验证。

### P1｜[University of Antwerp｜Theoretically Sound Item Similarity Measures for Recommender Systems](https://arxiv.org/abs/2610.34402)

**论文、机构与场景**

- **机构：University of Antwerp（Bart Goethals 同时隶属 Froomle）**
- 作者：Noah Daniëls, Joey De Pauw, Bart Goethals
- 来源：arXiv:2610.34402v1
- 场景：隐式反馈 item-kNN top-N 推荐与物品相似度设计
- **论文主要内容：** 将隐式反馈协同过滤视为概率分类，用伯努利与多项式朴素贝叶斯推导可解释的物品相似度。

**主要创新或优化点**

- 把 item-kNN 相似度设计转为隐式反馈的概率分类与参数估计，使相似度成为特定优化目标的闭式解，而非仅靠试错。
- 从 Bernoulli 与 multinomial 事件模型推导两种相似度；Related Work 表明 Bernoulli/多项式朴素贝叶斯用于 CF 已有先例，新颖性应限定在 item-kNN 相似度设计与建模选择。
- 把平滑解释为 Beta/Dirichlet 先验下的 MAP 伪计数，区分均匀与经验贝叶斯平滑。
- 将余弦和条件概率重解释为不同正则权重下的优化解，揭示流行度偏差来源。

**核心方法**

- 将隐式反馈矩阵的 item-kNN 打分 ŷ(u,i)=Σ_j X_uj S_ij 视为概率分类，用朴素贝叶斯分别建立 Bernoulli（目标物品为标签、其他物品为二元特征）和 multinomial（用户历史为物品计数袋、下一个物品为多类别标签）事件模型，导出相似度 S_ij=log p(j|i) 及偏差项 log p_i。
- Bernoulli 模型给出 p_i=n(i)/n、p_{j|i}=n(i,j)/n(i)，并引入负特征权重 γ 修正 MAP 目标；论文指出在打分时直接丢弃负特征而不调整参数在概念上错误，必须同步修正参数或保留负特征项。
- multinomial 模型用 p_i=n(i)/Σ_k n(k)、p_{j|i}=n(i,j)/Σ_k n(i,k)，只从正交互学习参数，并通过 softmax 耦合避免全正平凡解；平滑用 Beta/Dirichlet 先验做 MAP，作者将 cosine 和条件概率重解释为 λ=∥X·i∥∥X·j∥=sqrt(n(i)n(j)) 或 n(j) 的正则化优化解。

**关键结果**

- Amazon Books 上，多项式朴素贝叶斯（NB）相似度的 Recall@10 为 0.221，高于 item-kNN cosine 的 0.170 和条件概率的 0.146，低于 EASE（Embarrassingly Shallow Autoencoders）的 0.251；相对拟合时间为 EASE 的 0.040。
- MIND 上，多项式 NB 的 Recall@10 为 0.168，高于 cosine 的 0.150 和条件概率的 0.131，接近 EASE 的 0.169；相对拟合时间为 0.049。
- ML25M 上，多项式 NB 的 Recall@10 为 0.254，低于 cosine 的 0.258、高于条件概率的 0.201，EASE 为 0.351；相对拟合时间 0.064，显示增益依赖数据集且 EASE 仍最强。

**收益归因**

- 主要：离线 Recall@10 的增益来自多项式 NB 相似度及偏差/平滑等建模选择的组合；消融显示偏差与平滑作用会相互替代，不能从整体结果拆分单模块因果；线上收益未核实。
- 次要：概率平滑作为先验伪计数，可在共现稀疏时稳定相似度；经验贝叶斯平滑让信息少的物品少影响打分，均匀平滑可能引入伪相关。
- 次要：余弦/条件概率的优化解释可用于分析流行度偏差来源，并指导相似度改写，而不只依赖调参。
- 次要：闭式共现计数相对 EASE 的全矩阵优化更轻量；论文报告 NB 相对拟合时间约为 EASE 的 0.04–0.08。

**与你的关联**

- 适用于需要轻量、可解释 item-item 相似度的隐式反馈召回/排序场景；若线上使用 item-kNN 或 CF 召回，可测试多项式 NB 相似度、偏差项与经验贝叶斯平滑，但需在自己的数据上验证平滑与剪枝策略。

**风险或局限**

- 仅三个公开数据集离线评估，无线上 A/B、生产部署或独立复现，无法确认工业规模与真实业务收益。
- 作者明确不追求 SOTA；基线只含 EASE 和 item-kNN 的 cosine/条件概率，未与更多近期推荐模型比较。
- 增益依赖数据集与事件模型：ML25M 上多项式 NB 的 Recall@10 低于 cosine，最优平滑类型随数据集变化，且剪枝对 NB 相似度普遍有害。


### P2｜[Gamaizer、Université de technologie de Compiègne/CNRS Heudiasyc、Sorbonne Université/CNRS LPNHE｜CA-HNM: Constraint-Aware Hard Negative Mining for Dense Retrieval with Structured Domain Models](https://arxiv.org/abs/2610.35045)

**论文、机构与场景**

- **机构：Gamaizer、Université de technologie de Compiègne/CNRS Heudiasyc、Sorbonne Université/CNRS LPNHE**
- 作者：Ngoc Luyen Le、Marie-Hélène Abel、Bertrand Laforge
- 来源：arXiv:2610.35045v1
- 场景：教育课程资源稠密检索
- **论文主要内容：** 针对稠密检索硬负例仅按检索接近度选择的问题，用结构化域约束筛选不兼容负例并微调双塔。

**主要创新或优化点**

- 问题重定义：把硬负例从“检索接近且非已知正例”扩展为同时满足结构化域不兼容，用关系、范围/层级、目标上下文冲突构造负例池，且不改变双塔推理结构。
- 机制新增：围绕查询目标构建局部类型化上下文，用确定性规则输出匹配/不匹配/歧义/无证据及违规证据，使负例选择可审计；结构化信息只在离线负例构造阶段使用。

**核心方法**

- 候选构造：对每个查询取 BM25 Top-K 与稠密 Top-K 的并集，先删除已有正例标注，再用显式概念标识或标签/别名匹配确定查询目标概念，并围绕该目标构建含关系邻居的局部类型化上下文。
- 约束分类：使用确定性规则检查候选与目标上下文，输出目标匹配、关系不匹配、范围或层级不匹配、目标上下文不匹配、歧义或无约束证据，并记录违规集合与证据；只保留不匹配候选作为约束感知负例池。
- 负例使用：Pure 按主要违规类型轮转选择且每查询至多 4 个负例，Mixed 将随机、BM25、稠密、约束感知池去重合并；训练时物化(q,d+,N(q))微调 BGE 或 E5 双塔，可用 triplet loss 或 cached multiple-negatives ranking loss（cached MNRL），结构化信息不输入编码器。

**关键结果**

- 在2数据集×2编码器×2损失×10 seeds下，CA-HNM-Pure相对rank-matched在6/8配置的平均NDCG@10更高；四个分层95% bootstrap区间全大于0（Course/E5/triplet +0.0911，MOOC/BGE/cached +0.0177，MOOC/BGE/triplet +0.0819，MOOC/E5/triplet +0.0268）；MOOCCubeX各编码器-损失块的绝对最高值仍由DPR-Random或DenseNeg取得。
- BGE/cached MNRL下，CA-HNM-Mixed相对matched-mixed的NDCG@10仅+0.0038（Course-Skill Atlas）和+0.0076（MOOCCubeX），差异较小。
- 结构变体：Course-Skill Atlas上shuffled-graph NDCG@10=0.1174、no-structure=0.0950，高于CA-HNM-Pure的0.0311；MOOCCubeX上no-structure=0.1835高于0.1724，说明结构变化同时改变候选资格与负例池组成。

**收益归因**

- 主要：rank-matched 对照（替换约束感知来源、近似固定检索位置）显示，约束感知负例在部分配置尤其 triplet loss 下取得更高 NDCG@10；但混合池中替换该来源的差异很小，且位置未被完全控制，故属整包配置级观测差异，不能归因为规则机制的单独因果。
- 次要：记录关系、范围/层级、目标上下文违规证据，便于审计负例池组成和调试规则。
- 次要：用 rank-matched 与 matched-mixed 控制近似固定检索位置/混合池组成，评估结构化选择的增量。

**与你的关联**

- 适用于搜索/推荐召回阶段双塔模型的硬负例构造，尤其当物料有概念层级、先修关系或类目/层级等显式结构化元数据时；迁移需保证结构化关系可靠且负例选择在离线完成。

**风险或局限**

- 全部结果使用 development 划分，Course-Skill Atlas 仅有 32 条 dev query，区间宽度需谨慎解读，未报告 test 或线上 A/B。
- 两个数据集均为教育领域且有显式结构化元数据，约束分类器依赖源标签、别名、词面证据和手工规则，跨域迁移未验证。
- 混合池和结构实验仅限 BGE/cached MNRL，rank-matched 只是近似匹配检索位置；结构变体同时改变候选资格，无法隔离关系语义的单独作用。

### P0｜[快手｜ECHO: Efficient Cascade with Homogeneous Operators for Distillation-Guided 100K-Sequence Modeling](https://arxiv.org/abs/2610.28569)

**论文、机构与场景**

- **机构：Kuaishou Technology（北京，作者邮箱 @kuaishou.com）**
- 作者：Wenhao Li, Qinglin Jia, Chenghou Jin, Zihong Xian, Jiezhou Ji, Yanzhi Liu, Zezheng Wang, Bo Chen, Ruiming Tang, Chaoyi Ma, Zhaojie Liu, Wenwu Ou
- 来源：arXiv:2610.28569v2
- 场景：快手短视频推荐精排中10万级用户长行为序列的target-aware建模
- **论文主要内容：** 用蒸馏的用户级选择器把10万级历史压到1万条原始记录，再做目标感知检索与兴趣聚合。

**主要创新或优化点**

- 已有长序列方案两难：搜索式（SIM/TWIN）保留item级原始记录但GSU对每个候选扫描全长历史、成本随序列长度增长；压缩式（C-Former/SequenceO1/TWIN V2）降低候选相关计算却丢失item级可寻址性。DS把可搜索空间先压到K=10K原始记录，让候选相关计算与原始长度L解耦。
- DS的监督来自候选感知的全历史teacher：学生仅依赖用户特征、与候选无关，因而可跨请求跨候选复用；蒸馏用带温度的softmax分布匹配（stop-gradient）而非只对齐teacher Top-K的二值标签，保留teacher对各位置的偏好强度。
- 边界定向辅助损失针对蒸馏后仍被挡在Top-K外的teacher偏好位置，按teacher概率质量挖出漏选与低质量入选位置配对，用gap权重加margin排序损失校正选择边界，属于对选择器而非排序器的训练信号改造。
- 沿用TWIN的scoring-consistency思路并延伸到teacher：Θrel查询/键相关性参数导出给TFR与target attention，使级联各段使用同一相关性度量，减少检索与聚合打分不一致。

**核心方法**

- Distilled Selector（DS）只输入用户侧特征（用户id嵌入等），用多头内积给历史每个事件打分并按分值取Top-K（线上K=10000）保留原始事件记录（含item id、时间戳、侧特征）写入中间存储，跨请求、跨候选复用，在线只读不重跑DS。
- 目标感知蒸馏：候选感知的全历史teacher按目标计算每个历史位置的相关性logits，学生与该目标无关；用温度T的softmax分布做带stop-gradient的分布匹配L_KD，并加边界定向L_aux（在Top-K外挖teacher高概率漏选位置、与入选低质量位置配对，加权margin排序惩罚）拉回边界错选。
- Target-aware Fine-grained Retriever（TFR）只在保留的K条记录中按多头相关性检索M=100条，经target attention聚合进多任务排序器；TFR与聚合共享teacher导出的Θrel参数；部署上用公共用户输入共享、定宽打包记录（64→43字节/条）、key侧投影吸收（⟨qW_Q,hW_K⟩=⟨(qW_Q)W_K^T,h⟩）降低显存、存储和数据搬移。

- 离线GAUC在KuaiRand-1K四个任务（Click/Long-view/Like/Comment）与快手工业数据集四个任务（Effective-view/Long-view/Like/Comment）上均最优，相对最强基线提升0.227%–1.520%（KuaiRand-1K）与0.113%–0.345%（工业），如Comment由0.6252升至0.6347、工业Comment由0.7824升至0.7851。
- 按论文解析式FLOPs估算（R_tr=40、R_inf=300、命中率0.5/0.6，仅计序列分支、不含特征投影与存储访问），L=100K、K=10K时对比STCA：训练14.262927 vs 0.088960 GFLOPs/target（160.3×）、推理1.346437 vs 0.008456（159.2×）；未给实机吞吐或延迟。
- 七天线上A/B（5%流量，接入已含TWIN检索与类C-Former/SequenceO1压缩的现有生产系统）：Kuaishou与Kuaishou Lite的Total App Usage Time分别+0.240%与+0.373%；v1摘要中的单一+0.613%口径已被拆为两场景数值。

**收益归因**

- 主要：候选无感的用户级蒸馏选择器把10万级历史压到1万条原始记录，使在线target-aware检索与注意力聚合的候选相关计算与原始序列长度解耦，同时保留item级匹配证据。
- 次要：软分布蒸馏加边界定向辅助损失提升保留集的选择质量：10K保留记录覆盖teacher Top-100行为99.976%、保留98.5%的相关性概率质量（热度截断仅57.9%与55.9%），减少压缩造成的信息损失。
- 次要：记录定宽打包（每条64→43字节，十亿用户单副本640TB→430TB）与key侧投影吸收分别降低存储体积和在线投影/数据搬移开销。
- 次要：在MLP、RankMixer、MixFormer三种下游底座上相对TWIN均有提升（Click 0.15%–0.35%，Long-view 0.09%–0.35%），说明选择机制不绑定特定排序结构。

**与你的关联**

- 适用于精排侧超长行为序列（10万级）且必须在严格延迟下做target-aware打分的场景；迁移前提是有可实时刷新的用户级选择器与记录存储、排序端使用target attention加多任务头，并能承担一条全历史teacher训练分支。

### P1｜[Cross-Domain Sequential Recommendation with Representation-Level User Transfer](https://arxiv.org/abs/2610.35550)

**论文、机构与场景**

- **机构：未披露**
- 作者：Abdulaziz Samra、Nikita Sukhorukov、Alexey Grishanov、Alexey Vasilev、Evgeny Frolov
- 来源：CIKM '26（arXiv:2610.35550v1）
- 场景：跨域序列推荐，目标域下一物品预测，约束为跨域数据隔离与用户部分重叠
- **论文主要内容：** 提出仅传用户表示的跨域序列推荐框架，用融合层注入源域信息并支持无源历史用户。

### P1｜[悉尼科技大学、澳门城市大学、香港教育大学｜MIDA: Multi-Interest Decoding with Adaptive Aggregation for Session-based Recommendation](https://arxiv.org/abs/2610.34192)

**论文、机构与场景**

- **机构：悉尼科技大学（L. Guo、N. Bisht）、澳门城市大学（S. Wu）、香港教育大学（G. Xu）**
- 作者：Linjiang Guo、Nitin Bisht、Shiqing Wu、Guandong Xu
- 来源：arXiv:2610.34192v1（IEEE TKDE 作者接受稿，DOI 10.1109/TKDE.2026.3740693）
- 场景：基于会话的下一物品推荐
- **论文主要内容：** 针对会话推荐解码器长会话利用不足，提出双空间解耦的多兴趣聚类与稳定性-塑性自适应聚合框架。

**主要创新或优化点**

- 指出现有 SBR 解码器的瓶颈：池化解码器压平序列、点式解码器偏重最近物品，导致长会话中远距离语义相关交互未被利用；这是跨 GRU、GNN、Transformer 骨干的实证观察。
- 提出两空间解耦：聚类只在原始物品嵌入上进行，编码器输出只用于聚合，避免编码器学习到的关系偏置污染语义分组，并降低两阶段目标间的梯度干扰。
- 设计稳定性-塑性双查询：稳定性查询按簇大小对数加权历史簇增强表示，塑性查询锚定最后物品，再以平均簇大小为条件门控融合，直接由聚类结构控制聚合。
- 用全局可学习相似度阈值和软簇权重正则项控制簇密度，阈值经反向传播优化；理论上说明稀疏簇时退化为历史平均加最后物品，稠密簇时趋近池化解码器。

**核心方法**

- MIDA 先对原始物品嵌入做 L2 归一化，并按维度步长 k=4 下采样以计算会话内两两余弦相似度；硬簇定义为 C_i={j | M_ij≥τ}，不做 top-k 截断；软权重 \tilde w_ij=max(sigmoid((M_ij-τ)/γ),ε) 仅用于簇内加权聚合。
- 对簇内邻居加入位置嵌入后，用共享位置感知注意力按软权重聚合，并经 ReLU 得到簇增强嵌入；稳定性查询对除最后物品外的簇增强嵌入按 ln(1+|C_i|/2) 加权求和，塑性查询直接取最后物品的簇增强嵌入。
- 两个查询分别通过独立注意力头对编码器输出（加位置嵌入）做注意力，得到 z_st 与 z_pl；门控 g=σ(W_g[z_pl||z_st||平均簇大小]) 融合为会话表示并对全物品表 softmax 打分；训练目标为下一物品负对数似然加 η 倍软簇权重和正则项。

**关键结果**

- 在四个公开数据集、四种骨干上仅替换解码器，MIDA 的 Recall@5/MRR@5 大多优于 Naive、RL、Ms-PoE、AttenMixer 与 IDEA；例如 GCE-GNN 在 Diginetica 上 R@5 31.47、MRR@5 18.77，Naive 为 30.49/17.87（5 次运行，标准差≤0.15）。
- GCE-GNN 的 16+ 长会话子集上，Yoochoose R@5 由 39.24 升至 40.59，RetailRocket MRR@5 由 17.36 升至 19.98；表 VII 显示多数数据集上收益随会话变长而增大，但 RetailRocket 的更长组并未严格单调上升。
- 在 GCE-GNN 骨干下，Diginetica 全测试集推理延迟 MIDA 0.192 ms/session，Naive 0.151、AttenMixer 0.509；MIDA 相对 Naive 增加 0.041 ms，AttenMixer 为 MIDA 的 2.65 倍（RTX A5000，表 V）。

**收益归因**

- 主要：原始嵌入空间的可微多兴趣聚类与稳定性-塑性双查询聚合是主要改进来源；表 IX 消融显示移除聚类或任一查询均下降，门控机制仅有行为分析，未见单独移除门控的消融。
- 次要：可学习阈值与软簇权重正则项让阈值随预测损失反向传播，减少人工设定簇数；消融中固定选择策略导致 Yoochoose R@5 从 46.21 降至 41.83。
- 次要：解码器替换保持编码器参数与训练计划不变，便于接入不同骨干；参数量约 30K（d=100），低于 AttenMixer 约 60–120K。
- 次要：推理仅单次前向，Diginetica 相对 Naive 增加 0.041 ms/session，且显著快于 AttenMixer。

**与你的关联**

- 适用于电商、新闻、视频流等匿名会话的下一物品推荐，尤其长会话或兴趣分散场景；可替换现有 GRU/GNN/Transformer 排序模型的解码聚合层，但需重新训练阈值并验证线上延迟。

**风险或局限**

- 只在四个公开离线数据集做全库打分评测，没有线上 A/B、生产部署或业务指标，无法确认真实流量收益。
- 主实验固定各编码器只替换解码器，未将 MIDA 与端到端联合训练的 SBR 系统在同一骨干下直接比较；作者将此类比较列为未来工作。
- 聚类需会话内 O(L^2) 成对相似度，极长会话（L≫100）可能带来显著开销；稳定性-塑性两分支假设可能不足以覆盖复杂多兴趣结构，类别纯度也仅在 Diginetica 验证。

### P0｜[阿里巴巴、中国人民大学、中国科学院自动化研究所｜HiRank｜Unified Heterogeneous Feature Interaction via Effective-Rank Scaling for Recommender Systems](https://arxiv.org/abs/2610.35318)

**论文、机构与场景**

- **机构：阿里巴巴集团（Ao Zhang、Haochuan Li、Boya Du）、中国人民大学（Jian Yang）、中国科学院自动化研究所（Qihang Fang、Yulin Xu）**
- 作者：Ao Zhang、Haochuan Li、Boya Du、Jian Yang、Qihang Fang、Yulin Xu
- 来源：arXiv:2610.35318v1
- 场景：淘宝首页信息流与主搜索的多场景CVR/加购预估排序
- **论文主要内容：** 针对多场景CVR排序中序列与非序列特征分离、场景负迁移问题，提出统一异构特征交互框架HiRank。

**主要创新或优化点**

- 已有排序模型常采用先编码序列、再与特征交互的分离流程，序列摘要成为唯一行为输入；HiRank在统一骨干中保留主序列事件状态，并让候选token通过共享K/V的交叉注意力读取序列，使后续特征交互能持续回看事件级行为证据。统一自注意力对所有语义token同质处理，在序列与非序列信号有效秩不同时可能低效；HiRank把门控序列注意力、长期记忆检索、token混合与逐token前馈耦合，并在块间用交互输出更新序列状态和检索查询。长期记忆检索若只用静态画像构造查询，可能把表示方向集中在少数方向；HiRank由主序列生成兴趣查询、由更新后的候选token初始化候选查询，两路从同一长期记忆读取互补证据，查询随交互结果演化。多场景共享表示可能忽略场景差异并引发负迁移，复合token也可能信息密度不均；HiRank用场景token压缩最终token bank，再以独立复合投影生成多视图复合token做高阶注意力，目标是提供互补表示方向与更均衡奇异值谱，而非保证有效秩上升。

**核心方法**

- 将非序列特征与池化行为摘要按用户、物品、请求上下文分组独立投影为语义token；主行为序列按事件投影并保留事件级状态，多类长期历史分别投影为只读长期记忆。
- 每个HiRank块对主序列做门控自注意力，候选token以共享K/V的另一路交叉注意力读取序列；首层由可学习查询种子对主序列做注意力生成兴趣查询，更新后的候选token初始化候选查询，两路分别从同一长期记忆检索互补证据，检索结果经token混合与SwiGLU后作为下一层查询。
- 堆叠块后，场景token作为查询对最终token bank做交叉注意力压缩，再由三组独立复合投影把压缩状态映射为多枚复合token，经多头注意力建模高阶交互，最后送入各任务MLP输出CVR与加购等logits。

**关键结果**

- 论文报告离线CVR对比中，HiRank在淘宝首页AUC 0.9163、GAUC 0.7801，较最强基线分别高0.0009和0.0186；主搜索AUC 0.8764、GAUC 0.6787，分别高0.0005和0.0009；模型299.04M参数、1.530 GFLOPs/候选。
- 论文报告淘宝首页线上A/B相对生产排序器：PV +0.45%，Orders/u +2.27%（p<0.01），GMV/u +2.86%（p<0.05），DAC +2.13%（p<0.01）；另有点击用户数+0.85%、每千次曝光订单+1.81%。
- 论文报告CVR消融（全量HiRank数值与首页表一致）：完整HiRank AUC 0.9163、GAUC 0.7801；同时移除token交互与High-Rank Attention降至0.9143、0.7312，AUC降0.0020、GAUC降0.0489；单独移除门控注意力或互补检索也下降。

**收益归因**

- 主要：整包配置收益：HiRank相对生产排序器在淘宝首页线上A/B提升Orders/u与GMV/u，离线CVR也优于基线；但线上只比较整包，统一骨干、场景压缩和复合投影的单模块因果未核实。
- 次要：长期记忆作为只读事件级记忆，由兴趣查询和候选查询分别检索；这是避免把全部历史并入主序列的设计动机，未给隔离的延迟或内存节省实测。
- 次要：场景token先压缩最终token bank，使复合投影矩阵尺寸与骨干token数无关，为高秩注意力提供较低维输入。
- 次要：联合移除token交互与High-Rank Attention使AUC/GAUC下降，支持二者组合对排序质量的贡献；不能据此单独归因High-Rank Attention。

**与你的关联**

- 适用于候选打分/精排阶段的CVR与多目标预估，尤其是已有主行为序列与多路长期行为、需要融合非序列特征的电商推荐；迁移需有可缓存的长期记忆和场景标识，并重新验证线上延迟与多场景负迁移。

**风险或局限**

- 线上A/B只覆盖淘宝首页信息流，主搜索仅报告离线指标；其他流量来源和场景的线上收益、负迁移是否缓解未验证。
- 未披露线上服务延迟、吞吐、候选规模与资源成本，仅给离线参数量和GFLOPs；论文虽提及时延约束，但未给部署成本边界。

### P1｜[University of Antwerp｜Do Similarity Measures Measure Similarity? How User Activity Creates Phantom Correlation in Recommender Systems](https://arxiv.org/abs/2610.35765)

**论文、机构与场景**

- **机构：University of Antwerp**
- 作者：Marco Favier, Noah Daniëls, Jens Leysen, Sander Marinus, Bart Goethals
- 来源：arXiv:2610.35765v1
- 场景：隐式反馈推荐中的物品-物品相似度与流行度偏差分析
- **论文主要内容：** 用Rasch模型量化用户活跃度异质性在物品相似度中造成的虚假相关。

**主要创新或优化点**

- 把用户活跃度异质性压缩为独立消费、活跃度单调影响所有物品、消费数量充分三个最小假设，并证明满足三者的分布唯一为Rasch活动模型，从而把物品共现中的幻影相关从经验直觉变成可推导基线。
- 对lift、cosine和Pearson相关推导活动诱导关联随物品流行度变化的精确依赖，并给出仅用前两个假设即可证明任意物品对非负相关的结论；相比已有二部网络度数偏差工作，覆盖lift/cosine及任意活动分布。

**核心方法**

- 将用户活跃度θ作为唯一隐变量，假设给定θ物品独立消费、θ单调影响每个物品、消费数量S对θ充分，推出Rasch模型：logit P(X_i=1|θ)=h_i+θ。
- 用EM拟合：E步按历史长度S=k计算活跃度后验，M步更新活跃度分布权重与物品参数h_i，使拟合模型精确复现每个物品流行度；拟合只使用流行度和历史长度分布，不使用物品对共现。
- 以拟合活动模型隐含的共现作为基准，用Poisson deviance比较其与经验共现，并按流行度分块计算lift/cosine/Pearson的标准化误差及EASE在期望Gram矩阵上的权重，量化活动单独能解释的关联份额。

**关键结果**

- 在MovieLens-1M和MovieLens-20M上，活动模型分别消除独立性模型总体系统性偏差的0.81和0.73；分块lift/cosine/Pearson份额分别为0.99/0.99/0.99和0.98/0.98/0.96，EASE为0.79和0.75。
- MovieLens-1M上81%的物品对观测共现落在活动模型隐含值的两倍以内，独立性模型下仅35%；但观测与模型lift的Spearman相关仅0.31，活动解释关联水平而非具体配对排序。
- Amazon Books上活动模型消除总体偏差的0.50，分块lift/cosine/Pearson份额为0.84/0.84/0.73；Last.fm因列表截断50导致总体偏差份额为0.00，分块各度量接近零。

**收益归因**

- 主要：提供可计算的活动基线，量化物品相似度中由用户活跃度产生的伪关联份额，用于相似度选择与偏差诊断；其定位是基线而非配对筛选，下游收益未验证。
- 次要：对lift/cosine/Pearson给出活动诱导关联随流行度变化的解析形式，可指导相似度选择与解释。
- 次要：EM拟合仅使用流行度和历史长度分布，可复用现有隐式反馈统计做离线诊断。
- 次要：Poisson deviance与分块标准化误差可量化各相似度被活动解释的份额，并扩展到EASE期望Gram矩阵。

**与你的关联**

- 适用于诊断item-item相似度及item-kNN/SLIM/EASE类打分中的流行度/活跃度伪关联；在已有隐式反馈日志上拟合活动模型即可做离线诊断，未验证去偏后的下游排序收益。

**风险或局限**

- 仅在MovieLens-1M/20M、Last.fm、Amazon Books四个公开数据集上离线分析，没有线上A/B或下游推荐质量指标，无法证明去偏后的业务收益。
- 活动模型只解释关联的整体水平与流行度形状，不能识别哪些物品对真正突出；论文报告MovieLens-1M上观测与模型lift的Spearman相关仅0.31。
- Last.fm列表截断50使度数欠分散、总协方差为负，违反非负关联的必要条件；Amazon Books残差显示还需主流度等第二维度；EASE在Amazon Books因矩阵过大未计算，稀有物品对噪声需分块汇总。


## LLM 增强与对话推荐

### P2｜[中国科学技术大学、Independent Researcher｜DICE｜Decision-Native Recommendation with Large Language Models](https://arxiv.org/abs/2610.34124)

**论文、机构与场景**

- **机构：中国科学技术大学（University of Science and Technology of China）与 Independent Researcher（Jiayi Liao）**
- 作者：Daoxuan Liu、Jiayi Liao、Jiancan Wu、An Zhang、Xiang Wang、Xiangnan He
- 来源：arXiv:2610.34124v1
- 场景：图书、音乐、工业商品序列推荐，从给定候选集中选择下一物品并输出选择置信度
- **论文主要内容：** 提出DICE，用LLM表示在给定候选集上直接学习下一物品选择分布，并校准选择置信度。

**主要创新或优化点**

- 提出 decision-native 推荐范式：不生成物品名，而在给定候选集上学习候选选择分布并输出校准置信度，把合法选择、候选重排等变、置信度反映准确率列为三项联合要求。DICE（Direct Item Choice Estimation）在冻结主干加 LoRA 上用共享决策头做候选级 softmax 交叉熵，替代词表生成与答案解析；树打包沿用 SpecInfer/Medusa 模式，候选隔离与位置对齐沿用 InvariRank，温度校准属既有方法。

**核心方法**

- 把 [指令; 历史; 候选; EOS] 拼接为序列，用主干冻结、注入 LoRA 的预训练 LLM 取 EOS 隐状态，再经所有候选共享的 LayerNorm 加线性决策头得到各自 logit。
- 对同一示例 K 个候选 logit 联合 softmax，以观测下一物品为标签计算候选级交叉熵（训练 T=1），只更新 LoRA 与共享决策头，不用 LLM 词表头；推理取 argmax 直接指定候选项，无答案解码。
- 推理把共享历史前缀与 K 个候选分支打包为树状输入，用树注意力掩码阻断候选间注意力，各分支位置索引接续共享前缀而非其在打包输入中的物理位置，一次前向得到全部分数。

**关键结果**

- Qwen3-0.6B、K=20（目标加 19 个均匀采样负例，三种子均值）：DICE-I 的 HR@1 为 0.5332/0.6160/0.3767（Goodreads/LastFM/Amazon Industrial），比 HR@1 最强基线 LlamaRec 的 0.4718/0.5960/0.3650 高 6.14/2.00/1.17 个百分点（原文写作 +6.14% 等，为绝对差）。
- 重排测试（Goodreads/LastFM 各 64 样例×20 种重排）：DICE-I/DICE-S 的 FlipRate 全为 0.0000，logit 与概率最大绝对差为零；SFT/S-DPO 为 0.2984–0.4500。SFT 的 ValidRatio 为 80.55%/92.58%，DICE 为 100%（直接选候选，无答案解析）。
- 在留出开发集为各方法拟合温度后，DICE-I 的选中项 ECE（期望校准误差）为 0.0538（Goodreads）/0.0203（LastFM），均低于同口径校准的 LlamaRec 与 InvariRank。

**收益归因**

- 主要：收益来自候选级选择接口（合法候选、无答案解析）加 LoRA 任务适配与可校准置信度：表示适配的必要性有 Frozen 编码器与 ID-only 对照支持，前缀共享的加速有同检查点 flat 与 tree 匹配对拍支持；相对生成式方法的整包加速不能归因于单一模块。
- 次要：树结构注意力共享历史前缀、隔离候选分支，一次前向完成 K 个候选打分；匹配对拍显示选择与独立编码一致、延迟降低。
- 次要：候选隔离加统一位置索引带来重排等变，在所测 20 种重排下选择与概率不变，减少展示顺序导致的决策翻转。
- 次要：校准后的选中项概率可用于选择性推荐（高置信子集准确率更高）与低置信样本升级到更大模型，无需单独路由器；均为离线结果。

**与你的关联**

- 适用于已有候选池的 LLM 重排或选择场景（推荐、对话推荐），尤其看重合法候选项、顺序稳定和可校准置信度；迁移需物品文本、用户时序历史与固定候选集，并接受额外 LLM 推理成本及在留出集上拟合温度与阈值的流程。

**风险或局限**

- 候选集由观测目标加 19 个均匀采样负例构成（主实验 K=20，候选数敏感性最多测到 K=100），未与真实检索池耦合，也未评估目标不在候选池时的弃权；作者将其列为未来工作。
- 候选重排一致性、ECE 校准与置信度路由均只在 Goodreads/LastFM 上评估，未覆盖 Amazon Industrial；路由与选择性推荐为离线分析，延迟按 0.6B/4B 组件成本作线性估算且不含路由开销，无线上验证，本分析未见独立复现。
- 冷启动物品可能已出现在 LLM 预训练中；Goodreads 上 SFT/S-DPO 的冷启动 HR@1 高于 DICE-I，且 DICE-S 相对 DICE-I 的优势随数据集与候选数变化。

### P2｜[Pinterest Inc.，Lin Yang 同时为 University of California, Los Angeles｜RLBP｜Reinforcement Learning for Controller Parameters in the Auto-Bidding System at Pinterest](https://arxiv.org/abs/2610.33248)

**论文、机构与场景**

- **机构：Pinterest Inc.，Lin Yang 同时为 University of California, Los Angeles**
- 作者：Yichu Zhou、Qinyi Chen、Fei Feng、Jacob Loh、Mehdi Ben Ayed、Lin Yang、Andrei Curelea、Jiajing Xu
- 来源：arXiv:2610.33248v1
- 场景：Pinterest 广告自动出价中的预算投放与成本控制
- **论文主要内容：** 将强化学习作为日级元控制器选择广告出价的PID参数，以平衡预算投放与eCPC。

**主要创新或优化点**

- 将 RL 限定为日级元控制器，只选择 PID 增益乘子并物化为查询表，保留原 PID 秒级反馈控制，降低线上替换风险。
- 多头上 Q 网络分别预测预算利用率与 CPC，推理时用生命周期相关 β(d) 融合，无需重训即可调整成本-投放权衡。
- 用相对生产基线的 lift 作为奖励，归一化不同指标尺度并重塑动作奖励差，缓解 CPC 绝对误差主导训练。

**核心方法**

- 将每个 campaign 的日级 PID 调参建模为离散动作 MDP：状态包含 campaign ID embedding、剩余天数、日预算、PID 目标与昨日 CTR/CPC/revenue；动作为 kp、ki 的乘子（各从 {1−α,1,1+α} 选，kd 固定为1），共9个动作。
- 多头上 Q 网络共享状态表示，分别输出预算利用率 Q_bu 与 CPC Q_cpc；以相对生产基线的 lift r=(v−v_prod)/v_prod 作为奖励，CPC 头 Bellman backup 用 min，总损失为两个 TD loss 之和。
- 推理时按 Q̂=Q_bu−β(d)Q_cpc 融合两头，β(d) 随剩余天数递减并采用线性形式；在 top-K 动作上做温度 softmax 采样，选出的乘子每日写入 lookup table，线上 PID 继续秒级调价而不加载 DQN。

**关键结果**

- Pinterest 7 天线上 A/B：全量 treated campaign-days 的 eCPC 下降 0.25%（p<0.05），revenue 基本持平，clicks +0.19%。
- 线上 A/B 的 lifetime-ended campaign 子集：revenue +0.43%、clicks +0.25%、eCPC +0.18%，作者解释为临近结束更偏向预算投放。
- 上线后两个月对照 holdout：剩余≥7天组 eCPC -0.98%、BU -0.59%、CTR +0.66%；<7天组 eCPC -0.72%、BU +0.60%、CTR 0.00%，因流量不均衡未做统计检验。

**收益归因**

- 主要：保留生产 PID 的稳定性，同时用日级 RL 选择 campaign 级 PID 增益乘子，以低推理成本改善 eCPC 与预算投放的权衡。
- 次要：多头上Q网络解耦预算利用率与CPC目标，推理时用β(d)按生命周期调权，无需为不同权衡重训。
- 次要：相对生产基线的lift奖励统一不同指标尺度，缓解CPC绝对误差和跨campaign量纲差异对训练的干扰。
- 次要：日级查表服务避免在线加载DQN，降低推理延迟和替换生产控制器的风险。

**与你的关联**

- 适用于广告自动出价/预算平滑团队评估用 RL 调 PID 参数的方案；迁移需有稳定基线控制器、可记录的随机探索流量和可离线评估的 IPS 数据。

**风险或局限**

- 线上 A/B 仅 7 天且只报告一个 Pinterest 场景；两个月 post-rollout 对照 holdout 流量/预算不均衡，作者明确未做统计检验。
- 动作空间仅 kp、ki 各三档乘子且 kd 固定、每天只决策一次，作者承认这会限制调参精度与对日内波动的响应。
- 离线 IPS 依赖均匀随机探索日志与已知 propensity，生产 holdout 流量较小；缺少独立复现及对 guardrail/异常失败率的系统报告。

### P2｜[Independent Researcher｜How Much Fresh Data Should CTR Recalibration Use? A Temporal Evaluation of Post-hoc Calibration](https://arxiv.org/abs/2610.33168)

**论文、机构与场景**

- **机构：Independent Researcher（PDF 首页署名；署名邮箱 RL2987@columbia.edu）**
- 作者：Rui Liu
- 来源：arXiv:2610.33168v1
- 场景：Avazu 广告点击日志上的 CTR 模型校准时序离线评测与后处理重校准
- **论文主要内容：** 研究随机划分高估CTR校准与后处理重校准伤害，在Avazu上做多起点、多种子逐日评测和切片实验。

**主要创新或优化点**

- 将CTR校准评测从单次随机划分扩展到两个滚动起点、逐日分桶和三种子复现，量化随机划分对ECE的低估及日期/种子不稳定性；测量重校准伤害率与切片跨度、样本量关系，固定评估集上12小时跨度大幅降害，但跨度、小时构成与数据年龄未分离；切片ECE gate跨起点无检测收益，bias规则仅提供机制线索且不可部署；模拟拍卖中利润变化小且符号不一致，不能由ECE改进外推收益。

**核心方法**

- 构造两个滚动时间起点和一个随机划分对照：每个起点用连续5天、最多400万行训练LR、DeepFM、DCN-v2，测试随后4天按gap 0–3分桶，每臂三个种子。
- 对每个测试桶用紧邻其前的6小时数据拟合Platt scaling和isotonic regression；gap 0只用当日首6小时拟合并在剩余小时评估，避免校准器看过被评样本。
- 除ECE（15等宽分箱）和signed bias外，将原始/校准概率送入固定每次点击价值1.0的模拟二价拍卖，并做1–24小时切片长度扫描及12小时跨度/1小时样本量对照。

**关键结果**

- 在origin 1最近测试日（gap 0），随机划分把LR的ECE报成时序值的55–62%（三个种子稳定），但DeepFM/DCN-v2的比值随种子波动；跨24个时序单元，随机划分在20–23个单元低报ECE。
- 6小时切片重校准在强误校准单元最大降61% ECE，但48个应用中有14–17个反而变差；固定评估集上12小时切片把伤害从13–17/36降到3–5/36，24小时又回升到9–11/36。
- 在固定评估集上，12小时切片下采样到1小时切片的样本量（约5%曝光）仍恢复88%的增益，拟合快20–25倍；样本量本身不足以解释改善，但跨度、小时构成与数据年龄未分离，不能将全部改善归因于跨度。

**收益归因**

- 主要：通过多时间起点、多种子逐日评测揭示随机划分对ECE的低估，并在该数据上量化重校准切片跨度、样本量与伤害率的关联，为校准协议和刷新策略提供测量依据；不构成线上收益或单因素因果证明。
- 次要：在该数据固定评估集上，12小时跨度下采样到约5%曝光规模恢复88%的增益并显著降低拟合成本；属配置/样本设计收益，不能拆成单模块因果。
- 次要：模拟拍卖中利润变化很小且符号不一致，避免把校准指标提升直接外推为竞价收益；结果受固定出价与价格分布限制。

**与你的关联**

- 适用于CTR/广告排序模型的离线校准评测、后处理校准刷新策略与ECE监控；若团队使用随机划分或无条件小时级重校准，可据此设计多起点多种子时序验证并评估切片跨度。

**风险或局限**

- 仅用Avazu十天2014移动广告日志，且无线上A/B；模拟拍卖固定每次点击价值1.0和对数正态价格，利润变化仅-0.21%到+0.26%，不能外推到真实市场或其他消费概率的环节。
- 两个时间起点共享大部分日期，不是独立时间复现；深度模型ECE种子标准差最高0.0031/0.0051，其日间模式、gap-0随机/时序ECE比值和伤害在起点间的分配不能跨种子复现。
- 主gate分析只在6小时切片下进行，切片长度扫描显示12小时更优；其跨起点检验不是跨时间独立验证，且12小时扫描、gap 0评估集变化、窗口年龄/小时构成/样本量混淆限制外推。


## 精排与排序

### P0｜[快手｜UniRec: Cross-stage Multi-Task Fusion with Preference Optimization for Cascaded Recommender Systems](https://arxiv.org/abs/2609.11052)

**论文、机构与场景**

- **机构：快手科技（Kuaishou Technology）**
- 作者：Lingyuan Kong、Jiaqi Cui、Fanjiao Zeng、Congqi Wang、Yu Li、Yuan Cheng、Jingxin Liu、Xiaoshuang Chen、Kaiqiao Zhan
- 来源：arXiv:2609.11052v4
- 场景：快手短视频推荐级联系统的预排序与排序多任务融合
- **论文主要内容：** 针对级联推荐预排序与排序融合模块各自优化导致偏好不一致，提出联合双智能体与偏好优化框架。

**主要创新或优化点**

- 认识（实证）：在快手生产流量抽样上扫描融合权重时，把预排序融合权重直接设成排序公式本身并非一致性最高的组合，说明跨阶段一致不能靠复制下游融合函数，预排序融合函数须适配自身候选分布与预测质量。
- 新增机制：把预排序与排序的多任务融合模块作为联合优化对象，构建共享嵌入加阶段专用融合塔的单一可微图（共享嵌入承载梯度耦合，适配器以stop-gradient只把上游表示当特征）；双轴偏好优化中，阶段内用pXTR与曝光反馈构造成对保序损失，跨阶段只迁移排序融合分的成对方向、不复制排序融合函数。
- 稳定化与效率：AGRR按属性分位数分桶做组内相对优势并加KL约束（组相对思想借自GRPO），紧凑成对偏好聚合（CPPA）按方向聚合把Softplus评估从O(MN^2)降到O(N^2)，置信度感知成对剪枝（CAPP）按置信度每候选保留Top-K对降至O(KN)；属训练稳定化与效率设计，不是新的打分骨干。
- 沿用说明：Softplus成对保序损失与prior+posterior监督框架沿用EMER式做法，DCN、MLP-Mixer、AutoInt-Lite为既有模块，不计为本文原创。

**核心方法**

- 预排序与排序各设一个融合智能体：共享嵌入编码用户/物品/上下文与预排序pXTR（多任务预测率），排序侧额外拼接排序pXTR；共享参数接收两阶段损失梯度，跨阶段梯度耦合仅限该共享嵌入空间。两塔均先过DCN，预排序用MLP-Mixer、排序用AutoInt-Lite；适配器以stop-gradient把预排序表示送入排序塔，使排序目标不反向塑形预排序表示。
- 双轴偏好优化：阶段内以各pXTR诱导的成对方向加曝光反馈构成Softplus保序损失；预排序训练时还接收排序pXTR在I_p上的成对先验监督（排序pXTR只作监督不作输入）；跨阶段只把排序融合分的成对方向经stop-gradient传给预排序，不复制排序融合函数。
- 属性组相对正则（AGRR）按视频时长等属性分位数分桶，在组内标准化由pXTR偏好导出的奖励优势并以KL散度约束目标分布，抑制按属性组整体抬分；紧凑成对偏好聚合（CPPA）按偏好方向聚合多目标Softplus，置信度感知成对剪枝（CAPP）按置信度保留每候选Top-K对，将成对损失由O(MN^2)降至O(KN)。

**关键结果**

- RecFlow离线：UniRec rank_GAUC 0.6330，对比最强基线0.6158；预排序NDCG@3 0.5075，高于COPR的0.5011；Kendall τ 0.6017、Spearman ρ 0.7644，分别高于COPR的0.5150、0.6802。
- 快手九周线上A/B（5%流量，最终周）：总观看时长+0.675%、视频观看时长+0.755%、使用时长+0.616%、活跃用户+0.189%，作者称无指标下降并已全量部署。
- 工业数据消融：去掉共享嵌入后rank_GAUC 0.7851→0.7801、rank_NDCG@1 0.5346→0.5263；去掉AGRR使GAUC降0.0040、ASH降0.0251，且≥300s视频相对过推从+25.0%降至+3.2%。

**收益归因**

- 主要：整包联合融合框架上线带来的总观看时长+0.675%、使用时长+0.616%、活跃用户+0.189%；单模块因果需看离线消融，不能由整包A/B拆分。
- 次要：跨阶段一致性（RecFlow，整包对比COPR）：Kendall τ由0.5150升至0.6017、Spearman ρ由0.6802升至0.7644；这是整包对比结果，消融只显示去掉共享嵌入或对齐项会降低ASH/τ，不能据此拆出共享嵌入的单独因果。
- 次要：AGRR抑制按属性组整体抬分的奖励偏置：消融中≥300s视频相对过推从+25.0%降至+3.2%。
- 次要：CPPA/CAPP降低多目标成对偏好训练成本：CPPA使loss计算约降5倍、吞吐20→49 req/s，CAPP在K=50时比全成对快3.6倍。

**与你的关联**

- 适用于已有级联预排序/排序链路、各阶段有独立多任务融合模块且希望联合优化融合规则的短视频/信息流推荐；迁移需能共享用户/物品/上下文嵌入、拿到两阶段pXTR与曝光反馈，并接受在线只增加训练耦合、部署仍分图执行。

**风险或局限**

- RecFlow不提供原预排序/排序pXTR，作者用DSSM/DIN训练冻结的7头骨干替代，离线结果受替代预测器质量影响，复现需匹配该数据与冻结设置。
- 线上A/B仅在快手5%随机抽样流量、九周监测并取最终周报告相对提升；Table 3列出多项互动指标但未给置信区间与显著性检验，作者称无指标下降，独立复现缺失。
- CAPP的K=400及λalign=1、λfb=1、λAGRR=0.3来自特定数据调参，正文显示λalign增至5时rank_GAUC降至0.7692；消融中w/o CAPP仅微降rank_GAUC而ASH降幅更明显，说明其主要作用是效率与跨阶段一致性；AGRR仅以视频时长分桶为例，跨场景需重调。


### P2｜[Chiang Mai University｜TEA｜Discovering Topics from Linear Autoencoders](https://arxiv.org/abs/2610.34739)

**论文、机构与场景**

- **机构：Chiang Mai University**
- 作者：Jutiyakhun Srisoparp、Donlapark Ponnoprat
- 来源：arXiv:2610.34739v1
- 场景：基于用户-物品交互的线性自编码器推荐与物品主题发现
- **论文主要内容：** 研究从闭式线性自编码器权重矩阵恢复物品主题，并提出物品与用户归一化的TEA推荐模型。

**主要创新或优化点**

- 证明在加权隐因子模型下，闭式线性自编码器的权重矩阵列空间可确定物品主题；借助已有可分离NMF/锚词主题模型的锚条件，证明该列空间中可分离非负基唯一（至多列置换与正缩放），把推荐器与主题模型联系起来。
- 提出TEA：用物品流行度幂权重与基于用户交互数的无调参用户权重归一化共现矩阵，抑制热门物品与高活跃用户对主题的支配。
- 给出从训练好的线性自编码器权重直接提取主题的流程：取K维特征子空间并用ppSPA恢复主题，无需额外训练独立主题模型。

**核心方法**

- 在加权隐因子模型(wLFM)下，交互均值E[X_ui]=w^I_i w^U_u⟨β_i,:,f_u⟩且用户跨物品条件独立；归一化共现矩阵的期望分解为E[Ĝ]=L+D，L=βΦβ^T秩≤K、D为对角方差项。
- TEA用物品权重w_i^I=g_i^α压低热门物品；用户权重q_u∝(d_u-1)/(d_u(d_u+τ̂))，τ̂=t̂/ŝ，并按均值归一使Σq=n，无需调参，用于降低高活跃用户给共现矩阵带来的方差。
- 在归一化共现矩阵上取dropout正则Λ=p/(1-p)diag(G)+λI，计算P̂=(Ĝ+Λ)^-1与B̂=-H(P̂)diag(P̂)^-1；对Â=-H(P̂)取前K个特征向量，经ppSPA得β̂并按列L1归一化即得主题。

**关键结果**

- 六个公开数据集上，TEA的TQ分别为0.331、0.380、0.508、0.492、0.472、0.290，均为最高或与最高值统计持平，并显著高于所有专用主题模型。
- 推荐指标上，TEA的NDCG@10在books、cds、gowalla、steam与最佳方法统计持平，在ml-1m和retail最多低0.004；recall@10在每个数据集与最佳方法差距不超过0.01。
- 合成实验中m=400、K=5、EASE的λ=250，n从500增至1e7时，前K特征子空间相对误差随n下降并趋近由省略对角项造成的不可约误差；特征值在K后有可见截断。

**收益归因**

- 主要：整包配置对比：TEA（物品归一化+无调参用户归一化+dropout正则）相对EASE在三个数据集TQ显著更高、另三个统计持平，六数据集推荐精度与最佳调参推荐器竞争力相当；论文未报告逐模块移除消融，不能据此推断单模块因果。作者以有效用户数n_eff作机制解释：EASE在TQ显著落后的数据集上主题由少数活跃用户支撑。
- 次要：物品归一化用g_i^α压低热门物品在共现矩阵中的权重，目标是减少热门物品跨主题重复出现。
- 次要：用户归一化用交互数d_u构造q_u，目标是降低高活跃用户给归一化共现矩阵带来的方差。
- 次要：主题提取复用已训练权重矩阵的K维特征子空间并经ppSPA恢复，目标是免去独立主题模型和物品文本。

**与你的关联**

- 适合需要可解释推荐、主题画像或线性自编码器基线分析的场景；迁移到大规模工业推荐需评估物品共现矩阵求逆与更新成本、归一化参数在真实反馈上的稳定性以及线上排序收益。

**风险或局限**

- 主题恢复保证依赖wLFM的线性均值与条件独立、因子分析式识别条件（每个物品存在两组不相交且各含K个物品的可逆子矩阵，隐含物品数下限）以及可分离性（每主题有锚物品）；真实交互不满足时保证不成立，论文未做假设检验。
- 实验仅覆盖六个公开数据集，每数据集截取5000个最热物品和最多5000个用户；未报告工业规模矩阵求逆、在线更新或线上A/B收益，也未测试序列或在线推荐设置。
- 主题质量以TQ=TD×TC和留出用户bootstrap检验衡量；论文只给出定性主题示例，未报告正式人工可解释性评估，也未做业务指标或部署验证。

### P2｜[Tongji University、Tsinghua University、Shanghai Qi Zhi Institute｜DiffAuction: An Auction-Driven Framework for Generative Image Advertising](https://arxiv.org/abs/2610.34917)

**论文、机构与场景**

- **机构：Tongji University、Tsinghua University、Shanghai Qi Zhi Institute**
- 作者：Yijie Su, Ruiyang Si, Tonghan Wang
- 来源：arXiv:2610.34917v1
- 场景：生成图像广告中多广告主曝光竞争、点击意图评估与拍卖定价
- **论文主要内容：** 面向生成图像广告，联合可控曝光生成、点击意图评估与拍卖定价。

**主要创新或优化点**

- 针对扩散图像广告中多广告主曝光份额难控、逐配置评估成本高：RSC把联合注意力输出分解为产品特定残差并按目标份额重标定范数占比，每步一次前向即可调相对曝光，区别于Sun et al.多次条件评估；SCP把目标份额相对均分比例映射为五级提示，改视角与布局，与RSC连续校准互补，组合消融支持但单模块不充分。CTI用VLM抽四维证据、LLM打分，构造可解释产品级代理；拍卖把配置选择与定价建模为联合可行配置上的AMA，允许配置特定每单位CTI私有估值，并在给定估值模型下保证DSIC/IR。

**核心方法**

- 可控生成由RSC与SCP组成：RSC免训练地把联合注意力输出按产品token分解为残差R_i，计算占比p_i并按(s_i/p_i)R_i缩放，使各产品残差范数占比匹配目标份额且总量不变；SCP再把r_i=N s_i映射为五级显著度提示，改写产品描述以调整视角和布局；生成时每去噪步一次前向，前8步应用RSC。
- CTI评估用InternVL3-14B为每个产品抽取产品显著度、品牌可识别性、场景融合、情境价值传达四维视觉证据，再由Qwen2.5-7B-Instruct按固定量表打1–5分，等权平均线性缩放到[0,1]作为产品级点击意图代理。
- 拍卖把每个生成配置k的目标份额s_k与历史期望CTI向量q_k公开固定，广告主报告配置特定每单位CTI私有估值b_ik；可学习AMA用权重w_i和偏移β_k按β_k+Σw_i q_ik b_ik选配置，按仅依赖他人报告的菜单P_ik定价，离线训练w、β最大化期望收入，并在给定估值模型下保证DSIC/IR。

**关键结果**

- 在1,000个两产品场景、19,000张图像上，RSC+SCP的share-CTI Pearson为0.7222，高于Sun et al.的0.6675和prompt-only FLUX的0.2181。
- 在A800上按每去噪步计时（十次运行均值），2个产品0.6654s vs 1.2734s（1.91×），10个产品0.9289s vs 4.2571s（4.58×），随产品数增加优势扩大。
- 在独立私有估值模拟中，2个和3个广告主的AMA平台收入0.8535/0.9086，较Myerson基线0.5648/0.6031分别高51.12%/50.66%。

**收益归因**

- 主要：离线实验显示RSC+SCP整包提升share–CTI单调性，AMA在合成私有估值下提高模拟平台收入；均非线上A/B或真实CTR收益。
- 次要：消融中RSC+SCP组合最佳、SCP-only与RSC-only较低，支持组合贡献，不能据此推导单模块因果。
- 次要：RSC按残差范数占比连续重标定，单步一次前向；SCP以五级提示改变视角与布局。
- 次要：AMA在给定估值模型下保证DSIC/IR，收入提升仅来自合成估值模拟。

**与你的关联**

- 适用于生成式广告创意、图像广告曝光分配、广告拍卖定价及VLM离线广告效果评估；迁移需可控扩散模型、可离线构造的CTI表与广告主私有估值假设。

**风险或局限**

- 所有拍卖结果来自合成私有估值，生成与CTI评估均为离线实验，无真实广告线上A/B或真实CTR/收入数据，不能证明部署增益。
- CTI评估器与四维rubric人工评分Pearson 0.669、ICC 0.653，属中等一致；CTI是点击意图代理而非真实CTR，DSIC/IR还依赖q_ik等于真实期望价值。
- 生成实验固定FLUX.1-schnell、作者自建场景/标注及阈值，同品类仅50个场景，跨扩散模型、跨广告类目与真实素材的稳定性未验证。


## 今日最值得立项的实验

### 预排序与排序融合模块联合训练（跨阶段成对方向对齐）

- 假设：共享用户/物品/上下文嵌入并以stop-gradient只迁移下游融合分的成对方向，可提升两阶段排序一致性并在不改变部署分图的前提下提升观看时长。
- Control：现网预排序与排序融合模块各自独立训练、互不传梯度，融合权重沿用线上配置。
- Treatment：在共享嵌入上加两阶段联合损失与双轴偏好优化（阶段内Softplus保序+跨阶段成对方向对齐），保留各自融合塔与推理分图执行。
- 保持变量：同一训练日志与时间窗、同一特征与候选口径、同一融合权重初始化、同一评测集与分流桶。
- 离线指标：rank_GAUC与预排序NDCG@3；两阶段Kendall τ与Spearman ρ；成对偏好损失训练吞吐与损失计算成本
- 线上 Guardrail：总观看时长、使用时长与活跃用户不出现负向；互动指标（点赞/评论等）无显著下降；属性分组（如视频时长分桶）曝光结构不出现整体过推；服务P99延迟与训练资源在预算内

### 长序列选择器保留集规模与蒸馏信号的消融

- 假设：在固定在线检索与聚合预算下，候选无感的用户级选择器把10万级历史压到1万条原始记录，其收益主要来自保留item级证据与软分布蒸馏，而非单纯缩短序列。
- Control：现网长序列方案（搜索式保留原始记录或压缩式摘要）在同一排序骨干与同候选预算下。
- Treatment：接入蒸馏选择器保留Top-K原始记录、下游做target-aware检索与注意力聚合；再分别替换为二元标签蒸馏与去掉边界定向辅助损失作为子臂。
- 保持变量：同一排序骨干与多任务头、同一训练与评测窗口、同一K与检索宽度、同一服务打包格式。
- 离线指标：各任务GAUC相对基线的提升；保留集对教师Top-100的覆盖与相关性概率质量；序列分支FLOPs与实际吞吐/延迟
- 线上 Guardrail：精排端到端P99延迟与存储增量在预算内；长尾目标相关事件召回不回退；各场景（含短视频以外的流量来源）主指标无负迁移，极端长序列用户不出现明显退化

### CTR后处理重校准的切片跨度与评测协议

- 假设：面向逐日评测的时序多起点验证下，采用更长跨度（如12小时）的样本拟合重校准器比小时级刷新伤害率更低，且在约5%样本量下仍能恢复大部分校准增益。
- Control：现有随机划分离线评估加6小时切片重校准（每测试桶用紧邻其前6小时数据拟合）。
- Treatment：两个以上滚动起点、逐日分桶、多种子评测；重校准切片改为12小时跨度并对部分臂下采样到约1小时样本量；保留Platt与isotonic两种校准器。
- 保持变量：同一CTR模型与特征口径、同一评测日切分规则、同一点击价值假设与模拟拍卖设置、同一分箱数。
- 离线指标：逐日ECE与signed bias（含随机划分与时序划分比值）；重校准伤害率（校准后变差单元占比）与拟合成本；模拟拍卖利润变化及符号一致性
- 线上 Guardrail：线上CTR预估校准指标（ECE/偏差监控）不恶化；排序主指标与广告收入不出现负向；重校准刷新频率提高后训练/推理资源不超预算，避免按日期或人群出现系统性偏高/偏低


## 一句话总判断

证据概况：收录 17 篇，全文核验 16 篇；标记为线上 A/B 证据 5 篇。

本期主线是级联链路的联合设计与长序列/生成式召回的服务成本：UniRec把预排序与排序融合模块放进同一可微图但部署仍分图，ECHO用用户级选择器把10万级历史压到1万条原始记录，PinGER把SID历史压成每物品一个服务token并配宽beam服务栈，三者都有线上A/B，但均为整包对比，不能据此拆出单模块因果。第二类是可落地的训练与评测侧改动：OptIDC与DICE聚焦输入侧配置与候选级选择接口，两篇Antwerp工作分别从概率相似度与活跃度伪相关角度重审item-item相似度，校准论文说明随机划分会系统性低报ECE。工程判断：优先验证跨阶段联合训练与长序列选择器的成本结构，生成式召回侧重点已转向服务栈而非换骨干；本期没有证据表明存在同一离线表征被多个线上模型复用意义上的Foundation Feature。
