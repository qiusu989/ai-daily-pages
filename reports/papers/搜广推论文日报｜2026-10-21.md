## 生成式召回

### P0｜[SPAR: Stepwise Personalized Autoregressive Recommendation with Prefix-Balanced Semantic IDs](https://arxiv.org/abs/2610.27898)

**论文、机构与场景**

- **机构：电子科技大学、中国科学技术大学、HUJING Digital Media & Entertainment Group、西南交通大学**
- 作者：Chunrui Zhang、Gaoyun Lin、Chang Zhou、Zheng Hu、Qiran Song、Shimin Cai、Tao Zhou
- 来源：arXiv:2610.27898v1
- 场景：优酷首页视频推荐中的 SID 生成式召回
- **论文主要内容：** 针对SID生成推荐逐步个性化不足与分支负载失衡，提出PATH解码器、RQ-PIB构造及偏好对齐。

**主要创新或优化点**

- 针对 SID 解码中固定用户表征难以随前缀变化的问题，PATH Decoder 按 SID 深度构造粗到细长期历史视图，用 Q-Former 压缩为记忆库，并以当前解码状态和已生成前缀做 cross-attention 读取，再把近期行为、画像与事件上下文融入每一步 token 决策。
- 针对同一父前缀下兄弟分支历史交互负载不均衡、全局码字均衡忽视局部热度的问题，RQ-PIB 在残差 K-Means 冻结码本后按父前缀设负载上限，以最小重构失真增量贪心迁移物品，尽量保留语义结构并压低局部主导分支。
- 将 beam search 候选经冻结排序模型构造偏好对，联合 SFT 与 DPO 做偏好对齐，使生成器在保持下一物品监督的同时偏向近期请求偏好，并与 SID 构造、逐步记忆读取组合成统一生成式召回框架。

**核心方法**

- PATH Decoder 将长期历史按 SID 深度构造成粗到细视图，用共享 Q-Former 与各视图 query 压缩成记忆库；解码时以近期 SID 序列和已生成前缀为 query 做 cross-attention 取回前缀相关证据，再融合画像 User Token、事件 Event Token 预测下一 SID token。
- RQ-PIB 先用残差 K-Means 学习并冻结各层语义码本，按父前缀统计兄弟分支历史交互负载并设每前缀上限，在超载分支中反复迁移增加重构失真最小的正权重物品到可行子分支，直至满足上限并保留有效 trie。
- 训练分 SFT 与偏好对齐：SFT 对目标物品三层 SID token 做下一 token 最大似然；DPO 用 trie 约束 beam search 生成候选、由冻结排序模型打分，取 top-M/bottom-M 组成偏好对，联合 SFT 与 DPO 损失更新生成器。

**关键结果**

- 在优酷首页生产日志上，SPAR 相对最强基线 OneRec 的 HR@10/20/50/100 从 0.4648/0.5492/0.5828/0.6013 提升到 0.4831/0.5662/0.5947/0.6108，四个截断平均相对提升 2.66%。
- 7 天线上 A/B 中，SPAR 覆盖优酷约 10% 生产流量，相对生产 Base 将播放转化率提升 3.38%、人均观看时长提升 3.95%、总观看时长提升 3.98%。
- RQ-PIB 在各 SID 层级将流量加权最大子分支占比从 9.8%/36.4%/65.7% 降至 6.4%/23.2%/47.6%，平均相对降低 32.84%。

**收益归因**

- 主要：前缀条件化的长期记忆读取与局部 SID 分支负载再平衡共同提升生成式召回命中，并转化为线上播放转化和观看时长。
- 次要：PATH Decoder 的逐步记忆读取改善深层 SID token 预测，并降低目标前缀在 beam 中被提前剪掉的风险。
- 次要：RQ-PIB 降低兄弟分支热度集中，缓解流行 SID 路径主导并改善局部候选空间均衡。
- 次要：DPO 偏好对齐在不改 SID 映射和架构的情况下提升头部命中，尤其 HR@1。

**与你的关联**

- 直接相关于生成式召回和 SID 分支解码，可用于优化短视频推荐召回阶段的 SID 构造与用户条件解码；线上收益来自优酷特定场景与生产 Base，迁移前需复现。

**风险或局限**

- 线上 A/B 为作者在优酷首页、约 10% 流量、7 天的内部实验，未提供独立审计或复现，结论仅限该生产 Base 与短期窗口。
- 离线与消融均基于优酷单场景生产日志；SID 负载权重来自训练期交互计数，论文明确不保证未来曝光平衡，冷启动与新物品分配未验证。
- RQ-PIB 为按父前缀的贪心最小失真迁移，作者承认不保证全局最优或严格负载均衡；DPO 还依赖冻结排序模型和 beam 候选质量。


### P0｜[WeGR: Towards Unified Generative Retrieval via Behavior-aware Tokenization and Preference Alignment](https://arxiv.org/abs/2610.16979)

**论文、机构与场景**

- **机构：未披露**
- 作者：Jiajun Han、Guoxin Ma、Felix、Liangsheng Xu、Ruiqi Yu、Yingdi Guo、Zongbing Wang、Xinhua Ye、Chenyan Hua、Xin Xie、Pengcheng Yang、Haijun Wu
- 来源：arXiv:2610.16979v3
- 场景：大规模工业电商搜索的生成式召回与偏好对齐
- **论文主要内容：** 针对工业搜索生成式召回的码本塌缩与奖励稀疏，提出协同感知 SID 分词和动态视野偏好对齐。

**主要创新或优化点**

- CoCo-VAE 在量化前用 Q2I/I2I 共现对比学习把协同信号注入连续表征，避免已有方法直接在码本上约束导致语义冲突，目标是同时保留行为信息与码本优化空间。
- Codebook Refresh 只作用于第一量化层，按 EMA 使用量识别死码字并用活跃码字加小扰动重启；FAR 在样本级聚合多码字扩大梯度、在码字级惩罚分配碰撞，针对 RQ-VAE 硬 top-1 更新不足。
- DHPO 不改写 outcome reward，而沿 SID 层级逐步扩展奖励评估与策略优化 horizon，只更新匹配前 h 个 token，把稀疏的完整 SID 匹配转成由粗到细的 GRPO 偏好学习，避免依赖辅助 ranker 的稠密奖励。
- MSFT 对同一搜索会话的多个点击/下单正例 SID 联合做下一 token 监督；当 GRPO 组内奖励差异不足时，用多正例 SFT 维持检索能力，并与 DHPO 联合优化。

**核心方法**

- CoCo-VAE 在量化前对 query-item 与 item-item 历史共现做 InfoNCE 对比学习，把协同信号注入连续表征，避免直接在码本上施加协同约束而干扰量化。
- CoCo-VAE 对第一层码本按 EMA 使用量检测死码字，并用活跃码字加小高斯扰动重启；深层用残差保真项聚合多个相似码字扩大梯度，同时用码字分配碰撞正则抑制样本向少数码字集中。
- DHPO 沿 SID 层级逐步扩展奖励评估与策略优化 horizon，只对前 h 个 token 计算 GRPO 优势并更新；MSFT 对同一搜索会话的多个正例 SID 做联合下一 token 监督，在组内奖励差异不足时维持 SFT 检索能力。

**关键结果**

- 2026-06-22 至 08-04 的线上 A/B 中，V1.2 配置移除其他召回通道 80% 候选后，订单、CTR、CVR 分别相对提升 2.539%、1.508%、1.381%，论文称均 p<0.05。
- 同一 V1.2 配置下，进入粗排的候选数为基线 61.90%（减少 38.10%），CPU/GPU 用量降至 74.5%/73.9%（节省 25.5%/26.1%），平均时延下降 21.7ms。
- 离线 Click/Order 各 20k 测试中，DHPO 的 HR@6 为 0.2810/0.4217，高于 TPMA-GRPO 的 0.2750/0.4133；CoCo-VAE 的 HR@6 为 0.2759/0.4103，高于 RQ-Kmeans 的 0.2641/0.4051。

**收益归因**

- 主要：行为感知 SID 与 DHPO 提升生成式召回质量，并用生成候选替换传统多路召回，压缩进入粗排的候选量，带来订单/CTR/CVR 增益及算力与时延下降。
- 次要：CoCo-VAE 通过首层码本重启与深层保真/碰撞正则提升码本利用，同时用 Q2I/I2I 对比学习保留协同信号。
- 次要：DHPO 用动态 horizon 缓解 outcome reward 稀疏，MSFT 在多正例上提供补充监督，减少对辅助奖励模型的依赖。
- 次要：生成式召回替换大量传统候选后，进入粗排的候选量下降，传导为 CPU/GPU 用量和平均服务时延降低。

**与你的关联**

- 直接命中生成式召回、SID 构建和 RL 偏好对齐；线上候选压缩、CPU/GPU 与时延收益对工业搜索链路有较强参考。

**风险或局限**

- 线上结果来自论文自述的单一工业电商搜索平台、6 周 A/B，未提供独立复现或公开数据集；v3 首页未披露机构，平台名称在标题和正文中也被泛化，部署环境外部可审计性有限。
- 用户分组与查询频次分层是同一 A/B 的异质性切片，作者明确指出这些增益来源机制仍需进一步受控实验验证。
- 离线只使用 31 天日志、Click/Order 各 20k 与 GPT-2 Small，SID 配置为 (16384,128,128)；跨场景仅验证电商直播搜索，向其他目录或更长 SID 的外推有限。


### P2｜[Neighborhood-Aware Unlearning for Generative Recommendation](https://arxiv.org/abs/2610.27232)

**论文、机构与场景**

- **机构：BIFOLD & TU Berlin（德国，Lubitzsch、Schelter），University of Amsterdam（荷兰，Tang、de Rijke）**
- 作者：Pierre Lubitzsch、Yubao Tang、Maarten de Rijke、Sebastian Schelter
- 来源：arXiv 2610.27232v1
- 场景：基于SID的生成式推荐中的交互级遗忘学习
- **论文主要内容：** 针对SID生成式推荐遗忘波及语义邻居的问题，提出约束邻居概率质量的邻居感知遗忘方法。

**主要创新或优化点**

- 已有问题：SID共享使遗忘更新误伤语义邻居，而全局指标掩盖该效应。
- 新增认识：本文实证指出局部概率重分配是SID生成式推荐遗忘的关键失败模式，并给出显式控制邻居概率质量的干预机制。
- 差异与范围：相对交互级遗忘仅删除目标交互，NAU增加邻居层面约束；结论限于论文所测数据、tokenizer与训练预算。

**核心方法**

- 论文观察到遗忘更新会波及被遗忘交互SID的语义邻居，而这种局部影响被全局指标掩盖
- NAU方法：在交互级遗忘的基础上，额外约束被遗忘物品邻居的预测概率质量分配，从而抑制SID共享造成的局部效用下降
- 实验在3个数据集和4个SID tokenizer上验证，用重训练参考对比遗忘后全局效用与邻居效用

**关键结果**

- NAU在3数据集4 tokenizer设定下将spam注入曝光恢复至接近重训练参考，同时保留超过95%的重训练效用
- NAU在不损失全局指标的情况下恢复了forget-and-repair方法损失的邻居效用
- 论文显示遗忘后全测试集效用几乎不变，但被遗忘SID邻居上的效用显著下降

**收益归因**

- 主要：SID邻居概率质量显式约束，减轻遗忘更新对语义相邻物品推荐的连带损伤
- 次要：在保持全局推荐效用的前提下改善被遗忘交互邻居的推荐质量
- 次要：为spam注入等脏数据移除提供可对照的遗忘流程

**与你的关联**

- 面向生成式召回SID空间的遗忘与数据删除，涉及SID共享导致的局部效用维护，可关联推荐系统数据治理与SID设计。

**风险或局限**

- 只有离线实验证据，摘要未披露线上A/B或生产部署结果
- 机构信息未在输入中披露，需PDF首页核验
- 邻居范围定义与概率质量控制的具体实现细节需PDF正文核验，摘要仅给原则

### P2｜[Measuring the Influence of Modality-Specific Node Representations on Graphs](https://arxiv.org/abs/2610.23863)

**论文、机构与场景**

- **机构：Xu Wang 属山东大学（威海）空天科学与工程学院，Xunkai Li 与 Rong-Hua Li 属北京理工大学计算机学院，Yinlin Zhu 属中山大学计算机学院**
- 作者：Xu Wang、Xunkai Li、Yinlin Zhu、Rong-Hua Li
- 来源：arXiv 2610.23863v1
- 场景：多模态属性图上的模态特定节点表征影响力测量
- **论文主要内容：** 针对多模态属性图节点表征，提出基于替换响应的模态影响力测量任务与MoGI评分方法。

**主要创新或优化点**

- 提出面向多模态属性图节点表征的影响力测量任务，把单个候选替换对自身及邻近节点预测的分布式响应作为度量对象，区别于面向单一输出、训练样本或整图元素的既有归因与数据估值方法。
- 设计MoGI：用传播训练标签定义任务方向，读取偏好类与完整类分布两类替换响应并平均排名，无需重训预测器或引入可学习评分参数，降低评测部署成本。

**核心方法**

- 给定编码图、已训练预测器、训练划分和固定候选表征，用同模态训练节点均值替换候选，对比替换前后预测变化，得到每个候选对节点预测的影响分数
- 分别输出文本与图像两个模态的独立排名，并为每个候选计算一个影响力分数
- MoGI通过传播训练标签定义任务方向，同时读取对偏好类与完整类分布的替换响应，再对两种排名取平均，无需重训练预测器或学习评分参数
- 在五个数据集、八种预测器的共享基准上，与五种外部方法比较各排名截断下的聚合留出集损失增量

**关键结果**

- 在五数据集八预测器的共享基准上，MoGI在所有测试排名截断处取得了比五种外部方法更大的聚合留出集损失增量
- 实证观察显示，邻近节点响应包含仅看源节点分数与简单代理所遗漏的信息，而响应幅度本身不能识别由哪些类别变化支撑任务

**收益归因**

- 主要：提供多模态属性图中模态特定节点表征的离线影响力评分与独立排名，用于诊断模型对文本/图像输入的依赖
- 次要：通过邻近节点分布式响应补充源节点单点归因遗漏的信息
- 次要：无需重训预测器即可计算影响力排名，降低评测迭代成本

**与你的关联**

- 若工作在推荐场景的多模态属性图上，该工作提供筛选文本/图像节点表征影响的离线评测思路，可作为表征治理与归因工具的参考；与召回、粗排、精排的线上链路无直接关系。

**风险或局限**

- 实验仅在作者选定的五个数据集与八种预测器上离线进行，未提供线上A/B或生产部署证据
- 论文以聚合留出集损失增量作为主要评价，未报告推荐业务指标（如CTR、召回率）的直接影响

### P0｜[ECHO: Efficient Cascade with Homogeneous Operators for Distillation-Guided 100K-Sequence Modeling](https://arxiv.org/abs/2610.28569)

- **论文主要内容：** 提出蒸馏选择器保留原始长历史，再做目标感知检索与聚合以降排序开销。

**主要创新或优化点**

- 现有搜索式长序列方法需为每个候选扫描全历史，隐式压缩又丢失item级可寻址性；ECHO先用用户级选择保留Top-K原始事件，把10万级历史缩到可检索的1万条，并保留ID、时间戳和side features供下游目标匹配。

**核心方法**

- DS仅用用户特征对历史事件打分并保留Top-K原始记录（生产K=10,000，原始L约100K），记录保留item ID、时间戳与side features，线上请求不执行DS或重扫全序列
- 候选感知全历史教师为每个目标计算相关性logits，通过温度softmax的KD损失蒸馏到DS，并加入选择边界辅助损失，将教师偏好但未入选的事件与低相关已选事件组成排序对
- TFR读取DS保留记录，按教师共享的Θrel检索至多M=100条，再用同参数目标注意力聚合后送入多任务ranker；线上路径仅读K条记录，不执行DS或全历史教师

**关键结果**

**收益归因**

- 次要：教师相关性Q/K参数复用到检索与聚合，减少选择与下游匹配的度量不一致
- 次要：共享用户输入、43字节记录编码与key侧投影吸收降低显存、存储和数据移动
- 次要：选择机制在MLP、RankMixer、MixFormer等不同下游骨干上均带来离线GAUC增益

**与你的关联**

- 与短视频推荐精排的长序列建模直接相关，可借鉴用户级蒸馏选择、目标感知细粒度检索、参数复用和线上部署优化；线上A/B与生产部署证据较强。

- 线上 Guardrail：线上播放转化率、人均与总观看时长不回退；冷启与新物品SID召出率不下降；SID解码P99延迟与GPU用量在现网预算内

### 十万级长序列蒸馏选择加目标感知检索的精排离线对照

- 假设：以仅用户特征的蒸馏选择器保留Top-K原始事件记录，再用教师共享相关性参数做目标感知检索与聚合，可在显著降低序列分支计算的同时保持或提升精排GAUC。
- Control：现有生产长序列精排路径：搜索式全历史扫描或隐式压缩表征，按现网方案为准。
- Treatment：参照ECHO：DS用用户特征选Top-K原始记录（含ID、时间戳、side features），候选感知全历史教师蒸馏并加选择边界损失；TFR按共享Θrel检索至多M条后聚合送入多任务ranker。
- 保持变量：同一训练样本与特征口径、同一ranker骨干与多任务权重、同一序列长度上限设置、同一评价切分与统计口径。
- 离线指标：各任务GAUC相对基线提升及分任务最小值；极长尾目标命中率与选择边界覆盖；序列分支训练/推理FLOPs与显存占用估算
- 线上 Guardrail：总App使用时长与人均时长不回退；精排P99延迟与QPS满足现网预算；长尾用户与冷启物品分桶不出现显著负向

### 协同感知SID码本与动态视野偏好对齐对生成式召回候选压缩的收益验证

- 假设：在量化前注入Q2I/I2I对比学习并修复死码字，配合沿SID层级扩展horizon的偏好优化，可在提升生成式召回质量的同时压缩进入粗排候选量并降低算力。
- Control：现有生成式召回SID方案：RQ-KMeans类码本加outcome reward偏好优化，保持现有多路召回并行。
- Treatment：参照WeGR：CoCo-VAE编码器加首层死码字重启与深层保真/碰撞正则，DHPO逐层扩展奖励horizon，MSFT多正例联合监督，并逐步减少其他召回通道候选。
- 保持变量：同一query/用户日志、同一SID层数与码本规模、同一生成器骨干与训练预算、同一粗排模型与评测集。
- 离线指标：Click/Order HR@6相对基线提升；码字使用率与死码字比例；进入粗排候选数、平均时延与CPU/GPU用量
- 线上 Guardrail：订单、CTR、CVR不回退；召回覆盖率与长尾query召出不下降；服务平均时延与资源用量不高于现网基线


## 一句话总判断

本期最强证据集中在两篇PDF核验的工业线上工作：SPAR把SID生成式召回的个性化下沉到每一解码步，并用父前缀负载上限抑制分支热度集中；ECHO用用户级蒸馏选择把十万级序列压成可检索原始事件，兼顾降本与目标相关性；WeGR则给出行为感知码本加分层偏好对齐的电商搜索路径。工程上SID方向正从“构造更好码本”转向“解码条件化、负载均衡与训练-服务一致”，但三者场景、Base与收益量级不可互换，迁移前必须按自有链路复现并做线上灰度。评测侧DPFR与MOSS提示：单指标与全局指标可能掩盖公平性或语义失败，监控与联合评测应同步立项。
