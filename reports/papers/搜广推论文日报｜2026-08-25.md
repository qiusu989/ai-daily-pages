### P1｜[Adaptive Item-based Collaborative Structures via Noise Rescheduling in Diffusion for Generative Recommendation](https://arxiv.org/abs/2608.23400)

**论文、机构与场景**

arXiv 2608.23400v1（ACM 投稿格式预印本）；作者来自同济大学、华为技术有限公司和复旦大学；面向通用生成式推荐而非广告场景，评测于 Amazon Scientific/Instrument/Game、MovieLens 与 Steam 数据集。

**核心方法**

提出 ANR-DiffRec：由物品共现矩阵经 SVD 得到协同嵌入，与 Sentence-T5 语义嵌入融合后经 RQ-KMeans 生成 4 级 256 码本 SID，为离散扩散提供协同先验；核心创新为物品级自适应噪声重排：结合几何衰减的局部可恢复性估计与行为感知 item-level attention，动态分配 mask token 去噪权重，总损失 L=λL1+L2；推理采用 SID 合法性约束解码与 beam search；复杂度与标准 Transformer 同阶 O(M^2 d)，训练较 LLaDA-Rec 仅增约 1%。

**主要创新或优化点**

首次在推荐离散扩散中显式集成物品级协同结构：协同 SID 先验补足纯语义 SID 缺失的共现信息，自适应噪声重排替代统一调度以利用物品结构依赖，在 5 个数据集稳定超过 AR 与扩散生成式 SOTA 并开源代码。

**关键结果**

在 5 个数据集上一致优于 16 个基线；Scientific 上 Recall@1=0.0122 对 LLaDA-Rec 0.0098，提升约 24.5%，统计显著 p<0.05；消融显示移除噪声重排使 Scientific NDCG@1 从 0.0122 降至 0.0099（降超 15%），是最大收益来源；协同 SID 与重排相互增强；训练耗时 88.351s/epoch（LLaDA-Rec 87.402s）；Beam=50 每用户推理 10.18ms 对 10.06ms，几乎无额外延迟。

**与你的关联**

与生成式召回/SID 空间候选生成直接相关；若团队关注生成式推荐、扩散模型召回或语义 ID 索引，本方法的协同先验与训练加权策略可复现参考。

**可信度**

technical_report

**风险或局限**

仅离线学术数据集评估，无工业线上 A/B，未覆盖十亿级物料规模与服务级延迟验证；论文自述尾部物品提升相对较小，极端稀疏物品行为证据有限，Instrument 极端尾部 RPG 仍保持领先；依赖离线 SVD 共现矩阵与 RQ-KMeans 管线，且模型规模（8 头 256 维、4 层/6 层 Transformer）偏小，工业扩展性未验证。


### P1｜[Faithful Evaluation of Semantic-ID Tokenizers for Generative Recommendation](https://arxiv.org/abs/2605.25330)

**论文、机构与场景**

CIKM'26《Faithful Evaluation of Semantic-ID Tokenizers for Generative Recommendation》（arXiv:2605.25330v2），作者 Qian Zhang、Lech Szymanski、Jeremiah D. Deng 来自新西兰奥塔哥大学，Haibo Zhang 来自澳大利亚新南威尔士大学，研究场景是基于 Semantic ID 的生成式推荐。

**核心方法**

发现问题：SID 碰撞使多个物品共享同一 SID 序列，SID 级 Hit@10 相对 item 级最高膨胀 103.36%（RK-Means/Scientific），碰撞率最高 30.52%；提出 CCE 与 ZCR：CCE 用碰撞组大小折减计算 ItemHit@K/ItemNDCG@K，无需重训；ZCR 固定前 L-1 级 code，用最小代价重分配末级 code 构造零碰撞 SID；在 Amazon Scientific/Cell/Beauty 和 Yelp 上比较 RK-Means、RQ-VAE、LETTER、QuaSID、MQL4GRec；item 级重评可翻转 tokenizer 排名，ZCR 相对贪心重分配降低重分配代价最多 18.80%。

**主要创新或优化点**

系统量化 SID 碰撞对生成式推荐评估的偏差，证明 SID 级指标可翻转 tokenizer 排名；CCE 与 ZCR 无需重训即可修正评估，直接影响 SID/生成式召回选型与离线评测口径。

**关键结果**

RK-Means/Scientific 的 SID 级 H@10 0.1330 对 ItemHit@10 0.0654 膨胀 103.36%；Cell 58.40%、Beauty 49.54%、Yelp 32.59%；ZCR 使 RK-Means/Scientific 的 ItemHit@10 提升 24.1%（0.0654→0.0812）、ItemNDCG@10 提升 41.0%；RQ-VAE 各数据集 IH@10 提升 5.6%-25.0%；按 SID 级 H@10，RK-Means 在 Scientific/Cell/Beauty 领先，但在 IH@10 下反转垫底；RQ-VAE vs LETTER 的成对排名在 Scientific/Cell/Beauty 同样反转。

**与你的关联**

对使用 SID/RQ/LLM-token 生成式召回的团队：可用来校正 ItemHit/NDCG 指标、对比 tokenizer、避免因碰撞虚高误判召回质量，方法可直接落地到离线评测。

**可信度**

peer_reviewed_paper

**风险或局限**

CCE 对同一 SID 碰撞组内所有 item 给均等分数，未建模 popularity 或 context，不能区分组内目标；ZCR 只改末级 code 且要求每个 prefix 组大小不超过 codebook 容量 V=256，更大碰撞组或小 codebook 时需扩大 V 或多模态特征；实验仅用 Amazon/Yelp 公共数据和单一 T5 生成器，膨胀量与排名反转在更大工业数据集上可能不同。


### P1｜[Rethinking Item Tokenization in Generative Recommenders: From Fixed Atoms to Semantic Subwords](https://arxiv.org/abs/2608.22734)

**论文、机构与场景**

CIKM '26 论文（arXiv 2608.22734v1），作者来自中国科学技术大学与华为技术；应用场景为基于 SID 的生成式推荐/序列推荐，离线评估使用 Amazon Beauty、Instruments 和 Yelp 三个公开数据集。

**核心方法**

提出 Semantic Subword Tokenization (SST)：Item-level Subword Tokenization (IST) 将固定长度 SID 中稳定相邻的 atom token 按 BPE/WordPiece/新提出的 CondEntropy 合并为语义子词，压缩编码端历史序列；Behavior-induced Co-occurrence Augmentation (BCA) 挖掘语义前缀共现并回放子序列训练样本；目标端仍保留固定长度 SID 解码；SST 不依赖特定 RQ tokenizer 与 backbone，在 TIGER-RQVAE、TIGER-RQ-KMeans、LETTER 三个生成式推荐 backbone 上均获得一致提升；作者用 token 级注意力负载分析验证 intra-item attention overload 降低；与 SARQ/VSID 变长 SID 基线对比表明，仅缩短历史 token 序列不够，语义子词结构与 BCA 行为增强是增益来源；代码已开源（github.com/mxrcandy/Semantic-Subword-Tokenization）。

**主要创新或优化点**

生成式召回中固定长度 SID 长期是默认设计；本文首次将其拆分为目标端解码语法与历史端表征两种角色，指出 intra-item attention overload 并提出不对称语义子词 tokenization，在三个主流 backbone 上一致提升，附带代码；对生成式召回、SID 训练和序列建模有方法论启发。

**关键结果**

在 Beauty/Instruments/Yelp 三数据集上，SST 相对最强非 SST 基线的提升为：TIGER-KM HR@5 4.9%–10.4%、NDCG@10 5.3%–10.0%；TIGER-VAE HR@5 7.1%–11.8%、NDCG@10 7.3%–10.1%；LETTER NDCG@10 3.0%–6.0%；注意力负载分析显示 SST 在三个数据集上一致降低 Intra-Item Attention Budget 与 Atom Reassembly Load，且 atom→subword、subword→atom 注意力通道仍非零，说明子词吸收而非丢弃 item 内表示；端到端时间与 Fixed 基本持平（Beauty 0.718→0.659h、Instruments 0.729→0.691h、Yelp 1.689→1.709h）；把目标端也改成变长 SID 后性能大幅下降，验证非对称 tokenization 设计的必要性。

**与你的关联**

若团队负责 SID/生成式召回、基于 LLM 的推荐或长序列 item tokenization，本文可直接参考其历史侧子词合并与行为共现增强思路；若只关注精排/出价或非 SID 双塔召回，则相关性较低。

**可信度**

peer_reviewed_paper

**风险或局限**

仅在 Amazon Beauty/Instruments 与 Yelp 三个公开数据集离线评测，无线上 A/B 或工业规模验证；提升幅度总体偏小且依赖数据集结构；IST 合并准则和 BCA 超参数需按数据集验证集选择，最优准则在 Instruments 上随 backbone 变化，迁移到新数据需要重调；目标端无法安全使用变长子词：VarLen target 使 merged bucket 的 HR@10 降至 0.0002，说明方法依赖固定长度 SID 解码语法，扩展性受限。


### P1｜[The Disconnect Between Better Descriptive Reasoning Trace Quality and Recommendation Effectiveness](https://arxiv.org/abs/2608.23154)

**论文、机构与场景**

arXiv 2608.23154 论文，作者均属 Spotify，研究生成式推荐中显式描述性推理轨迹质量与离线推荐效果的脱节，实验于 Amazon 三个产品域和 Spotify 生产 playlist continuation。

**核心方法**

采用 2x2 因子设计，共享 Qwen3-1.7B 骨干，对比语义 ID（SID）与自然语言标题两种 item 表示及有无 CoT 推理，三阶段训练：LoRA SFT 基线、推理 SFT、GRPO RL；显式推理降低传统离线效果：Title 在 Video Games R@10 下降约 23%，SID 下降较小且不显著；完整复现 SIDReasoner 八任务对齐后推理反而进一步恶化；LLM-judge 复合奖励使 SID 在 Office/Industrial 超过无推理基线（R@10 .1646 vs .1595、.1401 vs .1361），表明奖励密度比轨迹语义更重要；生产 playlist 中推理与无推理候选 rank aggregation 得最佳结果。

**主要创新或优化点**

首个在共享骨干下对 SID 与标题推理轨迹的受控对比，证明提高描述性推理质量不必然提升离线推荐效果，揭示奖励稀疏是推理 GRPO 退化的关键，为生成式召回的训练目标和评估协议提供依据。

**关键结果**

引入显式推理在 SFT 和 GRPO 下产生负或零 reasoning delta：Title 在 Video Games 和 Office 显著下降（R@10 -20% 至 -23%），SID 未达统计显著；完整八任务对齐（SID-A）提高轨迹质量（aggregate 3.51）但使推理模型 R@10 从轻量基线的 .0689/.1589/.1324 降至 .0519/.1239/.1134；GRPO+Judge 使 SID 在 Office/Industrial 超过无推理基线（.1646 vs .1595、.1401 vs .1361），在 Games 恢复约45%差距；Embedding 稠密奖励近似达到同样效果。

**与你的关联**

对做生成式召回/LLM 推荐的团队直接有用：不要用轨迹质量代理推荐效果，优先设计稠密或 LLM-judge 奖励；生产场景可尝试推理与无推理候选 rank aggregation 以提升覆盖。

**可信度**

technical_report

**风险或局限**

仅评估 Qwen3-1.7B 单一骨干，更大模型关系可能不同；Stage 2 使用 answer-conditioned 的 GPT 教师轨迹，自生成的推理初始化可能表现不同；全部为离线评估，单 ground-truth 交互协议可能低估推理价值，需在线验证。


### P1｜[When KV Meets Embeddings: Dynamic GPU Memory Allocation for Accelerating Generative Recommender Serving](https://arxiv.org/abs/2605.04450)

**论文、机构与场景**

RACER 论文（arXiv:2605.04450v2，目标 SC26 会议）由香港浸会大学（Wenjun Yu、Amelie Chi Zhou）与阿里巴巴（Shuguang Han）合作，面向 Meta HSTU 类生成式推荐（GR）在线推理服务优化 GPU HBM 的 EMB 与 KV 缓存分配。

**核心方法**

提出 RACER 系统，由三层 PPO 控制器（冻结基策略、在线残差适配器、突发恢复控制器）在 5s 决策周期内动态调整 EMB-KV 分配比例，并采用仅移动 EMB 边界的零拷贝调整与后台 H2D 带宽节流避免干扰线上推理；EMB-KV 感知路由按 KV 命中、EMB 覆盖与节点负载加权评分选择服务节点，权重由离线测得的 miss 成本归一化得到，并含用户亲和度奖励；在 32 节点 A100（80GB）集群、5TB 嵌入表、8K-15K 序列长度的三个数据集（Taobao、Amazon Video-Games、Amazon Books）上评估，覆盖 Steady/Trend/Burst 负载。

**主要创新或优化点**

首次将生成式推荐（GR）推理中 EMB 热缓存与 KV 缓存对 GPU HBM 的竞争作为联合优化问题，通过在线 RL 分配与 EMB-KV 感知路由消除静态分配 20-30% 的潜在延迟损失，为生产级 GR serving 提供可落地的闭环方案，并验证跨 GPU 代际的普适性。

**关键结果**

相比最优静态分配 KV-EMB-Opt，P99 延迟降低 25-34%（3层模型）和 28-38%（6层模型）；30ms SLO 满足率 93.5-99.6%（Burst 下 93.5-95.3%），优于静态基线 56-91%；SmartAllocator 控制决策仅需 32µs，分配比例与离线最优的差距为 0.019-0.031（Steady/Trend/Burst），优于 PID、BO、MILP、XGBoost、LSTM 和 PPO-only；弱扩展 2 到 32 节点时吞吐量相对 KV-EMB-Opt 提升 23-36%，且决策开销 32µs、路由元数据 <100KB/节点，控制面开销低。

**与你的关联**

对采用 HSTU 类生成式推荐模型的搜广推团队有直接参考价值：可借鉴 EMB-KV 联合分配、PPO 在线适配和路由设计以降低 P99 延迟与 SLO 违规；对精排/召回算法同学可作为 serving 基础设施背景。

**可信度**

peer_reviewed_paper

**风险或局限**

评估基于公开数据集与模拟的生产 trace 重放，而非实际线上流量 A/B 实验，收益数字来自离线/模拟仿真；系统针对 HSTU 架构设计，KV 缓存无共享前缀，对支持跨用户 KV 共享或前缀复用的 GR 变体需重新适配；硬件泛化性（H100/H200）只做了理论分析（F_gpu/B_pcie 比值），未在真实 H100/H200 集群实测。

### P1｜[A Dual-Expert Strategy Integrating LLMs to Mitigate Negative Transfer in Cross-Domain Sequential Recommendation](https://arxiv.org/abs/2608.23131)

**论文、机构与场景**

DuELRec由SK Telecom与KAIST学者Hyeongjun Yun、Kihyuk Song、Jaegul Choo、Chung Park完成，发表于CIKM '26，面向跨域顺序推荐，并在电信个人助手App中部署。

**核心方法**

提出domain-gated dual experts框架：item-aware attention将subtoken聚成item级表征，单域专家与跨域专家用不同block级因果掩码，门控按item融合；dual-sampling token-to-item对比学习从单、跨域物品池抽负样本；在Amazon五域与Telco五域上与26个IDRec/LLMRec基线对比，多数域HR/NDCG/MRR领先，并给出负迁移、冷热物品/用户、超参p敏感性等分析；2025年1-3月线上A/B：约500万用户、14个域，Top-1推荐，CTR从SASRec变体的0.90%升至1.33%（相对+47.6%），双重比例z检验p<0.01，推理延迟242ms/次。

**主要创新或优化点**

首个宣称ID-free且同时处理三域以上CDSR的LLM方案，将item级协同信号引入LLM文本表征，用门控双专家显式抑制负迁移，并在10域离线评测与线上A/B中验证实际增益。

**关键结果**

Amazon上HR@5相对最优基线提升：Books +3.81%、Jewelry +20.6%、Outdoors +1.70%、Toys +10.8%；Games未超越RecFormer；线上A/B中CTR 1.33% vs SASRec 0.90%（+47.6%）vs popularity 0.63%，p<0.01；延迟242ms/次，满足生产约束；相对IDRec训练慢1.67x、推理慢2.29x；相对LLMRec RecFormer训练快1.16x、推理快3.19x；负迁移对比中所有域HR@5均优于单域SASRec。

**与你的关联**

若关注跨域顺序召回、LLM增强召回或负迁移控制，其门控双专家与单/跨域负采样设计可直接借鉴；线上A/B架构与指标拆解对部署有参考价值。

**可信度**

online_ab

**风险或局限**

离线评估用leave-one-out且仅用1个正样本+99个随机负样本，未做全物料候选评测，Top-K指标存在偏差；线上A/B只在电信助手App的目标域Top-1场景验证，单一业务场景，CTR结论向电商/短视频/广告链路的泛化未证明；基于TinyLlama-1.1B的双专家LLM方案推理延迟242ms/次，高于工业在线常用轻量召回，训练也慢于IDRec。


### P1｜[Bidding-Aware Retrieval for Multi-Stage Consistency in Online Advertising](https://arxiv.org/abs/2508.05206)

**论文、机构与场景**

CIKM 2026 论文《Bidding-Aware Retrieval for Multi-Stage Consistency in Online Advertising》由阿里巴巴淘宝与天猫集团团队完成，应用于阿里展示广告平台的广告检索阶段。

**核心方法**

BAR 在检索打分函数中引入真实出价特征，通过单调性约束（BAO）与 pCTR/pBid 多任务蒸馏（DAO）训练 eCPM 排序，使检索结果与精排 eCPM 逻辑一致；Asynchronous Near-Line Inference 在广告预算或约束调整等操作触发时异步重算 ad embedding 与 HNSW 邻接关系，单条写入 P99.9 小于 0.5ms，索引近实时收敛；Task-Attentive Refinement 设置 pCTR、pBid、eCPM 三个头部分支，解耦用户兴趣与商业价值信号，在线仅 eCPM 头驱动 top-k 检索。

**主要创新或优化点**

这是首个在工业级广告召回阶段直接利用稠密出价特征并近实时响应出价变化的检索框架，全量部署验证了平台收入显著提升与广告主操作响应的大幅改善。

**关键结果**

SA-RSQ由天津大学、美团、中科院软件所合作发表于arXiv（2608.22979v1），面向外卖广告平台2048D多模态MLLM特征的压缩与CTR应用。

**核心方法**

核心方法：以Top-K masked softmax稀疏路由替代argmin硬量化，逐层残差压缩MLLM嵌入为(Index,Prob)元组，存储仅与K×L相关，避开STE并支持端到端梯度回传；在专有外卖广告数据集上，8/32/48字节预算下SA-RSQ离线CTR AUC均优于RQ-VAE、R3-VAE、VQ-VAE、SoftVQ-VAE等基线，48字节配置AUC 64.913、gAUC 63.013；作者在10%流量上运行一周A/B，相对无多模态特征生产基线CTR +2.51%、CPM +3.66%，并公布核心实现于github.com/WishArdently/SA-RSQ。

**主要创新或优化点**

工业推荐中2048D MLLM多模态特征落地受存储和延迟限制；SA-RSQ用可微Top-K稀疏概率元组在8-48字节内保留连续语义，是硬量化SID与稠密embedding之间的折中，并有外卖广告平台线上验证和开源实现。

**关键结果**

离线：48字节(Index,Prob)配置AUC 64.913、gAUC 63.013，重建损失RL 0.1553，优于所有对齐预算基线；在线：一周A/B相对生产基线CTR +2.51%、CPM +3.66%（作者报告的峰值配置，未给显著性指标）；生成式初步：NDP范式下R@10 0.0096、R@20 0.0131，高于NTP最高0.0088/0.0126。

**与你的关联**

与搜广推特征压缩和多模态向量落地直接相关，可替换SID或稠密embedding作为CTR精排输入；NDP概率目标也为生成式召回提供新方向。

## 今日最值得立项的实验

### SID 碰撞校正后的生成式召回离线评测与 tokenizer 重选

- 假设：SID 级指标虚高导致 tokenizer 误选，用 CCE 校正后 item 级指标可翻转 tokenizer 排名。
- Control：现有 SID 生成式召回离线评测，使用 SID 级 Hit@K/NDCG@K。
- Treatment：用 CCE 碰撞组折减计算 ItemHit@K/ItemNDCG@K，对候选 tokenizer（RK-Means、RQ-VAE、LETTER）重新排名。
- 保持变量：生成器、数据集、beam 大小、候选集数量均不变。
- 离线指标：ItemHit@10；ItemNDCG@10；碰撞率；膨胀率
- 线上 Guardrail：确保 CCE 不引入 popularity 偏差；报告 tokenizer 排名变化与差异幅度

### 历史侧语义子词 tokenization 替换固定长度 SID 序列

- 假设：将固定长度 SID 历史序列按语义子词合并，可降低 intra-item attention overload，提升生成式召回指标。
- Control：现有固定长度 SID 历史序列直接输入生成式召回模型。
- Treatment：用 BPE/WordPiece/CondEntropy 合并稳定相邻 atom token 为子词，并加入行为共现增强（BCA）回放样本。
- 保持变量：目标端 SID 解码、模型结构、训练数据、优化器均不变。
- 离线指标：HR@5；NDCG@10；token 级注意力负载
- 线上 Guardrail：监控端到端训练时长与吞吐不显著下降；确保变长目标端不用以避免性能崩溃

### 广告召回阶段引入出价感知 eCPM 蒸馏与近实时索引更新

- 假设：在检索打分中引入真实出价特征并异步更新 embedding，可提升平台收入与广告主响应。
- Control：现网广告召回，基于 pCTR 排序，索引静态或批量更新。
- Treatment：采用 BAR 式出价感知多任务蒸馏（pCTR/pBid）训练 eCPM 排序，并配置异步近线推理更新 embedding 与 HNSW 邻接关系。
- 保持变量：候选集规模、召回通道、精排模型等下游链路保持不动。
- 离线指标：Recall@2000；eCPM 排序一致性；近实时索引收敛延迟
- 线上 Guardrail：线上收入与 RPM 不下降；监控广告主操作响应 RIR/IIR 提升；控制吞吐下降在可接受范围（如 <20%）


## 一句话总判断

本期证据显示生成式召回进入工程化收敛期：SID 从固定长度 token 拆分、多样性噪声调度到评测碰撞校正均有独立推进，但多数仍停留离线学术数据集，工业落地仅靠少数公司自报。广告侧 BAR 首次把出价感知带入召回阶段并近实时响应，是漏斗一致性方向的强证据；Pinterest 与 Netflix 分别证明站外图嵌入和 LLM 上下文压缩可在精排/召回带来在线收益，但收益绝对值小且依赖自报。方法层面，从固定架构转向可复用表示与训练信号设计是明显主线。
