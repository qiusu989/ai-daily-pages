## 生成式召回

### P2｜[Controllable Generative Recommendation via Guided Token Refinement](https://arxiv.org/abs/2610.28642)

**论文、机构与场景**

- **机构：Xi’an Jiaotong-Liverpool University、University of Liverpool、The Hong Kong Polytechnic University**
- 作者：Haichao Zhang, Zhixuan Liang, Chong Zhang, Zixi Chen, Wen Wang, Jia Wang
- 来源：arXiv:2610.28642v1
- 场景：基于离散 Semantic ID 的生成式物品召回与可控生成
- **论文主要内容：** 将 SID 生成从自回归解码改为掩码并行迭代精化，并用拓扑约束树保证结果可映射真实物品。

**主要创新或优化点**

- 已有生成式推荐依赖从左到右自回归解码，早期 token 决策被锁定，难以整体规划与实时控制，直接干预又易破坏语义结构、生成不存在的物品。本文将生成重构为掩码填充的并行迭代精化，一次预测全部 Semantic ID（SID）token 以获得全局视野，使控制信号可直接施加于高语义 token 且无需重训。针对并行解码可能产出非法 SID，本文加入拓扑约束树，在 beam 推理中迭代修正低置信预测并强制走合法码本路径，以提升生成物品的有效性；整体目标是在同一生成框架内实现更可控的准确率—多样性权衡。

**核心方法**

- 作者提出 ReGen：将自回归逐 token 解码改为掩码填充式并行迭代精化，一次预测全部 Semantic ID（SID）token，保留全局视图，使高层语义 token 可直接施加控制信号而无需重训模型。
- 作者提出拓扑约束树：在 beam 推理中沿合法码本路径迭代修正低置信预测，使生成的 SID 能映射到真实物品、避免不存在物品。
- 代码已在摘要给出的 GitHub 链接开放；摘要未披露具体消融、训练细节、数据集与指标数值。

**关键结果**

- 作者称 ReGen 在中等引导强度下取得更有利的准确率—多样性权衡，并保持生成 Semantic ID 的高有效率；摘要未给出数据集、基线或指标数值。

**收益归因**

- 主要：未核实
- 次要：作者称，掩码并行精化提供全局 token 视图，使控制信号可施加于高层语义 token 而无需重训；该收益为机制解释，未经独立验证。
- 次要：拓扑约束树用于在 beam 推理中强制合法码本路径；摘要仅称保持生成 SID 高有效率，未给出量化提升。

**与你的关联**

- 潜在适用于以 Semantic ID 生成召回的推荐系统，需要在不重训模型的前提下调节准确率与多样性的场景；迁移需评估掩码迭代推理的延迟与码本路径约束的构建成本。

**风险或局限**

- 仅摘要级证据且 PDF 正文未提供，未给出数据集、基线设置、指标数值与统计口径，无法量化提升或复现实验。
- 拓扑约束树依赖合法码本路径；其构建、更新与冲突处理细节未在摘要披露，无法判断约束冲突时的行为。
- 并行迭代精化的推理轮数与 beam 成本未披露，无法评估推理开销；摘要未给出与自回归基线的对照口径。


### P2｜[Generative Recommenders Forget the Long Tail: Restoring Memorization in Retrieval and Ranking](https://arxiv.org/abs/2610.29298)

**论文、机构与场景**

- **机构：中国科学技术大学（University of Science and Technology of China）（Xu Huang、Jiancan Wu、Hongzheng Qin、Jiawei Feng、Xiang Wang）；蚂蚁集团（Ant Group）（Can Ye、Wencong Zeng、Fengze Li，页面标注为 Independent Researcher，邮箱域名为 antgroup.com）**
- 作者：Xu Huang, Jiancan Wu, Hongzheng Qin, Jiawei Feng, Can Ye, Wencong Zeng, Fengze Li, Xiang Wang
- 来源：arXiv 2610.29298v1
- 场景：生成式推荐的商品与音乐域检索与排序长尾恢复
- **论文主要内容：** 分析生成式推荐检索与排序双重遗忘长尾，提出免训练共现增强插件恢复记忆。

**主要创新或优化点**

- 揭示生成式推荐的检索与排序共享似然导致长尾双重遗忘：beam 按前缀概率质量剪枝使尾项早期淘汰，且加宽 beam 收益有限。
- 提出训练无关的共现感知池扩展 CAPE，在 beam 外以共现证据补回尾项并复用冻结生成器打分，弥补生成式检索缺失的 item 级记忆。
- 以共现证据校准生成器排序分数，同时保留首物品，使检索扩展与排序修正协同；论文将其表述为对应协同过滤式记忆的两阶段恢复方案。

**核心方法**

- 指出生成式推荐共享同一似然分数时，检索阶段 beam search 按子树概率质量保留前缀导致尾项被过早剪枝，排序阶段似然把尾项排到头部项之后，二者均源于缺少 item 级记忆
- CAPE 的记忆通道在 beam 之外用共现证据召回受共现支持的尾项，再用冻结的生成器对其打分，作为候选补充
- 记忆校准排序将生成器似然与共现证据融合以重新打分，同时保留生成器的首个物品不变
- CAPE 为无需训练的插件，实验在两个生成式骨架及商品、音乐域上进行，并报告相对骨架与共享同候选的重排基线有所提升

**关键结果**

- 在商品与音乐域两个生成式骨架上，CAPE 相比骨架及使用相同候选的重排基线显著提升长尾准确率，同时保持或改善整体准确率
- 作者报告 CAPE 仅增加小部分延迟，但摘要未给出具体延迟数值与硬件配置

**收益归因**

- 主要：利用共现记忆在 beam 外补回长尾候选并以共现证据校准排序，提升长尾准确率
- 次要：保持或改善整体准确率，未以长尾换取头部性能
- 次要：免训练插件形式，可附加于冻结生成器，额外计算仅少量延迟

**与你的关联**

- 适用于以语义 ID 或 item token 生成候选并统一打分的生成式推荐系统，尤其关注长尾覆盖与检索排序一致性的场景；迁移需具备可用的物品共现统计。

**风险或局限**

- 摘要级证据，未披露统计显著性检验细节与具体延迟数值
- 共现证据依赖物品共现统计的质量与覆盖率，冷启动物品缺乏共现时效果未说明
- 实验仅在商品与音乐域的两个生成式骨架上进行，跨域与工业规模部署效果未验证


### P2｜[Progressive Learning from Content to Relevance to Personalization for CTR Prediction](https://arxiv.org/abs/2610.29138)

**论文、机构与场景**

- **机构：未披露**
- 作者：Zhiguang Yang, Yulin Yang, Fuyu Lv, Dan Ou
- 来源：arXiv 2610.29138v1
- 场景：多模态 CTR 预测，融合内容、query-item 相关性与用户个性化
- **论文主要内容：** 针对多模态 CTR 中细粒度内容与 ID 预测器难融合的问题，提出三阶段渐进式 SID 学习框架。

**主要创新或优化点**

- 提出内容→相关性→个性化的渐进式训练框架，用统一细粒度 SID 打通多模态内容 tokenizer 与 ID 预测器，缓解现有稠密嵌入或粗离散 ID 难以融合细粒度异构内容的问题。
- 三阶段各有显式目标且共享预测器：语义预训练建立 query-item 匹配先验，再以点击监督微调承接个性化，为表征学习与 CTR 预测之间提供衔接路径。

**核心方法**

- 第一阶段用预训练多尺度视觉 tokenizer 与文本 tokenizer 将图文内容转为细粒度 Semantic IDs（SIDs），并与传统 ID 特征显式对齐。
- 第二阶段在 query-item 相关性监督下做全参数语义预训练，在同一共享预测器内联合优化多模态 SID 与常规字段的交互，得到匹配先验。
- 第三阶段以点击监督直接微调该预训练预测器，学习隐式个性化偏好；三阶段共享同一细粒度离散表示并保留 token 级内容访问。

**关键结果**

- 摘要称离线与线上评估在标准 CTR 指标和核心业务指标上均有明显提升，但未披露具体数值、基线与统计口径。
- 摘要称 FineSID 提升同产品内创意区分能力，体现超越传统 ID 记忆的语义泛化，未给出量化结果。

**收益归因**

- 主要：未核实
- 次要：未核实

**与你的关联**

- 若从事多模态内容侧表征与 ID 召回/排序融合的工作，可参考其 SID 构造与相关性预训练加点击微调的训练组织方式；但摘要级信息不足以直接迁移到具体链路。

**风险或局限**

- 摘要未给出各阶段增益的消融拆分，无法判断提升来自语义预训练、SID 表示还是整体配置。
- 线上评估与业务指标的具体数值、基线、流量规模和统计口径均未披露，工业结论不可核验。
- 机构未披露，且未提供 PDF 正文核验，tokenizer 细节、码本设计与训练成本无法确认。

- **机构：未披露**
- 作者：Viswonathan Manoranjan、Taeyoon Kim、Nicholas Do、Sang Woo Kim、Dawei Li、Zhen Tan、Tianlong Chen、Yunmei Liu
- 来源：arXiv 2610.28636v1
- 场景：生物医学预印本个性化文献发现与排序
- **论文主要内容：** 面向生物医学预印本，用适配双编码器检索加多样性重排实现个性化文献发现。

**主要创新或优化点**

- 将 GPT-4o 生成的查询与 cross-encoder 软标签蒸馏结合，用于适配生物医学预印本的双编码器检索训练。
- 在检索之外加入 DPP 多样性重排与 LID 课程式排序，以缓解近重复推荐并控制新颖度与专精度。

**核心方法**

- prism 采用双编码器检索器，以 GPT-4o 生成的查询并结合 Multiple Negatives Ranking 与 MarginMSE 混合目标、cross-encoder 软标签在生物医学预印本上适配训练

**关键结果**

- 作者称完整 pipeline 运行延迟低、适合交互使用，但摘要未给出具体延迟或硬件数值

## 序列建模与兴趣表征

### P2｜[Think Harder Where It Matters: Item-Level Adaptive Recursion for Sequential Recommendation](https://arxiv.org/abs/2610.30128)

**论文、机构与场景**

- **机构：中国人民大学高瓴人工智能学院（Gaoling School of Artificial Intelligence, Renmin University of China）**
- 作者：Zhanshuo Cao, Jiakai Tang, Yuqi Zhou, Sunhao Dai, Jun Xu
- 来源：arXiv 2610.30128v1
- 场景：序列推荐
- **论文主要内容：** 针对序列推荐固定计算预算问题，用带门控的逐物品自适应递归深度分配计算。

**主要创新或优化点**

- 作者报告同一交互序列内物品计算需求高度不均：多数浅层即收敛，少数关键物品需满深度；并以 oracle 访问目标物品的实验指出固定深度分配次优。LoopRec 用权重共享递归块加每层轻量门控，为每个物品独立做退出/继续决策，无需辅助深度标签，把全局深度转为物品级可学习属性。作者称学到的分配模式与事后 oracle 分析一致：低频物品与更近交互获得更深计算，为按物品分配算力提供可解释线索。

**核心方法**

- LoopRec 递归复用单个权重共享块，在每个递归边界设置轻量门控，对每个交互物品独立输出二值退出/继续决策，无辅助深度标签
- 表示成熟度高的物品提前退出，需要更深推理的物品继续递归，把固定全局深度转为逐物品的可学习属性；作者称该设计易适配多种骨干架构
- 作者报告分配模式为低频物品与更近交互获得更深计算，代码已发布于 GitHub Elpmis117/LoopRec

**关键结果**

- 在公开基准、四个骨干家族上，LoopRec 相对同骨干固定深度对照均更优；摘要未给出具体指标、统计口径或提升幅度。
- 作者报告：在 oracle 访问目标物品时，非均匀深度分配一致优于固定分配，并据此认为统一计算浪费容量且损失质量；属作者解释，非独立复现。
- 学到的逐物品深度分配呈现与事后 oracle 分析一致的模式：低频物品与更近交互获得更深计算；量化幅度未核验。

**收益归因**

- 主要：摘要报告在同骨干固定深度对照上质量更优；算力节省与延迟收益未量化，属机制推断。
- 次要：门控无需辅助深度标签即可学习逐物品退出策略；是否降低调参成本未量化
- 次要：作者称权重共享递归设计易适配多种序列骨干；实际迁移成本未验证

**与你的关联**

- 适合序列推荐精排或兴趣表征模块探索按物品自适应计算预算；迁移需具备可递归的权重共享骨干与训练预算，收益幅度与线上延迟收益需另行验证。

**风险或局限**

- 仅摘要级证据，关键指标、统计口径与基线细节未核验；所附资料未含作者机构，机构声明无法核实。
- 公开基准与四个骨干家族的离线实验，无在线 A/B 或生产部署证据。
- 逐物品递归在推理时引入门控分支，实际吞吐与延迟成本未披露；亦无独立复现。

### P2｜[Hierarchical Exponential-Gaussian Mixtures for Watch-Time Distribution Prediction](https://arxiv.org/abs/2608.23356)

**论文、机构与场景**

- **机构：AI VK 与 Lomonosov MSU（其中 Sofia Gulevskaia 与 Mikhail Trapeznikov 同时隶属 AI VK 和 Lomonosov MSU，Aleksandr Poslavsky 与 Alexander D'yakonov 隶属 AI VK）**

- 来源：arXiv 2608.23356v2
- 场景：短视频推荐中的观看时长分布预测
- **论文主要内容：** 针对观看时长分布预测的混合模型失效问题，提出分层跳看分解与稳定化训练方法

**主要创新或优化点**

- 指出 EGMN 类观看时长分布模型存在方差塌缩、组件冗余和组件失活等失效模式，并给出分层跳看分解的结构化修正，把分布建模的稳定性问题显式暴露出来。
- 以固定骨干仅替换预测头的协议做对照实验，并配 1.5 个月线上 A/B，说明观看时长分布头的改进在相同表征下可独立带来排序收益。
- 移除强制高斯位移与熵正则、引入可选 KL 方差正则，为过参数化混合模型提供更可控的训练约束，提升可解释性。

**核心方法**

- 基线 EGMN 以指数-高斯混合建模完整条件观看时长分布，本文复现发现方差塌缩、组件冗余和组件失活三类失效模式
- HEGM 采用分层跳看分解：把观看时长拆为跳看与非跳看部分，分别用指数与高斯混合刻画，并配合结构化初始化
- 方法移除强制高斯位移，去除熵正则项，并对过参数化混合模型提供可选的基于 KL 的方差正则
- 代码与模型在 github.com/rw404/HEGM 公开；实验采用固定骨干、仅替换预测头的协议，与可复现轻量基线对比

**关键结果**

- 在固定骨干头替换协议下，HEGM 在大规模工业与公开数据上相对可复现轻量基线提升排序准确率与阈值事件预测，同时点估计精度保持竞争水平
- 作者报告 1.5 个月生产 A/B 测试中参与度指标有统计显著提升，但摘要未给出具体幅度与统计口径
- 论文报告混合模型稳定性与可解释性相对 EGMN 明显改善，具体量化指标未在摘要中披露

**收益归因**

- 主要：通过分层跳看分解与稳定化正则改善观看时长分布预测的稳定性与排序准确性
- 次要：移除强制高斯位移与熵正则，减少混合组件冗余与失活，提升可解释性
- 次要：可选 KL 方差正则缓解过参数化混合模型的方差塌缩问题

**与你的关联**

- 适用于短视频或内容推荐中需要建模观看时长等长尾、近零膨胀、多峰分布的精排环节；迁移前提是已有可固定骨干的分布预测头，并能接受同等量级线上评测成本。

## 今日最值得立项的实验

### 观看时长分布头：分层跳看分解替换 EGMN 的离线对照

- 假设：在同一固定骨干下，将观看时长分布头替换为分层跳看分解（指数刻画跳看、高斯混合刻画非跳看）并去掉强制高斯位移与熵正则，可在保持点估计精度的同时提升排序准确率与阈值事件预测。
- Control：现有 EGMN 类指数-高斯混合分布头，同骨干、同训练数据与同样的仅换头协议。
- Treatment：HEGM 分层跳看分解加结构化初始化，可选 KL 方差正则；移除强制高斯位移与熵正则。
- 保持变量：同一骨干与特征口径、同一训练/测试时间窗口、同一损失权重搜索预算、同一评测协议。
- 离线指标：排序指标（AUC/GAUC）；阈值事件预测指标；观看时长点估计误差；混合组件使用率与方差塌缩诊断
- 线上 Guardrail：线上观看时长与参与度指标不出现显著负向；分布头 P99 推理延迟与吞吐在预算内；长尾/近零时长样本的校准误差不恶化

### 生成式召回长尾恢复：共现记忆补候选的离线对照

- 假设：在冻结的 SID 生成式召回器 beam 之外，用共现证据补回受共现支持的尾项候选并以共现证据校准排序分数，可在不损整体准确率的前提下提升长尾准确率。
- Control：同骨干的 SID 生成式召回基线，以及使用相同候选集的重排基线。
- Treatment：CAPE 免训练插件：beam 外共现记忆召回尾项加冻结生成器打分，排序阶段似然与共现证据融合且保留首个物品不变。
- 保持变量：同一 SID 码本与生成器权重、同一训练日志与测试集、同一 beam 宽度与候选预算。
- 离线指标：长尾物品命中率/准确率；整体 HR@K；生成 SID 有效率；额外推理延迟
- 线上 Guardrail：整体准确率与头部物品曝光不回退；线上召回 P99 延迟增量在预算内；冷启动物品缺乏共现时行为不劣化

### 多模态 SID 相关性预训练对 CTR 排序的增量验证

- 假设：在统一细粒度 SID 上先做 query-item 相关性语义预训练、再以点击监督微调，相比直接用 ID 特征训练，可带来排序增益且增益部分来自匹配先验而非 SID 表示本身。
- Control：传统 ID 特征直接训练的同骨干 CTR 模型。
- Treatment：三阶段渐进框架：图文 tokenizer 生成 SID 并与 ID 显式对齐，相关性预训练后点击微调。
- 保持变量：同一训练样本与特征池、同一骨干规模、同一评测集与训练预算。
- 离线指标：CTR 预测 AUC；分创意/分内容组的排序指标；各阶段消融差值
- 线上 Guardrail：线上 CTR 与核心业务指标无负向；多模态 tokenizer 侧离线特征产出成本可接受；SID 对齐后 ID 特征召回覆盖不下降
