### P2｜[Efficient Multimodal Generative Recommendation with Latent Narrative Reasoning](https://arxiv.org/abs/2609.16070)

**论文、机构与场景**

- **机构：首页明确列出 1Weixin Group, Tencent；2The Hong Kong Polytechnic University（其中 Hao Miao 属香港理工大学，其余作者属腾讯微信事业群）**
- 作者：Chenxing Wang, Nantao Zheng, Hao Miao, Juyuan Wang, Xinke Jiang, Yuchen Fang, Aolin Li, Haijun Wu
- 来源：arXiv 2609.16070v1
- 场景：短剧续写中的多模态生成式推荐，将物品预测重构为语义标识生成，目标由叙事演进而非用户偏好决定

**核心方法**

- 提出 NarraLite 框架，联合压缩感知与推理：Progressive Spectral Compression 将长视觉上下文蒸馏为紧凑的叙事相关证据，保留转场关键信息并减少冗余视觉计算
- 提出 Latent Narrative Reasoning，引入上下文路由的隐式推理 token 并与未来续写语义对齐，从而在不自回归解码文本理由的情况下完成隐式叙事推断
- 建立了用户无关的多模态短剧续写 benchmark，覆盖 UGC、PGC 与 OOD 设置

**主要创新或优化点**

- 把生成式推荐从用户偏好预测扩展到叙事演进驱动的多模态内容续写，并尝试用隐式潜变量推理替代显式文本理由生成以降低开销，属于生成式召回的新场景探索。

**关键结果**

- 摘要声称 NarraLite 在续写准确率、叙事连贯性与鲁棒性上持续优于现有方法，但未给出具体数值
- 摘要声称取得较优的准确率—效率权衡，但未披露具体效率或延迟数字

**收益归因**

- 主要：未核实
- 次要：隐式推理替代显式理由生成以降低计算开销
- 次要：多模态叙事证据压缩

**与你的关联**

- 与生成式召回（SID/token 生成）和多模态表征方向相关，但面向短剧叙事续写而非电商/广告/短视频主推荐链路，迁移性需自行评估。

**风险或局限**

- 只有 arXiv 摘要证据，无 PDF 正文核验，也未见同行评审或线上 A/B
- 所有关键结果均无具体数值，准确率与效率收益无法量化核验
- 机构信息未披露，且任务为短剧续写 benchmark，与工业搜广推链路的映射关系不明确


### P2｜[ReliGRec: Reliability-Oriented LLM-Based Generative Recommendation via User-Risk-Aware Prompt Routing](https://arxiv.org/abs/2609.16560)

**论文、机构与场景**

- **机构：Haoran Yang、Fei Chen 属 Central South University，Yutian Xiao 属 Beihang University，Jiahao Liang 属 South China University of Technology**
- 作者：Haoran Yang、Fei Chen、Yutian Xiao、Jiahao Liang
- 来源：arXiv 2609.16560v1
- 场景：LLM 基生成式推荐中的用户级弱风险感知提示路由

**核心方法**

- 从部分用户的评论反馈信号派生用户级弱风险代理标签，用于弱监督训练，不依赖显式恶意意图标注
- 用 Behavior Token 表示序列行为、用 temporal Graph Token 表示协同上下文，二者经 Dual-View Weak-Risk Estimator 融合输出用户级弱风险分数
- 弱风险分数在推理时选择 Simple 或 Cautious Prompt
- Cautious Prompt 引导关注稳定、协同支持的证据，抑制对孤立短期与重复交互的过度依赖
- 聚合 Graph Token 为生成下一物品 Semantic ID 提供协同上下文，使弱风险估计从辅助预测变为生成时控制信号

**主要创新或优化点**

- 把用户级可靠性/弱风险估计从训练期重加权或图聚合，转为 LLM 生成式召回的推理期提示路由控制信号，提供了生成式推荐鲁棒性的一条新接口

**关键结果**

- 摘要报告推荐效果与弱风险代理标签预测均具竞争力，未给出具体指标数值
- 路由分析刻画了弱风险引导提示对推荐质量与推理成本的影响，未披露具体开销数字

**收益归因**

- 主要：未核实
- 次要：鲁棒性
- 次要：用户风险感知

**与你的关联**

- 若线上存在刷单、shilling 或兴趣突变用户，该提示路由思路可迁移到 SID 生成式召回链路的用户侧风险控制

**风险或局限**

- 仅 arXiv 摘要证据，无 PDF 正文核验，方法细节与实现不可确认
- 无在线 A/B 或生产部署结论，标注为弱监督弱风险代理而非真实恶意标签
- 模型未能核实机构，作者背景与实验环境不可验证

### P2｜[Efficient Swing Computation for Retrieval in Large-Scale Recommender Systems](https://arxiv.org/abs/2609.16850)

**论文、机构与场景**

- **机构：香港浸会大学（Hong Kong Baptist University）**
- 作者：Runhao Jiang, Renchi Yang
- 来源：arXiv:2609.16850v1
- 场景：大规模推荐系统 item-to-item 相似度检索（Swing 分数计算）

**核心方法**

- Swing 分数利用 user-item-user 交互结构评估物品对相似度，广泛用于工业级 i2i 召回
- 现有 Swing 计算方案存在物品度数的二次时间复杂度开销，或依赖截断启发式导致质量不佳
- 论文提出 ASC 与 K-ASC 两种算法：ASC 结合 GNS 和 USS 两个随机算法自适应处理高度数/低度数查询物品，K-ASC 采用 filter-refinement 范式处理 top-K 查询

**主要创新或优化点**

- Swing 是工业 i2i 召回常用相似度度量，将其从二次复杂度降至近似算法并保持质量，可能降低大规模图上的召回索引计算成本。

**关键结果**

- 在 8 个真实数据集上，ASC 与 K-ASC 相比对比方法在计算时间上有数量级加速，同时保持相同的近似与 top-K 查询结果质量
- K-ASC 在包含十亿级边的 Yambda 与 MAG 图数据集上表现高效

**收益归因**

- 主要：降低大规模 user-item 图上 Swing 相似度计算的运行时间
- 次要：保持 top-K 查询质量
- 次要：支持十亿边规模图

**与你的关联**

- 属于召回阶段 i2i 相似度计算效率优化，与短视频/电商/广告召回链路中协同过滤相似度构建相关。

**风险或局限**

- 仅摘要与元数据可用，未核验 PDF 正文与实验细节
- 无线上的 A/B 或生产部署证据，加速结论仅来自离线数据集实验
- 方法聚焦 Swing 近似计算，是否扩展到其他 i2i 度量未知

### P2｜[Evaluating Brand Retrieval and Ranking in Large Language Model Recommendations](https://arxiv.org/abs/2609.16304)

**论文、机构与场景**

- **机构：Northwestern University（Edward Malthouse、Kun-Yu Lee、Sanchary Pal、Xueyan Feng）与 Boston University（Jing Yang）**
- 作者：Edward Malthouse、Kun-Yu Lee、Jing Yang、Sanchary Pal、Xueyan Feng
- 来源：arXiv 2609.16304v1
- 场景：LLM 开放式品牌推荐（检索与排序）的评测框架

**核心方法**

- 提出不依赖模型输出定义竞争集合的评测框架，用重复采样估计推荐流行度与显著性，而非基于单次生成的列表
- 定义 Brand Recommendation Probability (BRP@k) 与 MRR@k 两项指标以量化品牌被检索与排序的情况
- 在六个 LLM、五个产品品类上应用该框架
- 含 category-only 查询、needs-based 查询与 diagnostic positioning probes 三类探测
- 开源软件与数据以支持 LLM 品牌推荐的可复现评测

**主要创新或优化点**

- 把 LLM 推荐视为随机检索-排序过程而非单次生成列表，为 LLM 推荐提供可复现的评测协议与指标，暴露传统品牌流行度假设的失效。

**关键结果**

- Category-only 查询下，成熟品牌出现大量遗漏，且推荐显著性与传统品牌流行度关联证据有限
- 推荐显著性与更广泛的市场可见度信号相关，尤其是搜索兴趣与在线品牌讨论
- Needs-based 查询改变了被检索到的品牌
- 常规推荐中被遗漏的品牌在提供独特线索后仍可条件性检索到

**收益归因**

- 主要：LLM 生成式推荐评测框架与指标设计
- 次要：重复采样估计推荐流行度
- 次要：开源评测数据与软件

**与你的关联**

- 与搜广推中的 LLM 推荐评测方法论相关，但针对品牌推荐场景，离短视频/电商广告主链路较远。

**风险或局限**

- 仅摘要证据，未核验 PDF 正文与指标定义细节
- 样本限于六个 LLM、五个产品品类与品牌推荐场景，未涉及工业推荐/广告线上链路
- 未提供在线 A/B 或部署结论，显著性归因仅为关联性证据

## 今日最值得立项的实验

### Swing近似计算在大规模i2i召回索引构建的离线验证

- 假设：用ASC/K-ASC随机近似算法替代现有Swing全量二次计算，可在保持top-K相似度质量的前提下显著降低i2i索引构建时间。
- Control：沿用现有Swing相似度精确计算流程构建i2i索引，不做近似。
- Treatment：按ASC（GNS+USS自适应处理高度数/低度数查询物品）与K-ASC（filter-refinement top-K查询）实现近似Swing计算并重建i2i索引。
- 保持变量：用户-物品交互图快照、相似度阈值、top-K截断值、召回候选集规模与下游排序链路保持一致。
- 离线指标：索引构建总运行时间与峰值内存；top-K相似度结果与精确Swing的重合率/近似误差；以近似索引驱动的召回Recall@k
- 线上 Guardrail：线上召回覆盖率与CTR/GMV不劣化；索引构建延迟不进入线上服务关键路径；高度数物品的近似误差不导致头部内容召回显著偏移

### 用户弱风险提示路由接入生成式召回链路

- 假设：在现有SID生成式召回链路上，按用户级弱风险分数在推理时切换Simple/Cautious提示，可降低风险用户对上孤立短期与重复交互的过度依赖，同时不显著损害整体推荐质量。
- Control：所有用户统一使用现有Simple提示生成SID候选。
- Treatment：按ReliGRec思路，用行为Token与temporal Graph Token融合估计用户级弱风险分数，对高风险用户切换到Cautious提示生成SID。
- 保持变量：生成式召回模型与SID码本、用户历史构造、下游精排模型与特征、评测口径保持一致。
- 离线指标：整体Recall@k/NDCG@k；风险用户分组的孤立短期重复交互占比；风险分组召回质量与推理成本增量
- 线上 Guardrail：线上A/B整体CTR/GMV不劣化；提示分叉带来的推理延迟与算力增量在预算内；弱风险代理标签不替代真实风控标签，避免误伤正常用户
