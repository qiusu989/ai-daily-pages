## 生成式召回

### P0｜[阿里巴巴、中国科学技术大学、新加坡国立大学｜HERO｜Diverse-Teacher On-Policy Distillation for Generative Recommendation](https://arxiv.org/abs/2611.03272)

**论文、机构与场景**

- **机构：中国科学技术大学、新加坡国立大学、阿里巴巴集团**
- 作者：Zhipeng Yi、Xinyu Lin、Minxuan Shan、Zipeng Chen、Yujiao Zhao、Chuanyu Xu、Wenjie Wang
- 来源：arXiv:2611.03272v1
- 场景：1688 首页“Guess What You Like”生成式推荐
- **论文主要内容：** 针对生成式推荐中OPD放大流行度偏差，提出双教师路由与尾部SID路径增广的HERO框架。

**主要创新或优化点**

- 已有 OPD/GKD 主要沿学生轨迹做 token 蒸馏，未区分教师反馈与 rollout 覆盖带来的流行度偏差；本文指出教师偏好热门 token 与学生少采尾部 SID 会相互强化，并把偏差放大拆成反馈来源与路径覆盖两个可干预环节。
- 异构教师与目标感知路由：按目标物品频次训练头/尾两个教师，并将每个样本路由到与真实目标流行度组匹配的教师；与单一教师或固定混合教师相比，学生能在同一次 OPD 中获得头尾不同的 token 级分布监督。
- 多样性感知物品 rollout：在 student 自生成 SID 轨迹之外，将真实 SID 路径纳入蒸馏，所有样本加 CE，尾部样本再在真实前缀上对齐尾教师，以覆盖学生很少生成的正确尾部路径；该机制不改变推理模型，只改变蒸馏训练信号。

**核心方法**

- 异构教师训练：按训练交互中目标物品频次把头/尾样本分为 D_h/D_t，分别用 D_h 与 ρ 比例 D_t、D_t 与同比例 D_h 从零训练两个冻结教师 q_h/q_t；推理不用教师。
- 多教师 OPD：学生以 trie 约束 Beam-J 生成 SID 轨迹，按真实目标物品所属头/尾组路由教师 q_g，在每条轨迹的生成前缀上以 forward KL 匹配教师的完整下一 token 分布，不通过 beam search 反传。
- 联合目标：所有样本保留真实 SID 的 token CE，尾部样本额外在真实前缀上对齐尾教师 q_t；总损失为 L_rollout+L_GT-CE+I[g=t]L_tail-GT-KL，仅更新 SFT 初始化的学生，推理只保留学生。

**关键结果**

- 1688 首页模块 15 天用户级随机 A/B：HERO 较原生成式推荐器 GMV 提升 3.412%，95% CI [0.759%,6.065%]，p=0.0104；较传统非生成式推荐器 GMV 提升 25.3%，95% CI [21.63%,28.982%]。
- 同一 1688 在线实验中，尾部指标相对原生成式推荐器提升：TailExposure/UV +0.80%、TailClick/UV +3.53%、TailCTR +2.71%，论文称线上推理仅用学生且响应时间无实质变化。
- 离线在 1688 与 Beauty、Pet、MovieLens-1M 上整体与尾部 Hit 均最高；如 1688 的 Click/Pay/Tail Hit@240 为 0.5819/0.7607/0.5416，MovieLens-1M 的 Hit@20/Tail@20 为 0.1936/0.0995。

**收益归因**

- 主要：HERO 整包在 1688 模块取得 GMV +3.412%，收益来自异构教师路由与尾部 SID 路径增广共同提供头尾差异化监督；单模块对 GMV 的因果贡献未拆分。
- 次要：离线消融中，去除 rollout KL 或尾部 GT-KL 会降低整体/尾部命中，支持两类监督信号互补。
- 次要：在线尾部指标同步提升：TailExposure/UV +0.80%、TailClick/UV +3.53%、TailCTR +2.71%，说明收益伴随尾部曝光与点击效率改善。
- 次要：仅学生上线且论文报告响应时间无实质变化，减少推理侧模型替换成本。

**与你的关联**

- 适用于使用 SID 生成式召回、需要蒸馏或后训练且关注流行度偏差与尾部供给的推荐系统；迁移需具备可分组目标频次、可从 SFT 初始化的学生与可冻结的分组教师，并验证线上延迟与多样性收益。

**风险或局限**

- 线上 A/B 仅在 1688 首页单模块、15 天、由作者自行披露，缺少独立复现或开源实现；外推到其他场景需谨慎。
- 尾部在线指标只以相对提升图给出，未报告置信区间或显著性检验；用户级随机分流虽已说明，但新奇效应与长期影响未评估。
- 头/尾划分阈值与跨组比例 ρ=10% 固定，正文未给出敏感性分析；两教师训练与 J 路 beam rollout 的训练成本缺少量化，影响复现预算判断。


### P0｜[快手｜UAGR｜Utility-Aware Generative Recommendation: Utility-Enriched Semantic Codes and Utility-Guided Decoding](https://arxiv.org/abs/2611.02981)

**论文、机构与场景**

- **机构：快手科技（Kuaishou Technology，北京）**
- 作者：Yang Hu、Duo Wang、Ning Li、Kang Li、Junda She、Chengcheng Guo、Kuo Cai、Bin Liu、Youhua Liu、Xiaoshuang Chen
- 来源：arXiv:2611.02981v1
- 场景：快手短视频推荐中的SID生成式召回与在线A/B
- **论文主要内容：** 针对SID忽略效用及beam误删高效用候选，提出UE-SID与UGD对齐多目标效用。

**主要创新或优化点**

- UE-SID针对传统语义SID只按多模态相似度组织、忽略分享/长观看等曝光后效用的问题，在末级LFQ码中重分配少量比特给效用桶，并保留前级语义结构；相比协同信号Token化，它不改变SID长度和词表，且效用位可增量刷新。
- UGD针对生成似然与下游效用错配、beam在中间前缀过早剪掉高效用候选的问题，把多行为效用预测直接并入每步剪枝分数；相比GRPO的序列级对齐和后置重排，它作用在不可逆剪枝发生前，并用stop-gradient隔离主干训练。

**核心方法**

- UE-SID保留前L−1级RQ-KMeans码本，仅将末级改为LFQ二值码；在B位中掩蔽移除后SID冲突增幅最小的B_u位，将释放容量用于物品历史CTR分桶的效用码，再与剩余语义位拼接为末级SID，不增加SID长度和词表。
- UGD复用生成主干在SID位置l的隐藏状态，经stop-gradient和共享MLP投影后，由各曝光行为专属头预测观看时长、长观看、点赞、分享等分数；在beam剪枝时将归一化效用分与累计生成对数似然相加，且效用只计当前步、不跨步累加。
- 训练目标为L_NTP+βL_utility，效用损失按M个行为、L个SID位置加权求和；在线新物品走固定量化器+行为统计查表+分桶+位拼接，效用位每小时刷新，桶边界每周按效用分布重校准。

**关键结果**

- 离线KuaiRand-27K：UAGR的Recall@3=2.7741%、NDCG@3=2.2740%，较最强基线RecForest的2.5748%、1.9516%分别相对提升7.74%、16.52%。
- Kuaishou短视频一周线上A/B（双侧t检验p<0.05）：对比生产基线，App使用时长+0.074%、视频观看时长+0.206%、视频播放量+0.164%，QPS-0.03%。
- 消融/码本：UE-SID将SID冲突率由Base的4.2915%降至0.9801%，ICR=0.9902、Gini=0.0050、熵=8.0918；UE-SID单独使用R@3=2.4089%，高于RQ-KMeans的2.1114%。

**收益归因**

- 主要：线上A/B只支持UAGR整包相对生产基线的收益；UE-SID与UGD的单模块贡献主要由离线消融支持，不能从整包A/B推导单模块在线因果。
- 次要：UE-SID用LFQ和效用位降低SID冲突（离线4.2915%→0.9801%），提升语义相似但效用不同物品的可区分性。
- 次要：UGD在离线消融中单独加入即优于GRPO和后置重排，并提高高效用前缀在beam中的存活比例（L2层+16.3pp）。

**与你的关联**

- 适用于已采用SID生成式召回的短视频/内容推荐系统；若希望在不改生成主干和SID长度的前提下注入多目标效用，可复用UE-SID的末位比特重分配和UGD的beam重打分，但迁移前需校准效用统计口径、分桶边界刷新与多目标权重。

**风险或局限**

- 离线只在KuaiRand-27K上验证，生成主干固定为OneRec-1.7B，未报告其他数据集、模型规模或冷启动物品的分层结果。
- 线上A/B为UAGR整包对生产基线，未给出UE-SID与UGD分别上线的模块级在线实验，0.206%观看时长增益不能在线归因到单个模块。
- UGD四个行为权重固定为0.6/0.2/0.1/0.1，UE-SID离线以经验CTR作为效用统计；正文未给出权重敏感性、桶数选择或跨场景迁移的充分消融。


### P1｜[Meta｜ACT｜Beyond Semantic IDs: Atomic Creator Tokens for Large-Scale Generative Recommendation](https://arxiv.org/abs/2611.00323)

**论文、机构与场景**

- **机构：Meta Platforms（Menlo Park, CA, USA）**
- 作者：Zhuosheng Liu、Yihan Wu、Ziyun Xu、Xiaoxuan Liu、Longfei Yun、Kevin Han、Mingze Gao、Pengfei Wang、Junfeng Pan、Wenjie Fu、Haoran Liu
- 来源：arXiv:2611.00323v1
- 场景：未关注创作者推荐的下一创作者预测，使用 Meta 生产互动数据
- **论文主要内容：** 针对未关注创作者冷启动，提出每创作者一个可训练token的ACT，移除SID并端到端训练。

**主要创新或优化点**

- 指出生成式创作者推荐中 SID 层而非语言模型是冷启动瓶颈：多对一映射产生碰撞并由流行度重排截断创作者级召回，冻结量化器还阻断梯度回传。
- 提出 ACT：用双射为每个创作者分配独立词表 token，移除语义 ID 与码本 join，推理可直接在创作者 token logits 上取 top-k，并让创作者嵌入参与端到端训练。
- 给出头部/长尾路由的适用边界：ACT 覆盖有足够训练样本的头部创作者，稀疏长尾仍交给传统召回，这是对一 token 替代 SID 适用范围的经验界定，而非无条件替换。

**核心方法**

- ACT 为每个候选创作者分配一个独立词表 token，通过双射 φ 将创作者映射到扩展词表（研究中最多 30Y 个 token），模型输出层直接对创作者 token 做 softmax，推理取 top-k 后经 O(1) 查表还原创作者，不需要码本 join 或流行度重排。
- 以 Llama-3.2-3B 为骨干，将用户画像文本与历史中已互动创作者的 token 序列拼接成 prompt，用目标创作者 token 的下一 token 交叉熵训练；创作者嵌入作为词表行参数可被梯度直接更新，另给出可选的 in-batch 对比辅助损失。

**关键结果**

**收益归因**

- 主要：去除多对一 SID 量化与码本 join，使创作者级召回不再受碰撞和流行度 tie-break 截断，并用可训练词表嵌入直接优化下一创作者预测。
- 次要：推理效率：单 token/创作者只需一次解码与 O(1) 查表，避免五 token SID 的多步解码和码本 join；作者报告约 2.7× 更低每用户延迟、较低显存和更高吞吐。
- 次要：训练一致性：创作者嵌入是模型参数，下一 token 交叉熵可直接更新它们，避免冻结量化器与语言模型目标错配。
- 次要：部署可组合性：同一 LLM 骨干加创作者词表即可替换 token 层，适合将 ACT 作为头部召回组件并与长尾传统检索路由组合。

**与你的关联**

- 适用于有大规模创作者或物品词表、需要生成式召回且头部样本充足的场景；可迁移到短视频、直播、电商的作者或商品 token 化召回。需先评估每 token 样本量、词表 softmax 成本、长尾路由和线上显著性。

**风险或局限**

- 线上 A/B 仅报告方向性正向，除对 prod 的产品互动 p≈0.05 外均很小且未给出显著性/置信区间，不能据此认定线上收益已确立。

- 主要：在论文所测 TIGER/RQ-VAE 设置中，把 beam 容量前移到首个 SID 解码步，以更低名义前缀容量复现宽 beam 的有序 top-K，并降低解码延迟。
- 次要：在 RQ-VAE 全测试上输出保持，可在不重训、不改 SID 和分数条件下替换解码预算分配；RQ-KM 未给同等全测试验证。
- 次要：减少后步候选与选择工作量，但前向/缓存路径仍保留，因此解码延迟节省有限。

**与你的关联**

- 适用于采用 SID/RQ-VAE 与 beam search 的生成式召回服务；若线上关注 top-K 输出保持、beam 预算或解码延迟，可用 first-prune depth 定位损失并重分配各 SID 位置宽度。迁移需有精确打分参考和可复现的 SID trie/beam 实现。

### P2｜[Stony Brook University、University of Massachusetts Lowell、Columbia University等｜TRACER: Token ReAssignment for Concept ERasure in Generative Recommendation](https://arxiv.org/abs/2606.07688)

**论文、机构与场景**

- **机构：Stony Brook University、University of Massachusetts Lowell、Columbia University、Institute of Science and Technology Austria、Sapienza University of Rome、National University of Singapore**
- 作者：Ziheng Chen、Jiali Cheng、Zezhong Fan、Hadi Amiri、Diyuan Wu、Gabriele Tolomei、Yang Zhang
- 来源：arXiv:2606.07688v2（NeurIPS 2026）
- 场景：Amazon 商品序列生成式推荐的概念遗忘（品牌/价格带）
- **论文主要内容：** 提出可微 SID token 重分配与语义一致性损失，用于生成式推荐的概念遗忘并保持推荐效用。

**主要创新或优化点**

- 论文称首次把概念遗忘定义为生成式推荐任务，指出 SID 由遗忘/保留物品共享，直接套用 LLM 遗忘会因 token 不可解释且重叠而产生严重 forget-retain 梯度冲突。
- 提出可微 token 重分配：把 RQ-VAE 的逐级最近码字选择松弛为带可学习扰动 φ 的温度 softmax，仅重分配目标概念物品，并用软 token 嵌入保持原码本语义结构。
- 引入语义一致性损失与选择性更新掩码：用 top-K 相似保留物品约束遗忘后的推荐连贯性，只更新高重叠且对遗忘损失有正梯度的 φ，并给出重叠度 Ω 影响 retain loss 的理论界。

**核心方法**

- TRACER 保留预训练 RQ-VAE 的三级码本与层级语义结构，仅对目标概念物品 i∈I_c 引入可学习扰动 φ，将每级最近码字选择松弛为温度 softmax qφ，并以期望 token 嵌入 ẽ 接入 LLM；其他物品固定 φ=0 以保留原 SID。
- 训练目标由四部分构成：保留交互的生成损失 LR、抑制遗忘物品原 SID token 的损失 LF、以 top-K 相似保留物品为正例的 coherence 损失 LCoh，以及对 φ 的 L1 正则；推理仍按 SID 自回归生成下一个物品。
- 选择性更新用掩码 M 只更新同时满足“token 在 retain 集频率高于当前期望频率”和“对 LF 的 φ 梯度为正”的条目；附录给出在弱耦合假设下该更新可降低平均 forget-retain token 重叠 Ω 与 LF 的引理。

**关键结果**

- 在 Industrial & Scientific 的 MOR 骨干上，TRACER 的 Forget HR@5 为 0.080，低于最强基线 PISCES 的 0.101（约低 20.8%），同时 Retain HR@5 为 0.123，接近原模型 0.126。
- 作者在 5 个 GenRec 骨干、3 个 Amazon 数据集上报告：保留集平均保持原模型 97.1% 的 HR/NDCG/MRR，24/25 个 retain 侧比较最佳或并列最佳，语义相似度均值 0.834（原模型 0.852）。
- 效率上，TRACER 在 4×A100 上单次遗忘耗时 19–27 分钟，作者称比 PISCES 快 33.5%、比 REPNoise 快 36.7%，约比 ELM 快 2 倍。

**收益归因**

- 主要：机制与离线消融支持：重分配降低 forget-retain 的 SID 重叠；去掉重分配会同时降低保留效用和遗忘效果，coherence loss 的消融支持其维持语义连贯性。整包离线指标优于基线，但单模块因果仅由消融与机制解释支撑。
- 次要：coherence loss 以 top-K 相似 retain 物品为正例，缓解遗忘目标概念后推荐结果语义不连贯的问题。
- 次要：选择性 φ 更新掩码只更新高重叠且对 LF 有正梯度的 token，设计意图是减少对概念无关 SID 分配的扰动。
- 次要：软 tokenizer 复用预训练码本与层级结构，仅学习小扰动 φ，不重新设计 tokenizer；LLM 仍参与遗忘优化。

**与你的关联**

- 适用于使用 RQ-VAE/SID 的生成式推荐系统做品牌、价格带或物品级概念遗忘；需要能访问 tokenizer、码本、用户序列与推荐模型参数，并接受离线重训练式更新。

**风险或局限**

- 方法假设敏感信息以语义概念形式存在，而非直接编码在 SID 或潜在表示中；对 SID 内嵌个人信息的场景未覆盖。
- 重分配倾向使用 retain 集少用的 token，作者承认未系统研究其与物品流行度的交互，低流行且与重分配 token 重叠的 retain 物品可能被过度影响。
- 实验限于英文 Amazon 商品评论与离线排序指标（5 次运行、4×A100），没有在线 A/B 或生产部署验证，跨语言/跨域与工业规模结论未确认。

- 实证：标准对比SFT放大VLM序列推荐的模态坍缩，融合梯度更随文本梯度，视觉可分性接近1，加图像嵌入反成负迁移；覆盖Beauty/MovieLens/Toys/Clothing及多种VLM。提出弱模态惩罚对比学习（LWPCL）按每用户margin识别弱模态，stop-gradient固定强模态，Softplus加权对比负项；跨模态关系拓扑正则（LCRTR）用双向KL对齐候选集关系分布。

**核心方法**

- 用同一VLM分别以“描述该物品文本序列/图像序列”提示编码整段标题序列和图像序列，取最后一层last-token隐状态并L2归一化，文本与视觉表示直接相加融合；物品侧用单物品同提示编码，最终以序列-物品余弦相似度排序。
- 训练目标为LWPCL+λLCRTR：LWPCL按每用户文本/视觉margin差识别弱模态，以stop-gradient固定强模态、Softplus(margin gap)加权对比负项；LCRTR在候选集上用双向KL对齐文本/视觉的softmax关系分布；仅LoRA微调VLM。
- VLM2Recplug离线预计算所有物品的融合嵌入E，经线性适配器替换SASRec等SR backbone的物品嵌入表，冻结E、只训练适配器与backbone，线上不调用VLM。

**关键结果**

- 在Toys/Beauty/Clothing/Sports/MovieLens全排序评测中，VLM2Rec（Qwen2.5-VL-3B）的N@20较最强基线相对提升10.61%–15.18%，H@20相对提升6.32%–10.65%，5个随机种子paired t-test p<0.05。
- VLM2Recplug以SASRec为backbone时N@20较最强基线相对提升5.18%–13.04%，H@20相对提升8.43%–15.04%；并在DiffuRec/FMLP/GRU4Rec上均取得最优N@20。
- 在Beauty/MovieLens的N@20 dropout test中，标准SFT把TEXT–VISION相对差距从6.9%/7.2%扩大到12.1%/14.6%，VLM2Rec收窄到1.3%/2.0%，并使FUSION高于TEXT和VISION。

**收益归因**

- 主要：收益主要来自LWPCL提升每个用户弱模态的判别力，以及LCRTR对齐文本/视觉关系结构，使融合嵌入从负迁移转为正收益；消融显示去掉LWPCL退化最大，去掉惩罚权重或stop-gradient也会下降。
- 次要：VLM2Recplug把VLM物品嵌入离线缓存后接入SR backbone，线上不调用VLM，使多模态收益可在常规SR服务延迟下使用。
- 次要：至多十次交互物品相对ID-only SASRec增益最大；跨域迁移取得最优；嵌入可复用到DiffuRec/FMLP/GRU4Rec及M3SRec/HM4SR。
- 次要：对Qwen3-VL-Embedding预训练多模态embedder，VLM2Rec仍能缩小TEXT–VISION差距并提升融合N@20。

**与你的关联**

- 适用于需要把商品标题与图像序列用于next-item召回的电商/内容推荐；若线上已有SASRec类backbone，可优先评估VLM2Recplug的离线物品嵌入替换方案，并关注模态坍缩诊断与弱模态加权训练。

**风险或局限**

- 离线全排序评测仅覆盖Amazon四域和MovieLens，5个随机种子；没有真实工业在线A/B、生产流量或长期收益验证，表2增益不能直接外推到线上。
- VLM2Rec直接服务需每次请求编码用户多模态历史，训练和编码成本高于常规SR；VLM2Recplug虽避免在线VLM调用，但论文只报告训练/物品嵌入生成时间，未给出QPS、端到端P99延迟或目录更新成本。
- 主实验的负样本与LCRTR候选集均来自in-batch items；附录显示image-similar hard negatives还能提升，说明主结果未覆盖更难负样本和大候选集下的关系对齐效果。


## 多任务与目标建模

### P1｜[Meta｜LaCo｜Improving Ads Ranking Models with Auxiliary Supervision: Techniques and Insights](https://arxiv.org/abs/2611.01280)

**论文、机构与场景**

- **机构：Meta Platforms, Menlo Park, California, USA（作者邮箱均为 @meta.com）**
- 作者：Nikhil Bhale, Apurva Pathak, SaiSujithKumarReddy MarapaReddy, Xiao Yin, Prateek Bhansali
- 来源：arXiv:2611.01280v1（已被 IEEE ICDM Workshop on AI for Personalization, WAIP 2026 接收，将收录于 ICDMW proceedings）
- 场景：大规模广告排序系统中点击后转化率（pCVR）预估的多任务训练
- **论文主要内容：** 用行为、语义、派生、合成信号作MTL辅助任务提升稀疏pCVR，并提出线性化标签、拆分架构与LaCo。

**主要创新或优化点**

- 把问题从“如何共享参数”转到“用什么信号做辅助任务、如何处理噪声”：用行为、语义、派生、合成四类补充信号构建训练期 MTL 辅助任务，辅助任务不进入推理图。线性化标签按 n-quantiles 分 2–4 桶或按漏斗层级取首个正标签，提供更细粒度监督；拆分架构把 7 天 pCVR 分解为 0–1 天与 1–7 天两个互斥穷尽子任务，专家预测求和后与主任务 ensemble，属问题分解式架构变体；LaCo 在标签设计阶段用 F-Beta 与逻辑算子穷举组合噪声信号，把精度优先策略落为搜索流程。

**核心方法**

- 辅助标签按四类信号构造：行为信号（点击前浏览广告时长、第三方漏斗事件如加购、点击后返回前的 dwell time）、语义信号（会话浏览品类与广告品类匹配、会话 URL 出现转化关键词）、派生信号（用仅在曝光后可得、实时服务不可用的 privileged features 训练代理标签并蒸馏）、合成信号（用用户与广告主内容的视频观看互动生成 pCTR 训练数据）；可表示为概率/布尔值的信号建二分类辅助任务，数值型信号（如 dwell time）可建回归任务且主任务为回归时更有效；论文另称对某些信号做对数变换可能提升效果。
- 线性化标签把连续或序数信号按 n-quantiles 切为 2–4 个桶，转成多类分类任务；也可把漏斗层级标签（conversion、dwell time>10s、HTML 内容加载）按对转化的预测性降序排列，取第一个为正的标签作为真实类别；缺失该信号的样本用 gating 排除在对应辅助任务训练之外，避免被当作负例。
- LaCo 以各信号相对主转化标签的 F-Beta 为选择准则，对不超过 10 个信号的 AND/OR/NOT OR/NOT AND/XOR 组合穷举搜索，选 F-Beta 最高的组合合成单一派生标签；β 在 0.001–10 内网格搜索，最优 β=0.02（精度约 91%、召回中等），β≥1 时性能持续下降；另用 DivideMix、Tri-Training 增强对残留标签噪声的鲁棒性。

**关键结果**

- 基线 pCVR 模型离线 NE=0.5400（越低越好），单项改进为：LaCo 0.5387（相对 −0.25%，单项最大）、线性化标签 0.5392（−0.15%）、拆分架构 0.5393（−0.13%）、噪声标签训练 0.5395（−0.10%）。
- β 调参实验：在转化预测模型上扫描 β 从 0.001 到 10，最优 β=0.02 取得约 91% 精度与中等召回，作者据此主张辅助标签质量应精度优先、再在精度约束下最大化召回。
- 线上：这些技术与其他改进打包上线，在线上 A/B 中广告主转化量取得统计显著提升；论文明确无法拆分单项技术的线上贡献，只说明该量级离线 NE 改善历史上与线上收益相关；训练数据约 50% 样本缺失转化标签，模型每日处理数十亿样本并按天刷新。

**收益归因**

- 主要：各技术在基线 pCVR 模型上的单项离线 NE 改善（−0.10% 至 −0.25%，LaCo 最大）；线上为整包配置收益，不能归因到单模块。
- 次要：线性化标签提供比二值标签更细粒度的辅助监督，相对基线 NE 改善 −0.15%。
- 次要：拆分架构通过互斥穷尽子任务分解与 ensemble，相对基线 NE 改善 −0.13%。
- 次要：LaCo 在标签设计阶段用 F-Beta 与逻辑组合降噪，相对基线 NE 改善 −0.25%。
- 次要：机制解释（非线上实测）：辅助任务仅在训练期使用，论文称推理不使用，因此不改变推理图。

**与你的关联**

- 适用于已有共享底层 MTL 骨架、CVR 标签稀疏且能取得额外行为/语义/派生/合成信号的广告或推荐精排模型；迁移前提是具备逐信号相对主标签的 precision/recall 统计、按样本可用性 gating 的数据管道，以及以 NE 为主的离线评估；论文称辅助任务不入推理图，因此不增加推理图开销，线上成本仍需结合自身服务确认。

**风险或局限**

- 线上结论来自包含本文技术与其他改进的打包上线，无法隔离任一单项技术的线上贡献，作者仅以历史相关性说明离线 NE 幅度与线上收益相关。
- 模型性能离线评测以 NE 为主，未报告校准、AUC 或分场景模型指标；标签质量评估使用 precision/correlation/recall，不等同于排序指标。各单项离线相对提升 0.10%–0.25%，未报告统计显著性。
- 分桶数 2–4 与 β=0.02 来自本文实验设置；论文明确 β 最优随模型、数据分布和训练管线变化，分桶阈值也需按场景调整，n≤10 仅为组合搜索可行性设定；未给出跨模型或跨场景复现实验。


## 偏差与校准

### P2｜[Meta、上海交通大学安泰经济、管理学院｜ACRC｜Efficient Conformal Calibration for Paired Recommendation Decisions](https://arxiv.org/abs/2611.01053)

**论文、机构与场景**

- **机构：上海交通大学安泰经济与管理学院（Antai College of Economics and Management, Shanghai Jiao Tong University）；Meta**
- 作者：Xinyu Qiao, Yichen Lin, Zhewen Chen, Xue Wang, Tao Yao
- 来源：arXiv:2611.01053v1
- 场景：冻结推荐规则的风险控制后处理校准与配对推荐决策
- **论文主要内容：** 针对冻结推荐规则在风险约束下激活不足，提出先平均后裁剪的共形校准算子 ACRC，并分析其风险有效性…

**主要创新或优化点**

- 提出 ACRC：对分数损失先对辅助 Bernoulli 逆计数做条件平均、最后裁剪，证明可交换损失下期望风险有效且点式激活不低于 raw 和 RB；随机化与条件平均是既有工具，与 raw/RB 内部对照的关键差异是最终裁剪位置，有效性属于 SCoRE 的 e-value 框架，新增点是该具体有效算子及其效率刻画。进一步在固定用户池无放回抽样中保留校准集与评估补集的采样协方差，处理异质用户收益和切换风险约束，给出预算附近正效用增量的渐近条件；这是机制分析，不是部署期正效用证书。同规则控制固定候选提议、拟合头、动作损失、有效动作范围与 C/T 用户，仅替换 raw/RB/ACRC，并用信息匹配 SCoRE 与冻结 Jester 确认检验适用边界。

**核心方法**

- 对冻结规则观察到的分数损失 l_i∈[0,1]，引入条件独立辅助变量 B_i~Bernoulli(l_i)，令 K_B=ΣB_i、A=α(n+1)；ACRC 先算 a(l)=A·E[1/(1+K_B)]，再取 w+(l)=min{1,a(l)}，与 raw 的 min{1,A/(1+Σl_i)} 和 RB 的先裁剪后平均形成裁剪位置差异。
- 对每个风险约束把动作下行损失按标签无关上界 H 归一化为 L=x/H、α=ε/H，计算 w+ 后对多个约束取最小并做 53 位向下量化，得到候选规则的激活概率 p+；服务时以 1-p+ 保留原列表，否则从冻结候选分布采样完整列表。
- 候选规则在 S 上用 b=24 个共享子集和 raw 校准估计的收益选择，冻结后再在独立 C 上做 ACRC 校准，T 只用于评估；这隔离最终标量算子，不联合训练候选提议。

**关键结果**

- 在 KuaiRec、KuaiRand-random、Amazon-Music、Epinions、MovieLens-25M、Jester 六个域、三种 backbone、五个训练种子的同规则控制中，仅替换最终校准算子使平均折现净效用较 raw 提高 0.010226±0.000401、较 RB 提高 0.008337±0.000201；平均实际风险从 raw 的 0.011135/0.004481 升至 0.012495/0.004983（预算 0.02/0.01）。
- 在与信息匹配的 SCoRE（风险预测与收益比两个分数族）比较中，固定候选提议和拟合信息后，ACRC 的平均效用优势为 0.015934±0.001440，18 个设置均值全为正、16 个五种子 95% 配对区间排除 0。
- Jester 冻结确认中，规则和过滤固定、方法在主终点冻结后，同规则同过滤的校准增量较 raw 为 0.011025±0.001082，15 个 backbone/seed 组合均值全正；实际风险 0.014512/0.007563 高于 filtered raw 的 0.012431/0.006466。

**收益归因**

- 主要：同规则下仅替换最终校准算子，使更多有用的候选修改在相同风险预算内被激活；收益取决于上游候选提议本身有正价值。
- 次要：保留分数损失幅度而非压成二值或求和，可恢复部分被风险控制抑制的激活；
- 次要：在固定用户池中显式保留校准集与评估补集的采样协方差，避免把激活增量直接当作效用保证；
- 次要：用标签无关动作范围归一化可收紧有效上界，但不替代最终校准所用的观测动作下行损失。

**与你的关联**

- 适用于推荐/排序后处理中的风险控制与激活校准、离线观察反馈评估；迁移需有冻结候选规则、可观测分数损失、标签无关损失上界和独立校准集，并区分校准集分配平均与单个已实现校准集的风险。

**风险或局限**

- 证据仅来自离线观察反馈池和声明的对称估值 λ=1 净效用，不是点击、平台成本或利润；不能外推到全目录、未来流量或任意候选生成器。
- 风险保证是对校准集分配和服务随机化平均的期望风险，不保护每个用户，也不保证单个已实现校准集的风险低于预算；表3中 shared LightGCN 的经验效用下行 0.020595 已高于 0.02 预算。
- 理论比较限于指定的标量校准算子类，不建立对输入自适应方法或所有用户选择器的支配；与 SCoRE 比较使用共同预算而非匹配实际风险，且 PerK 原生提议、UMC、MIR 等部分设置下并不占优。


## LLM 增强与对话推荐

### P2｜[蚂蚁集团、东北大学计算机科学、工程学院｜PACERec: Progressive Adaptation of LLM Item Embeddings with Collaborative Evidence for Recommendation](https://arxiv.org/abs/2611.03068)

**论文、机构与场景**

- **机构：东北大学（沈阳）计算机科学与工程学院与蚂蚁集团**
- 作者：Junzhao Huang、Xi Wu、Zihan Wang等
- 来源：arXiv:2611.03068v1
- 场景：基于冻结LLM物品嵌入的序列推荐全目录打分与长尾物品推荐
- **论文主要内容：** 用前驱行为目标和频次加权流匹配渐进适配LLM物品嵌入，用于长尾序列推荐。

**主要创新或优化点**

- 针对冻结LLM物品嵌入只保留静态内容相似、难以覆盖序列前驱转移的问题，提出用前驱交互上下文构造固定行为目标，并以频次加权flow matching学习共享速度场，把频繁物品的行为证据迁移到长尾和零交互物品。
- 相对逐物品ID更新或全局几何校准，PACERec不保留物品ID，适配由物品语义条件化的共享流完成，可对无自身可靠行为目标的冷启动/长尾物品直接推断适配表示，同时用位移半径约束和语义锚限制语义漂移。
- 在排序端将适配后的物品表示同时用于序列主干和近期意图残差，并与参数无关的冻结LLM语义相似度分数融合，形成不依赖物品ID的全目录候选打分路径。

**核心方法**

- 语义编码：冻结Qwen3-Embedding-4B的2560维物品嵌入经输入/输出带LayerNorm的两层MLP映射为256维语义源x_i；输出投影以全库嵌入PCA前256维坐标为参照，在随机采样的4,096个物品上以最小二乘初始化，使无交互物品也获得源表示。
- 行为目标与监督：按L=5、衰减0.8汇聚前驱初始源表示，经范数匹配并裁剪到半径2得固定目标p_i（训练前一次算好且固定）；仅c_i≥κ的物品参与flow matching，权重为归一化的sqrt(c_i/(c_i+c0))；κ按训练交互覆盖规则由数据确定，实验取Yelp=5、Beauty/Food=2。
- 渐进适应与排序：以x_i为条件，用含正弦时间嵌入和两个残差MLP的速度场做S=2步Euler更新，累计位移经tanh半径约束得适配表示r_i；序列主干加近期意图残差产生偏好分，再与标准化LLM语义相似度加权融合后全目录排序，推理时全库r_i缓存。

**关键结果**

- 在Beauty、Food、Yelp与SASRec、FMLP-Rec、LRURec的九个设置中四个指标均为最优；相对各设置最强基线，Overall Hit@10提升7.14%–27.00%，Overall NDCG@10提升7.28%–28.41%（相对值，全目录排序）。
- Tail NDCG@10在九个设置平均相对提升33.31%：Yelp 71.01%–79.12%、Beauty 11.47%–15.90%、Food 1.61%–18.29%，均为相对最强基线；尾部按训练频次最低部分物品划分。

**收益归因**

**论文、机构与场景**

- **机构：香港理工大学；南洋理工大学**
- 作者：Liangbo Ning, Siyuan Liang, Yi Zhou, Yifeng Zhang, Qing Li, Wenqi Fan, Dacheng Tao
- 来源：arXiv:2611.02457v1
- 场景：Amazon CDs、Video Games、Musical Instruments 三数据集的下一次物品推荐与全目录排序
- **论文主要内容：** 针对单教师推理蒸馏的知识天花板与盲目监督，提出多教师效用筛选和自探索框架来提升LLM推荐。

**主要创新或优化点**

- MUSE（Multi-Teacher Utility-guided Selection with Self-Exploration）用多教师异构池按实例选轨迹，缓解单教师能力不匹配；渐进自探索把学生轨迹并入候选池，作者称缓解教师知识天花板，离线消融支持但非完全突破；RGUA（Rank-Gain Utility Assessment）按真实物品全目录排名归一化增益选正负轨迹，ConDistill（对比轨迹蒸馏）与ConUtil（对比推理利用）分别约束生成器偏好高效用轨迹、编码器更充分利用正推理。

**核心方法**

- 构建多教师推理候选池：DeepSeek-V3.2-Thinking、Gemini-3-Flash-Preview、GPT-5-Mini 各为每个用户生成一条推理轨迹；学生模型按训练轮次从自身采样推理轨迹（S_max=6，前2轮预热，E_s=10），并与教师轨迹合并为候选池。

- 训练时生成器在最优轨迹上做自回归SFT，并用ConDistill（对比轨迹蒸馏）要求正轨迹的长度归一化对数似然高于负轨迹且间隔随效用差自适应；推荐编码器用学生当前推理做in-batch softmax，并用ConUtil（对比推理利用）惩罚负推理比正推理更接近目标物品。

- 在 CDs and Vinyl（Qwen2.5-3B）上，MUSE 的 N@5=0.0295、H@10=0.0584、H@20=0.0804，均高于最强基线 R2ec 的 0.0243、0.0545、0.0743。
- 在 Video Games（Qwen2.5-3B）上，MUSE 的 H@10 从 R2ec 的 0.0921 提升到 0.1020（作者报告相对提升 10.7%），H@20 从 0.1346 提升到 0.1399。
- 在 Video Games 消融中，将 RGUA 换成随机选轨迹后 H@10 由 0.1020 降至 0.0844；去掉 ConDistill 为 0.0847，去掉 ConUtil 为 0.0915。

**收益归因**

- 主要：多教师异构推理池扩大监督覆盖，RGUA 以全目录排名增益筛选正负轨迹，ConDistill 与 ConUtil 把该信号用于生成器和编码器，从而提升推荐排序。
- 次要：多教师异构监督缓解单教师能力不匹配；消融中 GPT、Gemini、DeepSeek 单教师变体在三个数据集上均低于完整 MUSE。
- 次要：渐进自探索提供教师池外轨迹；消融中去掉自探索后 Video Games 的 H@10 由 0.1020 降至 0.0998。
- 次要：ConDistill 与 ConUtil 分别改善推理生成和推理利用；消融中去掉 ConDistill 后 H@10 降至 0.0847，去掉 ConUtil 后降至 0.0915。

**与你的关联**

- 适用于已有LLM推理生成器与轻量推荐编码器的两阶段推荐；若在工业链路复现，需要能离线批量生成并缓存教师轨迹、对全目录做效用评估，并验证在线延迟。

**风险或局限**

- 仅在 Amazon 三个公开数据集上做留一法全目录离线评测，没有在线 A/B、生产候选规模或工业延迟验证，离线增益不能直接外推到线上推荐。

- **机构：Tencent, Beijing, China**

**核心方法**

- PACT 为每个新闻身份汇总来自 16 个生成器-策略组合的离线改写，经实体、事件、数量、时间限定与归属核查，并去除分词截断后可见重复，保留原 ID、类别和点击标签，仅替换标题。
- 训练时对每次候选出现独立抽取固定 m 个改写（默认 m=1，允许放回），辅助前向预算固定为 m 而不随改写池大小增长，且该采样给出池平均一致性目标的无偏估计。
- 对同一原始用户上下文分别计算原标题与改写标题分数，以固定尺度 τ 归一化后的平方差作对称惩罚，梯度同时经过两分支；该惩罚与点击交叉熵损失相加，正负候选角色分别平均后按 λ=0.3 加权，推理不加过滤。

**关键结果**

- MIND-small、5 次运行均值下，9 组攻击-骨干组合中 PACT 的 BSR 与 Expo@50 均最低；三种评估攻击所用的生成器族均未进入防御池（未见生成器迁移设定）。LANCE 攻击下相对最强防御基线，NAML/NRMS/LSTUR 的 BSR 再降 2.2、3.0、1.6 个百分点。
- 重训练攻击（RQ5，攻击预算匹配、5 次运行均值）下，PACT 在全部 6 组攻击-骨干组合的 RankGain 与 BSR 最低：重训练 LANCE 下 NRMS 的 RankGain 为 1248.5（SheepDog-adapted 1735.8），BSR 0.552 对 0.589。
- LANCE 攻击输入下的效用呈骨干依赖（5 次运行、run 内配对未取整分数算相对变化）：LSTUR 的 AUC/MRR/nDCG@5/nDCG@10 为 +0.19%/+0.51%/+0.74%/+0.51%，NRMS 为 -0.41%/-0.93%/-1.26%/-0.84%，NAML AUC +0.15% 而 nDCG@5 -0.49%。

**收益归因**

- 主要：整包配置收益及归因边界：pool–sample–align 组合在 9 组攻击-骨干中 BSR 与 Expo@50 最低；池组成消融（同为 PACT 目标、匹配数据量与更新次数）显示 16 源全池在三个骨干的 BSR 均低于单源与纯提示源池，属配置级证据；但 NRMS 上全池 RankGain 反高于纯微调源池，且无移除一致性损失或替换采样的单模块消融，采样仅有无偏性证明（附录 A）。
- 次要：推理阶段不加改写过滤、不增模型分支，作者据此声明零额外延迟；论文未给线上延迟实测，属结构性论证。
- 次要：按正负候选角色分别平均一致性损失，防止数量占优的负样本主导正则项（机制解释，未单独消融）。
- 次要：按生成器族与攻击策略留出评估：RQ1 留出 Gemma 族、RQ2 额外移除 LANCE 或 ATR-2FT 策略，为估计对未见攻击源的迁移提供池层面的评估条件。

**与你的关联**

- 适用于需防御标题或文案改写攻击的新闻与内容推荐排序模型；迁移需具备同一新闻身份下的事实保持改写池、可离线批量生成改写（论文用 16 个生成器-策略组合），并允许在点击损失上叠加分数一致性正则；评估时须保留未入池的生成器族以检验迁移。

**风险或局限**

- 实验仅在 MIND-small 一个新闻数据集、NAML/NRMS/LSTUR 三个骨干上完成，未报告工业在线 A/B、真实平台攻击流量或跨域推荐场景，推广性有限。
- 防御收益依赖离线改写池的生成器与攻击策略覆盖；策略留出时 RankGain 仍增加 77.1–93.7 位、BSR 增加 0.4–0.6 个百分点，说明未见策略下保护变弱。
- 推荐效用存在骨干相关退化：LANCE 攻击输入下 NRMS 的 nDCG@5 下降 1.26%、NAML 排序指标下降；论文仅离线全目录评测，虽固定 m=1 视图预算与 742 次更新，但未报告实际训练耗时、显存与线上延迟实测。

### P2｜[快手、香港理工大学、电子科技大学等｜A/B Agent: A Self-Evolving Agent for Strategy Iteration in Industrial A/B Testing](https://arxiv.org/abs/2608.04625)

**论文、机构与场景**

- **机构：香港理工大学、电子科技大学、西南交通大学、快手科技（Zhuohang Jiang 实习期间完成）**
- 作者：Zhuohang Jiang, Yuxin Chen, Yongsen Pan, Boyang Xia, Zheng Hu, Wenqi Fan, Qing Li, Hongyang Wang, Jun Wang, Zhongbo Sun, Wenwu Ou, Peng Jiang
- 来源：arXiv:2608.04625v2
- 场景：短视频电商推荐系统的策略迭代与线上 A/B 实验优化（Cart GMV、GPM、OPM 及 guardrail 指标）
- **论文主要内容：** 用分层经验树、多路检索与实验树闭环，让 LLM Agent 自动生成并迭代推荐 A/B 策略。

**主要创新或优化点**

- 分层策略经验树：针对扁平 RAG 忽视业务场景、推荐阶段、目标与实验上下文层级关系导致检索错配的问题，把碎片化历史实验拆成策略块并按语义路径索引，同一策略可挂多路径以支持跨场景迁移。
- 多路 Tree-RAG 检索与层级相关性 boosting：在稀疏+稠密融合分数之上叠加树路径距离加权，再经 Qwen-Reranker 精排，使提供给生成阶段的证据与目标场景、阶段、目标对齐，而非仅靠文本相似度。
- 实验树驱动的自演化闭环：用父-子/兄弟对比定位有效改动，以含 guardrail 惩罚项的效用函数权衡核心收益与安全，参数饱和或约束被违反时切换机制，成功与失败实验都回流经验树，区别于只做一次性推荐的 RAG Agent。
- 五维 LLM 评审体系（正确性、证据强度、交付完整性、可行性、新颖性）作为部署前策略筛选与离线评估口径，并用独立评委给出的分数与线上 A/B 结果的相关性、以及多个 judge 与人工排序一致性做校准。

**核心方法**

- 历史知识组织：先用统一的 schema 将历史实验记录（包含业务上下文、推荐阶段、优化目标、策略改动、指标、部署条件）结构化，再由策略 Agent 将每条记录拆成自包含策略块，保留动机、机制、参数、适用条件、结果与风险，并从问题、场景、机制三个视角分别表示，同时进行 schema 校验、指标一致性检查和原子性校验。
- 分层经验树与多路检索：策略块按 domain/scenario/stage/objective 语义路径 π(c) 索引，允许同一条策略挂在多条路径下；检索时对 BM25、TF-IDF、embedding 多路得分归一化后加权融合，再用树路径最短距离计算的层级相关性 boosting，融合后选 top-K 候选，最后由 Qwen-Reranker 精排，作为生成可执行策略和参数配置的证据。
- 实验树驱动自演化：每轮 A/B 节点记录策略、配置、指标与上下文，通过父-子对比（判断单次改动效果）和兄弟对比（挑出最优配置），以置信度加权后的 Δy（ρ_jΔy_j）构造效用 U(v)=Σcore w_j·(ρ_jΔy_j) − λ·Σguard w_k·max(0,−ρ_kΔy_k)；当收敛、预算耗尽或 guardrail 约束阻止继续探索时停止，成功与失败实验均回流为策略块写回经验树（基座模型 GLM-5.1）。

**关键结果**

- 线上 A/B（真实短视频电商推荐，每轮 10% 流量、等量对照组）：第 5 轮策略 GMV +4.829%（CI [2.38, 7.27]）、GPM +4.677%（[2.26, 7.10]）、OPM +0.841%、CVR +0.578%，四类 guardrail 指标平均 +0.342%；Agent 5 轮共 8 天，对比专家 10 轮 14 天（1.75×），专家终版 GMV +2.679%（CI [-0.22, 5.58]），两者置信区间重叠。
- 离线评测（310 条历史策略、3 个工业电商场景，外部评审 DeepSeek-V4.1-Flash 按五维+Overall 打分）：A/B Agent 平均 Overall 8.126，高于最强单模型 Claude-Sonnet-4.6 的 6.704（+21.2%）与最强 RAG 基线 CRAG 的 5.075（+60.1%）；四个独立 LLM judge 与人工评测（A/B Agent 8.235 vs 7.608、7.148）排序一致。
- 评测有效性与消融：五维得分与线上结果正相关（Correctness Pearson 0.742/AUC 0.882，Overall 0.668/0.870）；去掉知识库 Overall 下降 1.739（21.4%），替换经验树 RAG 下降 1.252–1.305，去掉多路检索下降 1.419（离线评分口径）。

**收益归因**

- 主要：经验树检索生成可执行策略并由线上 A/B 反馈自演化的整体框架：5 轮 8 天取得 Cart GMV +4.829%、GPM +4.677%，相对专家 14 天调优为 1.75× 加速；线上未做单模块因果拆分。
- 次要：分层经验树与多路检索的离线消融：去掉知识库 Overall 降 1.739、替换经验树 RAG 降 1.252–1.305、去掉多路检索降 1.419（均为 LLM 评委 Overall 分，非线上因果）。
- 次要：实验树效用函数显式纳入 guardrail 惩罚；迭代轨迹中四类 guardrail 平均变化由 Strategy 1 的 −0.405% 到 Strategy 5 的 +0.342%，论文未做该模块单独因果拆解。
- 次要：五维 LLM 评审可作离线筛选代理：Overall 与线上结果 Pearson 0.668、AUC 0.870；论文未报告评审成本测量。

**与你的关联**

- 适用于已有结构化实验记录和 guardrail 指标定义的推荐系统团队（论文为短视频电商场景）；可迁移组件是语义路径经验树、多路+层级 boosting 检索、实验树效用函数与五维评审表；迁移前需外部验证基线比较的统计检验、跨场景/跨平台适配与经验树数据需求。

**风险或局限**

- 线上对比只有一个专家设计的策略作为基线，且为单平台单场景一次部署；Strategy 5 与专家策略的 GMV 置信区间重叠（[2.38, 7.27] vs [-0.22, 5.58]），论文未报告两者差异的显著性检验。
- 离线结论依赖 LLM 评委（外部 DeepSeek-V4.1-Flash 打分），虽与线上结果相关 0.668–0.742，但仍是替代指标；人工只做系统级风险拦截，PDF 明确不修改 agent 策略，未报告评审者间一致性统计。
- 论文为 arXiv 预印本，首页会议模板与版权信息仍为占位符，未见同行评审；错误分析显示 43.1% 失败为 solution mismatch，跨平台/跨业务迁移未评估，需重建经验树与约束规则属于推测。

- 次要：可复用FuxiCTR插件接口与冻结配置，便于把新数值编码器接入既有数据集-骨干-种子矩阵
- 次要：逐cell AUC、尺度迁移与配对延迟结果可用于离线评估数据分布和延迟预算下的候选，不构成生产选型依据
- 次要：开源脚本与逐种子结果提供复现和审计材料

**与你的关联**

- 适用于CTR/推荐排序中数值特征编码器选型与离线评测；迁移时需按自身数据验证输入尺度、骨干交互结构、延迟预算，并重新调参。

**风险或局限**

- 仅覆盖3个数据集，AutoML-A与AutoML-E同源，不能视为三个独立领域；每个方法只使用一个全局调参预算。

- 次要：资格检查在训练前拦截接口或执行失败，未解决失败跳过评估并记录诊断与成本。
- 次要：共同 3M token 上限下验证增益更高；该比较为整包配置，不能单独归因于某一模块。

## 今日最值得立项的实验

### 生成式召回尾部SID路径增广与组路由蒸馏

- 假设：在固定SID与同一SFT学生下，按目标物品频次路由头/尾教师并对尾部样本在真实SID前缀上额外对齐尾教师，可提升尾部与整体命中且不改推理模型。
- Control：仅真实SID token交叉熵微调的学生模型，推理同约束beam search。
- Treatment：在同一学生上叠加学生beam轨迹的前缀KL蒸馏（尾部样本路由尾教师）与尾部真实前缀尾教师KL项。
- 保持变量：同一SID分词器与物品映射、同一学生初始化与训练样本、同一beam宽度与解码约束、同一评估切分。
- 离线指标：整体与尾部Hit@K、NDCG@K；学生生成的SID分布相对教师的尾部覆盖变化
- 线上 Guardrail：线上仅保留学生、响应时间不劣化；尾部曝光与点击不下降，头部指标不回退

### 精排SID码本端到端联合训练与协同融合消融

- 假设：让CTR梯度经straight-through回传更新RQ码本，并把排序模型初始化的协同嵌入与冻结多模态门控融合，可优于冻结SID精排基线。
- Control：冻结预训练RQ-VAE SID加同架构精排塔。
- Treatment：在同一精排塔上启用可微量化回传、协同与内容门控融合及辅助SID码字预测损失。
- 保持变量：同一物品集与交互切分、同一tokenizer初始化、同一MMoE专家配置与训练预算、同一负采样比例。
- 离线指标：AUC/GAUC及分组AUC；码本更新前后的SID冲突率与重构损失
- 线上 Guardrail：码本刷新不影响线上新物品编码一致性；推理打分延迟与显存不超预算

### beam宽度按SID位置重分配的输出保持验证

- 假设：在相同名义前缀容量预算下把容量前移到首个SID解码步，可复现更宽beam的有序top-K并降低解码延迟。
- Control：当前线上beam宽度配置与默认剪枝。
- Treatment：等名义容量下按SID位置分配宽度，首步多留、末步保证完整物品数。
- 保持变量：同一SID trie与候选合法集合、同一模型权重与打分、同一请求batch与硬件环境。
- 离线指标：Search Recall@K与前缀首丢深度分布；有序top-K与原配置完全一致率、解码延迟分位数
- 线上 Guardrail：输出集合与原配置一致率达标后再灰度；端到端P99延迟不劣化
