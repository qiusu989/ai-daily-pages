# AI 与算力重点简报｜2026-09-26

## ① 今日最重要的 3 件事

### 1. [Near-Oracle KV Selection via Pre-hoc Sparsity for Long-Context Inference](https://arxiv.org/abs/2602.08329)

把长上下文推理的成本瓶颈从“是否稀疏”推进到“稀疏选择可在注意力打分前完成并带有丢弃注意力质量的先验上界”，且给出 CUDA 内核级实现与端到端吞吐数据，改变了 KV cache 稀疏化的工程可落地判断。

证据：arXiv 原始论文，输入标注 PDF 正文已核验；关键结果为论文自报的离线基准与单机 A100 实验，无生产部署或工业 A/B 验证。

### 2. [Learning Generalizable Behaviors for Terminal Agents](https://arxiv.org/abs/2608.22631)

把 agentic RL 的收益归因从“环境数量与多样性”转向“验证器与奖励信号质量”，并给出行为层正则与可复现配方，改变了 Agent 后训练数据与环境设计的优先级判断。

证据：arXiv 原始论文，PDF 正文已核验；结果为离线终端 benchmark 上的论文自报数据，行为验证器消融显示多数行为项无额外收益，无线上验证。

### 3. [Pistis Technical Report](https://arxiv.org/abs/2609.28554)

把 on-policy distillation 与 RL 在同一训练循环内交替编排，并展示冻结策略下自动改进推理 harness 的闭环，为多模态 Agent 的长程稳定训练与测试时编排提供新工程路线。

证据：ByteDance 提交的 arXiv 技术报告，PDF 正文已核验；自评未同行评审，无第三方复现或线上 A/B，27B 未验证 IDRL，PAH 仅在多模态搜索上小幅提升。


## ② 最新 LLM 论文 / 技术报告

### [Near-Oracle KV Selection via Pre-hoc Sparsity for Long-Context Inference](https://arxiv.org/abs/2602.08329)

**机构、作者与来源**

- **机构：University College London、中国科学院深圳先进技术研究院、香港中文大学、南洋理工大学**
- 作者：Yifei Gao、Lei Wang、Rong-Cheng Tu、Qixin Zhang、Jun Cheng、Dacheng Tao
- 来源：arXiv:2602.08329v2
- 场景：长上下文 LLM 推理的 KV cache 稀疏选择（非搜广推）

**核心方法**

- 提出 Pre-hoc Sparsity (PrHS)，在注意力打分前选择 KV 条目，并推导路由互信息扰动上界 ΔI ≤ g(δ̄)=2[h_b(δ̄)+δ̄ log L]，通过控制丢弃注意力质量 δ̄ 提供先验信息保证
- 实例化三个正交预选择器：CIS 沿时间维共享并膨胀相邻相似查询的关键索引集合，PSAW 沿深度维指数收缩滑动窗口，ETF 沿层维冻结早期 token 更新

**关键结果**

- 在 GSM8K 和 COQA 上，CIS 在匹配或更好精度下将检索复杂度降至 HShare 的约 1/3，并避免超过 90% 的 head-layer 检索
- 在 LongBench v2 上 CPE 平均精度下降低于 1%，在超过 128k token 上下文仍有效

**为什么值得读**

- 长上下文 serving 的核心成本在 KV cache 线性增长
- 该工作把稀疏选择前移到注意力打分之前并给出可验证的丢弃质量上界，配合 FlashAttention-2 集成与内核实现，是少见的理论约束与工程收益同时给出的路线，值得评估其 serving 侧迁移成本

**证据边界**

- 所有结果均为离线基准与单机 GPU 实验，未提供生产部署或工业 A/B 验证
- 理论上界只控制 attention-routing 互信息扰动，作者明确不保证下游任务精度直接提升

### [Learning Generalizable Behaviors for Terminal Agents](https://arxiv.org/abs/2608.22631)

**机构、作者与来源**

- **机构：Salesforce AI Research、Carnegie Mellon University（通讯邮箱 @andrew.cmu.edu）**
- 作者：Yihang Yao、Bo Pang、Xuan Phi Nguyen、Ding Zhao、Shafiq Joty、Semih Yavuz
- 来源：arXiv:2608.22631v3（cs.LG，2026-09-24，Preprint）
- 场景：终端（命令行/软件工程）Agent 的 RL 后训练环境与验证器质量研究

**核心方法**

- 提出 Agentic Compositional Generalization 假设：预训练与 SFT 提供低层原子技能，RL 主要塑造组合、路由这些技能的高层多轮行为，因此验证器质量比单纯扩大环境数量与多样性更关键
- RIVER 配方：先用不执行沙箱的 rubric 过滤（八类质量问题，TMax 中超过 60% 环境至少命中一类），再用 GPT-5.4+Terminus-2 harness 做 pass@k=2 oracle 过滤剔除 pass@k=0，得到 RIVER-TMax-3.5K（约 3.5K 环境，<30% TMax）

**关键结果**

- River-8B（Qwen3-8B，SFT+RL）在四个终端 Agent benchmark 平均 19.4±1.2（×10^2），优于 OpenThinker-8B-RL 的 17.8±0.7 与 TMax-RL-8B 的 14.6±1.2
- 仅用不到 30% 的 TMax 环境，RIVER 在 Terminal-Bench-Lite 与 Terminal-Bench-v2.1 上平均 RL 增益分别提升 106% 与 30%（2B–27B 模型）

**为什么值得读**

- 对“RL 到底在 Agent 训练中学到了什么”给出行为 vs 技能的机制解释与 AUC-ROC/RSA 诊断证据
- 并把环境过滤与 advantage shaping 落到可复现配方，对自建 Coding/Terminal Agent 后训练与奖励验证器设计有直接参考价值

**证据边界**

- 全部结果为离线终端 benchmark（OpenThoughts-TBLite、Terminal-Bench-v2.1/Pro、TerminalWorld-Verified），无线上 A/B 或生产部署验证
- 行为验证器消融中只有重复惩罚带来明显整体提升，奖励 verify-before-done 无额外收益，说明行为与任务成功可能只是相关而非因果

### [Pistis Technical Report](https://arxiv.org/abs/2609.28554)

**机构、作者与来源**

- **机构：ByteDance**
- 作者：Pistis Team（Heyun Chen 等）
- 来源：arXiv:2609.28554v1
- 场景：多模态大模型后训练与多模态搜索 Agent

**核心方法**

- Pistis 含 27B 与 9B 两个规模，分别基于 Qwen3.6 与 Qwen3.5，经约 3.2M QA 多模态 SFT 后训练，产出 Thinking 与 Agentic 变体
- 提出 IDRL，在单个训练循环内交替 on-policy distillation（JSD-50）与 RL（SAPO），并加入 step-level positive-advantage suppression 将无效中间步骤正优势置零

**关键结果**

- Pistis-27B-Thinking 在 24 个非 grounding benchmark 平均 82.3，Qwen3.6-27B 为 82.0，Qwen3.8-27B 为 82.4
- 其 6 个 grounding benchmark 平均 80.5，高于 Qwen3.6-27B 的 76.4 和 Qwen3.8-27B 的 71.9

**为什么值得读**

- 把 OPD 与 RL 交替编排、step-level 正优势抑制和冻结策略下的 harness 自动优化组合到同一多模态 Agent 训练与推理体系中，覆盖后训练到测试时编排全链路，适合关注长程多轮工具调用稳定性的团队精读消融设计

**证据边界**

- arXiv 技术报告自评，未同行评审，无第三方复现或线上 A/B
- 27B 变体使用纯 RL，IDRL 仅在 9B 变体验证，27B 同时作为 9B 的 OPD teacher，规模与方法消融不完全隔离
