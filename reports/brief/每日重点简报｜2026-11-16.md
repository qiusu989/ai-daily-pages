**判断影响**

给出 AI 生成代码规模化后的一线审查工程实践：验证左移、多 agent 交叉审查、按风险分级人工审批与轮次预算，并用回滚率与审查轮次分布衡量效果。

**关键变化**

来源：InfoQ 新闻（2026-11-15）；作者：Robert Krzaczyński 报道 Addy Osmani、Morgan Westlee Lunt、Qing Wang 的实践；机构：Anthropic（Claude Code 团队）；场景：AI 生成代码的 PR 审查与合并流程；提交 PR 前，Claude 先运行测试、构建与 lint，另一个独立上下文的 agent 复审改动；每个 PR 由 Claude 驱动的多个审查 agent 独立排查潜在 bug，再由另一组 agent 交叉验证；独立安全审…

**数据与证据**

据 Anthropic，6 月至 9 月 Claude Code 仓库合并 PR 数翻倍以上，需回滚改动比例下降超 40%；据 Anthropic，单轮审查加修复即通过 PR 占比从 65% 升至 78%，需 5 轮及以上占比从 8.9% 降至 1.5%；媒体或社区报道。数据为 Anthropic 自述，未经独立审计或线上 A/B 验证；未披露 PR 总量、回滚定义与统计口径，指标可比性有限；流程依赖 Claude 自身模型能力，迁移到其他 agent 栈的效果未验证
