### [Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control Between Reasoning and Action](https://arxiv.org/abs/2610.31376)

**机构、作者与来源**

- **机构：Queen’s University Belfast、New York University**
- 作者：Chao Gu、Quanyan Zhu
- 来源：arXiv:2610.31376v1
- 场景：LLM Agent 工具调用执行安全，含自主发布 Agent 的测试、审批与部署流程

**核心方法**

- 提出 agentic execution Petri net（AEPN），把能力、审批、预算等表示为 place 中的 mark，把工具调用、消息和记忆写入表示为 transition，并按动作、责任主体与可控性标注 transition
- 准入规则把 LLM 提议映射为候选 transition，要求 validator、Petri 网使能与监督器允许同时通过

**关键结果**

- 形式化证明：若 A1–A4（初始对应、步骤模拟、安全反射、完全中介）成立且监督器安全，则网上的安全性可转移到运行系统
- 在重规划闭环中，传统最大允许监督器可比更严格的安全监督器任意更干扰

**为什么值得读**

- 把 Agent 工具执行安全落到运行状态准入层，用 Petri 网表达审批与预算的一次性消耗并给出安全性转移证明
- 对搭建带审批、回滚护栏的 Agent harness 团队，是可对照的设计框架

**证据边界**

- 安全转移依赖 A1–A4：需完整中介、忠实建模运行状态、认证外部事件
- 接口映射错误或事件未上报会破坏保证

### [RECAP: Looking Once Is Not Enough for Vision-Language Reasoning](https://arxiv.org/abs/2610.30834)

**机构、作者与来源**

- **机构：Peking University、Chengdu Minto Tech**
- 作者：Zhaolu Kang, Tailong Luo, Chenxin Li, Yingjie He, Zhenyu Yu, Fengyu Zhou, Jiachen Qian, Lei Wei, Shuang Chen, Jiachen Li, Eric Hanchen Jiang, Rongchao Zhang, Zhengtao Yao, Hoi Leong Lee, Guansu Wang, Kaiyue Zhou
- 来源：arXiv:2610.30834v1（PDF页脚标注NeurIPS 2026）
- 场景：视觉语言模型长链思维推理中的视觉再访与RL信用分配

**核心方法**

- 将中层若干层、全部头的文本到图像跨模态注意力取均值，计算当前值相对前W个token滑动基线的正跳变，经min-max与温度sigmoid归一化为[0,1]的视觉再访信号，并在进入目标前做stop-gradient
- RECAP保持GRPO采样、裁剪比率和KL锚，将去梯度再访轨迹注入三处：把最近K步再访拼入优势/价值估计输入

**关键结果**

- 在Qwen2.5-VL-7B、InternVL3-8B、LLaVA-OneVision-7B上，RECAP的HallusionBench较GRPO分别+3.8/+3.5/+4.1点，较各自SFT基线+6.5/+6.1/+6.5点，论文称推理与纯文本基准基本保持
- Qwen2.5-VL-72B LoRA设置下，RECAP的HallusionBench为72.9，较LoRA-GRPO的69.8高3.1点

**为什么值得读**

- 将训练时跨模态注意力跳变转为视觉再访信号，注入 GRPO 的折扣与价值估计，在零推理开销下改善 grounding
- 对多模态长链 RL 后训练是低成本可插拔改造

**证据边界**

- 收益依赖跨模态注意力可访问且能代表grounding
- 作者指出短答案、纯文本任务或注意力代理较弱的架构上收益可能更小，显著干扰物或损坏图像区域会误导再访信号

### [AtManRL: Towards Faithful Reasoning via Differentiable Attention Saliency](https://arxiv.org/abs/2604.16158)

**机构、作者与来源**

- **机构：Aleph Alpha Research、TU Darmstadt、Hessian.AI、Lab1141**
- 作者：Max Henning Höth、Kristian Kersting、Björn Deiseroth、Letitia Parcalabescu
- 来源：arXiv:2604.16158v2
- 场景：通用 LLM 链式推理（CoT）的显著性与忠实性训练，非搜广推

**核心方法**

- 将 ATMAN 的加性注意力掩码限制在 CoT token 上，为每个 CoT token 学习一个 [0,1] 抑制值并乘以负常数，掩码可微，初始化全为 1 表示完全抑制
- 对每个 rollout 用梯度下降优化掩码，目标是在教师强制下恢复模型自身答案 token 的概率

**关键结果**

- 作者报告，在 Qwen2.5-3B、Granite-3.3-2B、Phi-4-mini 三个模型和 GSM8K、MMLU、ProofWriter、QuestBench 四个基准上，按平均 CoT 长度匹配比较，AtManRL 在错误注入下的答案改变概率比长度惩罚基线曲线高 3.9 个百分点（ω=0.1）和 4.0 个百分点（ω=0.05）
- 作者报告，在提示注入下，AtManRL 的忠实性（模型切换到提示答案后 verbalize 提示的概率）比长度匹配曲线高 7.7 个百分点（ω=0.1）和 5.7 个百分点（ω=0.05）

**为什么值得读**

- 用可微注意力掩码学习 CoT token 显著性并做奖励，回应 CoT 事后合理化问题
- 思路可复用到推理轨迹诊断

**证据边界**

- 仅评估 2–4B 参数模型，且每个设置只训练一个随机种子
- 更大模型、更多种子下显著性奖励与长度动态是否成立尚未验证
