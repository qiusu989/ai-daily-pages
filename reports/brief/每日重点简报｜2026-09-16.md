## ① 今日最重要的 3 件事

### 1. [VARG: Value-Aware and Ranking-Aligned Generative Retrieval for Dynamic E-commerce Search](https://arxiv.org/abs/2609.14493)

工业级电商搜索生成式召回直连精排的完整系统，涵盖 SID 设计、三阶段 SFT、GRPO 对齐和日更机制，线上 A/B 验证 GMV 正收益，对召回-粗排融合与生成式召回落地有直接参考价值。

证据：线上 A/B

### 2. [TATK: Triple-Aware Top-K Learning with Knowledge-Grounded Verification for LLM-based Sequential Recommendation](https://arxiv.org/abs/2609.14565)

LLM 文本生成式推荐与全目录 top-K 排序目标错配，TATK 用同一元数据图在提示、训练奖励与推理重排三处注入结构证据，在不增加 LLM 前向的前提下提升 NDCG@10，为 LLM 增强精排提供可解释、延迟可控的离线方案。

证据：技术报告

### 3. [Astera Labs Releases Leo 2 CXL Memory Controllers and Leo X Controller for Rackscale Fabric-Attached Memory](https://www.servethehome.com/astera-labs-releases-leo-2-cxl-memory-controllers-and-leo-x-controller-for-rackscale-fabric-attached-memory/)

CXL 内存池与 fabric-attached 内存是缓解 AI 推理 KV cache 与 DDR5 涨价瓶颈的基础设施方向，Leo X 把内存扩展接到加速器 fabric 而非只挂 CPU，可能改变机架级内存拓扑与推理成本结构。

证据：媒体或社区报道
