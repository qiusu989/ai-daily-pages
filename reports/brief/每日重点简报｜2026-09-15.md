# AI 与算力重点简报｜2026-09-15

## ① 今日最重要的 3 件事

### 1. [ChronicleRec: Pre-training Temporally Anchored Tokens for Lifelong User Modeling](https://arxiv.org/abs/2609.12375)

这是昨日论文中唯一带工业级线上 A/B 与生产部署证据的超长用户行为序列工作，把 lifelong user modeling 从逐候选 target-attention 检索改为目标无关、可缓存的时间锚定 token 预训练，直接改变超长序列精排的成本-效果权衡判断。

证据：arXiv v1 预印本（arXiv:2609.12375），含微信朋友圈广告 pCVR 七天线上 A/B：GMV +1.61%，95% 置信区间 [0.678%, 2.547%] 不含零；训练显存 28.0GB、620.3 分钟，约为 Full-Attn 的 4.8 倍加速。但未披露分流设计、延迟/QPS 与缓存写入成本，AdLive 为腾讯内部数据不可复现，离线精度仍低于 Full-Attn，未见同行评审。

### 2. [OneLA: Scaling Linear-Attention Decoding to Large Beams in Generative Recommendation](https://arxiv.org/abs/2609.12399)

把生成式推荐大 beam 解码的瓶颈从模型效果转向线性注意力循环状态的存储与带宽，给出共享状态+紧凑转换记录+祖先索引+融合 GPU kernel 的可复现系统方案，改变 GR serving 侧成本假设；但只有离线评测，尚不足以支撑线上收益结论。

证据：arXiv:2609.12399v1，作者来自香港大学、快手科技与北京大学，PDF 已核验；全模型 decode-forward GPU 时间较受控 FullState 降低 1.54–2.46×，算子级中位加速相对 vLLM/SGLang FullState 为 40.5×/42.5×，405 个算例最大绝对输出误差 4.88e-4。局限为无线上 A/B、输出仅 3–7 token、无业务指标。

## ③ AI 模型 / Agent / Coding

### P2｜[Simple-Attention-Sparsification](https://huggingface.co/tencent/Simple-Attention-Sparsification)

**判断影响**

长上下文 LLM 推理的注意力稀疏化是可复用底层能力，若门控路由质量成立，可用于搜索/推荐链路上的长上下文理解与推理成本压缩。

**关键变化**

腾讯混元发布 SAS（Simple Attention Sparsification），基于 Qwen3-4B/8B/14B 训练稀疏注意力门控路由器，配套 arXiv 2609.13141 与 GitHub 仓库；SAS 为每个 query 学习对 KV block 的排序与选择，在被选 block 上加连续 gate，使语言建模损失可端到端优化离散 Top-K 选择，而非蒸馏稠密注意力分数；发布的是 router-only 检查点（仅 33M/42M 门控参数，64/81 MiB），基座 Qwen3 冻结且…

**数据与证据**

官方仅提供推理与评测方式（MATH、GPQA-Diamond、AIME24/25、LongBench-E、BFCL、VitaBench 脚本），未在候选材料中披露具体稀疏注意力加速比或精度对比数字；声称门控参数可在不重训情况下适配 1024/2048/4096 不同稀疏预算；未披露线上 A/B、生产部署或工业级业务指标；官方发布。仅 router 检查点，必须搭配自定义 sglang fork，标准 transformers 无法直接运行，部署门槛高；候选材料未给出精度-效率权衡的量化结果，也未提供第三方复现；训练数据为数学推理语料 OpenR1-Math-220k，未验证在推荐/广告语料上的迁移效果…
