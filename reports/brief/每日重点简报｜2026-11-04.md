## ② 最新 LLM 论文 / 技术报告

### [The Cost of Mismatch: Noise Amplification in Zeroth-Order Reinforcement Learning](https://arxiv.org/abs/2611.03260)

**机构、作者与来源**

- **机构：华中科技大学、香港科技大学（广州）、香港科技大学、香港大学**
- 作者：Lianmin Chen、Junbin Qiu、Chenxing Wei、Yao Shu、Kun He
- 来源：arXiv:2611.03260v1（NeurIPS 2026）
- 场景：GSM8K/MATH 数学推理的 RLVR 后训练（非搜广推）

**核心方法**

- 将含噪零阶梯度估计精确分解为无噪项与 oracle-noise 项，并证明后者的条件二阶矩由两次有限差分评估的噪声相关性控制
- on-policy RL 的两次评估使用独立采样轨迹，导致 1/μ² 的 oracle-noise 放大

**关键结果**

- 在 Qwen2.5-1.5B/GSM8K 的扰动尺度扫描中，matched BOLT 的归一化 oracle-noise 方差约保持 2.1×10^-2，而 mismatched BOLT 与 on-policy RL 在 μ 从 10^-2 降至 10^-4 时近似按 1/μ² 增长
- Qwen2.5-1.5B/GSM8K 端到端对照中，ZO-BOLT matched 最佳准确率 63.78%，较预训练 52.24% 提升 11.54 个百分点

**为什么值得读**

- 若团队想在有限显存下做 LLM RLVR 后训练，这篇给出机制性解释与可复用设计：共享 minibatch 的匹配差分评估，以及离线固定数据加权 SFT 替代在线 on-policy 的路径，值得优先读

**证据边界**

- 实验仅覆盖 GSM8K/MATH 数学推理与不超过 7B 的模型，MATH 上 ZO-BOLT 与一阶 BOLT 差距明显，DeepSeek-R1-Distill-Qwen-1.5B 仅恢复 21.0% 增益
- 理论分析针对前向有限差分估计，完整 ZoAR 历史复用与 R-AdaZO 自适应预处理的方差和收敛性未给出保证

### [Dynamic Mixed-Precision Routing for Efficient Multi-step LLM Interaction](https://arxiv.org/abs/2602.02711)

**机构、作者与来源**

- **机构：亚利桑那大学、匹兹堡大学、北卡罗来纳大学教堂山分校、中佛罗里达大学**
- 作者：Yuanzhe Li、Jianing Deng、Jingtong Hu、Tianlong Chen、Song Wang、Huanrui Yang
- 来源：arXiv:2602.02711v3
- 场景：ALFWorld、ScienceWorld与TextWorld上的多步LLM智能体推理

**核心方法**

- 用PTQ从同一LLM构造高、低两个精度层，每步先在最高精度层对新增上下文预填充并取得末位归一化隐状态，再由路由器选择解码精度
- 低精度生成的回复KV条目在下一步丢弃并在高精度层重新预填充，使共享KV缓存保持高精度

**关键结果**

- 嵌套量化设置下，DMR在三个基准上平均相对FP16取得2.44倍解码加速，任务成功率与最高精度层相差不超过2.9个百分点，并以W3解码65%–77%的token
- ALFWorld的GPTQ W3/FP16设置下，DMR成功率为86.9%，FP16为87.2%，FP16→W3为75.5%

**为什么值得读**

- 对多步 agent 推理的量化部署给出步级精度调度与 KV 缓存复用设计，回答了固定低精度为何在关键步骤失效，是 agent 推理成本优化中少见的系统级方案

**证据边界**

- 仅评估ALFWorld、ScienceWorld、TextWorld三个文本智能体基准和Qwen3-4B/ER1-7B，无真实生产部署或在线A/B，不能外推为通用agent收益
- 面向批大小1、解码受内存带宽限制的场景

### [Beyond Safe Data: Pretraining-Stage Alignment with Regular Safety Reflection](https://arxiv.org/abs/2606.19168)

**机构、作者与来源**

- **机构：清华大学交叉信息研究院（Institute for Interdisciplinary Information Sciences, Tsinghua University）**
- 作者：Jinhan Li、Kexian Tang、Yihan Xu、Zhuorui Ye、Kaifeng Lyu
- 来源：arXiv:2606.19168v2
- 场景：大语言模型预训练阶段安全对齐

**核心方法**

- 将预训练文档按句切分并合并为不超过约100词的片段，避免在句内切断，超长句截断
- 在每个片段末尾插入一条安全反思，再按原顺序拼回文档

**关键结果**

- 在 MedSafetyWorld 单跳任务中，SRP 的预填攻击 ASR 为 7.60%、良性微调越狱率为 2.20%、一般任务性能为 75.00%
- Filtering 对应 30.60% 和 43.20%，Filtering-plus 越狱率接近 0 但一般性能从 73.46% 降至 53.89%

**为什么值得读**

- 把安全对齐前移到预训练语料，用反思片段训练自监控行为，为对齐鲁棒性的研究路线提供可检验的实证框架与受控合成环境，适合关注预训练/后训练边界的读者

**证据边界**

- 收益依赖闭源威胁模型：移除混合 SFT 样本与 chat template 修改后，良性微调 ASR 从 0.00 升至 20.75，对抗微调 ASR 从 7.00 升至 79.50，开源微调场景仍脆弱
- 真实实验只覆盖 SmolLM2 1.7B、FineWeb-Edu 100B tokens 和 Tulu3 英文子集
