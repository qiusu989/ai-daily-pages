### [Turn-level Multiscale Density Ratio Estimation for LLM Agents](https://arxiv.org/abs/2609.16760)

**机构、作者与来源**

- **机构：Alibaba Group**
- 作者：Zishuo Zhao、Kai Chen、Ao Li、Yuan Liu
- 来源：arXiv 2609.16760v1
- 场景：LLM Agent 多轮任务的后训练对齐优化，非推荐/广告系统

**核心方法**

- 提出 Turn-level Multiscale Density Ratio Estimation（tlm-DRE），按轮次分配不同权重
- 基于多轮任务正负样本空间差距提出非对称 token 级训练目标

**关键结果**

- 在多种 agent benchmark 上与 PPO/DPO/DIL/GRPO 等对齐方法相比取得有竞争力表现（摘要级证据，无具体数字）
- 在域内和域外多轮推理条件下表现稳健（摘要级声明，无量化指标）

**为什么值得读**

- 针对多轮 agent 任务的后训练对齐，按轮次分配权重并采用非对称 token 级目标，值得读在于它把对齐粒度从整条轨迹细化到单轮，是 agent 后训练的一个可参考方向；但输入仅摘要级证据，具体基线数值未披露。

**证据边界**

- 仅摘要级证据，未核实 PDF 正文、具体指标与实验设置
