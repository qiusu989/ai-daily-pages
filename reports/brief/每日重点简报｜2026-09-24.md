# AI 与算力重点简报｜2026-09-24

## ① 今日最重要的 3 件事

### 1. [PACT: From Credit Assignment to Critic Alignment](https://arxiv.org/abs/2609.26355)

把 token 级 credit 从启发式设计变为可由三条正则条件唯一刻画的统计量，并据此统一解释 OPD 教师即隐式 critic、RLOO 期望梯度等价与 GAE 取 λ=1 的原因；若成立，后训练 RL 的 critic 对齐与值估计（BCE 替代 MSE、Actor-then-Critic 顺序）有明确可复现的改进方向。

证据：arXiv 预印本且已核验 PDF 正文，含消融（去 critic 重要性采样校正降 5.13 个百分点）与两套基座结果；但均为离线 benchmark（Avg@16 / pass@1），无同行评审、无线上 A/B 或生产部署证据，且未披露随机种子、重复次数与算力开销。


## ② 最新 LLM 论文

### [PACT: From Credit Assignment to Critic Alignment](https://arxiv.org/abs/2609.26355)

**机构、作者与来源**

- **机构：首页署名 AllSpark Team，根据通讯作者邮箱域名 @pku.edu.cn 与 @xiaohongshu.com 推断为北京大学与小红书**
- 作者：Jiayan Fu、Hang Xu、Yong Zhang、Zhaokai Luo、Yao Hu、Dongyan Zhao、Mu Chuan
- 来源：arXiv:2609.26355v1
- 场景：LLM 后训练 RL 中的 token 级 credit assignment，评测为 agentic 数学推理与 SWE-bench 代码任务

**核心方法**

- 提出完整性、前缀一致性、中立性三条正则条件，证明满足三条件的 token 级 credit 唯一等于 Vi−Vi−1（条件期望之差），且构成鞅差序列
- 粗粒度 credit 可由 token 级聚合得到

**关键结果**

- 数学推理（Qwen3.5-4B + OpenCode，Avg@16）在 AIME 2025、AIME 2026、BeyondAIME、HMMT Nov.2025 平均 72.87%，高于 GRPO 8.80 个百分点、高于 PPO(λ=1.0) 13.16 个百分点
- SWE-bench Verified（Qwen3.6-35B-A3B + Codex）pass@1 为 67.4%，分别高于 GRPO、PPO(λ=1.0)、SAO 2.0、2.4、3.8 个百分点

**为什么值得读**

- 把 LLM 后训练 RL 里长期靠经验设定的 token 级 credit 与 GAE λ、critic 损失形式，收拢到一个可证明的唯一性框架下
- 并给出可复现的 actor-critic 改法

**证据边界**

- credit 定义为统计量（条件期望），论文自述不刻画替换单个 token 的反事实因果效应
- 唯一性依赖作者自设的三条正则条件，改变条件可得到其他自洽的 credit 表示

### [Agent0: Unleashing Self-Evolving Agents from Zero Data via Tool-Integrated Reasoning](https://arxiv.org/abs/2511.16043)

**机构、作者与来源**

- **机构：UNC-Chapel Hill、Google、Stanford University、Recursive Superintelligence**
- 作者：Peng Xia、Kaide Zeng、Jiaqi Liu、Can Qin、Fang Wu、Yiyang Zhou、Caiming Xiong、Huaxiu Yao
- 来源：arXiv 2511.16043v2（COLM 2026）
- 场景：零外部数据下的多轮工具集成推理自进化 Agent 训练

**核心方法**

- 同一 base LLM 初始化两个 agent：curriculum agent 用 GRPO 生成前沿任务，奖励由 executor 自一致性不确定性（p̂ 偏离 0.5 最大）、工具调用次数（λ_tool=0.6、上限 C=4）与重复惩罚合成
- executor agent 在冻结 curriculum 生成的任务池上按 |p̂−0.5|≤δ=0.25 过滤困难任务，用多数投票伪标签训练，并提出 ADPO：按 p̂ 缩放优势、对高歧义样本放宽上裁剪界

**关键结果**

- Qwen3-8B-Base 上数学推理平均从 49.2 提升到 58.2，通用推理平均从 34.5 提升到 42.1，论文称数学提升 18%、通用提升 24%
- 在 Qwen3-8B 数学平均上超过 R-Zero 6.4%、Absolute Zero 10.6%、Socratic-Zero 3.7%

**为什么值得读**

- 展示双 agent 协同进化加工具集成、完全不依赖人工标注数据的自进化训练路径
- 并给出 ADPO 与课程/执行者分工的细节

**证据边界**

- 评测仅覆盖 Qwen3-4B/8B-Base 与数学、通用推理基准，无搜广推任务、线上 A/B 或生产部署验证
- executor 训练依赖多数投票伪标签，论文承认存在标签噪声，未提供人工标注校验或额外监督对照

### [ME-VLM: A Unified VLM for Embodied Cognition and Agent Coordination](https://arxiv.org/abs/2609.24526)

**机构、作者与来源**

- **机构：Li Auto Inc.**
- 作者：Foundation Model团队
- 来源：arXiv:2609.24526v2
- 场景：具身认知与多模态Agent任务，包括物理理解、任务规划、动作执行与恢复，以及自动驾驶和具身导航

**核心方法**

- ME-VLM是一个统一的视觉语言模型，包含4B和35B-A3B两个变体，旨在统一具身认知与多模态Agent能力
- 训练流程包括具身能力注入（两阶段SFT）、分别对具身和多模态Agent专家进行强化学习（能力单元RL与环境循环RL），以及多教师在线策略蒸馏（MOPD）将互补能力合并到单一模型

**关键结果**

- ME-VLM 35B-A3B在26个具身基准上平均得分70.9，超过最强基线PhysBrain 1.5-8B 8.2分
- 在Agent基准上平均72.5，超过RynnBrain 1.1-9B 9.6分

**为什么值得读**

- 把具身认知与多模态 Agent 能力用多专家 RL 加多教师在线策略蒸馏合并进单一模型
- 并给出视觉 token 压缩与 W4A8 量化的端侧部署实测

**证据边界**

- 所有基准结果均来自论文自评，未提供独立复现或线上A/B测试证据
- 部分对比基线结果未在原始论文中报告（表中以*标注），且工具调用与长时程Agent任务仍落后于RynnBrain 1.1-9B
