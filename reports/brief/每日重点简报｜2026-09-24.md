# AI 与算力重点简报｜2026-09-24

## ① 今日最重要的 3 件事

### 1. [PACT: From Credit Assignment to Critic Alignment](https://arxiv.org/abs/2609.26355)

把 LLM RL 后训练的瓶颈从采样规模部分转向 token-level credit 定义与 critic 对齐：论文给出 credit 的唯一表示（条件奖励预测的鞅差），并据此设计 Actor-then-Critic 与 BCE critic，在数学推理与 SWE-bench 上同时超过 GRPO/PPO/SAO，影响后训练算法选型。

证据：arXiv 预印本并可核验 PDF 正文，含消融（去掉 critic 重要性采样修正后平均 67.74%，加回 72.87%）；无同行评审、无线上 A/B 或生产部署，评测仅限数学推理与 SWE-bench 两任务。

### 2. [Output-Aware Rotation for INT2 KV-Cache Quantization](https://arxiv.org/abs/2608.02691)

把极低比特 KV-cache 量化的优化目标从 cache 重建误差改为 post-WO 注意力输出误差，改变 INT2 KV-cache 不可用于长上下文推理的判断，直接关系长上下文服务的显存与带宽成本。

证据：arXiv 预印本且已核验 PDF 正文，报告 Qwen3-8B AIME25 与 RULER-NIAH 64K 大幅回升并集成 SGLang paged/prefix-cache；仅离线评测三个模型，无线上 A/B 或生产部署证据。

### 3. [Grow the Harness, Not the Context: From Strategy-Free Scaffolds to Reusable Specialist Agents](https://arxiv.org/abs/2609.26760)

提出 harness 本身为唯一可学习对象、用失败反馈把重复控制固化为可执行代码、LLM 只做语义推理，指向 Agent 在线成本与上下文压力的结构性下降路径，并提升小模型 agent 可用性。

证据：arXiv 预印本且已核验 PDF 正文，六组 benchmark-model 设置中五组成功率最高，报告 LLM 调用减少 76.0–91.8%；每 benchmark 仅 50 任务、每配置 3 次运行，置信区间较宽，成本统计不含离线优化与重试。


## ② 最新 LLM 论文 / 技术报告

### [PACT: From Credit Assignment to Critic Alignment](https://arxiv.org/abs/2609.26355)

**机构、作者与来源**

- **机构：AllSpark Team；据邮箱域名推断 Dongyan Zhao 为北京大学、Mu Chuan 为小红书**
- 作者：Jiayan Fu、Hang Xu、Yong Zhang、Zhaokai Luo、Yao Hu、Dongyan Zhao、Mu Chuan
- 来源：arXiv:2609.26355v1
- 场景：LLM RL 后训练 token-level credit 与 actor-critic 训练，在 agentic 数学推理和 SWE-bench Verified 上评估

**核心方法**

- 论文提出 Completeness、Prefix Consistency、Neutrality 三个正则条件，并证明 token-level credit 唯一表示为 C_i=E[R|F_i]-E[R|F_{i-1}]，即条件奖励预测的鞅差
- PACT 采用 Actor-then-Critic 更新顺序，在 actor 更新后用重要性采样修正 critic 目标，并用 BCE 替代 MSE 训练 critic

**关键结果**

- 数学推理：PACT 在 AIME 2025、AIME 2026、BeyondAIME、HMMT Nov. 2025 上 Avg@16 平均 72.87%，比 GRPO 高 8.80 个百分点，比 PPO(λ=1.0) 高 13.16 个百分点，比 SAO 高 21.73 个百分点
- SWE-bench Verified：PACT pass@1 67.4%，比 GRPO 高 2.0 个百分点，比 PPO(λ=1.0) 高 2.4 个百分点，比 SAO 高 3.8 个百分点

**为什么值得读**

- 给出 token-level credit 在三个正则条件下的唯一表示
- 并将 critic 对齐工程化（Actor-then-Critic、重要性采样修正、BCE 替代 MSE），是后训练 RL 算法设计中可复现、可迁移的参考，值得精读其推导与消融

**证据边界**

- credit 唯一性依赖作者提出的三个正则条件，换条件可得到不同表示
- credit 是统计而非因果，不等同于 token 的反事实因果效应

### [Output-Aware Rotation for INT2 KV-Cache Quantization](https://arxiv.org/abs/2608.02691)

**机构、作者与来源**

- **机构：University of Southern California, Seoul National University, Inha University**
- 作者：Vincent-Daniel Yun, Woosang Lim, Minsoo Cheong, Sunwoo Lee, Murali Annavaram, Sai Praneeth Karimireddy, Sungjoo Yoo
- 来源：arXiv:2608.02691v4
- 场景：长上下文大模型推理中的 INT2 KV-cache 量化

**核心方法**

- OptR 将 post-WO attention-output error 分解为 key-induced 与 value-induced 两项，并直接最小化该输出误差，而非优化 cache 重建或 pre-WO 代理误差
- 方法先做 attention-equivalent key 均值重参数化，再对每个 KV head 学习正交修正 R=R0 exp(A-A^T)

**关键结果**

- Qwen3-8B AIME25：QuaRot-INT2 由 17.33% 提升到 66.67%，OSCAR 由 54.67% 提升到 66.00%，BF16 为 68.00%
- 在三个模型与五个推理/编码基准上，OptR 一致提升 QuaRot 和 OSCAR，平均准确率接近 BF16

**为什么值得读**

- 把量化误差度量放到输出空间而非 cache 重建
- 并保持 paged/prefix-cache 与 fused decoding 兼容，是长上下文推理成本压缩在极低比特方向的参考实现

**证据边界**

- 评测限于 Qwen3-4B/8B 和 Phi4-14B 三个推理模型及推理/编码/长上下文基准，未覆盖通用对话、多语言或工业在线服务
- 校准使用 GPQA-Diamond 解码轨迹，虽报告校准成本，但未验证跨域与跨模型迁移的鲁棒性

### [Grow the Harness, Not the Context: From Strategy-Free Scaffolds to Reusable Specialist Agents](https://arxiv.org/abs/2609.26760)

**机构、作者与来源**

- **机构：中科院深圳先进技术研究院；中国科学院大学；深圳理工大学；澳门大学**
- 作者：Laizhen Li, Jiarui Li, Juanjuan Zhao, Kejiang Ye, Ye Li, Cheng-zhong Xu, Xitong Gao
- 来源：arXiv:2609.26760v1
- 场景：LLM Agent harness 学习与网页/深搜任务

**核心方法**

- 从无策略脚手架 h0 出发，固定 LLM 与工具接口，harness 本身是唯一可学习对象
- 函数级执行 trace 将失败定位到被调用的 harness 函数，优化器在失败窗口内联合修复，并受编辑预算 L 约束

**关键结果**

- 在 BrowseComp-Plus 与 WebArena-Verified 的六个 benchmark-model 设置中，五个平均成功率最高，第六个落后最佳均值 0.7 个百分点
- 相对 Tool-Calling，LLM 调用减少 76.0–91.8%，部署 agent 推理成本降低 74.4–98.6%

**为什么值得读**

- 把 Agent 能力增长从上下文扩张转为 harness 代码增长，给出失败定位、编辑预算与 held-out gate 回滚的完整闭环，对 agent 系统工程与成本控制有范式参考价值

**证据边界**

- 最终评估集每个 benchmark 仅 50 个任务、每配置 3 次运行，95% 置信区间较宽，结果可能受任务划分和优化器选择影响
- 在线成本仅统计部署 agent 的 LLM 调用，不含离线优化器、评测器和重试成本
