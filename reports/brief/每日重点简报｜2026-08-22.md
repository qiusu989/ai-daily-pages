## 1、大模型进展与发布

### P1｜[Change Log](https://api-docs.deepseek.com/updates/#date-2026-08-21)

**发生了什么**

DeepSeek 官方更新日志，2026-08-21 发布多模态视觉模型 DeepSeek-V4-Flash-Vision-Exp，通过 API 以模型名 deepseek-v4-flash-vision-exp 访问，实验性模型；DeepSeek-V4-Flash-Vision-Exp 在 Terminal Bench 2.1 上得 83.9，NL2Repo 57.7，DeepSWE 59.3，DSBench-Hard 63.6，ApexBench Pass@1 36.5，ZeroBench Pass@5 35.0，纯文本能力与 DeepSeek-V4-Flash 相当，在需要视觉理解的 agent 基准上显著提升；2026-08-13 更新：DeepSeek-V4-Pro GA 发布，Agent 能力显著增强，HLE 42.7/60.0，Terminal Bench 2.1 87.9，NL2Repo 61.5，DeepSWE 62.7，DSBench-Hard 67.2，原生支持 OpenAI Responses API 并适配 Codex；2026-07-31 更新：DeepSeek-V4-Flash 公开测试，Agent 基准远超 V4-Pro-Preview，原生支持 Responses API。

**为什么重要**

DeepSeek 多模态视觉模型与 V4 系列 GA 更新，显著增强 agent 能力并原生支持 Responses API，标志其模型家族在 agent 与多模态方向持续进化。

**关键技术或数据**

DeepSeek-V4-Flash-Vision-Exp 在视觉理解 agent 任务上较 DeepSeek-V4-Flash 大幅提升，接近 Opus-4.8 的多模态 agent 能力；DeepSeek-V4-Pro GA 版 Terminal Bench 2.1 达 87.9，DSBench-FullStack 71.1，Agent 能力在生产环境显著增强；DeepSeek-V4-Flash 公开测试版 Terminal Bench 2.1 82.7，NL2Repo 54.2，DeepSWE 54.4，Toolathlon verified 70.3。

**我的判断与你的关联**

相关于 agent 平台与模型 API 能力对比，可评估 DeepSeek V4 系列在生产 agent 任务中的适用性。

**可信度与局限**

证据等级：official_product_release。benchmark 为官方自测，使用 DeepSeek Harness minimal mode，未见第三方独立验证；多模态模型为实验性版本，可能不稳定；未见详细的技术报告或开源权重信息。


### P2｜[August 20, 2026](https://platform.claude.com/docs/en/release-notes/overview#event=August%2020%2C%202026)

**发生了什么**

Anthropic于2026年8月20日发布Python SDK v1.0，官方平台发布说明；SDK HTTP层从httpx迁移至httpx2，API兼容的fork，支持自定义http_client等对象；v1.0移除遗留Text Completions API及Messages方法的temperature、top_p、top_k参数；AnthropicBedrock在未配置AWS区域时改为报错，不再默认us-east-1。

**为什么重要**

SDK v1.0是Anthropic官方API客户端的实质能力更新，涉及API行为变化和长期维护方向，对依赖Claude API的开发者有迁移影响。

**关键技术或数据**

SDK v1.0要求Python 3.10及以上；异步客户端.with_raw_response需await response.parse()；提供完整v1迁移指南含before-and-after代码片段。

**我的判断与你的关联**

涉及Claude API的SDK使用，对调用Anthropic模型的工程集成有直接影响。

**可信度与局限**

证据等级：official_product_release。未披露SDK使用量或迁移统计数据；变更仅影响Python SDK，不涉及模型能力本身；证据仅来自官方发布说明，无独立验证。
