## 1、大模型进展与发布

### P1｜[Change Log](https://api-docs.deepseek.com/updates/#date-2026-08-21)

**发生了什么**

DeepSeek 官方变更日志（2026-08-21）发布实验性多模态视觉理解模型 DeepSeek-V4-Flash-Vision-Exp，可通过设置 model='deepseek-v4-flash-vision-exp' 在 API 平台访问；该模型在纯文本能力上与官方 DeepSeek-V4-Flash 持平，在需要视觉理解的 Agent 基准上相比 V4-Flash 有显著提升，多模态 Agent 能力接近 Opus-4.8；变更日志还记录了 2026-08-13 DeepSeek-V4-Pro GA 发布，显著增强 Agent 能力，原生支持 Responses API，并推出低/高/最大三档思考力度控制；API 定价调整为峰谷定价，非峰时段价格为高峰时段的一半，新价格于 2026-08-16 16:00 UTC 生效。

**为什么重要**

DeepSeek 官方连续发布多模态视觉 Agent 实验模型和 V4-Pro GA 版本，多项 Agent 基准成绩突出，且原生支持 Responses API 与 Codex 适配，反映模型能力在 Agent 场景的实质跃升，对 AI 智能体生态有直接影响。

**关键技术或数据**

DeepSeek-V4-Flash-Vision-Exp 在 Terminal Bench 2.1 得分 83.9，NL2Repo 57.7，DeepSWE 59.3，DSBench-Hard 63.6；在 ApexBench (Pass@1) 得分 36.5，Agents' Last Exam 27.3，Chartography 64.3，ZeroBench (Pass@5) 35.0；DeepSeek-V4-Pro GA 版在 Terminal Bench 2.1 得分 87.9，NL2Repo 61.5，Cybergym 83.3，DeepSWE 62.7。

**我的判断与你的关联**

用户若使用 DeepSeek API 构建多模态 Agent 或需要视觉理解，可立即尝试新模型；V4-Pro GA 增强的 Agent 能力和 Responses API 兼容性对生产环境有实际价值；峰谷定价影响调用成本规划。

**可信度与局限**

证据等级：official_product_release。DeepSeek-V4-Flash-Vision-Exp 为实验性模型，稳定性未经长期验证；基准测试方法部分使用 DeepSeek Harness 内部框架，DSBench-FullStack 和 DSBench-Hard 为内部测试集，外部可比性有限；多模态 Agent 能力对标 Opus-4.8 的说法缺乏第三方独立验证。


### P1｜[August 20, 2026](https://platform.claude.com/docs/en/release-notes/overview#event=August%2020%2C%202026)

**发生了什么**

Anthropic 官方于 2026 年 8 月 20 日发布 Claude Python SDK v1.0，属平台发布说明；v1.0 将 HTTP 层从 httpx 迁移至 httpx2（API 兼容的维护分支），要求 Python 3.10+，移除 Text Completions API 及 temperature、top_p、top_k 参数等长期废弃接口；异步客户端 .with_raw_response 结果需 await response.parse()，AnthropicBedrock 在未配置 AWS 区域时改为报错而非默认 us-east-1；官方提供 v1 迁移指南，含变更前后代码示例。

**为什么重要**

官方 SDK 主版本升级，涉及 HTTP 层依赖替换与多处破坏性 API 变更，影响所有基于 Python SDK 的 Claude 集成与模型调用代码。

**关键技术或数据**

SDK HTTP 层切换至 httpx2，兼容构建自定义 http_client、Timeout、transport；支持 httpx2.alias_httpx() 以适配依赖 httpx 的 tracing 或 mocking 库；移除消息方法上的 temperature、top_p、top_k 参数，属于破坏性变更。

**我的判断与你的关联**

如用户项目基于 Anthropic Python SDK，v1.0 迁移涉及 API 参数移除与异步响应解析变更，需评估升级影响。

**可信度与局限**

证据等级：official_product_release。官方文档未披露具体性能或稳定性量化数据；变更影响仅限 Python SDK，未涉及模型能力本身；httpx2 生态兼容性需实际验证。

**发生了什么**

Nvidia research, reported by TechCrunch, demonstrates that AI agents can perform well via harness tuning even if the underlying model is weak；The work highlights the harness (framework, fine-tuning, context management) as key to agent performance, not just the AI model.

**为什么重要**

Refocuses agent development on infrastructure and tuning, relevant to AutoResearch and self-improving systems.

**关键技术或数据**

**我的判断与你的关联**
