# AI 与算力重点简报｜2026-10-02

## ① 今日最重要的 3 件事

### 1. [It's All Training: A Fully Synthetic Single-Stage Recipe for LLMs](https://arxiv.org/abs/2609.37891)

首次以完整 PDF 证据显示全合成单阶段配方可在等算力下超过过滤网页数据，且 600M/MoE 以少 80–700× token 接近 Qwen3-0.6B；把数据质量与可学习性提升为与参数、token 数并列的独立缩放轴，改变对预训练数据来源的判断。

证据：arXiv:2609.37891v1（NeurIPS 2026）同行评审论文，PDF 正文已核验；含 22 项多选与 8 项开放任务、FActScore 与数据消融，但基线架构/tokenizer/后训练不一致，作者自称非受控比较，无线上 A/B。

### 2. [Provable Test-Time Scaling for Beam Search in LLM Reasoning](https://arxiv.org/abs/2609.38672)

给出 beam search 首个样本复杂度下界与修正算法，说明长 horizon 下 beam 剪枝会以高概率丢掉最优响应，把 test-time scaling 的判断从经验调参推进到可证明的解码策略设计。

证据：arXiv:2609.38672v1（NeurIPS 2026）同行评审论文，PDF 正文已核验；Theorem 1、Corollary 1 与 regret 上界为形式化结果，数值实验主要在合成 LLM 模拟器上，真实模型验证有限。

### 3. [PatchKV: Weight-Space Compensation of KV Cache](https://arxiv.org/abs/2609.39329)

提出与 token 空间压缩正交的权重空间补偿，把精度恢复成本从每 query 移到一次性 context-loading，且前向图与每 token 成本不变；为更激进 KV 压缩与长上下文服务成本结构提供新路径。

证据：arXiv:2609.39329v1（NeurIPS 2026）同行评审论文，PDF 正文已核验；在 KVzip、Attention Matching 与多架构多基准上一致提升，但需访问 full KV cache 作 teacher，参考 query 分布近似，多上下文并发服务未解决。


## ② 最新 LLM 论文 / 技术报告

### [It's All Training: A Fully Synthetic Single-Stage Recipe for LLMs](https://arxiv.org/abs/2609.37891)

**机构、作者与来源**

- **机构：PleIAs、Sorbonne Center for AI、EPFL、TU Munich、KU Leuven 等（据 PDF 首页 affiliation）**
- 作者：Pierre-Carl Langlais、Pieter Delobelle、Yannick Detrois、Pavel Chizhov 等 10 人
- 来源：arXiv:2609.37891v1（NeurIPS 2026）
- 场景：通用 LLM 全合成单阶段预训练，非搜广推任务

**核心方法**

- 发布 SYNTH 语料：约 80B token 合成文本、8 种语言，种子为 58,698 篇维基百科文章，把预训练、中期训练与后训练压缩为单一训练阶段
- 两阶段流程：阶段 1 用前沿 LLM 蒸馏数据微调 query 模型（Gemma-3-12B-base LoRA）与 reasoning 模型

**关键结果**

- 等算力下 SYNTH 优于过滤网页数据
- Baguettotron-600M/MoE 位于 token 效率前沿，22 项多选题平均落后 Qwen3-0.6B 4.7 分、8 项开放任务落后 0.7 分，而训练 token 少 80–700×

**为什么值得读**

- 值得读在于它把预训练、中期训练与后训练压成单阶段并给出可复现数据配方与消融，若成立则数据配方质量可与模型规模并列成为缩放轴，直接影响预训练算力预算与开源数据策略
- 同时明确暴露参数知识上限受种子规模约束这一失效模式

**证据边界**

- 参数知识上限受约 58k 维基种子文章限制，在依赖广泛网页知识的基准（ARC-Challenge、GeoBench）明显落后
- 对比基线在架构、tokenizer、数据与后训练上均不同，作者自称仅作参照而非受控同条件比较

### [Provable Test-Time Scaling for Beam Search in LLM Reasoning](https://arxiv.org/abs/2609.38672)

**机构、作者与来源**

- **机构：The Ohio State University、University of Pennsylvania、National University of Singapore**
- 作者：Qijia He、Yu Huang、Yuan Cheng、Yuxin Chen、Yingbin Liang
- 来源：arXiv:2609.38672v1，NeurIPS 2026
- 场景：LLM 推理的测试时计算（beam search 解码）

**核心方法**

- 提出 Confidence-Filtered Beam Search（CF-Beam），在 beam search 每步按估计 token 概率过滤低概率 token，再选 top-b 轨迹
- 证明 vanilla beam search 的样本复杂度下界为 Ω(C⋆(x)^2)，CF-Beam 在 prefix competitiveness 下将足够覆盖依赖从二次降至近线性

**关键结果**

- Theorem 1 构造难实例，证明 vanilla beam search 在 N≤(C⋆(x))²/16 时以至少 0.5 概率剪掉最优响应
- Corollary 1 表明 CF-Beam 每前缀样本量 N=Õ(C⋆_max)，总查询预算 Õ(bL³C⋆_max)，仅多项式依赖 L

**为什么值得读**

- 值得读在于它把 beam search 的测试时扩展从经验技巧变为带下界与 regret 上界的理论对象
- 并揭示前缀可竞争性是优势成立的前提

**证据边界**

- 实验主要在合成 LLM 模拟器上进行，真实预训练 LLM 上的验证有限（附录 H.2）
- 优势依赖 prefix competitiveness 假设（Assumption 3），即似然与最终奖励对齐

### [PatchKV: Weight-Space Compensation of KV Cache](https://arxiv.org/abs/2609.39329)

**机构、作者与来源**

- **机构：KAIST**
- 作者：Chanryeol Lee、Chanhyuk Lee、Yeonwoo Choi、Donggyun Kim、Seunghoon Hong
- 来源：arXiv:2609.39329v1，NeurIPS 2026（40th Conference on Neural Information Processing Systems）
- 场景：单上下文多查询长上下文 LLM 推理下的 KV cache 压缩补偿（长文 QA、检索、数学推理基准）

**核心方法**

- PatchKV 为训练无关框架：在现成压缩 KV cache 之上构造上下文特定的权重补丁，仅在 context-loading 阶段计算一次并服务该上下文后续所有查询，补丁合并后前向图与每 token 推理成本不变
- 补丁由闭式 ridge 回归导出，对每个 transformer block 对齐参考 query token 在 full cache（teacher）与 compressed cache（student）下的 block 激活，补丁加在 MLP 输出投影（down-projection）上，并采用逐 block 贪心求解与自适应 ridge 缩放

**关键结果**

- 在 KVzip（token eviction）与 Attention Matching（cache approximation）两种压缩方法上，PatchKV 在激进预算区间（b/n 0.02–0.1）一致优于仅压缩基线
- SQuAD 上即使不保留任何 KV cache 仍恢复最多 73% 的 full-KV 准确率

**为什么值得读**

- 值得读在于它把 KV 压缩的精度恢复从 token 选择转到权重补丁，且补丁可低秩存储、与前向图解耦，可与 eviction、cache approximation、KV 量化叠加
- 为长上下文服务的显存与带宽权衡提供新的正交手段

**证据边界**

- 参考 query 只是未知下游 query 分布的近似，作者明确指出分布偏移较大时补丁的恢复能力可能受限
- 补丁构造需一次性预处理成本，且必须访问 full KV cache 作为 teacher，适合单上下文多查询或足够长解码的场景
