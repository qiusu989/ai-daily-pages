# AI 与算力重点简报｜2026-10-08

## ① 今日最重要的 3 件事

### 1. [TRACE: Rollout-Guided Quantization-Aware Training for FP4 Reinforcement Learning of MoE Language Models](https://arxiv.org/abs/2610.07767)

把 FP4 RL 的失效机制从单路径量化误差重新定位为训练侧与 rollout 侧量化路径的不一致，并给出只改训练侧 rounding 的低开销对齐方案；若成立，4-bit rollout 可与 BF16 训练稳定性解耦，直接影响 RL 后训练的成本结构。

证据：arXiv 预印本，PDF 正文已核验；作者报告四个 Qwen MoE 规模的离线基准，FP4 分数接近或略超 BF16 参考；无线上 A/B 或生产部署，吞吐与步时为 4/72 张 GB200 受控测量，部分基线数字引自他人论文。

### 2. [Stabilizing Off-Policy Training for Long-Horizon LLM Agent via Turn-Level Importance Sampling and Clipping-Triggered Normalization](https://arxiv.org/abs/2511.20718)

多轮 agent 的 off-policy RL 崩溃问题此前多靠 replay correction 或 value baseline 缓解；SORL 把重要性比率与优势聚合从 token 级上移到 turn 级，并让归一化强度随 clipping 偏置自适应，是算法无关的稳定化层，可接入现有 PPO/GRPO 管线。

证据：arXiv 预印本，PDF 正文已核验；覆盖搜索问答、医疗 QA 与 AIME-2024 离线基准，报告策略梯度范数下降数个量级与后期不崩溃；无线上 A/B 或大规模工业验证，turn 边界依赖训练框架细节。


## ② 最新 LLM 论文 / 技术报告

### [TRACE: Rollout-Guided Quantization-Aware Training for FP4 Reinforcement Learning of MoE Language Models](https://arxiv.org/abs/2610.07767)

**机构、作者与来源**

- **机构：阿里巴巴 Token Hub（Alibaba Group）与俄亥俄州立大学（首页 affiliation 明确）**
- 作者：Xin Wang、Hao Yu、Zhengyang Zhuge 等
- 来源：arXiv:2610.07767v1
- 场景：MoE 大模型 RL 后训练中 FP4（W4A4+FP4 KV）rollout 与训练路径的量化对齐

**核心方法**

- 方法核心为 rollout-guided QAT：记录 rollout 侧 FP4 routed expert 激活与 KV 的量化结果，训练侧在第 9 步归一化后只在相邻两个 E2M1 codeword {q-, q+} 中选与 rollout codeword 更近者，替代标准 RTN
- 为降低引导信息开销，TRACE 只传输选定深层（默认后 20 层）的 mantissa+scale：每生成 token 约 7.5KB（1-bit mantissa、2048×20×1.5 bits），较缓存完整量化激活缩小约 6 倍

**关键结果**

- Qwen3.5-35B-A3B 推理 RL 下 NVFP4 W/A+KV：TRACE 四基准平均 75.3，QUADS 68.8、QaRL 58.6、QAT 59.6，BF16 参考 74.9
- HMMT25 由 QUADS 59.0 提升至 70.0

**为什么值得读**

- 低精度推理与 RL 后训练的交叉点：证明瓶颈在训练/rollout 量化路径不一致而非 FP4 本身精度，且用 mantissa-only 传输缓存压低引导开销。若团队在做 4-bit rollout 或 MoE 后训练，这是可直接复现的改动面最小的路径

**证据边界**

- 证据为 arXiv 预印本与内部模型实验，未披露线上生产 A/B 或实际部署结果，吞吐与步时数据来自 4/72 张 GB200 的受控测量
- 局部 rounding 保证仅在 captured site 且假设能获得精确 rollout codeword 时成立，压缩缓存后只用近似参考，文章未证明全网 discrepancy 或 policy 级 divergence 单调下降

### [Stabilizing Off-Policy Training for Long-Horizon LLM Agent via Turn-Level Importance Sampling and Clipping-Triggered Normalization](https://arxiv.org/abs/2511.20718)

**机构、作者与来源**

- **机构：Texas A&M University、GE HealthCare、Independent Researcher、University of Minnesota**
- 作者：Chenliang Li, Adel Elmahdy 等
- 来源：arXiv:2511.20718v3
- 场景：多轮 LLM agent 的 off-policy RL 训练稳定性，覆盖搜索问答、医疗问答与数学推理

**核心方法**

- 提出 SORL 框架，包含 turn-level importance sampling 与 clipping-triggered normalization，并实例化为 SO-PPO 与 SO-GRPO
- turn-level importance sampling 使用每 turn 的几何平均重要性比率，使同一 turn 内 token 共享聚合优势，将 credit assignment 对齐到 turn 粒度

**关键结果**

- 在 NQ 与 HotpotQA 上，SO-PPO 相比 token-level PPO 显著减少训练后期崩溃，success rate 保持稳定
- turn-level PPO 可将策略梯度范数降低数个量级

**为什么值得读**

- 提供 turn 粒度信用分配与 clipping 触发梯度归一化两个可插拔组件，脱离具体算法，适合作为长程 agent 异步 RL 的默认稳定化检查项
- 同时给出策略梯度范数这一可观测信号，便于在自有管线中验证

**证据边界**

- 仅用 Qwen2.5-7B、Qwen3-4B 等模型和 NQ/HotpotQA/医疗QA/AIME-2024 离线基准，未提供线上 A/B、生产部署或大规模工业验证
- 收益主要来自训练稳定性与避免崩溃，未证明能直接迁移为搜广推工业指标提升

### [DART-ES: Difficulty-Aware Reweighting and Targeted Replay for Fine-Tuning LLMs with Evolution Strategies](https://arxiv.org/abs/2610.06993)

**机构、作者与来源**

- **机构：西安交通大学、SGIT AI Lab**
- 作者：Zhishen Sun、Hongzhan Wang、Sizhe Dang、Guang Dai、Haishan Ye
- 来源：arXiv:2610.06993v1（cs.LG/cs.AI，预印本）
- 场景：以数学推理为主、兼顾代码生成与指令微调任务的 LLM 全参数微调

**核心方法**

- DART-ES 用扰动种群中各题的通过率估计参数邻域可解度 p_j，并用 EMA 累积为动态难度状态，同时驱动扰动方向重加权与稀有可解样本回放
- 连续难度重加权令 w_j=c+exp(-κ·历史通过率)，历史通过率越低权重越高

**关键结果**

- GSM8K 上 DART-ES 五模型平均准确率 73.53%，高于标准 ES 72.07%、ESSAM 73.28%、GRPO 73.26%、GRPO+LoRA 72.42%
- 五个高难度数学基准平均准确率 49.20%，高于 ES 48.34% 与基座 Qwen2.5-Math-7B 26.54%，略低于 Oat-Zero-7B 49.64%

**为什么值得读**

- 把问题级通过率同时用于扰动方向重加权与稀有可解样本回放，说明 ES 这类只做前向、不存梯度和优化器状态的后训练也能利用种群细粒度信息
- 对显存受限下的全参数后训练与数据分配策略有参考价值

**证据边界**

- 全部结果均为离线基准 Pass@1 对比，没有线上 A/B 或生产部署验证
- 核心实验集中在数学推理，跨任务验证仅覆盖指令微调、代码生成与 Countdown 各一项，且覆盖模型规模以 1.5B 至 14B 为主
