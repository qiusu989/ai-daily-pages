## ② 最新 LLM 论文 / 技术报告

### [KaLM-Embedding-Gemma3-12B-2511](https://huggingface.co/tencent/KaLM-Embedding-Gemma3-12B-2511)｜近两日补录

**机构、作者与来源**

- **机构：腾讯混元（Tencent Hunyuan）**
- 作者：未单列
- 来源：Tencent 官方 Hugging Face 模型卡（KaLM-Embedding-Gemma3-12B-2511，2026-11-11）
- 场景：通用文本嵌入与检索、STS、分类、聚类、重排评测

**核心方法**

- 基于 google/gemma-3-12b-pt 构建，模型规模 11.76B、嵌入维度 3840、最大输入 32k，并用 last-token pooling 生成句向量
- 支持 MRL 输出 3840/2048/1024/512/256/128/64 维，允许按存储或检索预算截断向量维度

**关键结果**

- 官方模型卡报告在 MMTEB（截至 2025-11）Borda 排名第 1，Mean(Task)=72.32、Mean(TaskType)=62.51
- 同一表格中 Retrieval 75.66、Classification 77.88、Bitext Mining 83.76 高于 Qwen3-Embedding-8B 的 70.88、74.00、80.89

**为什么值得读**

- 把开源通用嵌入基线推到 12B 级
- 同时给出 32k 输入、MRL 可截断维度与 vLLM 部署路径，值得核实其是否可作为自有检索/重排向量化链路的候选基线

**证据边界**

- 分数和排名均来自 Tencent 官方模型卡，未见独立复现、第三方 benchmark 或工业 A/B，不能视为已验证的线上收益
- 模型卡未披露训练数据规模、训练目标、指令模板构造细节、评测协议，以及吞吐/延迟/显存成本


## ③ AI 模型 / Agent / Coding

### P1｜[Anthropic 官方更新](https://platform.claude.com/docs/en/release-notes/overview#event=November%2012%2C%202026)

**判断影响**

将 Agent 运行时与会话数据整体下沉到自有基础设施，可满足数据驻留与合规要求，并允许切换模型后端。

**关键变化**

来源：Anthropic Platform Release Notes；作者：未披露；机构：Anthropic；场景：Claude Managed Agents 自托管部署；Anthropic 发布自托管 Claude Managed Agents，用户可在自有基础设施上运行完整 Managed Agents 服务，而非仅自托管沙箱；agent、session 与会话历史均存储于用户自有基础设施，服务端将模型请求转发至用户选择的模型提供方，默认 Anthropic；访问需联系 Anthropic 客户团队申请。

**数据与证据**

未披露；官方发布。仅有官方发布说明，无性能、吞吐、部署成本或安全审计的具体数据；未披露自托管与云端版本的功能差异、版本支持策略及迁移路径。
