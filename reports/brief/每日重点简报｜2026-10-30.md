## ② 最新 LLM 论文 / 技术报告

### [Mistral-Large-4-1T-A52B](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B)

**机构、作者与来源**

- **机构：Mistral AI**
- 作者：未单列
- 来源：Mistral 官方 Hugging Face 模型卡（无 arXiv 编号）
- 场景：通用多模态大模型发布

**核心方法**

- MoE 架构约 1T 总参数，每个 token 约 52B 活跃参数（每 token 49B 专家参数，含嵌入和输出层约 52B），128 个路由专家中每个 token 激活 4 个，另有 1 个共享专家
- 使用 3,800 块 NVIDIA Grace Blackwell GPU 从零训练，训练地点为 Mistral 欧洲自有数据中心

**关键结果**

- Artificial Analysis Coding Agent Index：ML4 得分 48%，与领先开权重模型 GLM-5.3 基本持平，平均每任务 token 用量少 47%
- Artificial Analysis Intelligence Index v5：得分 26，在西方开权重模型中最高

**为什么值得读**

- 值得读其 128 专家仅激活 4 个加 1 共享专家的路由设计、3,800 块 Grace Blackwell 从零训练路径、原生可变尺寸视觉编码器与 1M 上下文实现，以及嵌入 DSpark 投机解码 draft head 与 NVFP4 量化的推理效率取舍，作为开源 MoE 预训练与部署的工程样本

**证据边界**

- 两个基准均为 Mistral 自报，Artificial Analysis 指数未附完整基线、任务集与代价口径，缺少第三方复现
- 除两个指数外，安全、金融、法律等领域优势仅为文字声明，未提供具体指标与测试集

### [Guided-RLVR: Guided Exploration in Reinforcement Learning with Verifiable Rewards](https://arxiv.org/abs/2610.37041)

**机构、作者与来源**

- **机构：北京航空航天大学人工智能学院、未来区块链与隐私计算北京高级创新中心（PDF 首页署名 1 Beijing Advanced Innovation Center for Future Blockchain and Privacy Computing, Beihang University、2 School of Artificial Intelligence, Beihang University）**
- 作者：Bo Yang、Zishuai Zhang、Weihua Li、Qinnan Zhang、Sijia Wen、Hainan Zhang
- 来源：arXiv:2610.37041v1
- 场景：LLM 数学推理与代码生成的可验证奖励强化学习

**核心方法**

- Logic Controller 是一个小型 MLP：它先在 OpenThoughts-114k-math 的 DeepSeek-R1 轨迹上做冷启动，用规则标注句界之后出现的 6 类语义动作
- 在 RL 训练时，只有当上一 token 是句末标点、且下一 token 的熵超过动态阈值时才触发。触发后，它对最后 L 层隐状态求和，据此选择动作类别，并在类内按 R1 轨迹频率采样具体 token

**关键结果**

- 在 Qwen2.5-7B-Instruct 与 Qwen3-4B、GRPO 与 DAPO 四组组合上，Guided-RLVR 的十项指标均值均为最高，较最强基线高 1.1–2.8 个百分点（如 Qwen3-4B 加 GRPO 为 72.64，对比 REP 的 69.82）
- AIME2024、AIME2025、AMC2023 的 pass@128 在四组组合中均为最佳或并列最佳

**为什么值得读**

- 值得读其句界与动态熵阈值触发、闭式 logit 抬升至目标概率、以及控制器冷启动与条件化 log-perplexity 奖励的消融设计
- 这套状态条件化 steering 思路可迁移到任何受限于 rollout 预算的 RLVR 后训练流程

**证据边界**

- 实验仅覆盖 Qwen2.5-7B-Instruct、Qwen3-4B 与数学/Code-R1 基准，未验证其他模型族、通用推理或工业部署场景
- 主实验的控制器使用 OpenThoughts-114k-math/DeepSeek-R1 轨迹监督冷启动，而 ENT、REP 等基线未获得同等监督

### [AgentSentry: Mitigating Indirect Prompt Injection in LLM Agents via Temporal Causal Diagnostics and Context Purification](https://arxiv.org/abs/2602.22724)

**机构、作者与来源**

- **机构：武汉大学、纽约州立大学布法罗分校、暨南大学**
- 作者：Tian Zhang、Yiwei Xu、Juan Wang 等 11 人
- 来源：arXiv:2602.22724v2（NDSS 2027）
- 场景：工具增强 LLM Agent 的多轮间接提示注入防御

**核心方法**

- 在工具返回边界保存可重放快照，构造 orig、mask、mask_sanitized、orig_sanitized 四种无副作用反事实重放，以规范化工具调用签名判断待执行动作是否存活
- 由重放存活率计算用户视图替换、探针条件净化、净化后用户锚定和用户保持净化四类归因分，并用局部门控、三边界窗口斜率与延迟匹配触发 takeover

**关键结果**

- AgentDojo 四个任务套件、三类 IPI、三种黑盒骨干上，九个组合均记录 0 次成功攻击
- 平均 UA 76.10%，较最强基线提升 1.84–7.60 个百分点，良性 FPR 2.06%–5.15%

**为什么值得读**

- 值得读其工具返回边界快照与四类反事实重放的源归因、以及净化续跑替代检测即阻断的设计
- 在 1.9–2.2 倍延迟代价下维持任务效用，是 Agent 运行时安全的可借鉴工程范式

**证据边界**

- 零攻击成功不等于总体为零：每个骨干为 0/949，95% CI 上界 0.39%
- AgentDojo 以短程为主，长程压力测试 ASR 仍为 11.46%
