# AI 与算力重点简报｜2026-08-28

## ① 今日最重要的 3 件事

### 1. [OpenAI Details Jalapeño Inference Chip Performance and Multigenerational Roadmap](https://www.hpcwire.com/off-the-wire/openai-details-jalapeno-inference-chip-performance-and-multigenerational-roadmap/)

OpenAI 首次公开自研推理芯片 Jalapeño 的实测性能，覆盖三个外部开源模型，每瓦性能提升 1.5-1.9 倍、端到端延迟降低 1.7-3.6 倍，并给出多代路线图与年底部署计划。这是对自研芯片成本与算力供应格局的重要量化信号，显著改变了此前以 GPU 为基线的判断，直接影响 AI 基础设施成本预期。

证据：来源为 HPCwire 社区报道，数据为 OpenAI 自述与媒体转述，无独立复测或工业 A/B；对比系统与 AI 辅助设计收益均未披露具体细节，存在厂商选择偏差。

### 2. [Google Gemini 发布 gemini-omni-1.1-flash](https://ai.google.dev/gemini-api/docs/models/gemini-omni-flash)

Google 将对话式视频生成与编辑模型正式 GA，新增 extend、image_to_video 任务及 1080p/4k 分辨率能力，并明确预览端点 2026-09-30 弃用。这是由预览转向生产的确定时间表，直接影响依赖 Gemini API 的视频生成与编辑业务流程与迁移计划。

证据：官方 API Release Notes 发布，来源为官方文档，但模型能力与分辨率控制均为官方声明，无第三方独立评测；1080p/4k 依赖 upscaling 生成，原生质量未验证。

### 3. [GLM-5.3-Flash](https://docs.z.ai/release-notes/new-released#event=GLM-5.3-Flash)

Z.ai 发布 320B 总参 18B 激活的混合架构模型，叠加原生视觉闭环与自主工具使用，代表多模态 agent 模型在办公与金融场景的效率方向。作为开源模型在推理成本与 agent 能力上的双重信号，对 Foundation Model 路线与开源性价比判断有直接参考价值。

证据：官方 Release Notes 公告，无基准数字、模型卡、定价或第三方对比，性能与成本声明均为厂商自述，证据等级为官方发布但缺乏独立验证。

### P0｜[Google Gemini 发布 gemini-omni-1.1-flash](https://ai.google.dev/gemini-api/docs/models/gemini-omni-flash)

**判断影响**

这是 Google 官方将对话式视频生成与编辑模型正式商用化的关键发布，扩大了 API 能力并明确了旧端点的退役时间，对依赖视频生成能力的开发者和企业有直接技术影响。

**关键变化**

Google Gemini 官方 API Release Notes 于 2026-08-27 宣布 gemini-omni-1.1-flash 正式可用（GA），这是面向快速对话式视频生成与编辑的模型；新版本新增视频扩展（extend 任务）、图像插值（image_to_video 任务，支持最多 2 张图）、以及视频 360p/720p/1080p/4k 分辨率控制（1080p 和 4k 通过 upscaling 生成）；现有 gemini-omni-flash-preview 端点将于 2026-09-3…

**数据与证据**

GA 版本支持 360p、720p（默认）、1080p 和 4k 四种视频输出分辨率；支持通过 extend 任务或提示直接通过生成续集延长现有视频；支持使用 image_to_video 任务在两张图像之间生成过渡视频（插值）；官方发布。1080p 和 4k 输出依赖 upscaling 生成，可能影响原生分辨率质量；插值任务最多支持 2 张图像，不涉及更长序列的插值；预览端点将于 2026-09-30 弃用，现有用户需迁移。


### P1｜[Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)

**判断影响**

这是 Qwen4 架构的实验性预览，结合稀疏注意力、Gated DeltaNet 和 n-gram 嵌入，代表前沿模型架构方向，可能影响 agent 长上下文场景和效率范式。

**关键变化**

Qwen 官方发布 Qwen3.8-Flash-Next 实验性模型，权重开源，125B 参数含 6B 激活，外加 51B n-gram 嵌入和 4B MTP，属于视觉语言因果模型；该模型引入 Qwen Sparse Attention (QSA) 微块级稀疏注意力、Gated Residual、N-gram Embedding，以及基于 Muon/AdamW 的简化训练流程；架构在 48 层中每层配置 3 个 Gated DeltaNet→MoE 块加 1 个 QSA→MoE 块，原生上下文 262K，可扩展…

**数据与证据**

模型参数规模与架构细节已在官方模型卡中披露，但 benchmark 数值在摘要中被截断；上下文长度 262K 原生可扩展至 1M token，但缺乏独立验证；训练配方声称减少优化器步数并支持更大学习率，但未附具体数据；官方发布。未提供完整 benchmark 数据，无法评估实际能力；属于实验性预览，非生产稳定版本；上下文扩展至 1M 需额外配置，性能未独立验证。


### P1｜[GLM-5.3-Flash](https://docs.z.ai/release-notes/new-released#event=GLM-5.3-Flash)

**判断影响**

GLM-5.3-Flash结合视觉与混合注意力架构，降低推理成本，扩展coding agent能力到办公和金融场景，代表多模态agent模型的发展方向。

**关键变化**

Z.ai 于2026-08-26发布GLM-5.3-Flash，是官方Release Notes公告；模型具备原生视觉能力，可观察界面、渲染结果和交互反馈，形成代码、浏览器与GUI闭环；采用混合架构：线性与稀疏注意力结合，总参数320B，激活18B，降低计算与KV缓存需求；支持办公文档和金融研究流程，能自主拆解目标、使用工具并优化输出。

**数据与证据**

总参数320B，激活参数18B，降低计算与KV-cache需求；原生视觉闭环覆盖代码、浏览器和GUI操作；面向办公文档和金融研究的自主工具使用工作流；官方发布。未提供具体基准测试数字或与竞品对比；未披露模型卡、训练细节或安全评估；未提供API定价或部署方式。
