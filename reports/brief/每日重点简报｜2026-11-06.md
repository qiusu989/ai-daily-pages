# AI 与算力重点简报｜2026-11-06

## ① 今日最重要的 3 件事

### 1. [Understanding Reasoning from Pretraining to Post-Training](https://arxiv.org/abs/2607.16097)

把预训练损失、预训练 token 数与 RL 计算量纳入同一可拟合关系，给出固定预算下预训练/RL 分配的可检验前沿；并用棋类受控环境把 RL 效果拆成正确着法放大、尾部发现与错误模式放大，改变对 RL 只做锐化这一简单判断。

证据：arXiv 技术报告且已核验 PDF 正文，含 10 个模型尺度、11 个预训练预算的扫描；但验证环境为 81 词表棋类、精确二值奖励，最大模型 1B，数学迁移仅单个 1B 模型，属受控与早期证据，非生产验证。

### 2. [Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)

开源家族新增 27B 稠密档位并首次在该规模披露 Gated DeltaNet 与门控注意力 3:1 混合层、MTP 训练与 262K 原生上下文规格，改变长上下文与 Agent 场景开源基座的候选集，但能力增量尚不可核验。

证据：厂商官方模型卡，权重以 Transformers 格式发布并声明兼容主流推理栈；但正文在基准表首单元格即截断，无任何可核验分数，也无第三方评测或线上部署结论，属自述规格。

### 3. [Fractional Power-of-Two Quantization for Efficient and Effective Multiplier-Free LLM Inference](https://arxiv.org/abs/2610.21257)

把 PoT 的基 2 网格细化为基√2 半八度网格并用 1 个加法器近似√2，在 4-bit 下把权重 MAC 的乘法器换成移位加而精度接近均匀 INT，改变无乘法器量化在精度上不可行的判断。

证据：NeurIPS 2026 同行评审论文且已核验 PDF 正文，21 个设置中 20 个满足精度门槛；但硬件收益来自解析门数与外部 5nm RTL 数据外推，无端到端 RTL/ASIC 或服务吞吐验证。


## ② 最新 LLM 论文 / 技术报告

### [Understanding Reasoning from Pretraining to Post-Training](https://arxiv.org/abs/2607.16097)

**机构、作者与来源**

- **机构：New York University、Modal Labs、University of California, Los Angeles、University of Illinois Urbana-Champaign、Columbia University**
- 作者：Jingyan Shen、Ang Li、Salman Rahman、Yifan Sun、Micah Goldblum、Matus Telgarsky、Pavel Izmailov
- 来源：arXiv:2607.16097v3
- 场景：国际象棋谜题与数学推理的预训练到 RL 后训练研究

**核心方法**

- 将国际象棋作为受控测试台，每步棋编码为〈棋子〉〈起点〉〈终点〉〈标志〉四个 token、词表 81，按 Lichess 人类对局序列做自回归下一 token 预训练，模型规模覆盖 5M 到 1B，预训练语料 54B token
- SFT 由基础策略采样 K 条续着，按公共前缀合并成树并按深度优先序列化为棋步推理 trace

**关键结果**

- 在 10 个模型尺度和 11 个预训练预算（6.5×10^16–6.5×10^19 FLOPs）上 RL 提升 pass@1，但大模型的 pass@16 增益较小甚至略降
- 20M 前沿的 RL 计算占比从 5% 升至 32%

**为什么值得读**

- 把预训练/RL 算力分配变成可拟合可检验的前沿关系
- 并用可验证环境解释 pass@1 提升而 pass@16 收益有限的机制，是判断 RLVR 与 reasoning 训练投入时必须读的材料

**证据边界**

- 棋类词表仅 81、验证为逐步精确二值奖励，与自然语言开放动作空间和部分正确奖励差异大，论文明确限制定量外推
- 模型最大 1B，预训练/RL 最优比例随规模的变化未验证，算力分配前沿为拟合外推而非大规模实测

### [Fractional Power-of-Two Quantization for Efficient and Effective Multiplier-Free LLM Inference](https://arxiv.org/abs/2610.21257)

**机构、作者与来源**

- **机构：Seoul National University、LG Electronics**
- 作者：Sunghyun Wee、Geunjae Choi、Hyeonjin Kim、Suyoung Kim、Nojun Kwak
- 来源：arXiv:2610.21257v2（NeurIPS 2026）
- 场景：面向LLM线性层的高效4-bit权重量化与无乘法器推理

**核心方法**

- 先对每个Transformer线性层权重应用OSTQuant式旋转与逐通道缩放，将重尾权重重分布后再用GPTQ校准到基√2的FPoT网格，激活与KV cache保持均匀INT4
- FPoT把权重指数按k=2划分为半八度档位，相邻level间距为√2，最坏相对舍入误差从PoT的41.4%降至18.9%

**关键结果**

- Llama-3-8B W4A4KV4下，FPoT的WikiText-2 PPL为7.60、0-shot9为64.8%，均匀INT为7.36/65.2%，PoT为8.79/59.6%
- 相对PoT的0-shot9提升8.72%，相对均匀INT仅降0.4%p

**为什么值得读**

- 给出以算术单元换精度的具体量化配方与近似网格校准思路，适合评估端侧或专用硬件上 4-bit 线性层推理的可行性与代价

**证据边界**

- 硬件收益主要基于解析门数模型和Przewlocka-Rus等Samsung 5nm RTL数据外推，作者未做端到端RTL/ASIC验证
- Yosys综合给出FPoT/INT约0.57–0.59×而非解析0.50×

### [Qwen3.8-27B](https://huggingface.co/Qwen/Qwen3.8-27B)

**机构、作者与来源**

- **机构：Qwen（阿里）**
- 作者：未单列
- 来源：Hugging Face 官方模型卡（Qwen/Qwen3.8-27B，Apache-2.0）
- 场景：通用视觉语言大模型，面向 Coding、专业工作、研究与长程 Agent 任务

**核心方法**

- 主干为 64 层、隐藏维 5120 的稠密模型，层布局为 16×(3×(Gated DeltaNet→FFN)→1×(Gated Attention→FFN))：线性注意力分支 48 个 V 头/16 个 QK 头、头维 128，门控注意力分支 24 个 Q 头/4 个 KV 头、头维 256、RoPE 维 64
- FFN 中间维 17408，token 嵌入与 LM 输出均为 248,320（padded），并采用多步 Multi-Token Prediction（MTP）参与训练

**关键结果**

- 模型卡给出 Text Performance 对比表，与 Qwen3.6-27B、Qwen3.7-Plus、Muse Glimmer-30B、Opus4.6 Max 并列，但输入正文在表格首个单元格处即被截断，没有任何可核验分数
- 权重与配置以 Hugging Face Transformers 格式发布，声明兼容 vLLM、SGLang、TokenSpeed 等推理栈

**为什么值得读**

- 公开披露了线性注意力与门控注意力 3:1 混合层、MTP 与 262K 原生上下文在 27B 稠密模型上的落地规格，是评估开源长上下文基座架构选择的直接材料
- 但缺少可核验能力数字

**证据边界**

- 输入正文在 Text Performance 表格首个数据单元格处截断，无任何可核验基准分数，无法判断相对 Qwen3.6-27B 等基线的实际增益
- coding、专业工作、长程 agent 等提升均来自厂商自述，未见第三方独立评测、线上 A/B 或部署结论
