## 1、大模型进展与发布

### P1｜[DeepSeek 发布 V4-Flash-Vision-Exp](https://api-docs.deepseek.com/updates/#date-2026-08-21)

**发生了什么**

DeepSeek 官方变更日志（2026-08-21）宣布发布多模态视觉理解实验模型 DeepSeek-V4-Flash-Vision-Exp，可通过 API 以模型名 deepseek-v4-flash-vision-exp 访问；同日日志还回顾了 2026-08-13 DeepSeek-V4-Pro GA 更新：显著增强 Agent 能力，原生支持 OpenAI Responses API，并增加 low/high/max 三种思考强度控制；API 定价将采用峰谷计价，非高峰价格为高峰一半，自 8 月 16 日 16:00 UTC 生效；2026-07-31 官方将 DeepSeek-V4-Flash API 从预览转为公开 Beta，Agent 能力显著增强，并原生支持 Responses API 格式。

**为什么重要**

DeepSeek 官方连续发布新视觉模型、V4-Pro GA 及 V4-Flash 公测，展示 Agent 能力显著提升，并引入峰谷定价和 Responses API 支持，对模型 API 生态和下游 Agent 应用有实质影响。

**关键技术或数据**

DeepSeek-V4-Flash-Vision-Exp 基准：Terminal Bench 2.1 83.9、NL2Repo 57.7、DeepSWE 59.3、DSBench-Hard 63.6、ApexBench Pass@1 36.5、ZeroBench Pass@5 35.0；DeepSeek-V4-Pro GA 基准：Terminal Bench 2.1 87.9、NL2Repo 61.5、Cybergym 83.3、DeepSWE 62.7、Toolathlon-Verified 74.1、DSBench-Hard 67.2；DeepSeek-V4-Flash public beta 基准：Terminal Bench 2.1 82.7、NL2Repo 54.2、Cybergym 76.7、DeepSWE 54.4、Toolathlon-verified 70.3、DSBench-Hard 59.6。

**我的判断与你的关联**

提供可用的实验视觉模型和 V4-Pro/Flash 正式版本，支持 Responses API 和思考力度控制，峰谷定价利于成本优化，适合 Agent 开发者和 API 集成方。

**可信度与局限**

证据等级：official_product_release。部分 benchmark 为内部测试集（如 DSBench-FullStack/Hard），外部可比性有限；实验模型为预览版，稳定性与生产适用性未完全验证；视觉模型在部分评测（ApexBench、Agents' Last Exam）忽略多模态元素，纯文本能力与 V4-Flash 持平，视觉优势仅体现在需视觉理解的 Agent 任务。

### P2｜[AI Code Review at Scale: LinkedIn's Multi-Agent Approach](https://www.infoq.com/news/2026/08/linkedin-ai-code-review/?utm_campaign=infoq_content&utm_source=infoq&utm_medium=feed&utm_term=AI%2C+ML+%26+Data+Engineering-news)

**发生了什么**

LinkedIn 工程师构建多智能体 AI 代码审查平台，应对大规模 PR 审查；来源为 InfoQ 新闻报道，机构为 LinkedIn；平台采用多个独立 AI 审查者（不同模型与推理方式），基于 Kubernetes 事件驱动流水线，支持组织级/仓库级/场景级可组合定制，并过滤低信号评论；评估流水线对比生成建议与合并后代码，抽样 5230 条评论覆盖 1727 个 PR；63.9% 建议被开发者接受，逻辑错误类接受率 80%，并发 bug 类 100%。

**为什么重要**

展示多智能体 AI 代码审查在大型工程组织中的落地方式，提供接受率量化指标与可组合定制、幻觉抑制等可迁移实践。

**关键技术或数据**

63.9% 的 AI 审查建议被接受，逻辑错误 80%、bug 修复 58.1%、重构 43.5%、安全相关 40.6%、并发 bug 100%；90.1% 的抽样评论可基于合并代码高置信评估；多智能体交叉验证：多智能体独立识别同一问题视为强证据，唯一发现单独验证而非丢弃。

**我的判断与你的关联**

若团队关注代码审查自动化或智能体编排，该案例有参考价值；但与搜广推链路无直接关系。

**可信度与局限**

证据等级：community_observation。仅基于第三方新闻，无技术报告或源码核验；接受率由内部评估管线统计，未披露外部复现或独立基准；样本为 5230 条评论，类别间样本量差异未披露，部分类别接受率可能基于少量样本。
