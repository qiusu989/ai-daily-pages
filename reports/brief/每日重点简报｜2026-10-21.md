# AI 与算力重点简报｜2026-10-21

## ① 今日最重要的 3 件事

### 1. [How Data Scales in Agentic Reinforcement Learning: Laws and Synthesis Strategies](https://arxiv.org/abs/2610.23946)

把 agentic RL 的数据瓶颈从“总量”重新定义为 task/environment/trajectory 三轴预算分配问题，并给出可验证的幂律指数、合成数据折扣和 compute-optimal 配方，直接改变 Agent 后训练数据合成与算力投放的判断依据。

证据：arXiv v2 原始论文，PDF 正文已核验；在 Qwen3-4B/8B/14B、Llama-3.1-8B、Qwen2.5-7B 与 PPO/GRPO 上做受控单轴扫描，并用 held-out Qwen3-14B 验证配方；但均为作者离线实验，无生产部署或线上 A/B，SWE 成本系数下 environment 与 task 指数不可区分。

### 2. [Requests of a Feather Must Flock Together: Batch Size vs. Prefix Homogeneity in LLM Inference](https://arxiv.org/abs/2605.06046)

挑战“批越大越好”的默认调度前提，用受控实验显示批内前缀同质性对 decode 吞吐的影响强于批大小，并给出可在线自适应的停止策略与低开销前缀索引，改变推理服务调度与 KV cache 局部性的判断。

证据：SIGOPS ATC 2026 录用论文，PDF 正文已核验；吞吐与 CPU 开销数字为作者单卡实验（RTX 6000 Ada、A100-80GB），负载由 L-Eval/LongBench 剪枝后按 Poisson 合成，非真实生产 trace，无线上 A/B。

### 3. [Power Distribution Bridges Sampling, Self-Reward RL, and Self-Distillation](https://arxiv.org/abs/2605.04542)

把推理时 power sampling、自奖励 KL-RL 与离线自蒸馏统一到同一 power distribution，并给出把昂贵采样成本摊销为离线 SFT 的可行路径，改变推理时搜索成本与后训练流程取舍的判断。

证据：arXiv v2（NeurIPS 2026）原始论文，PDF 正文已核验；核心数字为作者在 Qwen2.5-Math-7B 与 MATH500 等上自测，仅覆盖 7B 及以下模型，未排除基准污染，无独立复现或生产部署。


## ② 最新 LLM 论文 / 技术报告

### [How Data Scales in Agentic Reinforcement Learning: Laws and Synthesis Strategies](https://arxiv.org/abs/2610.23946)

**机构、作者与来源**

- **机构：MBZUAI、McGill University、CityUHK、Columbia University**
- 作者：Bowei He、Yankai Chen、Xiaokun Zhang、Changjiang Han、Ye Yuan、Chong Li、Xue Liu
- 来源：arXiv:2610.23946v2
- 场景：LLM Agent 强化学习的数据缩放与合成预算分配

**核心方法**

- 将 agentic 数据拆为 task、environment、trajectory 三个基数轴，并加入 reward-density 控制变量，分别拟合幂律缩放关系
- 在 Qwen3-4B/8B/14B、Llama-3.1-8B、Qwen2.5-7B 上，跨 math+code、SWE、web、UI/tool、search 域，用 PPO 和 GRPO 做受控单轴扫描

**关键结果**

- Qwen3-8B math+code 拟合指数为 αE=0.41±0.03、αT=0.26±0.02、ατ=0.11±0.02
- αE>αT>ατ 在 21 个设置中保持

**为什么值得读**

- 提供可直接对照的按轴缩放律（αE≈0.41、αT≈0.26、ατ≈0.11）与合成/真实临界比（约 9.4/3.4/1.4），让 Agent 数据合成预算分配从经验判断变为可计算的配方，是当前 agentic RL 数据侧最值得读的方法论材料

**证据边界**

- 作者自述在 SWE 成本系数下 environment 与 task 指数变为不可区分（0.28 vs 0.29），因此不主张 DE 在所有域占优
- 环境结构轴受生成器 inventory 的 384 signatures 上限约束，held-out 验证预测 DE=500 中仅 384 个结构唯一

### [Requests of a Feather Must Flock Together: Batch Size vs. Prefix Homogeneity in LLM Inference](https://arxiv.org/abs/2605.06046)

**机构、作者与来源**

- **机构：Indian Institute of Technology Bombay（作者邮箱 @cse.iitb.ac.in）**
- 作者：Saksham Rathi、Preeti、Mythili Vutukuru
- 来源：arXiv 2605.06046v3（SIGOPS ATC 2026 录用论文，DOI 10.1145/3828523.3857087）
- 场景：LLM 在线推理服务 decode 阶段，前缀共享负载（few-shot、system prompt、RAG、代码库分析）的请求批调度

**核心方法**

- Feather 在调度层把批构建建模为顺序决策：状态为当前批大小 b、加入请求带来的共享前缀损失 Δ、以及新深度下等待请求数 w，动作为 Add/Stop，奖励为实测 decode 吞吐，实例化了启发式、上下文 bandit（UCB）与 Q-learning 三种策略
- Chunked Hash Tree（CHT）用固定大小 chunk 的累积前缀哈希向量替代 token 级 radix tree 遍历，维护 working set、每请求 missing count 与惰性更新最小堆，使最佳请求选择为 O(log W)、插入为 O(T)

**关键结果**

- 在 5 个 5K 前缀组、100 req/s 的负载下吞吐约为 vLLM FCFS 的 4 倍，且平均批大小更小
- 前缀组增至 100 时相对 vLLM FCFS 达 10 倍

**为什么值得读**

- 把推理调度从经验规则升级为带实测奖励的顺序决策
- 并给出可低成本集成的 CHT 前缀索引，适合自建承载 RAG/长 system prompt/Agent 流量的推理栈对照落地

**证据边界**

- 评估均在单卡完成（RTX 6000 Ada 48GB、A100-80GB 对比 PAT），分布式与多 GPU 场景被作者列为未来工作，未验证
- 实验负载来自 L-Eval、LongBench 按需剪枝后以 Poisson 到达合成的请求流，而非真实生产 trace，收益幅度依赖实际前缀共享度

### [Power Distribution Bridges Sampling, Self-Reward RL, and Self-Distillation](https://arxiv.org/abs/2605.04542)

**机构、作者与来源**

- **机构：The University of Tokyo**
- 作者：Akiyoshi Tomihari, Issei Sato
- 来源：arXiv:2605.04542v2（NeurIPS 2026）
- 场景：通用 LLM 数学、代码与科学推理任务的采样、自奖励 RL 与自蒸馏分析

**核心方法**

- 定义 power distribution π_α(y|x) ∝ π(y|x)^α，并证明当奖励取模型序列级 log-prob（self-reward）时，它是 KL 正则 RL 的闭式最优解，α=1+β^{-1}
- 提出 power self-distillation：把自奖励 KL-RL 目标改写为对 π_α 的前向 KL，等价于在离线教师样本上做 completion-only MLE/SFT，从而把 power sampling 成本摊销到训练阶段

**关键结果**

- Qwen2.5-Math-7B 在 MATH500 上，power sampling 将准确率从 base standard 的 0.508±0.016 提升到 0.714±0.006，self-reward 从 -0.316±0.043 提升到 -0.077±0.001
- 同一设置下，power self-distillation 配合温度解码达到 0.722±0.009 准确率，高于 base standard 的 0.508 和 power sampling 的 0.714

**为什么值得读**

- 为“推理时多采样还是离线蒸馏”这一成本取舍提供统一理论框架与可离线摊销方案，对后训练与解码成本规划有参考价值
- 但适用模型规模与任务范围有限

**证据边界**

- 自蒸馏继承基座模型能力，基座较弱时真实奖励增益可能很小
- 提升基座预训练质量不在研究范围
