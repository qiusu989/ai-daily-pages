# AI 与算力重点简报｜2026-10-16

## ① 今日最重要的 3 件事

### 1. [Scalable Power Sampling: Unlocking Efficient, Training-Free Reasoning for LLMs via Distribution Sharpening](https://arxiv.org/abs/2601.21590)

把免训练推理的锐化采样从 MCMC 迭代重采样改为 token 级自回归缩放，报告推理延迟较 MCMC 下降超过 10 倍并匹配 one-shot GRPO，改变了 inference-time compute 与后训练替代方案的成本判断。

证据：arXiv 论文（ICML 2026, PMLR 306），已核验 PDF 正文，Huawei Noah's Ark Lab 与 UCL 作者自测，属作者自报结果；未见独立复现或线上部署证据。

### 2. [$\boldsymbol{f}$-OPD: Stabilizing Long-Horizon On-Policy Distillation with Freshness-Aware Control](https://arxiv.org/abs/2605.17862)

将异步 on-policy distillation 的陈旧数据问题从 buffer 级刷新细化为样本级新鲜度控制，同时建模学生 rollout drift 与教师 supervision drift，改变长程 agentic 后训练中质量-吞吐折中的可行方案判断。

证据：arXiv 论文（NeurIPS 2026），已核验 PDF 正文，港理工作者自测，覆盖数学推理、工具调用与 SWE-bench Verified 编码 agent；无第三方复现，最大规模学生 8B。

### 3. [Titan-Llama: Retrofitting Pre-trained LLMs with External Neural Memory Modules](https://arxiv.org/abs/2610.19210)

用外部神经记忆模块近似历史注意力残差、冻结骨干仅增加约 1% 可训练参数，把长上下文改造从重新预训练转为推理时分块测试时训练，改变已有注意力骨干复用与长上下文成本的判断。

证据：arXiv preprint，已核验 PDF 正文，MIT 与 Cornell 作者自测；实验仅 1B 模型，作者明确键值重构是代理目标且无独立复现与部署验证。


## ② 最新 LLM 论文 / 技术报告

### [Scalable Power Sampling: Unlocking Efficient, Training-Free Reasoning for LLMs via Distribution Sharpening](https://arxiv.org/abs/2601.21590)

**机构、作者与来源**

- **机构：Huawei Noah’s Ark Lab、UCL Centre for Artificial Intelligence**
- 作者：Xiaotong Ji、Rasul Tutunov、Matthieu Zimmer、Haitham Bou Ammar
- 来源：arXiv:2601.21590v2，ICML 2026 (PMLR 306)
- 场景：LLM 推理的免训练推理与采样（数学、代码、QA）

**核心方法**

- 证明自回归 power distribution 可分解为 token 级缩放的低温分布：p(pow)_α(x_t|·) ∝ p_α(x_t|·)ζ_t(x_t)，其中 ζ_t(x'_t) 是未来轨迹在基座模型下的期望似然，从而将全局轨迹级依赖局部化为每 token 标量
- 提出训练免费且无需 verifier 的 Scalable Power Sampling：每步用 Top-K_t 候选，对每个候选做 M_t 次 lookahead rollout 估计 ζ_t，并用 jackknife 估计器校正蒙特卡洛比率偏差，将偏差从 O(1/M_t) 降至 O(1/M_t^2)

**关键结果**

- Qwen2.5-7B：MATH500 0.708、HumanEval 0.756、GPQA 0.349，分别高于 MCMC 的 0.706/0.622/0.318，并在多个基准上匹配或超过 one-shot GRPO（MATH500 0.740、HumanEval 0.561、GPQA 0.354）
- Qwen2.5-Math-7B MATH500 上 MCMC 平均 2.5 分钟/提示，本文方法 0.22 分钟/提示

**为什么值得读**

- 免训练、无需 verifier 的 power 分布采样，把全局轨迹锐化局部化为每 token 标量缩放，用 jackknife 降偏，值得读以评估其替代 MCMC 与部分 RL 后训练流程的可行性边界

**证据边界**

- 实验限于 MATH500、HumanEval、GPQA 等通用推理基准，未在推荐、广告、搜索排序或工业线上场景验证
- 方法仍需多次 rollout 和前向计算，绝对推理成本高于标准解码
- 且未与 Best-of-N 在不同预算下全面对比

### [$\boldsymbol{f}$-OPD: Stabilizing Long-Horizon On-Policy Distillation with Freshness-Aware Control](https://arxiv.org/abs/2605.17862)

**机构、作者与来源**

- **机构：The Hong Kong Polytechnic University**
- 作者：Xianwei Chen、Shimin Zhang、Jibin Wu
- 来源：arXiv:2605.17862v2，NeurIPS 2026
- 场景：LLM 的 on-policy distillation 后训练，覆盖短程数学推理、中程工具调用与长程 SWE coding-agent 任务

**核心方法**

- 将异步 OPD 相对同步 OPD 的目标差分解为 rollout drift（学生策略陈旧导致前缀分布偏移）与 supervision drift（教师条件上下文过期导致监督偏移），并给出基于 TV/KL 的上界式诊断
- 提出样本级 freshness score：用更新滞后 τ_i 与 token 级 KL 诊断 D_roll、D_sup 组合，式 f_i=(τ_i+1)^-1 exp(-α√D_roll-β√D_sup)，作为单调代理而非精确估计

**关键结果**

- SWE-bench Verified 编码 agent：f-OPD 达 1.46× 同步 OPD 吞吐、39.4 resolve，约为同步 41.8 的 94%，post-patch regression 2.6，collapse 0/5
- Vanilla async OPD 吞吐 1.61×，但 resolve 降至 26.8、collapse 3/5

**为什么值得读**

- 把异步蒸馏的不稳定性归因为 rollout drift 与 supervision drift
- 并给出样本级新鲜度控制机制，对异步 RL/蒸馏系统设计与长程 Agent 训练稳定性有直接参考价值

**证据边界**

- 最大学生/教师模型为 8B/30B，未验证更大规模
- 作者明确将结论限定在小规模

### [Titan-Llama: Retrofitting Pre-trained LLMs with External Neural Memory Modules](https://arxiv.org/abs/2610.19210)

**机构、作者与来源**

- **机构：MIT（sarahpan@mit.edu）、Cornell University（ab2947@cornell.edu）**
- 作者：Sarah Pan、Ali Behrouz
- 来源：arXiv:2610.19210v1（preprint）
- 场景：长上下文语言建模与推理，非搜广推任务

**核心方法**

- 方法：将Llamatransformer的注意力输出拆为历史项与局部项，保留局部全保真注意力，用外部神经记忆模块（NMM）读取的残差近似历史注意力，混合权重λ由查询经RMSNorm加线性层预测
- 写入方式：推理时以自监督键值重构损失Lc=||M(Kc)-Vc||^2对NMM做分块梯度更新（带学习到的动量、衰减、步长），骨干参数冻结

**关键结果**

- Llama-3.2-1B-Instruct上QuALITY准确率由分段注意力基线的23.87%提升至40.51%，LongHealth由14.50%提升至40.75%
- 推理基准：prefill快20%以上、中等上下文decode快37%、稳态decode显存低24%（80GB A100，batch size 1）

**为什么值得读**

- 提出免重训的长上下文改造路径：局部全保真注意力加固定大小外部记忆，仅约 1% 新增参数，值得读以判断外部记忆模块相对线性注意力与循环方案的效率取舍

**证据边界**

- NMM对历史注意力的近似不保证无损，作者明确键值重构只是有用记忆的代理目标，而非精确复现历史注意力
- RULER上多值检索在所有长度均低于全注意力，32K（超出16K训练长度）性能下降，长度泛化有限
