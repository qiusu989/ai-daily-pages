## ② 最新 LLM 论文 / 技术报告

### [Flat-RLVR: Sharpness-Aware Reinforcement Learning with Verifiable Rewards for Reasoning Capacity in LLMs](https://arxiv.org/abs/2610.29281)

**机构、作者与来源**

- **机构：UNIST（蔚山科学技术院）**
- 作者：Yeonbum Kim, Hyun Kyu Lee, Sung Whan Yoon
- 来源：arXiv:2610.29281v1
- 场景：LLM 数学与代码推理的 RLVR 后训练

**核心方法**

- 以 GRPO 的组相对优势为基线，将 RLVR 局部损失 Lq 的 SAM 目标 min_θ E_q max_{||ε||≤ρ} Lq(θ+ε) 加入更新：先沿梯度方向构造扰动 ε*，再在扰动点计算下降梯度更新策略参数
- 为适配 LLM 后训练，仅每 n 步执行一次 SAM 上升-下降

**关键结果**

- Qwen2.5-Math-1.5B（G=6，3 seeds）：Flat-GRPO/Flat-DAPO/Flat-CISPO 平均 Pass@256 为 67.3/68.6/68.5，较对应 GRPO/DAPO/CISPO 的 64.8/65.2/65.5 分别提升 +2.5/+3.4/+3.0，平均 Pass@1 基本持平
- Qwen2.5-Math-1.5B 全基准平均：GRPO 遗忘 6.3% 基座可解题、仅新解 5.4%

**为什么值得读**

- 在优化几何层面处理 RLVR 分布锐化，可跨 GRPO/DAPO/CISPO 迁移且训练开销接近基线，值得对照现有后训练流程评估低成本改造

**证据边界**

- 仅验证数学推理（MATH 训练，MATH500/AMC23/AIME24/25/26）与 MBPP 代码生成，未覆盖开放域、Agent、长上下文或工业业务任务
- 理论结论依赖累计平坦修正主导残差（ΣαρC_t ≥ Σr_t）等假设，高阶 Taylor 残差与神经切核近似下的项被忽略，实际训练是否满足未给出充分保证

### [Right On Q: Recovering Reasoning under Quantization via Self-Generated Trajectories](https://arxiv.org/abs/2610.29378)

**机构、作者与来源**

- **机构：University of Michigan, Ann Arbor；University of California, Santa Barbara；Meta AI**
- 作者：Boyuan Zheng、Jing Xiong、Chenwei Wu、Hui Shen、Zesen Zhao、Hei Ting Una Chan、Xueshen Liu、Zhen Zhang、Liyue Shen、Zechun Liu、Z. Morley Mao
- 来源：arXiv:2610.29378v1
- 场景：低比特 LLM 推理能力恢复（Qwen3-1.7B/4B/8B 的 2/3-bit 量化）

**核心方法**

- 量化初始化采用均匀非对称权重量化（group size 128，BF16 激活），按 EfficientQAT Block-AP 对 4,096 个 2,048-token 窗口逐 block 校准，得到 on-policy 训练的起始 checkpoint
- OnQ 让学生用自身量化前向采样回答，冻结全精度 teacher 在同一学生前缀上给出 next-token 分布并做 on-policy 蒸馏，以缩小训练前缀与推理轨迹的偏差

**关键结果**

- 在 Qwen3-1.7B/4B/8B 的 W2/W3 六个设置中，OnQ 均取得九基准最高平均分，并在 54 个基准-设置组合中赢下 48 个（表1）
- Qwen3-8B W2 九基准平均 70.68%，较最强基线 BitDistiller 的 60.42% 高 10.26 个百分点

**为什么值得读**

- on-policy 前缀蒸馏与候选级 Dynamic KL 提供低比特推理恢复的可移植配方，是评估 2-bit 部署可行性的直接技术参考

**证据边界**

- 仅为 arXiv v1 预印本，未见同行评审或独立复现
- 收益限于 Qwen3-1.7B/4B/8B、W2/W3、九个基准和给定训练预算

### [A Mechanistic Study of Automated Failure Attribution in LLM-based Agentic Systems](https://arxiv.org/abs/2610.28811)

**机构、作者与来源**

- **机构：University of Virginia、Nokia**
- 作者：Wendy Zheng、Liang Wu、Yinhan He、Mayank Darbari、Jundong Li、Liangjie Hong
- 来源：arXiv:2610.28811v1
- 场景：LLM 多智能体系统失败归因，在交互轨迹中定位最早导致失败的步骤

**核心方法**

- 冻结模型对每条轨迹做一次前向，按步骤末 token 抽取每层 post-attention 与 post-MLP 残差隐藏态，为每个位置单独训练带类别权重的 L2 逻辑回归探针，评估时对步骤打分取最高
- grafting 先在训练集用注意力落在真实错误步骤的比例选 locator heads（最多5个，排除末层），再用直接 logit 归因选指向模型自身输出步骤 token 的 writer heads（最多5个，排除首层）

**关键结果**

- 在 Who&When 的 Algo. 子集，Qwen 0.5B/1.5B/7B 的 probing step accuracy 分别为 36.51%/44.44%/47.62%，均高于最强 prompting 基线 23.81%/15.87%/14.29%
- grafting 在 Algo. 子集 Qwen 1.5B 达 33.33% step accuracy，高于 Step-by-Step 的 15.87%

**为什么值得读**

- 把 Agent 失败归因从提示工程推进到表征层探针与推理时头级嫁接，为多智能体可靠性和自动调试提供新的诊断路径

**证据边界**

- 仅在 Who&When 基准与 Qwen2.5、Llama3.2、Gemma3 七个开放权重模型上验证，未覆盖闭源模型的 probing/grafting 结果与更多 Agent 任务
- locator/writer head 选择依赖带真实失败步骤的训练集
