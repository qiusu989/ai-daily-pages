# AI 与算力重点简报｜2026-09-23

## ① 今日最重要的 3 件事

### 1. [Towards Full Pipeline FP8 Reinforcement Learning for LLMs](https://arxiv.org/abs/2609.22870)

首次把全流水线 FP8 RL 的训练中期熵激增归因于重要性比值噪声导致负优势 token 下界过度裁剪，并给出无需改算法的边界校准修复，改变低精度 RL 仅适合推理侧的判断，同时报告 tensorwise 最高约 1.5×、blockwise 10%–20% 训练吞吐提升。

证据：arXiv 预印本、已核验 PDF 正文，含 GRPO/DAPO 对比结果；无同行评审、无线上 A/B 或生产部署证据，评测仅限数学与代码推理，吞吐基准排除周期性 BF16 参考前向开销。

### 2. [FLARE: A Full-Lifecycle Dense Supervision Paradigm for Long-Horizon Coding Agents via Generative Reward Model](https://arxiv.org/abs/2609.23808)

把长程编码 Agent 的稀疏 Pass/Fail 转成可复用步级诊断信号，同一信号同时服务推理时 critical 步拦截重生成、SFT 数据筛选与 RL dense reward，改变 Coding Agent 瓶颈主要在模型能力而非过程监督与算力折中的判断。

证据：arXiv 预印本、已核验 PDF 正文，报告 F2P 修复率与 token 削减等多组条件协议下结果；无线上 A/B，token 统计不含输入与 GRM 推理开销，依赖预定义错误 taxonomy 并有约 6% severity 错标。

### 3. [Better prompt caching for GPT-6](https://openai.com/index/better-prompt-caching-for-gpt-6)

官方在推理侧引入显式断点与缓存诊断控制，直接改变长上下文与 Agent harness 的 token 成本与首 token 延迟变量判断，属产品接口层面的可行动变化。

证据：仅 OpenAI 官方博客摘要级描述，未公布命中率、延迟降幅或价格变化数据，无机制细节与第三方独立复现，效能主张不可量化核验。


## ② 最新 LLM 论文

### [Towards Full Pipeline FP8 Reinforcement Learning for LLMs](https://arxiv.org/abs/2609.22870)｜近两日补录

**机构、作者与来源**

- **机构：University of Wisconsin–Madison 与 ByteDance Seed（第一作者为实习期间完成）**
- 作者：Fanchao Chen, Ziheng Jiang, Ziyun Wei, Zheng Zhong, Du Li, Chi Zhang, Haibin Lin, Shivaram Venkataraman
- 来源：arXiv:2609.22870v1（cs.LG, cs.AI）
- 场景：大模型全流水线 FP8 强化学习（GRPO/DAPO，数学与代码推理），非搜广推场景

**核心方法**

- 指认失效模式：全流水线 FP8 训练中单 token 概率量化误差虽小，但重要性比值放大 1.7×–2.9×，使负优势 token 在 1−ε 下界被过度裁剪、梯度被错误置零，垃圾输出未被惩罚并累积，引发训练中期熵激增
- 提出 Calibrated Clipping：用 BF16 影子前向得到负优势 token 的目标裁剪分位 α_low = F_BF16,−(1−ε)，反解 FP8 分布下界 L

**关键结果**

- Qwen3-8B-Base GRPO：blockwise FP8 加 Calibrated Clipping 平均分 58.6，高于 BF16 基线 57.6
- tensorwise/rowwise 分别从 46.1、47.0 回升至 55.9、56.5

**为什么值得读**

- 低精度训练/RL 是后训练效率的核心变量，该文给出可解释的失效机制与低开销校准路径，并附吞吐与精度对照，值得作为 FP8 RL 工程改造的首选读本

**证据边界**

- 仅有 arXiv 预印本
- 无同行评审
- 也无任何线上 A/B 或生产部署证据
- 评测局限于数学与代码推理基准（AIME/AMC/MATH/Gaokao/Minerva/Olympiad/TACO/APPS 等）
- 未覆盖其他任务类型与更大模型规模

### [FLARE: A Full-Lifecycle Dense Supervision Paradigm for Long-Horizon Coding Agents via Generative Reward Model](https://arxiv.org/abs/2609.23808)｜近两日补录

**机构、作者与来源**

- **机构：首页标注 Independent Researcher、北京大学、南京大学、北京邮电大学（第一作者邮箱为 163.com，不能据此推断机构）**
- 作者：Jingxuan Xu、Gang Wu、Yanan Wu、Yutao Mou 等16人
- 来源：arXiv:2609.23808v1（cs.CL/cs.AI）
- 场景：长程 SWE 编码 Agent 的步级诊断、推理时干预与 SFT/RL 对齐训练

**核心方法**

- RADAR 离线诊断先做轨迹语义压缩（intent/action/observation），再双轨蒸馏：失败轨迹用反向因果链回溯定位 root cause 并标注 risk level、error type、diagnosis
- 成功轨迹做主动错误注入，按断点 rollout 恢复率判定 critical/trivial

**关键结果**

- RQ1 条件协议下 GRM-DBKR N=1 的 F2P 修复率 14.10%，高于 GR N=1 的 7.80% 与 GR N=5 的 13.72%
- base agent 输出 token 12,517，对比 GR N=5 的 66,711 约 5.3 倍降幅

**为什么值得读**

- 过程级监督、生成式 reward model 与 dense reward 构造在同一框架内闭环，对 Agentic RL 与 LLM judge 评测设计有直接借鉴价值，且给出跨 scaffold 的即插即用干预范式

**证据边界**

- 效果受基座 Agent 能力上界约束：GRM 只能定位过程性错误，遇到需要深层重构或严重 goal drift 的失败时，指出错误步不足以完成修复
- token/算力统计只覆盖 base agent 输出
- 不含 agent 输入、GRM 推理、环境执行与延迟
- 也不含离线标注与 GRM 训练的一次性成本
