# AI 与算力重点简报｜2026-11-11

## ① 今日最重要的 3 件事

### 1. [Staying in the Sweet Spot: Boost Reasoning Evolution via Responsive Rollout Difficulty Manipulation](https://arxiv.org/abs/2509.06923)

把 RLVR 的难度课程从经验调参变成可检验的目标：rollout 准确率在 50% 附近时单步损失下降上界最大，并用 3 参数 IRT 曲线在线反解 hint 长度，使实例级难度调控可嵌入现有 GRPO 循环且解析开销仅约 1.0055 倍。

证据：arXiv 预印本 PDF 已核验，机构含北大、百度等；结果为作者自测基准与消融，无独立复现或线上 A/B，额外采样成本仅有解析 FLOPs 估算。

### 2. [Recursive Semantic Divergence for LLM Agent Consistency](https://arxiv.org/abs/2610.33012)

将 Agent 跨次运行一致性从二值 pass^k 改为轨迹级语义分歧的折扣累积，并用 NLI 距离替代奖励差，可直接作为 GRPO 奖励或部署前单次前向监控信号；同时暴露一致性奖励可能放大稳定失败的边界。

证据：SAP SE 论文，PDF 已核验；τ2-bench 上 3B 降 CV 约 30%，但 7B 反升 14%，且每基准仅 8 样本×8 次、NLI 与 DeBERTa 一致率仅 41.6%，无生产部署验证。

### 3. [AERO: Adaptive Ensemble-Disagreement Routing for Oracle Feedback in Sample-Efficient Online RLHF](https://arxiv.org/abs/2611.10750)

把偏好标注预算从统一分配改为按上下文集成分歧路由，Otsu 自适应阈值替代固定查询比例，随机路由消融支持收益来自定向路由而非单纯减量；对在线对齐与奖励建模的标注成本判断有直接迁移价值。

证据：NeurIPS 2026 论文，PDF 已核验，RMIT 机构；oracle 为确定性奖励模型而非真人反馈，仅 DPO 实例化，8B 单 seed 且用 LoRA，AERO 计算开销高于 Online DPO。


## ② 最新 LLM 论文 / 技术报告

### [Staying in the Sweet Spot: Boost Reasoning Evolution via Responsive Rollout Difficulty Manipulation](https://arxiv.org/abs/2509.06923)

**机构、作者与来源**

- **机构：北京大学、百度、多伦多大学、中科院自动化所、中科院空天信息创新研究院、中国人民大学**
- 作者：Ziheng Li、Zexu Sun、Jinman Zhao、Erxue Min、Yongcheng Zeng、Hui Wu、Hengyi Cai、Shuaiqiang Wang、Dawei Yin、Xu Chen、Zhi-Hong Deng
- 来源：arXiv:2509.06923v2
- 场景：LLM 数学与通用推理的 RLVR 训练难度调控

**核心方法**

- 理论分析：设 θref=θold，KL 项做二阶泰勒展开并以 Fisher 信息阵近似，推出单步参数更新的损失下降上界为 (1/2β)E_x[a(x)(1-a(x))]（a 为 rollout 准确率），该上界在 a≈50% 处取得最大
- 多轮采样：每步把 rollout 拆成 m=4 轮、每轮 n=8 条

**关键结果**

- Qwen2.5-1.5B 上 6 个数学基准平均 34.2%，相对 GRPO 24.2% 提升 10.0 分、相对 SFT 25.8% 提升 8.4 分、相对最强基线 UFT 30.4% 提升 3.8 分（同一数据、模板与训练步数）
- Qwen2.5-Math-7B 上数学平均 59.0%、通用域平均 58.5%，数学平均超过最强基线 Prefix-RFT（56.3%）约 3 分，通用域超过 UFT（57.3%）1.2 分

**为什么值得读**

- 给出“成功率 50% 最优”的解析上界而非经验课程
- 并用 hint 长度回归把每样本难度拉到目标区间

**证据边界**

- 方法依赖把参考解分解为前缀 hint：推理链很短或解答高度压缩时 hint 粒度变粗、难度控制精度下降
- 当模型在目标任务上已足够强时 hint 机制很少触发，退化为标准 GRPO，收益有限（作者自述）

### [Recursive Semantic Divergence for LLM Agent Consistency](https://arxiv.org/abs/2610.33012)

**机构、作者与来源**

- **机构：SAP SE**
- 作者：Harshavardhan Abichandani、Penny Chong、Atin Ghosh、Daniel Dahlmeier
- 来源：arXiv:2610.33012v2
- 场景：LLM 工具调用 Agent 多轮执行的一致性度量与微调

**核心方法**

- RSD 将 LLM Agent 建模为以交互历史 h_t 为信念状态的 MDP，用 NLI 距离替代奖励差：双向蕴含记 0、矛盾记 1、中性记 0.5，并构造折扣递归一致性目标 U(s,s)
- 采用 MICo 参数化：状态经冻结的 Cohere embed-v4-0 编码，再由 3 层 MLP 映射到 256 维，距离由状态范数项和角度项组成

**关键结果**

- τ2-bench Qwen-2.5-3B：RSD 将 AUC CV 从 1.32 降至 0.91（−30.9%）、progress CV 从 1.25 降至 0.92（−26.1%），低于 token entropy 的 +3.9% 和 semantic entropy 的 −15.9%
- ToolSandbox Qwen-2.5-3B：AUC CV 从 0.90 降至 0.44（−50.5%），progress CV 从 0.86 降至 0.43（−49.3%），pass@1 从 14.1% 升至 18.8%

**为什么值得读**

- 把双模拟度量扩展到交互历史状态，用 NLI 语义分歧代替奖励差构造递归一致性目标，推理时一次前向即可输出每轮一致性分数
- 适合评估 Agent 可靠性奖励设计与早停监控，需注意其在弱模型上可能强化稳定失败

**证据边界**

- 一致性不等于正确性：τ2-bench 7B 出现 CV 上升，论文归因于某样本平均进度从 0.375 降至 0.125，RSD 可能强化稳定失败策略
- NLI 判定依赖 gpt-4.1，且与 DeBERTa-v3-large 的成对一致率仅 41.6%

### [AERO: Adaptive Ensemble-Disagreement Routing for Oracle Feedback in Sample-Efficient Online RLHF](https://arxiv.org/abs/2611.10750)

**机构、作者与来源**

- **机构：RMIT University**
- 作者：Shrey Singhal、Nannan Huang、Haytham M. Fayek
- 来源：arXiv:2611.10750v1（NeurIPS 2026）
- 场景：通用 LLM 在线 RLHF 偏好对齐（非搜广推）

**核心方法**

- 原文方法：每轮从当前策略采样 N=20 个候选，对每个上下文用 20 个 ERM 头的最高奖励投票计算 vote entropy，并用 Otsu 法在批次内按组间方差最大化选阈值，将上下文分为高分歧送 oracle 与低分歧用 ERM 合成标签
- 原文方法：Oracle 分支用 Thompson sampling 选锚点、按 ERM 头间奖励方差选挑战者

**关键结果**

- 作者报告：Llama-3.2-1B 与 Qwen2.5-1.5B 在 UltraFeedback 上的匹配 oracle 预算胜率曲线中，AERO 高于 Online DPO 和 COPO，并对 SEA 有较小但一致优势
- 1B/1.5B 为三个 seed

**为什么值得读**

- 把主动学习的投票熵用于在线 RLHF 上下文级路由，Otsu 阈值使查询比例随批次分布自适应，低分歧样本用集成均值合成标签且不回灌 ERM
- 对降低偏好标注成本的对齐流水线有直接参考价值

**证据边界**

- 证据边界：偏好 oracle 为确定性的 Skywork-Reward-Llama-3.1-8B 奖励模型，未使用真实人类或噪声反馈，作者也将其列为局限
- 证据边界：实验仅以 DPO 实例化，未验证 IPO、SimPO 等其他 DAP 目标
