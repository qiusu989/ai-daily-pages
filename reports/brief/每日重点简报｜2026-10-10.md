# AI 与算力重点简报｜2026-10-10

## ① 今日最重要的 3 件事

### 1. [SpatialOPSD: Self-Distilling Spatial Intelligence from Verified Coding Agent Traces](https://arxiv.org/abs/2610.11366)

改变了对 agent 轨迹价值的判断：已验证工具型 agent 轨迹可作为 privileged information 蒸馏进免工具单模型，且把 privileged 泄漏（照抄轨迹、自我重复）当作可用 n-gram 掩码加 unlikelihood 抑制的工程问题，影响 agent 经验回灌与 harness 内化设计。

证据：arXiv 预印本且已核验 PDF 正文，Alibaba Group 署名；MindCube-Tiny/ViewSpatial 与四个 OOD 基准均为离线精度，无同行评审、无线上 A/B 或生产部署；论文自述存在精度与泄漏抑制的权衡（Mask 53.0% 高于 Mask+UL 51.9%）。

### 2. [StoreBench: A Live-Commerce Environment for Evaluating and Training Autonomous Operator Agents](https://arxiv.org/abs/2610.10942)

改变了对长程 agent 评测与 RL 后训练的判断：提供奖励可验证、抗 reward hacking 的环境，并给出短任务 RL 向 held-out 任务迁移的证据，同时把 harness 与工具调用风格暴露为常被忽略的评测变量；模型与人类专家的对比显示当前 agent 运营能力仍有明显上限。

证据：arXiv 预印本且已核验 PDF 正文，AfterQuery 署名；模拟引擎与完整评测套件被刻意扣留，无法外部复跑或针对其训练；后训练仅一个基座一次运行，全年与短程任务 harness 与时程同时不同，论文自认无法隔离 harness 影响。

### 3. [VICO: Visual Environments Co-Evolving for Vision-Language Model Reasoning](https://arxiv.org/abs/2610.10782)

改变了对 RLVR 环境处理的判断：静态环境会让任务漂移出学习边界导致奖励方差与学习信号坍缩，把图像侧可验证环境当作与 actor 共同学习的组件、用 actor 通过率驱动难度校准，是无额外人工标注的自适应后训练路径，标注效率提升值得迁移到其他可验证任务。

证据：arXiv 预印本且已核验 PDF 正文，多机构（Virginia Tech、NVIDIA 等）署名；依赖可验证的图像侧结构（场景图、图表 CSV、掩码），无此类结构的视觉域未验证；未给出与基线的算力对齐比较，全部为论文内报告数字，无线上 A/B。


## ② 最新 LLM 论文 / 技术报告

### [SpatialOPSD: Self-Distilling Spatial Intelligence from Verified Coding Agent Traces](https://arxiv.org/abs/2610.11366)

**机构、作者与来源**

- **机构：Alibaba Group（首页 affiliation 明确列出）**
- 作者：Rongxue Li、Meng Yang、Yiru Mao、Yongliang Tao、Lulu Hu、Bin Yang、Zhao Xu、Weihua Luo、Bowen Xu
- 来源：arXiv:2610.11366v1（cs.LG，预印本）
- 场景：多模态大模型空间推理，把工具型空间 coding agent 轨迹内化为免工具模型，非搜广推任务

**核心方法**

- SpatialOPSD 采用 on-policy self-distillation：教师与学生同源同初始化，教师额外条件化于经验证 agent 轨迹构造的 privileged information I，学生只见原始输入 x，rollout 用 stop-gradient 采样
- 提出 Repetition-Aware Distillation：用 token n-gram 匹配同时检测自我重复与 privileged 内容照抄，对被标记 span 屏蔽蒸馏损失（mask）并加 unlikelihood 惩罚，默认 n=4、Lmin=32、λrep=0.1

**关键结果**

- MindCube-Tiny 与 ViewSpatial 平均从 Qwen3.5-9B CoT 的 45.9% 提升到 51.9%，高于 SFT 47.6% 与 GRPO 48.2%
- 免工具单次前向达到其工具教师 SpatialClaw（57.3%）的约 91%（51.9 vs 57.3）

**为什么值得读**

- 把工具型 agent 轨迹内化为单模型能力的 on-policy self-distillation 范式
- 并针对 privileged information 照抄与自我重复给出可复用的重复感知掩码机制，直接关系到 agent 训练与 harness 内化的下一步做法

**证据边界**

- 仅 arXiv 预印本，无同行评审、无线上 A/B 或生产部署证据，数字均为离线 benchmark 精度
- Repetition-Aware Distillation 存在精度与泄漏权衡：仅用 Mask 时平均 53.0% 高于 Mask+UL 的 51.9%，换取 PI 泄漏从 73.6% 降至 9.1%

### [StoreBench: A Live-Commerce Environment for Evaluating and Training Autonomous Operator Agents](https://arxiv.org/abs/2610.10942)

**机构、作者与来源**

- **机构：AfterQuery**
- 作者：Daksh Raghuvanshi、Ved Vedere、Yifan Wang
- 来源：arXiv:2610.10942v1
- 场景：LLM agent 在模拟服装电商存量店中进行长程运营决策与 RL 后训练

**核心方法**

- agent 仅通过 29 个 MCP 工具运营虚构服装店 Ostrelle，跑在生产级开源电商后端 Medusa v2 上，单集 30 至 365 模拟天，含 18 个月历史、40 家供应商市场与隐藏需求
- 世界时间以 operation 计量，只有 agent 动作或 end_window 才推进时钟，因此模拟时间与推理延迟无关，窗口预算不滚存

**关键结果**

- 短程 11 任务×3 seed×3 次尝试上，最优模型 DeepSeek-V4-Pro 平均 composite 0.700、通过 49% 的 task-seed 单元，低于 smart-triage 启发式的 0.764 与 97%
- 11 名人类专家经同一工具与预算平均 0.708，高于所有模型

**为什么值得读**

- 给出长程 agent 可验证奖励环境与 anti-reward-hacking 硬化的完整设计
- 并用 GRPO+LoRA 展示短任务训练向 held-out 任务的迁移，是构建 agentic RL 训练与评测沙盒时值得逐节读的方法学材料

**证据边界**

- 模拟引擎与完整评测套件被刻意扣留，外部无法运行或针对其训练，只能复现已发布轨迹的评分
- 后训练仅一个基座模型、一次人工调参的运行，且用 held-out 任务而非 held-out 种子，不构成可复用的训练配方

### [VICO: Visual Environments Co-Evolving for Vision-Language Model Reasoning](https://arxiv.org/abs/2610.10782)

**机构、作者与来源**

- **机构：Virginia Tech、NVIDIA、UChicago、Georgia Tech、Abaka AI、UC Berkeley、UGA、Cisco、WashU**
- 作者：Meng Lu、Ligeng Zhu、Olivia Xiao 等
- 来源：arXiv:2610.10782v1
- 场景：视觉语言模型视觉推理的 RLVR 后训练，非推荐/广告任务

**核心方法**

- VICO 联合训练 actor（Qwen3-VL-8B 等）与 Environment-as-Rewriter：后者编辑可验证的图像侧结构（CLEVR 场景图、ChartQA 底层 CSV 表、ZwZ 保护区域掩码）并重新渲染，生成标签有效的训练样本
- 环境难度校准奖励以 actor 的 K=8 次 rollout 经验通过率 p̂ 为共享信号，Rrewriter=exp(−β(p̂−α)²)，α=0.5、β=4.0

**关键结果**

- VICO-8B（Chart）在 8 个域外基准平均 64.9%，比基座 Qwen3-VL-8B 提升 +5.0%
- 其域内 ChartQA 从 76.9% 提升到 89.1%（+12.2%，第 4 轮峰值）

**为什么值得读**

- 把 RLVR 环境从静态增广变成与 actor 共演化的可学习组件，用 actor 通过率实现难度自适应，思路可迁移到任何具备可验证结构的数据域，对后训练数据合成路线有方法层面参考价值

**证据边界**

- 依赖可验证的图像侧结构（场景图、图表 CSV、目标区域掩码），无此类结构或可靠区域标注的视觉域是否能扩展未验证
- 每轮需多 rollout 估计通过率并同时更新 actor 与 EnvRewriter，计算成本高于一次性静态增广，论文未给出与基线的算力对齐比较
