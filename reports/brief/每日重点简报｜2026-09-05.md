## ③ AI 模型 / Agent / Coding

### P1｜[Anthropic 更新｜发布平台更新，2026年9月3日，ant CLI 1.30.0 新增 ant apply 命令](https://platform.claude.com/docs/en/release-notes/overview#event=September%203%2C%202026)

**判断影响**

这是 Anthropic 官方推出的基础设施即代码工具，将 agent 平台资源管理推向声明式配置，是 Agent 开发工具链的重要能力扩展。

**关键变化**

Anthropic 官方发布平台更新，2026年9月3日，ant CLI 1.30.0 新增 ant apply 命令；ant apply 通过仓库文件创建和更新 agents、environments、skills、memory stores 和 deployments，需审核输出计划；ant apply 写入 claude-lock.json 锁文件，后续运行可基于同一资源更新而非重复创建。

**数据与证据**

支持将 agents、environments、skills、memory stores、deployments 等资源以代码形式管理，覆盖开发到部署全流程；通过 claude-lock.json 锁文件实现声明式资源管理，可在本机和 CI 中复用同一套资源配置；具体功能细节和性能数据未在发布说明中列出；官方发布。摘要只提供功能描述，无性能、可靠性数据或与现有方法的对比；发布内容仅覆盖 CLI 工具新命令，未提及模型能力或 API 变化；对已使用其他基础设施即代码方案的用户迁移成本未说明。

**关键变化**

Tom's Hardware 于2026-09-04发布新闻分析，报道AI token使用量一年增长25倍，近一个月翻倍，低成本中端模型主导使用量增长；据OpenRouter数据，过去一个月最常用模型为OpenAI GPT 5.6 Luna，约12万亿token，单任务成本$0.05；中国Z-Ai的GLM 5.3 Flash达11.4万亿token，环比增长超1000%；文中引用Artificial Analysis数据：Anthropic Claude Fable 5.1在智能指数得分66，每任务成本$3.6…

**数据与证据**

OpenRouter工程师图表显示过去一年付费token使用量增长25倍，过去一个月翻倍；高成本前沿模型使用量低，如Fable 5月输出token仅数十亿；而低成本中端模型如GPT 5.6 Luna和GLM 5.3 Flash主导使用；中端模型可提供旗舰约90%的智能得分，成本仅为旗舰的约1/6，例如Gemini 3.8 Flash得分59 vs Fable 5.1的66，成本$0.58 vs $3.69；媒体或社区报道。数据来源为第三方媒体和社区观测，未经官方验证；部分价格和用量数据可能随时间变化，需核实原始来源；文章包含观点分析，非严格技术报告。
